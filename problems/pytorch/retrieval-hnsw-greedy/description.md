# 检索：HNSW 贪心图层搜索

## 题目描述

HNSW（Hierarchical Navigable Small World，Malkov & Yashunin, TPAMI 2018 / arXiv:1603.09320）是当前最主流的图索引 ANN 结构（Faiss `IndexHNSW`、hnswlib、各类向量数据库）。它在多层可导航小世界图上搜索：**上层稀疏、用于快速定位大致区域；下层稠密、用于精确近邻**。层间与层内的基本动作都是同一个 **贪心搜索（greedy search / `SEARCHLAYER` 取 \(ef=1\)）**：从入口点出发，反复跳到「当前点的邻居中离查询最近、且比当前点更近」的那一个，直到没有更近的邻居（抵达局部最优）为止。本题实现这一核心子过程——给定**单层图**做贪心搜索。

## 规则

实现 `solve(points, adj, entry, query)`。输入 `points`（float32，\((n, D)\)）为节点坐标；`adj`（int64，\((n, \text{maxdeg})\)）为每个节点的邻居表，`-1` 为占位（表示该槽无邻居）；`entry`（int）为入口节点下标；`query`（float32，\((D,)\)）为查询点。距离用**平方欧氏**。搜索：`cur=entry`；每步在 `cur` 的有效邻居里找**离 query 最近**者，若它比 `cur` 更近则 `cur` 移过去（一步只走一个点），否则停止；返回停止时的节点下标。返回**0 维 int64** 张量。邻居等距时取下标最小者。

## 示例

一维链 \(0-1-2-3-4\)，`points=[[0],[1],[2],[3],[4]]`，`query=[3.7]`，`entry=0`：

```
adj = [[1,-1],[0,2],[1,3],[2,4],[3,-1]]
距 query 平方差: node0=13.69 node1=7.29 node2=2.89 node3=0.49 node4=0.09
0 ->(邻居1更近)-> 1 ->(邻居2更近)-> 2 ->(邻居3更近)-> 3 ->(邻居4更近)-> 4
4 的邻居 {3}(0.49) 不比 4(0.09) 更近 -> 停在 4
out = 4   （0 维 int64）
```

## 约束

- CPU float32；距离用平方欧氏（单调、不改 argmin）。
- **严格更近才移动**（邻居距离 \(<\) 当前才走），保证无环、必然收敛。
- 一步只沿一条边跳到「更近邻居中最近者」（\(ef=1\) 的贪心），不是批量 \(ef\) 候选队列。
- 邻居等距取节点下标最小者；`-1` 槽跳过。
