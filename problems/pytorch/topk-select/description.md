# Top-K 选择（Top-K Selection）

## 题目描述

Top-K 沿某轴挑出最大的 `k` 个值及其原始索引，并按从大到小排序。它是 beam search、
专家路由（MoE 里每个 token 选 top-k 专家）、推荐检索召回、nucleus/top-k 采样等
的共同原语。请**不用 `torch.topk`**，用「重复取最大再屏蔽」的选择法实现。

## 规则

- 实现 `solve(x, k)`，沿**最后一维**取 top-k，返回 `(values, indices)` 元组。
- `values` 形状 `(..., k)` 且**降序**排列；`indices` 为其在最后一维中的原始位置。
- 每轮取当前最大值，记录值与索引，然后把该位置移出候选（置为 `-inf`），重复 `k` 次。
- 结果须与 `torch.topk(x, k, dim=-1, sorted=True)` 在测试数据（无重复值）下一致。

## 示例

```
输入：x = [[3, 1, 7, 2, 9],
          [5, 8, 0, 6, 4]]，k = 3
输出：values  = [[9, 7, 3],
                 [8, 6, 5]]
     indices = [[4, 2, 0],
                [1, 3, 0]]
```

## 约束

- float32 输入；`1 <= k <= 最后一维长度`
- 测试用随机连续值（无并列），因此 top-k 的索引唯一确定
