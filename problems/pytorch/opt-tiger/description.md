# 优化器：Tiger 动量符号更新（Sign of Momentum）

## 题目描述

自适应优化器要维护二阶矩、显存翻倍。sign 型方法（如 Lion、SignSGD）另辟蹊径：**直接用更新方向的符号**把每步幅度归一到 \(1\)，只靠动量平滑方向。Tiger 是这类里极简的一支——只保留**一份动量缓冲**，取动量的符号作为更新方向，配合解耦权重衰减。它常作为 Muon 家族中对非 2D 参数（偏置、归一化层）的“伴随优化器”出现。

本题要求你**继承 `torch.optim.Optimizer`** 实现 Tiger，`step()` 逐参数就地更新。评测喂入固定梯度序列并比对最终参数。

## 规则

- 工厂函数 `solve(params, lr=1e-3, beta=0.965, weight_decay=0.01)`，返回 `torch.optim.Optimizer` 子类实例，`step()` 就地更新 `params`。
- 每个参数只维护一份动量 \(m\)，初值 \(0\)。第 \(t\) 步、梯度 \(g\)：
  1. 解耦权重衰减（wd≠0，先做）：\(p \leftarrow p\,(1-lr\cdot\text{wd})\)
  2. 动量：\(m \leftarrow \beta\, m + (1-\beta)\, g\)
  3. 符号更新：\(p \leftarrow p - lr\cdot \operatorname{sign}(m)\)
- **无二阶矩、无偏差修正**：更新幅度恒为 \(lr\)（因为取了符号），动量初值为 0。`grad is None` 参数整体跳过。全程 float32，禁止调用现成优化器。

## 示例

单个参数 \(p=[1.0,\,-2.0,\,0.5]\)，`lr=0.01`、`beta=0.965`、`weight_decay=0.01`，喂入三步梯度：

```
g₁ = [ 0.10, -0.20,  0.30]
g₂ = [-0.40,  0.05,  0.20]
g₃ = [ 0.15, -0.10, -0.25]
三步后 p ≈ [1.009701, -1.969403, 0.469853]
```

## 约束

- dtype float32、就地更新；支持 1D 与多维混合
- 须与参考实现逐步一致（对拍口径见 notes.md）
