# 参考思路：前缀配分函数与逆向采样

## 为什么不是局部 softmax

当前位置能以某词条结尾，不代表所有词条应按自身分数直接归一化。该词条之前可能有不同数量、不同总权重的切分，甚至根本没有可达切分。把以词条 $i$ 结尾的完整前缀路径权重相加，得到：

$$
W_t(i)=\exp(L[s]+\alpha\,\mathrm{log\_scores}[i])
$$

因此先算所有前缀的 log partition，再按 $W_t(i)/\exp(L[t])$ 从右向左选择词条。之前已经选择的后缀对候选路径贡献相同的乘法因子，条件化时抵消，所以可以继续使用当前前缀的分布。

沿所选路径相乘，配分函数项逐步相消：

$$
\prod_j \exp\bigl(L[s_j]+\alpha\,\mathrm{log\_scores}[i_j]-L[t_j]\bigr)
=\exp\bigl(\alpha S(\pi)-L[n]\bigr)
$$

这正是全路径后验，而不是最佳路径选择或局部贪心。比如 `aaa`、词表 `["a", "aa"]` 在 $\alpha=0$ 时共有三条路径，末端 `a` 的概率是 $2/3$ 而不是 $1/2$。

## 实现与数值细节

- 先验证词表，即使文本为空也不能跳过重复项或空项检查。
- `L[0]=0`，不可达前缀为负无穷。逐个字符末端枚举 vocab ID，保存匹配且前缀可达的候选。
- 使用减最大值的 log-sum-exp，以 `math.fsum` 累加指数项和最终路径分数。合法分数可使原始权重下溢，例如长度 12、单字符分数 -100、alpha=4 的路径对数权重为 -4800。
- CDF 也在对数域累积：将已有 `log_cumulative` 与下一个条件对数概率作 LSE，严格比较 `log_cumulative > log(u)`；`u=0` 时令 `log(u)=-inf`。这样正概率即使小于浮点可表示的最小正数，也不会在 `u=0` 时被误当成零。
- 例如 `text="ab"`、词表 `["b","a","ab"]`、分数 `[-100,-100,0]`、alpha=4：末端 `b` 概率约为 $\exp(-800)>0$，`u=0` 必须选择它，路径为 `[1,0]`，不能选整词 `[2]`。
- 每步按 vocab ID 升序比较，严格大于而非大于等于；单候选也消费一个 uniform。最后候选仅吸收累计尾误差，返回 ID 最后反转。
- `log_probability` 是完整路径的归一化对数概率，不是原始分数或某一步的局部概率。

设文本码点数为 $n$、词表大小为 $V$、最长词条长度为 $K$。计入词表验证与 Python 子串比较，时间为 $O(VK+nV(K+1)+n)$，空间为 $O(V+nV+n)$。逆向采样至多 $n$ 步，每步最多 $V$ 个候选。

## 独立 oracle 与测试

oracle 从左向右穷举完整切分，不做前缀 DP。唯一非空词条意味着每个边界子集至多对应一条路径，长度至多 12 时最多 $2^{11}=2048$ 条。使用标准库 `decimal` 的 80 位局部精度保存整路径指数权重，避免极小正概率在 oracle 中也下溢。

按已选后缀过滤完整路径，按本步结尾 token ID 聚合保留的原始权重，以高精度条件 CDF 选择并剥掉尾词条。它不使用参考解的前缀递推或对数 CDF，也不是一次整路径抽样。

共 16 个 `check_*`，覆盖空与非法输入、全路径均匀、分数影响、极负分数、`u=0` 与最小正 uniform 的极小概率、ID 次序、CDF 等号、强制步骤消费、Unicode、随机穷举、不可达前缀、最大路径数、输入不变性和禁用全局 RNG。submit selftest 与 eval 直跑均 16/16。题面样例已重新执行；新增极小概率样例返回 `([1,0], 0.0, -800.0, 2)`。

## 来源与复现范围

已在内存读取 [SentencePiece 0.2.2 源码发布包](https://files.pythonhosted.org/packages/cc/33/ea3cb3839607eb175da835244a798f797f478c5ddf0e8ecdf57ea85a4c70/sentencepiece-0.2.2.tar.gz)，核对 `sentencepiece/src/unigram_model.cc`：

- 217–233 行 `Lattice::ForwardAlgorithm(inv_theta)`：对前驱节点的分数与前向质量作 log-sum-exp。
- 540–570 行 `Lattice::Sample(inv_theta)`：从 EOS 反向按前缀质量乘词条权重的条件概率选择前驱，最终反转路径。`inv_theta` 对应本题的 `alpha`，即逆温度。

两者共享前向累积、后向条件采样的数学机制，但原生实现使用 `float`、内部节点顺序、C++ `discrete_distribution` 和内部 RNG，并涉及 BOS 抽样；本题使用 Python 浮点、对数 CDF、ID 排序和显式 uniforms。原生词图还包含未知词回退等规则，本题不包含训练、规范化、空白元符号、未知词或特殊词条。这里不承诺接口、舍入结果或种子级复现。
