# Medusa：多头候选树的 Typical Acceptance 验证

## 题目描述

**Medusa**（Cai et al., 2024, [arXiv:2401.10774](https://arxiv.org/abs/2401.10774)）不给模型配一个独立的 draft 模型，而是在骨干网络顶部加 $K$ 个解码头：第 $k$ 个头直接预测未来第 $k$ 个位置的若干候选 token。把这些头给出的 top 候选组合起来，就得到一棵**候选树**（多条不同长度的续写路径）。验证阶段用并行 tree-attention 一次性算出目标分布在每个位置的概率，再用 **typical acceptance** 逐层判定哪些候选能被接受，最终吐出被接受的最长路径 + 一个 bonus token。

本题聚焦**验证/选择**这一步：给定已经组装好的候选路径集合与目标分布，按 typical acceptance 规则选出被接受的最长路径并采样 bonus。

## 规则

入参：
- `cands`：候选路径列表 `list[list[int]]`，每条是从第一个投机 token 起的 token id 序列（Medusa 各头候选的组合，路径长度可不等）。
- `P`：形状 $(T, V)$ 的目标概率，`P[t]` 是**位置 $t$** 的分布（`t=0` 对应第一条投机 token 的验证位置）。
- `eps`：typical acceptance 阈值。
- `u_bonus`：$[0,1)$ 上的均匀数，用于从 `P[D]` 采样 bonus。

1. **候选树节点** = 所有候选路径的**全部前缀**（含各路径本身），去重；空前缀视为根。
2. **逐层接受**：某节点（一条长度 $d$ 的路径）在第 $i$ 层（$1\le i\le d$，token 为 $\text{path}[i-1]$）被接受当且仅当 $P[i-1][\text{path}[i-1]] \ge \text{eps}$。一条路径整体被接受，当且仅当它**每一层**都被接受（即父链全接受）。
3. **选路**：在所有被接受节点中取**深度最大**的一条；若并列，取 token 序列**字典序最小**者。记选中长度为 $D$（根被接受但无 token 时 $D=0$）。
4. **bonus**：从 `P[D]` 按 CDF 反查 `u_bonus`（取最小 $k$ 使 $\mathrm{cumsum}_k > u$，即 $\text{bonus}=\min\{k:\sum_{j\le k}P[D][j] > u\}$）。

返回 `torch.long` 一维张量：选中路径的 token，末尾追加 bonus。

- 与线性 draft 序列的逐 token 拒绝采样（[arXiv:2211.17192](https://arxiv.org/abs/2211.17192)）不同，Medusa 同时验证**一棵树**，靠父子链共同决定接受，能一次吐出更深的路径。
- typical acceptance 只看目标概率本身（$P\ge\varepsilon$），不需要 draft 分布 $Q$，也不做残差归一化重采样。

## 示例

```
cands = [[1,2], [1,3], [0], [1,2,0]],  eps = 0.2,  u_bonus = 0.4

P[0] = [0.5, 0.3, 0.1, 0.1]
P[1] = [0.1, 0.3, 0.4, 0.2]
P[2] = [0.3, 0.1, 0.2, 0.4]
P[3] = [0.1, 0.5, 0.3, 0.1]

被接受节点（父链每层 P>=0.2）：
  [0]      0.5>=0.2                    -> 接受(深度1)
  [1]      0.3>=0.2                    -> 接受(深度1)
  [1,2]    0.3,0.4                     -> 接受(深度2)
  [1,3]    0.3,0.2                     -> 接受(深度2)
  [1,2,0]  0.3,0.4,0.3                 -> 接受(深度3)  ← 最深
bonus = CDF(P[3], 0.4)：cum=[0.3,0.4,0.6,..] -> 索引 1

输出 = [1, 2, 0, 1]
```

## 约束

- CPU float32；返回 `torch.long` 一维张量，用 `torch.equal` 比较。
- 位置对齐：路径第 $i$ 层 token 用 `P[i-1]` 判定；bonus 用 `P[D]`。
- 同深度并列时按 token 序列**字典序最小**选择，保证唯一。
- 保证 `len(P) >= D+1`（$D$ 为最大候选长度）。
