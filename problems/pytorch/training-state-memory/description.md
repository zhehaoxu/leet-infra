# 训练态显存四件套与 ZeRO 分片

## 题目描述

混合精度 + Adam 训练时，除激活外每个参数还会被拆成好几份拷贝存进显存。「一个 7B 模型为什么要
几十 GB 显存」就来自这里。本题清点 **单参数优化态字节数**，并算出 **ZeRO 三档分片后每卡显存**。

## 规则

- 实现 `solve(n_params, world)`，返回四元组 `(stage0, stage1, stage2, stage3)`，均为**每卡字节数**（float）。
- 采用标准的混合精度 + Adam **每参数字节**口径（fp16 存权重/梯度，fp32 存主权重与优化器动量）：

  | 分量 | 精度 | 字节/参数 |
  |------|------|-----------|
  | fp16 参数（前向用） | fp16 | 2 |
  | fp16 梯度 | fp16 | 2 |
  | fp32 主权重 master | fp32 | 4 |
  | Adam 一阶动量 m | fp32 | 4 |
  | Adam 二阶动量 v | fp32 | 4 |
  | **合计** | | **16** |

- 设 $N$ = `n_params`，$W$ = `world`（数据并卡的张数）。ZeRO 把这些分量在 $W$ 张卡间**均分**：
  - **Stage 0（不分区）**：每卡都存全套 → $16N$。
  - **Stage 1**：只把**优化器状态**（master+m+v = 12 字节）分区，参数+梯度仍复制 →
    $N\left(4 + \frac{12}{W}\right)$。
  - **Stage 2**：再把**梯度**（2 字节）也分区，参数仍复制 →
    $N\left(2 + \frac{14}{W}\right)$。
  - **Stage 3**：参数/梯度/优化器状态**全分区** → $\frac{16N}{W}$。
- 这里**不计激活显存**（另有专题），只算权重相关的训练态。

## 示例

```
输入：n_params=1_000_000_000（1B）, world=8
  stage0 = 16*1e9            = 16,000,000,000
  stage1 = 1e9*(4+12/8)=5.5e9 = 5,500,000,000
  stage2 = 1e9*(2+14/8)=3.75e9= 3,750,000,000
  stage3 = 16e9/8             = 2,000,000,000
输出：(16000000000.0, 5500000000.0, 3750000000.0, 2000000000.0)
  （约 14.90 / 5.12 / 3.49 / 1.86 GiB 每卡）
```

## 约束

- `n_params` 为正整数，`world` 为 ≥1 的正整数
- 返回**元组** `(stage0, stage1, stage2, stage3)`，元素为 float（字节）
- 判题对每元素用相对容差比较（`1e-6`）
