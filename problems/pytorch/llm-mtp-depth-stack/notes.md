# 详解：MTP 的多深度预测

## 出处

DeepSeek-V3 技术报告（arXiv:2412.19437）§2.2 的 Multi-Token Prediction：主干之后接 \(D\) 个 MTP 模块，第 \(k\) 个模块

\[ h'^{k}_i=M_k\big[\ \mathrm{RMSNorm}(h^{k-1}_i)\ ;\ \mathrm{RMSNorm}(\mathrm{Emb}(x_{i+k}))\ \big] \]

其中 \(M_k\in\mathbb R^{d\times 2d}\)，输出经与主干共享的 `OutHead` 得到对 \(x_{i+k+1}\) 的预测，训练时 \(\sum_k \lambda_k\,\mathcal L^{k}_{\text{MTP}}\) 与主损失一起优化。

本题只保留 \(M_k\) 这一段算子（归一化 + 拼接 + 投影），不涉及共享输出头、embedding 绑定与损失加权。RMSNorm 取**无可学习缩放**的版本——题目不提供 \(\gamma\)；若要加回，只需在归一化后逐维相乘，不影响任何结构性质。这样设计是为了让"隐藏层是否真的被归一化""嵌入是否单独归一化"这些性质可用**正数放缩不变性**直接断言。

## 核心与易错点

1. **深度是串行的，不是并行的**：第 \(k\) 层吃的是 \(h^{k-1}\)，不是主干的 \(h^0\)。写成"每个深度的输入都是 \(h^0\)"会退化成 \(D\) 个独立的单步预测，`check_depth_chaining` 里"改第 2 层应改变 \(h^2\)、改第 1 层应连带动 \(h^2\)"的断言会立刻暴露。
2. **嵌入前移一位**：第 \(k\) 层读 `embeddings[:, k:k+S]`。写成 `embeddings[:, :S]`（所有层都读同一段）是这类实现最常见的错位——注意两种写法形状完全相同，编译和运行都不会报错。
3. **第二段输入是 token 的输入嵌入，不是上一步的预测**：MTP 训练时用教师强制，嵌入来自共享的嵌入表。若用自回归的自产 token，梯度路径与论文完全不同。
4. **两段各自归一化后再拼接**：先拼接再归一化会把两段的尺度耦合在一起（\(h\) 与嵌入的范数差异被平均掉）。`check_rms_scale_invariance` 分别对 `hidden` 和嵌入切片做正数放缩，正是为了分离这两个归一化。
5. **拼接顺序与 \(W\) 的行序绑定**：本题约定 `[RMS(h) ; RMS(Emb)]`，即 \(W\) 的前 \(d\) 行乘隐状态、后 \(d\) 行乘嵌入。顺序对调形状不变但结果全错，判题用 oracle 逐值对拍。
6. **eps 在 sqrt 里面**：\(\mathrm{RMS}(x)=x/\sqrt{\mathrm{mean}(x^2)+\varepsilon}\)，不是 \(\sqrt{\mathrm{mean}(x^2)}+\varepsilon\)，也不是 \(x/(\sqrt{\mathrm{mean}}+\varepsilon)\)。三种写法在小 eps 下差异极小、在大 eps（如 `1e-2`）下明显——判题专门用 `eps=1e-2` 对拍一次。
7. **位置 0 的嵌入不该被任何层读取**：那个 token 已经被主干消化进 \(h^0\)。这条性质可以直接断言（改动 `embeddings[:, 0]` 后所有深度输出不变）。

## 对拍口径

参考解在 float64 下按深度循环：`_rms` 用 `mean(dim=-1)` + `sqrt`，拼接后用 `einsum("bsf,fe->bse")` 投影，逐层转 float32 收集。判题 `_oracle` 不复用任何张量运算：把 `(batch, 位置)` 逐个取出，用 python 标量算均方、开方、归一化、拼接与逐元素乘加，再重组成张量。结构断言五组：两段归一化的正数放缩不变性、深度的串行依赖（改第 1 层影响两层、改第 2 层只影响第 2 层）、嵌入窗口的位置敏感性（位置 0 / 1 / \(S+1\) 三处）、三组形状 × 多 eps 的 oracle 对拍、非法输入。阈值 `allclose(atol=1e-5)`。

## 复杂度

每层两次 RMSNorm（\(O(BSd)\)）+ 一次线性（\(O(BS\cdot 2d\cdot d)\)），共 \(D\) 层：时间 \(O(2DSBd^2)\)，空间除输出外只需保留当前隐状态，\(O(BSd)\)。
