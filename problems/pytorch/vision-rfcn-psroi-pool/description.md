# R-FCN 位置敏感 RoI 池化账

检测里的分类头通常对每个 RoI 全局池化一次，位置信息被抹平。R-FCN 的做法相反：先产出
`k × k` 组「位置敏感」得分图，第 `(i, j)` 个 bin 只读自己那一路通道，池化后把 `k²` 个
bin 的分数**等权**投票成该 RoI 的分类得分——平移不变性交给卷积，位置敏感性交给通道分组。

## 接口

```python
def solve(scores, rois, k) -> dict
```

`scores` 形状 `(C, k*k, H, W)`：第 `c` 个类别占 `k*k` 个通道，通道 `i*k + j` 只服务 bin
`(i, j)`。`rois` 是 `(N, 4)` 的**整数**特征坐标 `[x1, y1, x2, y2]`（左闭右开）。返回：

| 字段 | 含义 |
| --- | --- |
| `pooled` | `(N, C)`：每个 RoI 每类的最终得分 |
| `bins` | `(N, C, k*k)`：逐 bin 的池化值 |
| `bin_sizes` | `(N, k*k)`：每个 bin 覆盖的像素数 |
| `bounds` | `(N, 4)`：clip 之后的整数边界 |
| `empty` | `(N, k*k)`：哪些 bin 是空区域 |

## 输入输出

```
输入：scores=[1 个类别, k=2, 2x2]，四通道依次为 0/1/2/3
      rois=[[0, 0, 2, 2]]
输出：bins=[[0, 1, 2, 3]], pooled=[[1.5]], bin_sizes=[[1, 1, 1, 1]]
```

四个 bin 各读一个通道，`(0+1+2+3)/4 = 1.5`。

## 规则

- **bin 划分用整数整除**：行区间 `[y1 + i*h//k, y1 + (i+1)*h//k)`，列同理，
  `h = max(y2 - y1, 0)`、`w = max(x2 - x1, 0)`。不引入浮点 `round`。
- **通道按行优先绑定**：bin `(i, j)` 读通道 `i*k + j`；把 `i`/`j` 写反会取到转置的那一路。
- **bin 内是算术平均**：即该通道在子区域内的像素均值，不是求和，也不是 max。
- **`k²` 个 bin 等权投票**：最终得分是 `k²` 个 bin 值的平均，**不按 bin 覆盖面积加权**。
  一个 1 像素的 bin 和一个 9 像素的 bin 权重相同，所以结果不等于整幅 RoI 的全局均值。
- **空 bin 记 0.0 并参与平均**：`h < k` 时靠前的行 bin 会被压成空区间（整数整除的直接后果），
  空 bin 的 0 也被算进分母，会稀释得分；零面积 RoI（`x2 <= x1` 或 `y2 <= y1`）所有 bin 为空，
  输出 0。
- **先 clip 再分桶**：坐标先夹到 `[0, W]` / `[0, H]`，`bounds` 记录夹取后的值；图外的 RoI
  夹完可能退化成零面积。
- **校验**：`k` 为正整数（`bool` 拒绝）、`scores` 必须 4 维且第二维恰为 `k*k`、`rois` 必须
  `(N, 4)` 且全为整数；`N = 0` 合法（返回空账本）。

## 提示

- `pooled` 不等于 `bins` 的加权平均：先算 bin 均值再等权平均，这两步顺序不能合并成
  「先拼像素再一起平均」。
- 空 bin 不能直接对空切片取均值——`torch.mean` 在空张量上返回 `nan`，必须显式写 `0.0`。
