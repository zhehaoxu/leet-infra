## 恢复前提与问题范围

故障机器上的唯一内存状态一旦丢失，仅凭 rank 编号无法重新构造。本题明确假设有一个**一致且持久化的检查点，覆盖每个故障分片**；幸存者保留同一检查点状态的自身分片，丢失的分片从检查点读取，而不是从已故障 rank 的内存搬出。函数只输出恢复计划，不执行 I/O，也不检验真实检查点的存在性。

这是题目约定的旧分片保留与恢复模型，不是 torchelastic 的真实成员重组或 rank 分配实现。它不计算完整训练重启、不将全部参数按新 world size 重分片，也不对 ZeRO/FSDP 的实际状态恢复流程作保证。检查点读取延迟、元数据、优化器状态、重启开销与幸存分片的重新加载均不计入字节账。

## 幸存 rank 映射推导

把输入故障列表转换成集合 \(F\)，使重复 ID 只表示一次故障。所有 ID 必须属于原 rank 范围。按旧 ID 从小到大遍历，保留不在 \(F\) 中的 rank，并依次赋予新 ID。这样保持幸存者相对顺序，且新 ID 恰好覆盖 \([0,W')\)，其中 \(W'=W-|F|\)。

对任意幸存旧 rank \(r\)，也可独立写成

\[
\text{new}(r)=r-|\{f\in F:f<r\}|.
\]

故障位置则为 -1。这个等式解释了为何不能直接沿用旧 ID，也为测试提供了不复制参考循环的逐旧 rank 校验方式。

## 检查点目的地与负载推导

将 \(F\) 排序后，第 \(i\) 个检查点分片交给新 rank \(i\bmod W'\)。这里取模的是**排序后的位置**，不是故障旧 ID；目的列表始终与排序去重后的故障 ID 对齐，不随输入顺序改变。

令 \(|F|=aW'+b\)，\(0\le b<W'\)。前 \(b\) 个新 rank 各接收 \(a+1\) 个额外分片，其余接收 \(a\) 个，因此所有幸存者的额外分片数量差至多为 1。必须将收到零个额外分片的幸存者也计入比较。若只有一个幸存者，它接收所有故障检查点分片；若无故障，每个幸存者的额外负载均为零。

## 字节账与约束

每个原始分片大小为 \(s=\text{param_bytes}/W\)。仅恢复 \(|F|\) 个失败分片，因此 `migration_bytes` 为 \(|F|s\)。注意除数是**原** world size，不是新 world size。保留的数据量与恢复数据量满足

\[
W's+\text{migration bytes}=\text{param_bytes}.
\]

参数总字节数可以为零；此时仍生成相同的 rank 与目的映射，只是载荷为零。starter 完整列出类型与范围：原 world size 为正整数、字节数为非负且整除 world size 的整数、故障 ID 为合法整数列表，均不含 bool。不满足这些条件或去重后所有 rank 均故障时抛出 `ValueError`，不能静默截断非整除的字节数。全部 rank 故障即使有检查点也不符合本题，因为没有幸存接收者。

## 复杂度与独立验证

令 \(K\) 为输入故障列表长度（包含重复项）、\(F\) 为不同故障 ID 的数量。校验及去重耗时 \(O(K)\)，映射耗时 \(O(W)\)，排序耗时 \(O(F\log F)\)。总时间为 \(O(W+K+F\log F)\)，空间为 \(O(W+F)\)，包含返回列表。

测试对小 world size 枚举所有至少保留一个幸存者的故障子集。逐旧 rank 校验映射，并从每个新 rank 的视角检查它接收排序检查点序列中每隔 \(W'\) 个取到的分片；同时检查载荷守恒、所有幸存者的额外负载（含零负载）、无序和重复输入。这样既验证恢复对应关系，也避免只复制参考解的取模列表表达式。
