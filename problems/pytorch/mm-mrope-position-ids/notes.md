# 详解：Qwen2-VL 风格 M-RoPE 位置编号

## 出处
思路源自 Bai et al., *Qwen2-VL*（arXiv:2409.12191）的 M-RoPE：位置编号拆成 \((t,h,w)\) 三分量，图像按高/宽展开、文本三轴同步，使旋转位置编码能同时表达 1-D 文本与 2-D 视觉。本题实现**仅图像+文本**的简化确定版本（完整算法含视频时间维，此处不涉及）。

## 核心与易错点
1. **三轴共享一个 `running` 基准**：文本让三轴都等于 `running` 后 +1；图像块让 \(t\) 恒为 `running`、\(h/w\) 在 `running` 上加行/列偏移。别把三轴各自独立计数。
2. **图像块后 `running += max(h,w)`**（不是 h·w）：这样图像只推进对角跨度 max(h,w)，给二维展开留出空间——是最易记错的细节。
3. **图像 token 必须连续成块**、与 `grid_thw` 顺序一一对应，块大小 = \(h\cdot w\)。
4. 输出是 \((3,L)\) 整数编号、不是浮点特征，判题用精确相等。

## 对拍口径
参考解单游标 while 扫描、按块展开。判题 `_oracle` 用纯 Python 嵌套列表按同规则重算、结构不同（分相构建），逐元素整数 `==` 对拍。另设「纯文本序列退化为 1..L 三轴同值」「图像块内 t 恒定、h/w 呈行列网格」「示例数值」断言。

## 复杂度
\(O(L)\) 单遍。
