# 参考思路：固定渲染与字节归属

## 先区分三种坐标

字符串索引按 Unicode 码点计，UTF-8 偏移按字节计，模型 token 索引又是第三种坐标。本题只输出第二种，不实现第三种。组合字符不规范化；`é` 与 `e\u0301` 保持各自原始编码。

正文恰好包含 `<|im_end|>` 等字符串时，它仍属于正文。不能渲染后用正则、`find` 或 `rfind` 猜边界；重复正文、空正文和字面标记都会造成歧义。

## 参考实现

1. 校验开关、非空续写条件、消息结构和角色。
2. 按片段追加消息头、正文、消息尾。每个片段仅编码一次，字符串片段用于最终 `join`，字节片段用于 `input_bytes`。
3. 正文追加前后记录字节列表长度，得到半开区间。头尾语法填角色 -1，正文按角色填 0/1/2；只有角色 2 的字节填 `True`。
4. 续写只跳过最后消息的尾片段；生成提示作为无正文的新语法片段追加，不增加 span。

设输出字节数为 $B$，消息数为 $M$，时间和总空间均为 $O(B+M)$，其中返回值本身已经占这些空间。不要用反复拼接增长字符串造成平方开销。

## 独立测试设计

测试 oracle 先逐 Unicode 字符生成带角色的事件，记录字符边界，再把每个字符展开为 UTF-8 字节事件。字符边界通过对应字符前缀的编码长度转换成字节边界，**不复用参考解的消息片段字节偏移累积**。

共 15 个 `check_*`：基本样例、空会话与生成头、三种角色的续写、空正文、重复正文、字面标记、Unicode 标量与组合字符、尾空白、语法掩码、非法角色、非法消息记录、非法开关组合、输入不变性、固定局部种子的随机字符对拍、20 条各 1000 码点的最大输入。检查返回键集合和元素的 Python 类型，避免用 0/1 冒充布尔掩码。

已先通过 submit selftest 与 `.venv-eval` 直跑（各 15/15），再实际执行样例 dump 写题面：基本例的 spans 为 `[(17, 19), (52, 55)]`，共 66 字节；空会话生成头为 22 字节；续写 `答 \n` 的 span 为 `(22, 27)`。

## 与上游行为的边界及证据状态

已核对本地 Transformers 5.20.2 源码：

- `tokenization_utils_base.py:3043–3055,3122–3128,3176–3199`：生成提示与续写互斥、先渲染后 tokenize、assistant 字符区间需要通过 `char_to_token` 映射到模型 token。
- `utils/chat_template_utils.py:534–537,557–563,653–678,697–714`：涉及 Jinja 渲染、字符 `len` 和续写截断。

这些记录解释了渲染、字符坐标与模型 token 坐标需要分层，但**不证明本题模板就是某模型的默认完整模板**。本题不运行 Jinja，也不复现上游通用模板执行流程、字符到模型 token 的映射或特定模型监督策略。逐字节 `role_ids`、仅 assistant 正文的掩码、无隐式 system、任意最终角色可续写且原样保留尾空白，都是本题明确规定的契约，不能反向宣称是上游所有模板的行为。
