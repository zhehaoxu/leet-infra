# Concat 拼接（沿现有维）

## 题目描述

`torch.cat` 把若干张量沿一根**已存在的维**首尾相接：该维长度相加，其余维必须完全一致。它**不增加维度**——这正是与 `torch.stack`（新增一根维）的关键区别。

$$ \text{out}[i_0,\dots, i_{dim},\dots] = \text{t}_k[\dots, i_{dim}-\text{offset}_k, \dots] $$

## 规则

- 实现 `solve(tensors, dim=0)`，`tensors` 是形状相同的维数一致的一组张量。
- 输出维数与输入相同；`dim` 维长度 = 各张量该维长度之和；**其余每一维必须相等**，否则应报错。
- 拼接顺序即列表顺序，顺序会影响结果。
- 支持负 `dim`（`-1` 即最后一维）。
- 与 `torch.cat(tensors, dim)` 一致。

## 示例

```
输入：a=[[1,2]], b=[[3,4],[5,6]], dim=0
   dim0 长度 1+2=3，dim1 保持 2
输出：[[1,2],
      [3,4],
      [5,6]]     # 形状 (3,2)，仍是 2 维（不是 stack 的 (2,1,2)）
```

## 约束

- 所有输入 dtype 一致、维数相同；float32/float64
