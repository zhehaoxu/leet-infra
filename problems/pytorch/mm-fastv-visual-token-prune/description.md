# 多模态：FastV 第 K 层视觉 token 剪枝

## 任务

在视觉语言模型的第 K 层，用该层注意力矩阵**最后一个 query 行**对视觉 token 打分，只保留分数最高的少数视觉 token，并删除其余视觉 token。文本前缀与图像之后的文本一律保留，幸存 token 继续使用**原始位置编号**。

本题有意抽取 FastV（Chen et al., arXiv:2403.06764, ECCV 2024 Oral）官方实现里的单步剪枝规则，**不是完整推理管线**：注意力矩阵由调用方给出，模型不在此处前向，也不重新计算注意力。参数、形状、数值范围和异常约定统一见 starter 的双语契约，以下只定义计算规则。

## 打分规则

记视觉段为绝对下标区间 `[image_start, image_start + image_len)`，最后一个 query 行的下标是 `L - 1`。

1. 对每行 `b`，视觉段内第 `i` 个 token 的分数是
   $$
   \mathrm{score}[b,i]=\frac{1}{H}\sum_{h=0}^{H-1}\mathrm{attention}[b,h,L-1,\mathrm{image\_start}+i].
   $$
   即先对 head 维求平均，再取末行；只使用末行，其他 query 行不得影响结果。
2. 保留个数 `k = round(image_len * (1 - r))`，其中 `r` 是**丢弃比例**，`round` 是 Python 的四舍六入五取偶（half-to-even），因此 `round(1.5)` 与 `round(2.5)` 都等于 `2`。`k` 允许为 `0`，此时整个视觉段被删除。
3. 只有视觉段内的 token 参与竞争：`image_start` 之前的 system+question 前缀，以及 `image_start + image_len` 之后的尾部文本，无论 `r` 多大都永不剪除。
4. 取前 `k` 个分数时并列按「分数降序、下标升序」判定；选中的视觉下标必须**再按升序**发出，而不是按分数顺序，否则序列不再保持因果顺序。
5. 输出序列的下标集合是「前缀 + 升序保留的视觉下标 + 尾部」，长度 `L' = L - (image_len - k)`。`position_ids` 等于该集合本身：编号中出现空洞是**正确行为**，从 `0` 重新编号是常见错误。

返回四元组的顺序、形状与 dtype 见 starter 契约；剪枝后的每一行都是原行的逐字节拷贝，不重新归一化、不缩放。

## 样例 1：head 平均、并列与跳号

全部浮点张量为 float64，`image_start = 2`，`image_len = 4`，`r = 0.5`，故 `k = round(4 * 0.5) = 2`。下面只给出两个 head 的末行在视觉段上的切片，其他行与列不影响结果。

```text
hidden_states = [[[1, 10], [2, 20], [3, 30], [4, 40],
                  [5, 50], [6, 60], [7, 70], [8, 80]]]
image_start = 2, image_len = 4, r = 0.5
attention[0, :, 7, 2:6] = [[0.4, 0.2, 0.8, 0.6],
                           [0.6, 0.2, 0.2, 0.4]]

score                = [[0.5, 0.2, 0.5, 0.5]]
pruned_hidden_states = [[[1, 10], [2, 20], [3, 30],
                         [5, 50], [7, 70], [8, 80]]]
keep_indexs          = [[0, 1, 2, 4, 6, 7]]
position_ids         = [[0, 1, 2, 4, 6, 7]]
```

视觉段四个 token 的分数是 `0.5, 0.2, 0.5, 0.5`，并列的三个中按升序取绝对下标 `2` 和 `4`，绝对下标 `5` 落选。前缀 `0, 1` 与尾部 `6, 7` 原样保留，编号空洞出现在被删除的 `3` 和 `5` 处。

## 样例 2：逐行独立选择与 half-to-even

全部浮点张量为 float64，`B = 2`，一个 head，`image_start = 1`，`image_len = 3`，`r = 0.5`，故 `k = round(3 * 0.5) = round(1.5) = 2`。

```text
hidden_states = [[[1], [2], [3], [4], [5]],
                 [[10], [20], [30], [40], [50]]]
image_start = 1, image_len = 3, r = 0.5
attention[:, 0, 4, :] = [[0.2, 0.9, 0.1, 0.5, 0.3],
                         [0.2, 0.3, 0.7, 0.4, 0.1]]

score                = [[0.9, 0.1, 0.5], [0.3, 0.7, 0.4]]
pruned_hidden_states = [[[1], [2], [4], [5]],
                        [[10], [30], [40], [50]]]
keep_indexs          = [[0, 1, 3, 4], [0, 2, 3, 4]]
position_ids         = [[0, 1, 3, 4], [0, 2, 3, 4]]
```

两行的 `k` 相同，但保留哪几个视觉 token 由各行自己的分数决定：第一行删去绝对下标 `2`，第二行删去 `1`。

以上输出均由参考实现实跑，并通过独立 oracle 校验；展示值保留六位小数以内的精确十进制值。
