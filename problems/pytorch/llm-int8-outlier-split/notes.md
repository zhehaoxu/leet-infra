# 解题说明 · LLM.int8()

## 涌现特征维：为什么不能全 INT8

作者发现 Transformer 的激活里存在**数量极少但幅值极大**的"emergent dimensions"（约占 0.1%），它们几乎在每层、每个 token 上都稳定出现且取值可到正常通道的 100 倍。整型量化器要为这些极值让出量程，导致正常通道被"淹没"到很少的量化级；而这些离群值一旦被截断，误差会被它们自身的大权重放大，整段输出就崩。

## 混合精度分解（vector-wise quantization）

把 $XW$ 沿输入通道拆成"离群列 + 普通列"两块：

$$XW = X_{\text{out}}W_{\text{out}} \;(\text{FP16}) \;+\; X_{\text{normal}}W_{\text{normal}}\;(\text{INT8})$$

离群列极少（<1%），用 FP16 单列乘积开销很小；普通列占绝大多数、走 INT8 高速路径。二者相加与全精度几乎等价。

## 本题简化到权重侧

判题里不引入激活 $X$（它的离群列在推理时才动态确定、不利确定性），而是把这层思想**固定到权重**上：按"列 absmax 是否超过阈值 $\tau$"决定该列是原样保留（当作离群、FP 精度）还是量化。离群列原样返回，等价于"FP16 分支不做任何改动"。这样保留了 LLM.int8() 的**离散-连续二分**内核，又能纯 CPU 精确对拍。

## 与 SpQR / AWQ 的谱系

- **LLM.int8()**：离群列**整列**保留 FP，粒度是列。
- **SpQR**：离群**单个权重**（非整列）稀疏保留高精度 + 行列重要度分组，粒度更细。
- **AWQ**：不保留任何 FP，而是给重要列**缩放**后一起量化。

三者都在回答同一问题——"少数重要元素怎么在低位宽下保住"，只是手段从"整列豁免→单点豁免→缩放保护"逐步演进。

## 边界自检

`check_all_outlier_passthrough`：阈值极低全部离群 → 输出等于输入（无量化）。`check_no_outlier_all_quant`：阈值极高无离群 → 全走 RTN。两头夹住"列二分"逻辑。
