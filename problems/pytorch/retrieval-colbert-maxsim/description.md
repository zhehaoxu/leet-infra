# 检索：ColBERT MaxSim 与 MaxPooled 聚合

## 题目描述

ColBERT 的 late interaction 把 query 与文档都保留成**词向量序列**，用 MaxSim 打分：每个 query 词在整篇文档里找最相似的一个文档词，取其余弦相似度，再对所有 query 词求和：

\[ S=\sum_{i=1}^{L_q}\max_{1\le j\le L_d}\cos(q_i,d_j). \]

长文档要切块建索引时，一个自然的错误口径是「每块各算一遍 MaxSim 再相加」——同一个 query 词的贡献会在多个块里被重复计入，块越多分数越虚高。本题在实现基础 MaxSim 的同时，把文档按 `chunk_size` 硬切成块，先算**每 query 词在每个块内的最大余弦**（逐 chunk MaxSim 矩阵），再用两种口径聚合：MaxPooled（每个 query 词跨块只取一次最大值）与重复计分（逐块求和），后者作为判题对照值。

归一化与退化是本题的另一半：query / 文档的词向量都先逐行做 L2 归一化，零向量保持全 0、与任何向量的余弦按 0 处理；文档为空、query 为空、尾块不足都要有确定结果。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- **归一化**：query、doc 均逐行除以自身的 L2 范数；范数为 0 的行保持全 0（用安全分母，不产生 NaN）。余弦矩阵 \(C_{ij}=\hat q_i\cdot\hat d_j\)，其中 \(\hat q_i,\hat d_j\) 是归一化后的行。
- **基础分数**：\(S=\sum_i \max_j C_{ij}\)，为 0 维浮点张量。文档为空（\(L_d=0\)）时每个 \(\max\) 按 0 处理，\(S=0\)，不抛错。
- **最大下标**：同时返回每个 query 词的 \(\arg\max_j C_{ij}\)，并列时取**最小下标**；\(L_d=0\) 时该位置填 `-1`。
- **切块**：文档按 token 顺序硬切，第 \(c\) 块覆盖 \([c\cdot\text{chunk\_size},\ \min((c+1)\cdot\text{chunk\_size},L_d))\)；尾块不足一块也保留，块数 \(C=\lceil L_d/\text{chunk\_size}\rceil\)，\(L_d=0\) 时 \(C=0\)。块与块不重叠。
- **逐块矩阵**：形状 \((L_q,C)\)，第 \((i,c)\) 项是第 \(i\) 个 query 词在第 \(c\) 块内的最大余弦。
- **MaxPooled 聚合**：对每个 query 词先在块内取 max，再对块维取 max，最后对 query 词求和。由 \(\max_c\max_{j\in c}C_{ij}=\max_j C_{ij}\)，它恒等于基础分数——这正是「同一 query 词的贡献只计一次」的含义。
- **重复计分口径**：把逐块矩阵的**所有**元素直接求和（每个 query 词在每个块各贡献一次），作为对照值返回。只有一块时它等于基础分数；余弦非负时它不小于基础分数，块数越多膨胀越明显（极端情况下每个块都含同一个最佳文档词，可达到基础分数的 \(C\) 倍）。
- **空输入**：\(L_q=0\) 时基础分数与两种聚合分数均为 0、逐块矩阵形状 \((0,C)\)、下标为空；\(L_d=0\) 时逐块矩阵形状 \((L_q,0)\)。两者都合法。
- **错误约定**：query 或 doc 非二维、特征维不一致、dtype 不一致或不是浮点、`chunk_size < 1`，均抛 `ValueError`。
- **dtype**：逐块矩阵与三个标量跟随输入的浮点 dtype（float32 / float64），下标恒为 int64。全程确定性、不调用随机数。

## 示例

`query = [[1,0],[0,1]]`，`doc = [[1,0],[1,0],[0,1],[-1,0],[0.6,0.8]]`，`chunk_size = 2`。归一化后余弦矩阵为

\[
C=\begin{bmatrix}
1 & 1 & 0 & -1 & 0.6\\
0 & 0 & 1 & 0 & 0.8
\end{bmatrix}.
\]

文档切成 3 块：块 0 含 token 0、1，块 1 含 token 2、3，块 2 只有尾 token 4。逐块 MaxSim 矩阵为

```
[[1.0, 0.0, 0.6],
 [0.0, 1.0, 0.8]]
```

- 基础分数：query 词 0 取 \(\max(1,1,0,-1,0.6)=1\)，query 词 1 取 \(\max(0,0,1,0,0.8)=1\)，故 \(S=2\)；最大下标为 `[0,2]`（第一个 query 词的 1 在 token 0 与 1 并列，按约定取 0）。
- MaxPooled：两个 query 词跨块的最大值仍分别是 1、1，合计 2，与基础分数一致。
- 重复计分：逐块矩阵全部元素相加 \(1+0+0.6+0+1+0.8=3.4\)。query 词 0 在块 0 与块 2 各被计一次（\(1+0.6\)），query 词 1 在块 1 与块 2 各被计一次（\(1+0.8\)），比真实分数多出 1.4。

只有一块时（例如 `chunk_size` 不小于文档长度）三种分数相等；上面的 3.4 与 2 正是「重复计分」与「只计一次」的最小判别式。

## 约束

- 返回五元组：基础分数、最大下标、逐块 MaxSim 矩阵、MaxPooled 聚合分数、重复计分对照值。
- 下标用 `torch.equal` 判定，浮点值 float32 容差 \(10^{-5}\)、float64 容差 \(10^{-12}\)。
- \(L_q,L_d\ge 0\)、`chunk_size` \(\ge 1\)；零向量按余弦 0 处理，不得出现 NaN。
- CPU、确定性、不使用随机数；实现路径不限（矩阵乘、逐块循环、广播比较均可）。
