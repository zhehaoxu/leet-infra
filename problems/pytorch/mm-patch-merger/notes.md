# 详解：Qwen2-VL 2×2 视觉 Token 合并

## 出处
Bai et al., *Qwen2-VL*（arXiv:2409.12191）`PatchMerger`：把相邻 \(2\times2\) 的视觉 patch 嵌入拼接（token 数 ↓4、通道 ↑4），再经 LayerNorm+MLP 投影到 LLM 维度。本题只做确定性的 **空间 shuffle + concat**，剥离带权重的 Linear。

## 核心与易错点
1. **切块视图要保证行主序对齐**：`(gh//2, 2, gw//2, 2, D)` 的展平恰好等于网格 row-major（`(2i+r)*gw+(2j+c)`），`permute(0,2,1,3,4)` 得 (合并行, 合并列, r, c, D)。弄反会把上下/左右块接错。
2. **块内顺序 左上→右上→左下→右下**：即 (r,c)=(0,0),(0,1),(1,0),(1,1)，对应拼接后 4D 特征的分段顺序。
3. **合并的是空间邻域、不是序列相邻四项**：跨行的两个 patch 不在同一 2×2 块里。
4. 通道维 D 在最内，输出宽度 4D。

## 对拍口径
参考解 `view→permute(0,2,1,3,4)→reshape(-1,4D)`。判题 `_oracle` 双重循环按 2×2 块坐标显式取四 patch、依序 extend 拼接（结构不同、数值等价），`allclose`。另设「输出 shape=(gh/2·gw/2, 4D)」「输出是输入的元素置换（多重集相等）」「单块数值顺序」断言。

## 复杂度
\(O(g_h g_w D)\) 重排。
