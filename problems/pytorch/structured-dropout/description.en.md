# Structured Dropout: DropPath and Dropout2d/3d

## Problem

Ordinary dropout flips a coin per element, which barely regularizes spatially correlated convolutional features (Tompson 2015's observation: i.i.d. dropping degenerates into an effective learning-rate decrease). Structured dropout drops **whole blocks** instead — entire samples (DropPath / stochastic depth: Huang et al., ECCV 2016 randomly skip whole residual branches during training; timm's `DropPath` is the standard implementation) or entire channels (the spatial dropout of Dropout2d/3d: whole feature maps zeroed). This problem implements the unified forward \(y=x\cdot mask_{\text{broadcast}}/(1-p)\) (inverted scaling), with the key twist that **drop positions are not RNG-generated**: the mask is an explicit boolean / 0-1 tensor argument (1=keep, 0=drop), fully deterministic on CPU — a deliberate division of labor with the `dropout` problem, which builds its mask from a seed. The three mask granularities correspond to sample-level (timm DropPath's structural semantics) and channel-level (the structural semantics of `F.dropout2d`/`F.dropout3d` under training, with the mask given explicitly instead of sampled).

## Rules

- The full signature, parameter meanings and defaults live only in the starter's docstring; that is the single judging standard. Inputs: x is a float tensor (CPU, float32/float64); p is the drop probability; mask is an explicit boolean or 0/1 tensor; mode is one of `"droppath"` / `"dropout2d"` / `"dropout3d"`, anything else raises `ValueError`.
- **Unified semantics**: \(y=(x\cdot mask_{\text{broadcast}})/(1-p)\) — inverted scaling (consistent with `F.dropout` training=True); dropped samples/channels are **strictly zero** as a whole, surviving elements equal \(x/(1-p)\).
- **p validation**: \(0\le p<1\); \(p\ge1\), \(p<0\) or non-finite values (inf/nan) raise `ValueError`.
- **Three mask granularities** (any other shape raises `ValueError`; the mask broadcast to x's shape must match exactly — broadcasting in extra batch dims is not allowed):
  - droppath: x of rank \(\ge1\) (\((B,\dots)\), arbitrary tail), whole-sample dropping; mask \((B,)\) or \((B,1,\dots,1)\) (number of 1s = x's rank − 1). Rank mismatch raises `ValueError`.
  - dropout2d: x exactly 4-D \((N,C,H,W)\), whole-channel dropping (the entire \(H\times W\) feature map zeroed); mask \((N,C)\) or \((N,C,1,1)\). Rank mismatch raises `ValueError`.
  - dropout3d: x exactly 5-D \((N,C,D,H,W)\), whole-channel dropping including the depth dim; mask \((N,C)\) or \((N,C,1,1,1)\).
- **Degenerate cases and identity**: p==0 with an all-ones mask is a strict identity (`torch.equal(y,x)`); p==0 with zeros in the mask gives \(y=x\cdot mask\) exact elementwise.
- A bool mask is cast to x's dtype before multiplying; the result is a **new tensor** with x's shape and dtype, the input is never modified; no RNG calls anywhere.

## Example

Main example (values from the `EXAMPLE_*` constants in test_cases): x \((2,3,2,2)\), p=0.5, mask=\([1,0]\), mode=droppath — sample 0 survives and is scaled by 2 overall (\(=x/(1-0.5)\)), sample 1 is dropped entirely and strictly zero:

\[
\text{sample 0}=\begin{bmatrix}1&-2\\4&0\end{bmatrix},\begin{bmatrix}7&3\\-5&8\end{bmatrix},\begin{bmatrix}0.5&-1.5\\2.5&5.5\end{bmatrix};
\qquad \text{sample 1}=\text{all zeros}
\]

Probe set: mask=\([1,0,1,0]\), p=0.25 → surviving samples are exactly \(x/0.75\), dropped samples satisfy `all(==0)`. dropout2d: all-ones mask \((N,C)\), p=0.4 → \(y=x/0.6\) (no channel dropped); a zero in the mask → the corresponding \((n,c)\) feature map entirely zero. dropout3d: all-ones mask, p=0.5 → \(y=2x\). The two mask shapes \((B,)\) vs \((B,1,1,1)\), and bool vs 0/1 float masks, give `torch.equal` results.

## Constraints

- The mask shape whitelist is mode-specific with exactly two forms per mode; anything outside it (e.g. droppath on a 3-D x receiving \((B,C)\), \((B,1,1,1,1)\) or \((B,1)\); dropout2d receiving \((N,)\), \((N,C,1)\), \((N,C,1,1,1)\), or a value-mismatched \((N,C',1,1)\)) raises `ValueError`; a rank inconsistent with the mode raises `ValueError`.
- Cross-check: an independent pure-Python oracle performs manual broadcasting plus the \(1/(1-p)\) scaling on a separate path from the tensorized solution, `allclose` 1e-6 (1e-12 for float64), with shape and dtype asserted one by one; deterministic pseudo-random tensors and bool masks are generated by golden-ratio hashing (no RNG).
- Discriminating criteria the judge asserts directly: dropped blocks strictly all zero (`==0`, not approximate), surviving blocks exactly \(x/(1-p)\), the two mask shapes equivalent, bool ≡ 0/1 float, p=0 identity (`torch.equal`), and the error taxonomy over p / mask shape / mode.
