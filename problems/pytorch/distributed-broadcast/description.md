# 集合通信：Broadcast

## 题目描述

**Broadcast** 让一个指定的源 rank（`src`）把它的张量原样复制给**所有** rank。它是最简单的集合通信：
训练开始时同步初始权重、评估时下发配置，都靠它。

> 集合通信按纯函数建模：输入是「通信前各 rank 的本地数据」列表（第 $r$ 项是 rank $r$ 的张量，只有
> `src` 那份是有效数据、其余是占位），输出是「通信后各 rank 的数据」列表。

## 规则

- 实现 `solve(inputs, src)`：`inputs` 是长度 $W$ 的列表，`inputs[src]` 是源 rank 的有效张量（任意形状），
  其余 rank 的张量内容**不被使用**（占位）。
- 结果：通信后**每个 rank 都持有 `inputs[src]` 的一份拷贝**。
- 返回**长度 $W$ 的列表**，第 `r` 项都等于 `inputs[src]`。
- 不得修改输入张量。

## 示例

```
输入：inputs = [ [99], [99], [1.0, 2.0, 3.0] ], src = 2   # rank2 是源
输出：[ [1,2,3], [1,2,3], [1,2,3] ]                        # 所有 rank 复制源数据
```

## 约束

- `1 ≤ W ≤ 64`；`0 ≤ src < W`
- `inputs[src]` 形状任意；其余项形状可不同（反正不用）
- 返回 `list[torch.Tensor]`，长度 $=W$，每项与 `inputs[src]` `torch.equal`
- 与 All-Gather 的区别：Broadcast 只是**复制同一份**，不拼接不同分片
