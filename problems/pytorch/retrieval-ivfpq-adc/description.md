# 检索：IVF-PQ 非对称 ADC 打分

## 题目描述

IVF-PQ 是 Faiss `IndexIVFPQ` 的核心结构（Jégou, Douze, Schmid, *Product Quantization for Nearest Neighbor Search*, IEEE TPAMI 2011, arXiv:1009.5545）：先用粗量化中心把空间切成若干 Voronoi cell，每个 cell 维护一条倒排链；链内文档不再存原始向量，而是存 \(m\) 个子空间的 PQ 码字。查询时先选少数几个最近 cell，再在链内用**非对称距离计算（ADC, Asymmetric Distance Computation）**打分——查询保持原始浮点、不量化，只把库里文档的码字通过查找表还原成近似距离。

本题把「选 cell」与「ADC 打分」串成一个确定性函数。关键是把三件事同时做对：

- 每个查询独立地按 query 到粗中心的**平方欧氏距离**选 `nprobe` 个 cell，并列取 cell 号小者；
- 每个子空间各有一张 LUT，doc 的近似距离是 \(m\) 个子空间 LUT 值之**和**，不能跨子空间混用码本；
- 最终按 **(距离升序, 全局 id 升序)** 排序取 top-k，候选不足时用 `-1` / `+inf` 补齐。

CPU、全程确定性、不调用任何随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- **输入形状**：查询 \((Q,D)\) 浮点张量，\(Q\) 可为 0；粗中心 \((C,D)\)；码本 \((m,K,d)\)，且 \(D=m\cdot d\)。倒排表用两个长度均为 \(C\) 的 list 表示：第 \(c\) 项分别是该 cell 的全局 id \((n_c,)\) int64 与码字 \((n_c,m)\) int64，\(n_c\) 可为 0。三者 dtype 必须一致，仅支持 float32/float64。
- **选 cell**：对每个查询算 \(\|q-c_j\|^2,\ j=0\dots C-1\)，按升序取前 `nprobe` 个；距离并列取 cell 号小者。`nprobe=0` 不探测任何 cell，`nprobe>C` 视为探测全部 \(C\) 个 cell。
- **ADC 距离**：对子空间 \(j\) 与码字 \(t\)，
  \[
  \text{LUT}[j,t]=\bigl\|q_{j\cdot d:(j+1)\cdot d}-\text{codebooks}[j,t]\bigr\|^2,
  \]
  码字行为 \(\text{codes}[i]\) 的文档，其近似距离为
  \[
  \hat d(q,x_i)=\sum_{j=0}^{m-1}\text{LUT}\bigl[j,\text{codes}[i,j]\bigr].
  \]
  查询侧不量化；距离内部用 float64 累加，输出时转回查询的 dtype。
- **输出**：`ids` 形状 \((Q,k)\)、int64；`dists` 形状 \((Q,k)\)、dtype 与查询相同。每行先放真实候选，按 (距离升序, 全局 id 升序) 排列；真实候选不足 \(k\) 个时，尾部 `ids` 填 \(-1\)、`dists` 填 \(+\infty\)。`k=0` 时两个张量形状都是 \((Q,0)\)。
- **退化**：`nprobe=0`、所选 cell 全空、或 \(C=0\) 时，该行没有任何真实候选（若 \(k>0\) 则整行都是填充值）。空 cell 直接跳过，不占候选。
- **全局 id 约定**：同一 id 在整个倒排表中至多出现一次；本题不做去重，重复 id 不在契约内。
- **错误约定**：维度不符、\(D\neq m\cdot d\)、dtype 不一致或非 float32/float64、倒排表长度不等于 \(C\)、ids/codes 行数不一致、ids 不是 1-D int64、codes 不是 \((n_c,m)\) int64、id 为负、码字越界、`nprobe<0`、`k<0`，一律抛 `ValueError`。

## 示例

取 \(D=2,m=2,d=1,K=2,C=2\)：

- 粗中心：\(c_0=(0,0)\)、\(c_1=(10,10)\)；
- 两个子空间的码本都是 \(\{[0],[10]\}\)；
- cell 0：id 0 码字 \((0,0)\)（近似 \((0,0)\)）、id 1 码字 \((1,0)\)（近似 \((10,0)\)）；
- cell 1：id 2 码字 \((0,1)\)（近似 \((0,10)\)）、id 3 码字 \((1,1)\)（近似 \((10,10)\)）。

查询 \(q=(0,0)\)，`nprobe=2`、`k=3`：

| 文档 | 码字 | 子空间 0 距离 | 子空间 1 距离 | ADC 距离 |
|---|---|---|---|---|
| 0 | (0,0) | 0 | 0 | 0 |
| 1 | (1,0) | 100 | 0 | 100 |
| 2 | (0,1) | 0 | 100 | 100 |
| 3 | (1,1) | 100 | 100 | 200 |

\(q\) 到两个中心的平方距离分别是 0 和 200，故两个 cell 都探测。按 (距离, id) 排序，id 1 与 id 2 距离同为 100，取小 id 在先：

```
ids   = [[0, 1, 2]]
dists = [[0.0, 100.0, 100.0]]
```

若改为 `nprobe=1`，只探测最近的 cell 0，候选只有 id 0/1，`k=3` 的第三格填充：

```
ids   = [[0, 1, -1]]
dists = [[0.0, 100.0, inf]]
```

## 约束

- 返回二元组 `(ids, dists)`：`ids` 为 \((Q,k)\) int64，`dists` 为 \((Q,k)\) 且 dtype 跟随查询。
- 判题对 ids 用 `torch.equal` 精确比对；浮点距离 float32 用 \(10^{-5}/10^{-6}\)、float64 用 \(10^{-9}/10^{-12}\) 的 `atol/rtol`，填充位 \(+\infty\) 必须逐位为 inf。
- \(Q,C\) 可为 0，\(n_c\) 可为 0；`nprobe` 与 `k` 必须是非负整数。
- 不使用随机数；实现路径不限（逐查询循环、按 cell 拼接后向量化、或 LUT gather 均可），但结果必须与上述排序口径逐位一致。
