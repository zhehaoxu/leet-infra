# GPT-2 字节级预分词

## 任务

实现 `solve`：先按固定 GPT-2 规则切分原文，再将每段的 UTF-8 字节映射为可逆的 Unicode 字符串。这里只做预分词和字节编码，不做规范化、不添加前缀空格、不执行 BPE 合并。

## 输入与输出

- `text`：长度为 0 到 300 的字符串，由 Python 3.12 / Unicode 15.0 已定义的合法 Unicode 标量组成；不含代理码点或未分配字符，后续 Unicode 版本新增字符不在范围内。
- 返回列表，每项为 `(byte_encoded_piece, start, end)`。
- `start`、`end` 是**原文的 Python 码点下标**，区间左闭右开，不是 UTF-8 字节偏移，也不是编码后字符串的下标。
- 非空片段按顺序连续覆盖原文；空原文返回 `[]`。

## 切分规则

以下正则是语义定义，分支有序、大小写敏感；实现必须使用标准库 `unicodedata.category` 和手写有序扫描器，而不是第三方正则库：

```text
's|'t|'re|'ve|'m|'ll|'d| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+
```

1. 小写缩写优先，但仅在当前扫描位置尝试。`'S` 不等于 `'s`。
2. `L` 是 Unicode category 以 `L` 开头的字符；`N` 是以 `N` 开头的字符，包括 `Nd`、`Nl`、`No`，不仅是十进制数字。
3. 组合标记、emoji、标点及其他非空白且非字母数字字符属于第三类。不要把组合标记自动并入字母。
4. 三类连续串前的可选空格只能是 ASCII `U+0020`，最多一个。标点串可以吞掉后续撇号，不能在串内重新开始匹配缩写。
5. 空白集合精确如下：

```text
U+0009–U+000D, U+0020, U+0085, U+00A0, U+1680,
U+2000–U+200A, U+2028–U+2029, U+202F, U+205F, U+3000
```

`U+001C–U+001F` 不属于此集合，因此不能用 `str.isspace()` 代替。走空白分支时，尾部空白整段匹配；内部连续空白长度大于 1 时，先取除最后一个以外的部分，让下一轮处理最后一个；内部孤立空白由最后一支匹配。

## 字节编码

每个原文片段先编码为 UTF-8，然后逐字节映射：

- 字节 `33–126`、`161–172`、`174–255` 保持为同数值 Unicode 字符。
- 其余字节按字节值升序，映射到 `U+0100` 开始的连续字符。

例如 ASCII 空格变成 `Ġ`，换行变成 `Ċ`。编码字符串只是字节的可逆表示，不是翻译后的文本。

## 示例 1：原文偏移

```python
text = '你好  café\n'
输出 = [('ä½łå¥½', 0, 2), ('Ġ', 2, 3), ('ĠcafÃ©', 3, 8), ('Ċ', 8, 9)]
```

`你好` 占 2 个原文码点，虽然其编码片段有 6 个字符。中间两个 ASCII 空格分别归入独立空白片段和后面的字母片段。

## 示例 2：大小写敏感的缩写

```python
text = "We're I'M can't"
输出 = [('We', 0, 2), ("'re", 2, 5), ('ĠI', 5, 7), ("'", 7, 8), ('M', 8, 9), ('Ġcan', 9, 13), ("'t", 13, 15)]
```

## 示例 3：标点分支的贪心行为

```python
text = "!!'s 's"
输出 = [("!!'", 0, 3), ('s', 3, 4), ("Ġ'", 4, 6), ('s', 6, 7)]
```

第一段吞掉撇号；第二处从空格开始，匹配的是“空格加标点”，两处都不会产生独立的 `'s` 缩写片段。

## 实现要求

只允许 Python 标准库。不得导入 `tokenizers` 或第三方 `regex`，不得把偏移转换成字节偏移。参考算法为线性有序扫描；无需实现完整 tokenizer。
