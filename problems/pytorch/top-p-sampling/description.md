# Top-p / 核采样（Nucleus Sampling）

## 题目描述

温度/Top-k 采样要么太散要么截断生硬。**核采样**（Holtzman et al. 2021）动态选取
「概率最大的、累积质量首次达到 `p` 的最小 token 集合」（核），只在核内重新归一化后采样——
分布尖锐时核小、平坦时核大，兼顾多样性与合理性。它是几乎所有 LLM 推理引擎的默认解码之一。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法（CDF）实现。

## 规则

- 实现 `solve(logits, p, u)`：`logits` 形状 `(..., K)`，`p∈(0,1]`，`u` 为每行一个、
  取值 $[0,1)$ 的均匀随机数（形状 `(...,)` 或标量）。
- 步骤：① `probs=softmax(logits)`；② 降序排序求累积和 `cumsum`；③ 保留到累积和**首次 ≥ p**
  的元素（至少留 1 个，判据 `cumsum - sorted_prob < p`）；④ 核内归一化，映射回原顺序得到
  `filtered`（核外置 0）；⑤ 用 `u` 在核内 CDF 上做逆变换采样，返回选中 token 的原始索引。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`、每行和为 1；`chosen` 形状 `(...,)`。

## 示例

```
输入：logits = [2, 1, 0.5, -1, -2]
  probs = [0.6027, 0.2217, 0.1345, 0.0300, 0.0110]
  降序累积和 = [0.6027, 0.8245, 0.9590, 0.9890, 1.0]
  p = 0.8 → 核 = 前 2 个（0.6027 与 0.2217；累积到 0.8245 才 ≥ 0.8）
  核内归一化 = [0.7311, 0.2689] → 映射回原顺序
  u = 0.05，核内 CDF=[0.7311,1.0]，首个 ≥0.05 是位置0 → 选中原始索引 0
输出：filtered = [0.7311, 0.2689, 0, 0, 0], chosen = 0
```

## 约束

- float32 输入；`p∈(0,1]`，`u∈[0,1)`
- `filtered` 每行和为 1 且核外为 0；`chosen` 必落在核内
