# PEFT：SuperTuning 稀疏标量支撑与 LoRA 混合——算法详解

## 1. 公式与出处

SuperTuning 出自 arXiv:2607.09287，核心观察是：大模型权重中通常只有少量元素需要被精细修正，而这些位置正好对应 \(|W_0|\) 的峰值。因此它把可训练更新 \(S\) 限制在 \(|W_0|\) 的 top-\(k\) 支撑上：

\[\Delta W = M_k(W_0)\odot S.\]

当再叠加一个 LoRA 旁路时，论文称此混合变体为 **Supra**：

\[\Delta W = M_k(W_0)\odot S + \frac{\alpha}{r}\,BA.\]

## 2. top-\(k\) 掩码的确定性

- 将 \(|W_0|\) 拉平后稳定降序排序（`stable=True`），并列元素按原始下标从小到大进入 top-\(k\)。
- 得到一个 0/1 掩码 \(M_k\)，形状与 \(W_0\) 相同。
- \(M_k\) 与 \(S\) 逐元素相乘，再与 \(W_0\)、LoRA 项相加。

## 3. 退化与判题考点

- \(k=0\)：掩码全零，只剩 LoRA 项（若 \(r>0\)）。
- \(r=0\)：忽略 \(A,B,\alpha\)，只剩稀疏标量项。
- \(\alpha=0\)：LoRA 项消失。
- \(S=0\)：稀疏标量项消失。
- 并列测试验证稳定排序下标小者优先。

## 4. 与现有题的分工

- `peft-lora-forward`/`peft-lora-merge`：纯 LoRA 更新。
- `sparsity-magnitude-prune`：按幅值丢弃权重（不可逆压缩）。
- 本题：按幅值选择可训练标量支撑，并可与 LoRA 混合；重点在掩码构造与混合合并。
