# Diffusion：SDEdit strength 的截断起止步

## 题目描述

SDEdit 用「加噪到某个中间时刻再往回采样」把编辑强度变成一个旋钮：强度 \(s\) 越大，破坏越多、离原图越远。给定一条按噪声级升序排列的累积乘积表 \(\bar\alpha_0>\bar\alpha_1>\dots>\bar\alpha_{T-1}\)，强度映射到起始索引

\[ i=\left\lfloor s\cdot(T-1)\right\rfloor,\qquad x_i=\sqrt{\bar\alpha_i}\,x_0+\sqrt{1-\bar\alpha_i}\,\epsilon \]

随后采样器只走 \(i\to i-1\to\dots\to0\) 这一段（共 \(i\) 步），这正是「截断起止步」的账。注意 \(\epsilon\) 必须是显式入参：本题只考强度→索引→加噪这一步，不现采随机数。

## 规则

给定 `x0`、同形状 `noise`、一维 `alpha_bars`（严格递减、元素在 \((0,1]\)）与强度 `strength∈[0,1]`，返回 `(x_noisy, i)`：`x_noisy` 为 float32 张量，`i` 为 int 起始索引（同时也是剩余的采样步数）。

## 示例

\[ \bar\alpha=[1.0,0.81,0.64,0.49,0.36],\ x_0=[1.0,-2.0],\ \epsilon=[0.5,1.0] \]

```
s=0.5 -> i=2, x_noisy=[ 1.100000, -1.000000]
s=1.0 -> i=4, x_noisy=[ 1.000000, -0.400000]
```

## 约束

- `alpha_bars` 必须一维、至少两项、严格递减且落在 \((0,1]\)；`x0` 与 `noise` 形状必须一致。
- `strength` 必须落在 \([0,1]\)；索引取 `floor` 而不是四舍五入，保证 \(s=1\) 恰好落到最噪的末档。
- **退化性质**：\(s=0\) 时 \(i=0\)，若 \(\bar\alpha_0=1\) 则输出逐位等于 \(x_0\)；\(s=1\) 时 \(i=T-1\)，结果等于整条前向链的最噪一档。
- 索引随强度单调不减；给定某个 \(x_i\) 反解出的 \(\epsilon\)，按对应强度回代必须精确还原 \(x_i\)。
