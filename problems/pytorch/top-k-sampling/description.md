# Top-k 采样

## 题目描述

模型输出的词表分布里，长尾 tokens 概率虽小却数量庞大，采样时容易蹦出胡言乱语。
**Top-k 采样**（Fan et al. 2018）是最朴素的截断法：只保留概率（等价于 logit）最高的
`k` 个 token，把它们重新归一化成一个新分布后再采样。它生硬地砍掉第 `k` 名之后的全部候选，
与模型置信度无关——这正是后来 top-p / min-p 想改进的地方。它仍是几乎所有推理引擎
（含 llama.cpp 的 `top-k`）默认管线的一环。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法（在保留分布的
> CDF 上取首个 $\ge u$ 的位置）。

## 规则

- 实现 `solve(logits, k, u)`：`logits` 形状 `(..., V)`，`k` 为整数（`k≥V` 时保留全部），
  `u` 为每行一个、取值 $[0,1)$ 的均匀随机数（形状 `(...,)` 或标量）。
- 步骤：① `probs = softmax(logits)`；② 保留 logit 最大的 `k` 个（并列时按原序取先出现的），
  其余置 0；③ 保留部分重新归一化得到 `filtered`（形状同 `probs`，每行和为 1）；
  ④ 用 `u` 在 `filtered`（原顺序）的 CDF 上逆变换采样，返回选中 token 的原始索引。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`，`chosen` 形状 `(...,)`。

## 示例

```
输入：logits = [2, 1, 0.5, -1, -2, -3]，k = 2，u = 0.9
  probs(softmax) = [0.600294, 0.220836, 0.133944, 0.029887, 0.010995, 0.004045]
  保留 top-2 = [0.600294, 0.220836]，其余置 0
  归一化（除以 0.821130）→ filtered = [0.731059, 0.268941, 0, 0, 0, 0]
  CDF = [0.731059, 1.0]，u = 0.9 → 首个 ≥0.9 是位置 1 → 选中原始索引 1
输出：filtered = [0.731059, 0.268941, 0, 0, 0, 0], chosen = 1
```

## 约束

- float32 输入；`k ≥ 1`；`u ∈ [0,1)`
- `filtered` 每行和为 1，且非 top-k 位置严格为 0；`chosen` 必落在保留集合内
- 支持批量 `(..., V)`；并列 logit 的取舍按原索引先后稳定处理
