# P-less 采样

## 题目描述

top-k / top-p / min-p 都需要人给一个超参（`k`、`p`），换模型就得重调。**P-less**
（Barber 等，arXiv:2509.23234）是一族**免超参**的截断法：阈值直接从分布自身算出，
不含任何可调旋钮。它的判据来自**碰撞概率**——随机按分布 $p$ 抽两次、两次落到同一个
token 的概率是 $\sum_i p_i^2$（即 Rényi-2 指数）。P-less 规定：一个 token 只有当自己的
概率**不小于这个碰撞概率**时才保留：

$$\text{keep}_i = \big[\; p_i \ge \textstyle\sum_j p_j^2 \;\big]$$

直觉：$\sum p^2$ 衡量分布「把质量集中在少数 token」的程度。分布越尖，碰撞概率越高，
门槛越苛刻，只留最靠前的几个；分布越平，碰撞概率低，留下的就多。截断后归一化再采样。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法（在保留分布的
> CDF 上取首个 $\ge u$ 的位置）。

## 规则

- 实现 `solve(logits, u)`：`logits` 形状 `(..., V)`，`u` 为每行一个、取值 $[0,1)$ 的
  均匀随机数（形状 `(...,)` 或标量）。**无其它超参**。
- 步骤（逐行）：① `probs = softmax(logits)`；② `thr = (probs**2).sum(-1, keepdim=True)`
  （碰撞概率 $\sum p^2$）；③ 保留 `probs >= thr`，其余置 0；④ 保留部分归一化 → `filtered`
  （形状同 `probs`，每行和为 1）；⑤ 用 `u` 在 `filtered`（原顺序）CDF 上逆变换采样得 `chosen`。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`，`chosen` 形状 `(...,)`。

## 示例

```
输入：logits = [1, 0.8, 0.6, 0.4, 0.2, 0, -0.2]，u = 0.7
  probs(softmax) = [0.240601, 0.196987, 0.161279, 0.132044, 0.108109, 0.088512, 0.072468]
  thr = Σ p² = 0.164913
  保留 p >= 0.164913 → 索引 {0, 1}（0.2406、0.1970；0.1613 < thr 被丢弃）
  归一化（除以 0.437588）→ filtered = [0.549834, 0.450166, 0, 0, 0, 0, 0]
  CDF = [0.549834, 1.0]，u = 0.7 → 首个 ≥0.7 是位置 1 → 选中原始索引 1
输出：filtered = [0.549834, 0.450166, 0, 0, 0, 0, 0], chosen = 1
```

## 约束

- float32 输入；`u ∈ [0,1)`；无策略超参
- `filtered` 每行和为 1，被丢弃位置严格为 0；`chosen` 必落在保留集合内
- 支持批量 `(..., V)`；argmax 恒被保留（其 $p_{\max}\ge\sum p^2$ 恒成立）
