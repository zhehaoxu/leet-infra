# 稀疏化：逐行（局部）幅值剪枝

## 题目描述

与「全局阈值」相对的是**局部（layer-wise / row-wise）剪枝**：稀疏预算在**每个输出神经元（矩阵的每一行）内部**独立分配，保证每一行都恰好剪掉相同比例，避免出现某些神经元被整体剪空、另一些几乎不动的失衡。这在保持层输出分布稳定时更常用。

给定形状 \((\text{out},\text{in})\) 的权重 `weight` 与稀疏率 `sparsity`，对**每一行**独立地把该行绝对值最小的 \(k=\mathrm{round}(\text{sparsity}\cdot \text{in})\) 个元素置零，其余保留。

## 规则

输入 `weight`（float32，2-D：\((\text{out},\text{in})\)）、标量 `sparsity \in [0,1]`。返回同形状 float32：每行内按绝对值升序剪最小的 \(k\) 个（各行 \(k\) 相同），并列时行内按列索引升序先剪。禁止 `torch.nn.utils.prune`。

## 示例

`weight=[[1,-5,3,-2],[0.5,9,-2,-8]]`、`sparsity=0.5`（每行 \( \text{in}=4, k=2 \)）：

```
行0 |w|=[1,5,3,2]，剪最小 2 个(1,2) → [0,-5,3,0]
行1 |w|=[0.5,9,2,8]，剪最小 2 个(0.5,2) → [0,9,0,-8]
out = [[0,-5,3,0],[0,9,0,-8]]
```

## 约束

- CPU float32；每行独立竞争本行预算（区别于全局题 sparsity-magnitude-prune 的跨行比较）。
- 每行保留数量相同 → 每行稀疏率都是 `sparsity`。
- 只改被剪位置为 0，未剪元素原值原符号不动。
