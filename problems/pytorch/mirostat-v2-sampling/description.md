# Mirostat v2 采样

## 题目描述

top-k / top-p 用固定阈值截断，但「该留多少候选」本应随模型当下的**不确定程度**变化。
**Mirostat v2**（Mirsky 等）把采样目标定为**控制困惑度**（perplexity）在设定值 $\tau$ 附近：
维持一个内部阈值 $\mu$，每次把「比 $\mu$ 更出人意料」的长尾 token 砍掉，再根据这次实际抽到的
token 的困惑度反馈来**调节 $\mu$**——若结果太意外（困惑高于 $\tau$）就收紧 $\mu$、下次砍更狠；
若太平庸就放宽 $\mu$、允许更多候选。这是一个带**状态**的闭环控制器。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入；状态 $\mu$ 既作输入也作输出返回。

## 规则

- 实现 `solve(logits, tau, eta, mu, u)`：`logits` 形状 `(..., V)`，`tau`（目标困惑度）、
  `eta`（学习率）、`mu`（当前阈值，浮点）为标量参数，`u` 为每行一个、取值 $[0,1)$ 的随机数
  （形状 `(...,)` 或标量）。
- 步骤（逐行）：
  1. `probs = softmax(logits)`。
  2. 按概率**降序**排，令每个候选的 surprisal $s_i = -\log_2 p_i$。找到**第一个** $s_i > mu$
     的位置 $k$，只保留降序前缀的前 $k$ 个（丢掉其后更意外的尾巴）；若首元素就 $s_0>mu$ 则
     至少保留 1 个（$size=\max(k,1)$）；一个都不越界则全保留。
  3. 保留集合重新归一化 → `filtered`（映射回原顺序，形状同 `probs`，每行和为 1）。
  4. 用 `u` 在 `filtered`（原顺序）CDF 上逆变换采样得 `chosen`。
  5. 观测困惑度 $\text{obs} = -\log_2(\text{filtered}[\text{chosen}])$，更新
     $$mu_{\text{new}} = mu - \eta\,(\text{obs} - \tau)$$
- 返回 `(filtered, chosen, mu_new)`。

## 示例

```
输入：logits = [2, 1, 0.5, -1, -2, -3]，tau = 5.0，eta = 0.1，mu = 4.0，u = 0.5
  probs = [0.600294, 0.220836, 0.133944, 0.029887, 0.010995, 0.004045]
  surprisal(-log2 p) = [0.736, 2.179, 2.900, 5.064, 6.507, 7.950]
  第一个 > mu(4.0) 的是索引 3 → 保留降序前 3 个（本就是索引 0,1,2），归一化
  filtered = [0.628532, 0.231224, 0.140244, 0, 0, 0]
  CDF = [0.628532, 0.859756, 1.0]，u = 0.5 → chosen = 0
  obs = -log2(0.628532) = 0.670434；mu_new = 4.0 - 0.1*(0.670434 - 5.0) = 4.433006
输出：filtered = [0.628532, 0.231224, 0.140244, 0, 0, 0], chosen = 0, mu_new = 4.433006
```

## 约束

- float32 输入；`tau > 0`、`eta > 0`；`u ∈ [0,1)`
- `filtered` 每行和为 1，被丢弃位置严格为 0；`chosen` 必落在保留集合内（≥1 个）
- `mu_new` 形状 `(...,)`（与行数一致；单行时为标量张量）
- 反馈方向：抽到的 token 越平庸（obs < tau）→ mu 上升、下次放宽；越意外 → mu 下降、收紧
