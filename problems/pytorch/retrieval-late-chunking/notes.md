# 详解：late chunking 与父子块扩展

## 出处

- Late chunking：Günther, Mohr, Williams, Wang, Xiao, *Late Chunking: Contextual Chunk Embeddings Using Long-Context Embedding Models*, arXiv:2409.04701, 2024。做法是先用长上下文编码器编码整篇文档，再对 token 向量按块池化，使块向量携带跨块上下文；本题的输入正是「已编码完的上下文化 token 向量」，不跑编码器。
- 父子块（small-to-big / parent document retrieval）是 RAG 的工程惯例：用小子块做检索、命中后返回父块给生成阶段；LangChain 的 `ParentDocumentRetriever` 是常见实现，但没有统一的学术论文出处，具体谱系**待回源**。本题按 starter docstring 的机制定义判题。
- 相邻背景：`retrieval-rag-chunk` 只产出滑窗 token 下标矩阵；`retrieval-mmr` 是重排；`retrieval-colbert-maxsim` 是 query-token × doc-token 的 MaxSim 打分；`retrieval-pq-codes` 是向量压缩编码。它们都不做 mask 内块池化与父块去重。

## 完整推导与下标约定

**mask 均值池化**：块 \(c\) 的区间是 \([s_c,e_c)\)，块向量为
\[
v_c=\frac{\sum_{t=s_c}^{e_c-1} m_t h_t}{\sum_{t=s_c}^{e_c-1} m_t},
\]
分母是**有效 token 数** \(\sum m_t\)，不是区间长度 \(e_c-s_c\)。实测：4 个 token 的向量为 \([1,0],[3,0],[5,0],[7,0]\)、mask 为 \([1,0,1,0]\) 时，整段均值是 \((1+5)/2=3\)，而不是 \((1+3+5+7)/4=4\)；把被 mask 的 token 也算进分母是最常见的错误。分母为 0（零长度块或全被 mask）时输出全 0。

**先池化、后归一化**：`normalize=True` 是对**块向量**做 L2 归一化，不是先归一化每个 token 再平均。两者一般不同：token \([3,0]\) 与 \([0,4]\) 先各自归一化再平均得到 \([0.5,0.5]\)，归一化后是 \([0.7071,0.7071]\)；先原始平均得到 \([1.5,2]\)，归一化后是 \([0.6,0.8]\)。late chunking 的语义是「上下文化 token 的均值」，所以必须先均值后归一化。零向量归一化后仍是 0。

**父块分组**：子块 \(c\) 的父块编号是整数除法 \(p=c\,//\,\text{parent\_size}\)，因此每 `parent_size` 个相邻子块一组，最后一组可以不满。父块区间是组内**首个子块的 start** 到**末个子块的 end**，即 \([s_{p\cdot ps},\ e_{\min((p+1)ps,C)-1})\)。注意它不是「命中子块自己的区间」，而是整组覆盖的范围：即使只命中组内最后一个子块，父块也从组内第一个子块开始。

**父块向量必须从 token 重算**：父块向量是在上述整段区间上再做一次同样的 mask 均值，而不是把子块向量平均。子块长度不等时两者差异很大。实测：两个子块分别为 \([0,1)\) 的 token \([2,0]\) 与 \([1,4)\) 的 token \([0,6],[0,2],[0,2]\)，子块原始均值为 \([2,0]\) 与 \([0,3.3333]\)，二者平均是 \([1,1.6667]\)；而父块 \([0,4)\) 的 token 均值是 \([0.5,2.5]\)。用子块向量平均会让短块与长块等权，语义上也不等价于「整段池化」。

**命中去重与映射**：所有命中先换成父块编号 \(p=h//ps\)，去重后按 \(p\) 升序输出，所以 `parent_bounds` 的顺序是原始子块顺序，而不是命中出现顺序。`hit_to_parent` 则严格按 `hit_chunks` 的输入顺序逐项给出父块行号，重复命中映射到同一行。示例 \(hits=[2,0,3,2]\) 得到父块编号 \([1,0,1,1]\)，去重升序为 \([0,1]\)，映射为 \([1,0,1,1]\)：4 次命中只产生 2 个父块。

**重叠**：子块边界允许滑窗重叠，父块区间取组内首 start 到末 end，因此相邻父块也可能重叠。示例的父块区间是 \([0,5)\) 与 \([4,7)\)，在 token 4 处重叠 1 个 token；两个父块各自独立池化，token 4 会在两个父块向量里各出现一次。不要对父块区间做并集或二次合并，否则 `parent_bounds` 与映射都会错。

**边界约定**：块可以零长度（\(s=e\)），输出全 0；块可以从 token 1 开始（前面 token 不参与任何块）；末块可以只到 \(L\)；`chunk_bounds` 的 start 必须非降序，但 end 可以任意（允许前一块比后一块长）。区间越出 \([0,L]\)、\(s>e\)、start 乱序都是 `ValueError`。

**空命中与空文档**：\(H=0\) 时父块输出形状 \((0,2)\)、\((0,D)\)、映射 \((0,)\)，`chunk_vecs` 照常返回；\(C=0\) 时 `chunk_vecs` 形状 \((0,D)\)，任何命中都越界；\(L=0\) 时所有块只能是 \([0,0)\) 或不存在。这些都不应产生 NaN。

## 核心与易错点

1. **分母是有效 token 数**：mask 为 0 的 token 既不进分子也不进分母；用区间长度做分母会把 padding 摊进均值。
2. **先均值后归一化**：对块向量归一化，不是先归一化 token 再平均；零向量归一化后保持 0。
3. **全 mask / 零长度块输出显式 0**：不能跳过该块导致行数变少，也不能除零得到 NaN。
4. **父块向量从 token 重算**：不是子块向量的平均；子块长度不等时两者差异显著（实测 \([1,1.6667]\) vs \([0.5,2.5]\)）。
5. **父块区间取整组范围**：从组内第一个子块 start 到最后一个子块 end，而不是命中子块自身的区间。
6. **去重按父块编号、升序输出**：`parent_bounds` 不与命中顺序对齐；对齐的是 `hit_to_parent`。
7. **映射保持输入顺序与重复**：同一个父块内多次命中映射到同一行，不能把 `hit_to_parent` 也去重。
8. **重叠父块不合并**：滑窗重叠时父块区间可以重叠，每个父块独立池化；做并集会改变行数与区间。
9. **边界与错误面**：零长度块、首块不从 0 开始、触尾块都合法；越界、\(s>e\)、start 乱序、命中越界、`parent_size<1` 才是 `ValueError`。
10. **dtype**：块向量/父块向量跟随 `token_emb`（float64 判题用 \(10^{-12}\)）；区间与映射恒 int64。

## 与邻近题的区别

- **vs `retrieval-rag-chunk`**：那题只输出重叠滑窗的 **token 下标矩阵**，不涉及向量、mask、池化或父块；本题的输入已经是 token 向量，输出块向量与父块结构。
- **vs `retrieval-mmr`**：MMR 在候选文档集合上做**重排**；本题不排序文档，只把命中子块扩展到父块。
- **vs `retrieval-colbert-maxsim`（同批次）**：那题是 query 侧对文档 token 做 MaxSim 打分、比较重复计分与只计一次；本题是文档侧把 token 池化成块向量，再做层级（子块 → 父块）扩展，没有 query 也没有余弦。
- **vs `retrieval-pq-codes`**：PQ 把向量压成码本下标；本题保留浮点块向量，不量化。
- **vs `global-pooling` / `adaptive-avgpool`**：那些是规则网格上的均值/最大池化，没有 attention mask、变长区间与父子层级；本题的池化区间由外部边界给出且分母随 mask 变化。
- **vs `powernorm-attention-pool`**：那是带可学习/注意力权重的池化；本题是确定性的 0/1 mask 均值。

## 对拍口径与复杂度

- **主 oracle**：`_oracle` 纯 Python 逐块、逐 token 累加（`while t < e`，只累加 mask 非 0 的 token），再独立做归一化；父块按 `h // parent_size` 分组后用同样的逐 token 路径**重算**，映射用字典构造。它与参考实现的张量切片 + `unsqueeze` 乘法路径结构不同。覆盖：示例、重叠滑窗、块间留空隙、零长度块、全 mask 块、首块不从 0 开始、触尾块、`parent_size` 大于块数、`normalize=False`、bool mask、\(L=0\)、float64。
- **显式判别用例**：mask 参与均值（3 而非 4）、全 mask 块为 0 且无 NaN、空命中的三种空形状、重叠父块区间 \([0,6)\) 与 \([5,10)\) 及 5 次命中只出 2 个父块、同父块重复命中只占一行、`parent_size=1` 的升序重排、单父块时区间覆盖首 start 到末 end、float64 的 \(10^{-12}\) 对拍、多类 `ValueError`。
- **复杂度**：设子块区间长度之和为 \(S_c\)、被命中父块区间长度之和为 \(S_p\)，时间为 \(O((S_c+S_p)D + C + H)\)，空间为 \(O((C+P)D)\)；滑窗重叠会让 \(S_c,S_p\) 大于 \(L\)，但判题规模很小。实现路径不限，但均值分母、池化顺序与父块重算口径必须一致。
