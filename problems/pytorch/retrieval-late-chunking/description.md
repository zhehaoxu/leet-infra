# 检索：late chunking 与父子块扩展

## 题目描述

**Late chunking**（Günther et al., 2024）先让长上下文编码器把整篇文档编码成上下文化的 token 向量，**再**按块池化；这样每个块的向量都带着跨块上下文，缓解「先切块、再独立编码」造成的语义割裂。本题不跑编码器，输入就是已经编码好的 token 向量、attention mask 与子块边界：先做 mask 内均值池化得到块向量，再实现检索侧的**父子块扩展**——命中的是细粒度子块，返回时把它所在的父块（相邻 `parent_size` 个子块合并而成）去重后输出，让生成阶段拿到更完整的上下文。

两处口径决定成败：均值池化的分母是**有效 token 数**而不是区间长度；父块向量必须在合并后的整段区间上**重新按 token 池化**，而不是把子块向量再平均（子块长度不等时两者不同）。子块滑窗重叠时，相邻父块区间也可以重叠。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- **输入**：`token_emb` 为 \((L,D)\) 浮点张量；`attention_mask` 为 \((L,)\)，非 0 表示有效 token；`chunk_bounds` 为 \((C,2)\) 整型，每行 \([s,e)\) 是一个子块，按 \(s\) 非降序给出，允许块间重叠、留空隙、零长度块（\(s=e\)）与尾块不足，但必须 \(0\le s\le e\le L\)；`hit_chunks` 为 \((H,)\) 整型命中下标，允许重复、允许为空；`parent_size` 为不小于 1 的整数；`normalize` 默认 True。
- **块池化**：块 \(c\) 的向量为
  \[ v_c=\frac{\sum_{t=s_c}^{e_c-1} m_t\,h_t}{\sum_{t=s_c}^{e_c-1} m_t}, \]
  其中 \(h_t\) 是第 \(t\) 个 token 向量、\(m_t\in\{0,1\}\) 是 mask。分母为 0（零长度块或全被 mask 掉）时 \(v_c\) 记全 0，不抛错。`normalize=True` 时再对 \(v_c\) 逐行做 L2 归一化，零向量保持 0；`normalize=False` 时直接返回上述均值。
- **父块**：子块 \(c\) 属于父块 \(p=c\,//\,\text{parent\_size}\)，即每 `parent_size` 个相邻子块一组。父块区间取组内**首个子块的 start 到末个子块的 end**，是一个闭开区间；父块向量在同一区间上按同样的 mask 均值口径**从 token 重算**（不是子块向量的平均），并同样受 `normalize` 控制。
- **命中去重**：只输出被命中的父块。父块按 \(p\) 升序输出（即原始子块顺序），同一父块内的重复命中只占一行；同时返回每个命中子块到父块行号的映射，映射**保持 `hit_chunks` 的输入顺序与重复**。
- **重叠**：子块边界允许重叠（滑窗），因此相邻父块区间也可能重叠；每个父块独立池化，**不要**把重叠父块做区间并集或再次合并。
- **空命中**：\(H=0\) 时父块区间形状 \((0,2)\)、父块向量 \((0,D)\)、映射为空；`chunk_vecs` 仍完整返回。
- **错误约定**：`token_emb` 非二维或非浮点、`attention_mask` 长度不符、`chunk_bounds` 形状不是 \((C,2)\) 或非整型、区间越出 \([0,L]\) 或 \(s>e\)、`chunk_bounds` 的 start 乱序、`hit_chunks` 非一维/非整型/越出 \([0,C)\)、`parent_size<1`，均抛 `ValueError`。
- **dtype**：块向量与父块向量跟随 `token_emb` 的浮点 dtype；区间与映射恒为 int64。全程确定性、不调用随机数。

## 示例

`token_emb`（7 个 token，2 维）、mask 与 4 个子块如下：

```
t:      0        1        2        3        4        5        6
emb:  [1,0]   [0,2]   [1,1]   [2,0]   [0,1]   [1,3]   [0,0]
mask:   1        1        0        1        1        1        0
bounds: [0,3) [2,5) [4,6) [5,7)     parent_size = 2
hits:   [2, 0, 3, 2]
```

块池化（只统计 mask 非 0 的 token，再 L2 归一化）：

| 块 | 区间 | 有效 token | 均值 | 归一化块向量 |
|---|---|---|---|---|
| 0 | [0,3) | 0, 1 | [0.5, 1] | [0.4472, 0.8944] |
| 1 | [2,5) | 3, 4 | [1, 0.5] | [0.8944, 0.4472] |
| 2 | [4,6) | 4, 5 | [0.5, 2] | [0.2425, 0.9701] |
| 3 | [5,7) | 5 | [1, 3] | [0.3162, 0.9487] |

命中 `[2,0,3,2]` 对应的父块编号是 \(2//2=1,\ 0//2=0,\ 3//2=1,\ 2//2=1\)，去重后按升序只有父块 0 与 1：

- 父块 0 覆盖子块 0、1，区间 \([0,5)\)，有效 token 0、1、3、4，均值 \([0.75,0.75]\)，归一化 \([0.7071,0.7071]\)；
- 父块 1 覆盖子块 2、3，区间 \([4,7)\)，有效 token 4、5，均值 \([0.5,2]\)，归一化 \([0.2425,0.9701]\)。

于是 `parent_bounds = [[0,5],[4,7]]`（两段在 token 4 处重叠）、`hit_to_parent = [1,0,1,1]`。4 次命中只产生 2 个父块，重复命中的子块 2 只计一次；映射的第 0、2、3 项都指向父块行 1。

## 约束

- 返回四元组：全部子块向量、被命中父块的 token 区间、对应父块向量、命中子块到父块行号的映射。
- 区间与映射用 `torch.equal` 判定，浮点值 float32 容差 \(10^{-5}\)、float64 容差 \(10^{-12}\)。
- \(0\le s\le e\le L\)、`parent_size` \(\ge 1\)；允许 \(L=0\)、\(C=0\)、空命中。
- CPU、确定性、不使用随机数；均值分母必须是有效 token 数，全 mask 块与零长度块输出显式 0。
