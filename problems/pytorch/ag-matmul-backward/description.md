# matmul/linear 反向：dX 与 dW 的转置和广播账

## 题目描述

`Y = X @ W.T` 就是 `nn.Linear` 的前向，它的反向是任何框架里被调用次数最多的 kernel。规则只有两条：dX 是「上游梯度再乘一次权重」，dW 是「上游梯度转置后乘输入」——难的是**维度账**：当输入带多个前导 batch 轴时，dW 必须把所有前导轴折叠后求和，写成单个 \((M,N)^T @ (M,K)\) 就漏掉了这份累加。本题给你 `dY`、`X`、`W`，要求返回 `(dX, dW)`。

## 规则

- 完整签名与参数含义只写在 starter 的 docstring 里，那是唯一判题口径。
- `dX = dY @ W`，形状 `(..., M, K)`；`dW = Σ_b dY_b.T @ X_b`，形状 `(N, K)`，与 `W` 同形。
- `dY` 与 `X` 的前导轴必须完全一致（不允许靠广播蒙过去），`W` 必须恰好二维。
- `M = 1` 或存在零尺寸轴时按同一公式退化处理，不得特殊返回零。
- 内部用 float64 累计，`dX`/`dW` 的 dtype 分别与 `X`/`W` 相同；形状不符一律抛 ValueError。

## 示例

`X:(2,2)`、`W:(3,2)`、`dY:(2,3)` 全 1，数值取自 test_cases.py 的 EXAMPLE_* 常量：

```
dY = [[1, 1, 1],      X = [[1, 2],      W = [[1, 0],
      [1, 1, 1]]          [3, 4]]          [2, 1],
                                          [0, 3]]
dX = dY @ W          = [[3, 4],          dW = dY.T @ X = [[4, 6],
                                            [3, 4]]                      [4, 6],
                                                                         [4, 6]]
```

`dX` 每格是 `W` 三列方向之和（\(1+2+0=3\)、\(0+1+3=4\)）；`dW` 每行是 \(1\cdot1+1\cdot3=4\)、\(1\cdot2+1\cdot4=6\)。

## 约束

- 支持任意多个前导轴（3-D、4-D 输入）与负数步长无关的连续内存假设；与 `torch.autograd.grad((X @ W.T), (X, W))` 对拍
- float64 用例 atol=1e-10、float32 用例 atol=1e-5；`dW` 的 batch 折叠必须与 autograd 逐位一致
