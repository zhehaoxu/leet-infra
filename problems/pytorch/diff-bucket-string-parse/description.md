# 训练数据：分辨率分桶字符串的解析与校验

## 题目描述

多分辨率训练要给每张图挑一个「桶」（`height, width` 的尺寸对），桶清单常以命令行字符串的形式给出，例如 `--bucket "1024,1024; 768,1344"`。训练脚本必须在开跑前把这段配置解析成尺寸列表：格式不合规要立刻报错，尺寸与 VAE 的 8 倍下采样不对齐则只发警告。本题实现这个解析器。

## 规则

输入 `buckets_str`，输出按输入顺序排列的 `[(height, width), ...]`：

- 非字符串、空串都抛 `ValueError`；只含空白的字符串在切分后得不到任何合法桶，同样抛 `ValueError`。
- 先对整体做 `strip`，再按 `;` 切分；每一段必须**完整匹配** `^\s*(\d+)\s*,\s*(\d+)\s*$`：只认十进制数字字符，逗号两侧与段首尾允许空白，多一个逗号、负号、加号、小数点、科学计数法或 `512x768` 这类分隔符都抛 `ValueError`。
- 两段转成 `int` 后必须为正：`0` 也非法。这类错误的消息形如 `Invalid integer in bucket pair '0,0': Bucket dimensions must be positive integers.`。
- 任一边不能被 8 整除时**只发一条** `warning`（消息里包含 `not divisible by 8`），桶仍然保留。警告是按桶发的，两条边都不合规也只有一条。
- 结果保持输入顺序，重复桶不合并，元素是 `(int, int)` 元组。

## 示例

```
输入：solve("1024,1024; 768,1344; 1344,768")
输出：[(1024, 1024), (768, 1344), (1344, 768)]

输入：solve("  512 , 768 ;  256 ,256 ")
输出：[(512, 768), (256, 256)]

输入：solve("512,512;16,16;512,512")
输出：[(512, 512), (16, 16), (512, 512)]
```

`"500,1008"` 返回 `[(500, 1008)]` 并发一条警告（500 不是 8 的倍数）；`"3,5"` 也只发一条警告，因为警告的粒度是桶而不是边。

## 约束

- 分隔符只有 `;`，段内分隔符只有 `,`；`|`、换行、空格都不是分隔符。
- 段首尾的换行会被整体 `strip` 去掉，因此 `"512,768\n"` 是合法的。
- 不接受 `None` 或数字等非字符串输入。
- 任何解析或校验失败都抛 `ValueError`；不能整除 8 只警告、不报错。
