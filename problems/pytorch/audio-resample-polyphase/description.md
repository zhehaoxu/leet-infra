# 音频前端：整数比多相重采样

## 问题

语音模型前端的采样率是被钉死的（Whisper 16 kHz、部分声学模型 8 kHz），而输入可能来自 44.1 kHz 的麦克风或 48 kHz 的录屏。**整数比重采样**是最常用的一档：目标采样率 / 源采样率 = `L / M` 两个小整数之比（16k → 48k 是 3/1，16k → 24k 是 3/2）。

朴素做法是「先插零上采样 L 倍、再低通滤波、再每 M 个取一个」，但插零之后 `L-1` / `L` 的样本是 0，完整卷积里绝大多数乘加都是乘 0。**多相分解**把滤波器按相位切成 `L` 组，每组只在有数据的时刻参与运算，把每输出点的乘加从 `taps` 降到 `taps / L`：

```
y[m] = Σ_n x[n] · h(m·M - n·L)
```

`h` 是按「上采样后栅格」设计的 windowed-sinc 低通，中心偏移 `c = (taps-1)/2`，要求 `|m·M - n·L| <= c`。

三个容易错的常数：

- **截止频率**：`fc = 0.5 / max(L, M)`（单位是「每上采样样本的周期数」）。取 `L` 与 `M` 的较大者，才能同时挡住上采样的镜像和下采样的混叠。
- **原型滤波器增益**：归一化到 `Σh = L`，这样每个相位的系数和都等于 1，常数信号原样重建。
- **输出长度**：`out_len = ((T-1)·L) // M + 1`，只输出「主样本落在信号内」的那些点，边界外按 0 处理（不补边）。

## 任务

实现 `solve(x, up, down, taps=63, beta=8.0)`：

- 输入：`x` `(T,)`；`up = L`、`down = M` 为正整数；`taps` 为 `>= 3` 的奇数（原型滤波器长度）；`beta` 为 Kaiser 窗参数。
- 原型：`fc = 0.5 / max(up, down)`，`h(j) = 2·fc·sinc(2·fc·j) · kaiser(taps, beta)[j+c]`，`j = -c … c`，再缩放使 `Σh = up`。
- 输出：`y[m] = Σ_n x[n]·h(m·down - n·up)`，只累加 `|m·down - n·up| <= c` 的项；`out_len` 如上。
- 返回 `(out_len,)` float32，内部 float64。

## 示例

```
x = [1.0, 0.5, -0.5, 0.25]，taps = 7（c = 3），beta = 5

up = 2, down = 1（2 倍上采样，输出 7 点）
[1.014410, 0.754998, 0.507205, -0.009878, -0.507205, -0.129126, 0.253602]

up = 1, down = 2（2 倍下采样，输出 2 点）
[0.631391, -0.065841]

默认 taps = 63 时，上采样的偶数位恰好还原原信号：
[1.0, 1.082523, 0.5, -0.256106, -0.5, -0.145531, 0.25]
```

## 约束

- **相位对齐**：核的中心在 `j = 0`，所以 `m·down ≡ 0 (mod up)` 的输出点正好落在原始样本上，其余点才是插值。忘了减掉 `c` 会让偶数位与奇数位的增益互补地错开，常数信号会剧烈起伏。
- **截止频率用 `max(up, down)`**，不是 `down / up` 之类的比例；用错会让下采样时混叠、上采样时镜像。
- **`Σh = up` 而不是 1**：每个相位的系数和才等于 1。归一化到 1 会让输出整体小 `up` 倍。
- **不补边**：边界外按 0 处理，所以首尾各有约 `c / up` 个点的瞬态，这是参考实现的既定口径（不是 bug）。
- **`taps` 必须是奇数**：中心才落在整点上，`c` 的整除关系才干净。
- **非法输入抛 `ValueError`**：非一维、`up/down < 1`、`taps` 为偶数或小于 3、`beta < 0`、`x` 为空。
