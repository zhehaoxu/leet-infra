# 解题说明 · 多相重采样

## 从「插零 + 卷积 + 抽取」到多相

朴素流程是三步：上采样 `L` 倍（插入 `L-1` 个零）、与低通核卷积、每 `M` 个取一个。数学上完全正确，但有两处浪费：

- 卷积时 `L-1` / `L` 的输入是 0，绝大多数乘加都白做。
- 真正需要的只有被抽取的那 `1/M` 个输出。

把这两处浪费合起来看，第 `m` 个输出点只与「下标使 `m·M` 附近」的那些 `x[n]` 有关：

```
y[m] = Σ_n x[n] · h(m·M - n·L)
```

`h` 的下标是「上采样栅格」上的有符号偏移，`n` 只需取到让 `m·M - n·L` 落进 `[-c, c]` 的那些。按 `m·M mod L` 把核切成 `L` 组，每组长度约 `taps / L`——这就是「多相」这个名字的来源。

## 截止频率为什么是 0.5 / max(L, M)

`h` 定义在「上采样后」的栅格上，那里 Nyquist 是 0.5（单位：每样本周期数）。两种失真各给一个上限：

- 上采样会引入 `L-1` 个镜像，落在原信号频带 `[0, 0.5/L]` 之外，所以 `fc <= 0.5 / L`。
- 下采样要求抽取前把带宽压到 `0.5 / M`，所以 `fc <= 0.5 / M`。

同时满足就是 `fc = 0.5 / max(L, M)`。若按 `down / up` 之类的比例去算，总有一侧留出通带外能量：上采样时听到「金属音」，下采样时听到混叠的「嘶声」。

## 相位对齐：中心偏移 c

数组下标 `j ∈ [0, taps)` 对应有符号偏移 `j - c`，`c = (taps-1)/2`（`taps` 必须是奇数，`c` 才是整数）。取系数时下标是 `m·M - n·L + c`。

漏掉 `+ c` 的后果很隐蔽：`m·M ≡ 0 (mod L)` 的输出点（正好落在原样本上）整体平移 `c` 个样本，偶数位与奇数位朝相反方向偏，常数信号出现剧烈起伏，而脉冲响应看上去「只是有点怪」。判题里的常数增益检查就是为了抓这个。

## Σh = L 而不是 1

每个相位只是 `h` 的一个子集。若归一化到 `Σh = 1`，每个相位的和是 `1/L`，输出整体缩小 `L` 倍。归一化到 `Σh = L`，每个相位才恰好和为 1，常数输入 → 常数输出。

截断的 sinc 不是理想低通，这个和会有千分之几的纹波：`taps = 63` 时约 0.7%，加长 `taps` 可以继续压低。

## 输出长度与边界

`out_len = ((T-1)·L) // M + 1`：只输出「主样本 `m·M / L` 落在 `[0, T-1]` 内」的点，这样上采样后的最后一点正好对应原信号最后一点。信号之外一律按 0 处理、不补边，于是首尾各有约 `c / L` 个点带瞬态。

生产实现（如 `scipy.signal.resample_poly`）默认做边缘延拓来消掉这个瞬态；本题刻意选「零延拓」，因为它的行为唯一、可逐元素复现。

## 复杂度

朴素做法在上采样长度 `T·L` 上做全卷积，O(T · L · taps)。多相实现每个输出点只碰 `taps / L` 个样本，输出 `T·L/M` 个点，合计约 O(T · taps / M)——**与 L 无关**：上采样比值再大也不增加计算量，两个浪费同时被消掉，整体加速比约 `L·M`。
