# 推测解码：每位置多候选的批量验证与残差采样

## 题目描述

教科书式推测采样（Leviathan/Chen，arXiv:2211.17192 / 2302.01318）每个草稿位置只验证**一个** token；当 draft 侧能一次产出多个候选（多 draft 头、n-gram 库、beam 扩展——SpecInfer 的 token tree 每层正是并列多节点，arXiv:2305.09781）时，每个位置应该**并列**验证 \(C\) 个候选、先到先得，让"至少收一个"的概率显著上升。本题实现多候选推测解码（MCSD）的单次迭代：\(\gamma\) 个位置、每位置 \(C\) 个候选、批量验证 + 残差采样。

核心机制：位置 \(j\) 的局部状态从 \(P[j]\)、\(Q[j]\) 出发；依次尝试候选 \(i\)，接受概率 \(\mathrm{ratio}=\min(1,p[x]/q[x])\)（\(u\le\text{ratio}\) 即接受，**取等也算**）；拒绝则把残差分布更新为 \(\mathrm{norm}(\max(p-q,0))\)（可选**不放回**：把被拒候选的 draft 质量从局部 \(q\) 中剔除再归一化），残差被同位置**后续候选继续沿用**；\(C\) 个全被拒时该位置**当场终止**，末位 token 从**当前残差**采样，之后的位置不再验证。全 \(\gamma\) 个位置都收下时从 \(P[\gamma]\) 采一个 bonus token。随机性以显式均匀数 `u`、`u_end` 注入。CPU、全程无随机数调用。

## 规则

- 完整签名、参数含义与空输入约定只写在 starter 的 docstring 里，那是唯一判题口径。入参：`P` (g+1, V) 目标分布（第 \(g\) 行是 bonus 行）、`Q` (g, V) draft 分布、`cand` (g, C) 候选 id、`u` (g, C) 接受硬币、`u_end` 标量收尾均匀数、`no_replace` 0/1 开关。
- **逐位置顺序执行**（位置 \(j\) 的局部 \(p,q\) 初始化为 \(P[j]\)、\(Q[j]\) 的副本）：
  1. 依次尝试 \(i=0..C-1\)，\(x=\text{cand}[j][i]\)：\(q[x]>0\) 时 \(\text{ratio}=\min(1,p[x]/q[x])\)；\(q[x]=0\) 时按 \(p[x]>0\) 记 **1（必收）**、\(p[x]=0\) 记 **0**（此时仅 \(u=0\) 才收）。**每个尝试都计一次 trial**（被拒的也算）。
  2. \(u[j][i]\le\text{ratio}\)：输出 \(x\)、`picks[j]=i`、进入位置 \(j+1\)；**残差与 \(q\) 的修改不跨位置传递**。
  3. 拒绝：**按序两步**——先 \(p\leftarrow\mathrm{norm}(\max(p-q,0))\)（逐元素相减、截负、除以总和；总和为 0 则 \(p\) 保持原样）；若 `no_replace=1` 再 \(q[x]\leftarrow0\)、\(q\leftarrow\mathrm{norm}(q)\)（剔除后和为 0 则不归一化）。被拒过的 token 在新 \(p\) 里质量必然归零，`cand` 里重复出现它也绝不会再被接受。
  4. \(C\) 个候选全拒：`picks` 记 \(-1\)，输出在位置 \(j\) 终止，末位 token 从**当前残差**（已更新至多 \(C\) 次）按 CDF 反查取得，**之后位置一律不再验证**（不产生 token 也不产生 trial）。
- **CDF 反查** `cdf(d, w)`：返回**最小**下标 \(k\) 使前缀和**严格大于** \(w\)；全部前缀和 \(\le w\) 时兜底取 \(V-1\)。收尾 token（残差或 bonus）用 `u_end`。
- **返回 `(out, picks, trials)`**：`out` 是 long 一维张量（长度 = 被接受位置数 + 1，末位恒为收尾 token）；`picks` 逐位置记录胜出候选下标（耗尽时最后元素为 −1，此时 \(\text{len(out)}=\text{len(picks)}\)；无耗尽时 \(\text{len(out)}=\text{len(picks)}+1\)）；`trials` 为接受判定总次数（\(\le g\cdot C\)，被截断位置之后的候选不计）。
- 空输入：\(g=0\) 时退化为普通解码，输出 `[cdf(P[0], u_end)]`、`picks` 为空、`trials=0`；\(C=0\)（\(g>0\)）等价于位置 0 当场耗尽。
- 全程确定性；不许调用任何随机数发生器。

## 示例

主示例（\(\gamma=2,C=3,V=4\)，全部取值是 1/16 的整数倍、逐位精确）：

\[P=\begin{bmatrix}0.5&0.125&0.25&0.125\\0.125&0.625&0.125&0.125\\0.25&0.25&0.25&0.25\end{bmatrix},\quad
Q=\begin{bmatrix}0.5&0.25&0.125&0.125\\0.25&0.25&0.25&0.25\end{bmatrix},\quad
\text{cand}=\begin{bmatrix}1&2&0\\0&0&2\end{bmatrix},\]
\[u=\begin{bmatrix}0.75&0.25&0.0\\0.75&0.5&0.25\end{bmatrix},\quad u_{\text{end}}=0.9,\quad \text{no\_replace}=0.\]

- 位置 0：候选 1 的 \(\text{ratio}=0.125/0.25=0.5\)，\(u=0.75>0.5\) 拒绝 → 残差 \(p=[0,0,1,0]\)；候选 2 的 \(\text{ratio}=1/0.125>1\Rightarrow1\)，\(u=0.25\le1\) **接受** → `picks[0]=1`，输出 token 2（trials=2）。
- 位置 1（全新 \(p,q\)）：候选 0 的 \(\text{ratio}=0.125/0.25=0.5\)，\(u=0.75\) 拒 → 残差 \(p=[0,1,0,0]\)；候选 0 再次出现（\(p[0]=0\)）\(\text{ratio}=0\)，\(u=0.5\) 拒；候选 2 的 \(p[2]=0\Rightarrow\text{ratio}=0\)，\(u=0.25\) 拒（trials=5）→ 全拒，`picks=[1,-1]`，末位从残差 \(p=[0,1,0,0]\) 以 \(u_{\text{end}}=0.9\) 反查 → token 1。
- 结果：`out=[2,1]`、`picks=[1,-1]`、`trials=5`。

对照示例（\(\gamma=1\)，同一数据下放回/不放回的分歧）：候选 0（\(p[0]=0\)）必拒；`no_replace=0` 时 \(q\) 不动，候选 1 的 \(\text{ratio}=0.5\)、\(u=0.375\) 接受 → `out=[1,2]`（2 是 \(u_{\text{end}}=0.5\) 在均匀 bonus 行上的反查）、`picks=[1]`、`trials=2`；`no_replace=1` 时候选 0 的 draft 质量被剔并重归一（\(q[1]\) 从 0.25 变 0.5），候选 1 的 \(\text{ratio}\) 掉到 0.25、\(u=0.375\) 拒 → 候选 2 必收 → `out=[2,2]`、`picks=[2]`、`trials=3`。边界：\(u[0][1]=0.5\)（恰踩 ratio）仍接受，\(0.5625\) 则落到候选 2。

## 约束

- \(0\le u\le1\)、\(0\le u_{\text{end}}\le1\)；`cand` 候选可重复、\(C\) 可为 0；`g` 可为 0
- 全部输出与独立重算逐步一致（`out`/`picks` 用 `torch.equal`，`trials` 用整数相等）；260 组随机参数全网格对拍
- 三个判别口径评测直接断言：\(C=1\) 时逐位塌回**教科书式拒绝采样**（接受 \(u\le\min(1,p/q)\)、拒绝从 \(\mathrm{norm}(\max(p-q,0))\) 收尾——与 `inf-spec-decoding-rejection` 的口径互为印证）；\(u\) 恰踩在 ratio 上时**取等接受**；`no_replace` 只影响同位置内后续候选的分母（不改变 \(p\) 的更新、不跨位置）
