## 从专家路由推导网络负载

对源 rank \(r\) 的每个专家 \(e\)，目标 rank 固定为 \(q=e\bmod W\)。把对应 token 数累加到 \(S_{rq}\)，就得到发送计数。接收方视角交换源和目标，因此 \(R_{qr}=S_{rq}\)。专家数量不必整除 \(W\)，也允许某些 rank 不持有专家。

计数矩阵保留本地路由以描述完整 token 去向，但网络字节只来自 \(q\ne r\)。rank \(r\) 的网络发送 token 数是行和减去 \(S_{rr}\)，网络接收 token 数是列和减去 \(S_{rr}\)。相加再乘每 token 字节数，得到

\[
B_r=b\left(\sum_q S_{rq}+\sum_q S_{qr}-2S_{rr}\right).
\]

因此全局守恒关系为 \(\sum_r B_r=2b\sum_{r\ne q}S_{rq}\)。这里的 2 来自发送端与接收端都记负载，并不表示执行了 dispatch 和 combine 两次通信。本地计数即使很大，也不会改变任何 rank 的网络负载。

## 不均衡度、带宽与精度

令 \(M\) 是最大负载，\(\mu\) 是所有 rank 的平均负载，包含零负载 rank。不均衡度 \(M/\mu-1\) 在均匀时为零；全零时直接定义为零，避免除零。例如四个 rank 中只有 `0 -> 1` 有流量，负载为 `[x, x, 0, 0]`，不均衡度为 1，而不是把空闲 rank 从均值中删去。

计数和字节账使用 int64。参考实现用 float64 求均值，不能先转成 float32：例如两个相同的负载 \(2^{24}+1\) 经 float32 舍入后，会错误地产生非零不均衡度。最终两个指标是浮点数，仍受 float64 的表示精度限制。

带宽约定为每 rank 网络发送加接收的总字节/秒，单次 dispatch 的耗时估计为最大负载除以此带宽。每 token 字节数乘 \(k\) 时字节和耗时乘 \(k\)，不均衡度不变；带宽乘 \(k\) 时耗时除以 \(k\)。不得替换为全双工 `max(send, receive)` 或另加一次 combine。

## 约束与边界

starter 规定合法输入为非负 int64 路由张量，\(W\ge1\)、\(E\ge0\)，正的每 token 字节数与有限正带宽；计数及中间整数运算必须能用 int64 表示。这里按合法输入计算，不要求实现额外的非法输入校验。\(E=0\) 表示没有专家路由，仍返回完整的零计数矩阵。

\(W=1\) 时所有路由均为本地；全本地或全零路由时，网络字节、最大值、不均衡度和耗时都为零。非对称路由不能假设发送量等于接收量，但接收计数仍严格等于发送计数的转置。输出张量保持输入设备。

## 复杂度与独立验证

参考实现对每对源/目标 rank 扫描专家掩码，时间为 \(O(W^2(E+1))\)，包含输出矩阵初始化及后续归约；空间为 \(O(W^2+E)\)，不含输入。若改为按专家直接累加或 scatter，可将时间降为 \(O(WE+W^2)\)，但不是本题语义要求。

独立测试按源 rank 和专家逐项遍历，直接把每条非本地路由的字节加到两个端点，而不是从发送矩阵的行列和复制参考公式。测试还覆盖奇数专家数、专家少于 rank、非连续张量、全本地、非对称、跨 rank straggler、大整数均值和字节/带宽缩放。

## 简化模型与真实系统的边界

本题仅是单次 dispatch 的载荷账本，不执行真实集合通信。忽略专家计算及其延迟、通信启动延迟、元数据、网络拓扑和链路竞争；不模拟 token 丢弃或专家容量限制，也不计反向 combine。`e % W` 是题目固定的专家放置规则，不是对所有 EP 系统的声明。所得时间是该聚合带宽假设下的估计，不能视为真实训练步的测量值。
