# PEFT：GLoRA 权重合并与精确逆解

## 题目描述

**GLoRA**（Generalized LoRA, arXiv:2410.01485）把低秩增量写成「对基座权重的**逐元素乘性缩放** + **加性低秩项**」：

\[W' = W_0 + W_0 \odot A + B,\qquad A=A_dA_u,\quad B=B_dB_u\]

与 LoRA 只加 \(B A\) 不同，\(W_0\odot A\) 让增量按元素跟随基座权重的大小：大权重处可以改动更多，小权重处几乎不动，等于给低秩方向配了一个"基座形状"的先验。偏置也有对称的乘法旁路 \(b_0\odot D+E\)，并额外接受一个输入侧混入项 \(W_0C\)。

本题要求实现 **合并（merge）** 语义：把若干适配器一次性折进基座权重与偏置，之后只做一次普通线性前向；返回的 \((W',b')\) 还必须能被精确逆解回 \((W_0,b_0)\)（PEFT 的 `unmerge` 走的就是这条反解）。

## 规则

- 每个适配器给出低秩因子 \(A_d:(d_\text{out},r)\)、\(A_u:(r,d_\text{in})\) 与 \(B_d:(d_\text{out},r)\)、\(B_u:(r,d_\text{in})\)，以及偏置向量 \(C:(d_\text{in},)\)、\(D:(d_\text{out},)\)、\(E:(d_\text{out},)\)。
- 第 \(i\) 个适配器的贡献是 \(W_0\odot A_i+B_i\)，**每一项都乘原始 \(W_0\)**，不是在已合并权重上滚动叠加。
- 基座无偏置（`b0` 为 None）时 \(C,D,E\) 不参与运算，返回的 \(b'\) 也是 None。
- 内部 float64 累加，返回 float32。

## 示例

单个适配器，\(d_\text{out}=3, d_\text{in}=4, r=2\)：

```
输入：
  W0 = [[0.5,-0.2,0.1,0.3],[0.2,0.4,-0.1,0.0],[-0.3,0.1,0.5,0.2]]
  b0 = [0.1,-0.2,0.05]
  A_d = [[0.3,-0.1],[0.2,0.4],[-0.5,0.2]]
  A_u = [[0.1,0.2,-0.3,0.4],[-0.2,0.5,0.1,0.0]]
  B_d = [[0.1,0.2],[-0.3,0.1],[0.0,-0.2]]
  B_u = [[0.4,-0.1,0.2,0.0],[0.3,0.2,-0.5,0.1]]
  C = [0.5,-0.4,0.2,0.1]
  D = [0.2,-0.1,0.3]
  E = [0.05,0.1,-0.15]
  x = [[1.0,0.5,-0.3,0.2],[0.1,-0.4,0.6,0.3]]
输出：
  W' = [[0.625,-0.172,0.01,0.356],[0.098,0.546,-0.208,0.01],[-0.333,0.06,0.685,0.14]]
  b' = [0.55,-0.16,-0.155]
  y  = [[1.1572,0.2754,-0.6355],[0.7941,-0.4904,0.2407]]
```

## 约束

- `x` 支持任意前置维，最后一维为 \(d_\text{in}\)；`b0` 形状 \((d_\text{out},)\)。
- 低秩因子需 \(r\ge1\) 且内维一致；适配器列表非空；形状非法要抛 `ValueError`。
- 逆解公式：\(W_0=(W'-\sum_i B_i)/(1+\sum_i A_i)\)，\(b_0=(b'-\sum_i E_i-\sum_i W_0C_i)/(1+\sum_i D_i)\)；注意 \(C\) 项要用**逆解得到的** \(W_0\) 计。
- 多适配器合并结果与顺序无关，且必须等于"逐适配器未合并前向求和再减去 \((n-1)\) 份基座前向"。
