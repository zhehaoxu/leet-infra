# PEFT：LoRA 低秩适配前向

## 题目描述

**LoRA**（Hu et al., arXiv:2106.09685）是参数高效微调（PEFT）的奠基方法：微调时冻结预训练权重矩阵 \(W_0\in\mathbb R^{d_\text{out}\times d_\text{in}}\)，只训练两个低秩「旁路」矩阵 \(A\in\mathbb R^{r\times d_\text{in}}\)（降维，\(r\ll\min(d)\)）、\(B\in\mathbb R^{d_\text{out}\times r}\)（升维），把权重更新约束成 \(\Delta W = B A\)。前向时不改动 \(W_0\)，而是「\(W_0\) 的原输出 + 低秩旁路的输出」相加：

\[y = W_0 x + \frac{\alpha}{r}\,B A x\]

其中 \(\alpha\) 是缩放超参、\(\frac{\alpha}{r}\) 是标准缩放因子（把低秩增量校准到合适量级）。本题实现给定输入 batch 的 LoRA 前向输出，与「先把 \(\Delta W\) 合进 \(W_0\) 再一次矩阵乘」的结果逐元素等价。

## 规则

给定：输入 `x` 形状 \((\dots, d_\text{in})\)；冻结权重 `W0` 形状 \((d_\text{out}, d_\text{in})\)；`A` 形状 \((r, d_\text{in})\)；`B` 形状 \((d_\text{out}, r)\)；标量 `alpha`、`r`（秩）。约定线性层用 PyTorch `nn.Linear` 的「行向量 × 权重转置」惯例，即原输出 \(=x W_0^\top\)。计算：

1. 缩放因子 \(s = \alpha / r\)。
2. 基座输出 \(y_0 = x\,W_0^\top\)。
3. 低秩旁路 \(y_\Delta = s\cdot\bigl(x\,A^\top\bigr)B^\top\)（先经 \(A\) 降到 \(r\) 维、再经 \(B\) 升回 \(d_\text{out}\)）。
4. 输出 \(y = y_0 + y_\Delta\)。

返回 `y`（形状 \((\dots, d_\text{out})\)）。全程 float32，禁止调用现成 PEFT 库。

## 示例

\(W_0\)（3×5）、\(A\)（2×5）、\(B\)（3×2）、\(x\)（2×5）、\(\alpha=8.0\)、\(r=2\)（故 \(s=4.0\)）：

```
W0 = [[ 0.5,-0.2, 0.1, 0.3, 0.0],
      [ 0.2, 0.4,-0.1, 0.0, 0.6],
      [-0.3, 0.1, 0.5, 0.2,-0.4]]
A  = [[ 0.3,-0.1, 0.2, 0.0, 0.5],
      [-0.2, 0.4, 0.1,-0.3, 0.2]]
B  = [[ 0.1,-0.2],
      [ 0.3, 0.0],
      [-0.1, 0.4]]
x  = [[ 1.0, 0.5,-0.3, 0.2, 0.8],
      [ 0.1,-0.4, 0.6, 0.3,-0.2]]

y = [[0.610, 1.618, -0.804],
     [0.516, -0.212, -0.066]]
```

## 约束

- CPU float32；`x` 支持 2D \((n,d_\text{in})\) 与 3D \((b,l,d_\text{in})\)（把最后维当特征维）。
- 输出与「合并权重 \(W_0+\frac{\alpha}{r}BA\) 后单次矩阵乘」逐元素一致（对拍口径见 notes.md）。
- \(r\) 为 \(A,B\) 的公共秩维；本式 \(\alpha/r\) 用给定 `r`，不自动从形状推断。
