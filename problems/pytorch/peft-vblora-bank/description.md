# VB-LoRA：向量库选择适配器

## 题目描述

VB-LoRA 把 LoRA 的 `A`、`B` 两个矩阵彻底换掉：全模型只共享一张**向量库**（几千到几万行、每行 `vector_length` 个数），每个可训练参数不再存一个向量，而是存一串**对库中各行的打分（logits）**，前向时挑出分数最高的 `topk` 行、加权平均，临时拼出 `A` 和 `B`。这样单个适配器层的参数量可以压到几千个 float，而表达能力由共享库提供。

本题给定基座权重 `W0`、可选偏置 `b0`、向量库 `vector_bank`、两侧的 logits（`logits_A`、`logits_B`）与 `topk`，要求输出临时拼出的 `A`、`B`、增量 `delta = B @ A` 以及前向结果 `y`，四者必须自洽。

## 规则

记 `r` 为秩、`V = num_vectors`、`vl = vector_length`。`x` 的最后一维是 `d_in`，`W0` 是 `(d_out, d_in)`。两侧 logits 的倒数第二维分别是输入与输出被 `vl` 切成的 **tile** 数：

| 张量 | 形状 | 说明 |
| --- | --- | --- |
| `vector_bank` | `(V, vl)` | 全局共享的一张库 |
| `logits_A` | `(r, d_in // vl, V)` | 每个 `(秩, 输入 tile)` 对库中 `V` 行打一组分 |
| `logits_B` | `(d_out // vl, r, V)` | 每个 `(输出 tile, 秩)` 对库中 `V` 行打一组分 |

1. **逐 logit 向量的选择**：把最后一维（长度 `V`）当作一组打分，

   ```
   idx    = the topk largest scores of the V logits (ties: smaller index first)
   w      = softmax(logits[idx])           # normalized over the selected topk only
   vector = sum_t w[t] * bank[idx[t]]      # weighted sum of bank rows, length vl
   ```

   关键点是 **softmax 只在选中的 `topk` 个分数上归一化**，被丢弃的那些打分完全不参与；把整条长度 `V` 的 logits 一起做 softmax 会得到完全不同的权重。

2. **拼出 `A`（形状 `(r, d_in)`）**：`logits_A` 的选择结果形状是 `(r, d_in//vl, vl)`，按 **tile 主序**展平最后两维，

   ```
   A[:, t*vl:(t+1)*vl] = selection(logits_A[:, t, :])
   ```

3. **拼出 `B`（形状 `(d_out, r)`）**：`logits_B` 的选择结果形状是 `(d_out//vl, r, vl)`，**先转置成 `(out_tile, vl, r)` 再展平前两维**，

   ```
   B[o*vl + s, j] = selection(logits_B[o, j, :])[s]
   ```

   也就是说 `B` 的行号由「输出 tile 内的分量 `s`」决定、列号才是秩 `j`；漏掉这次转置会让同一个输出 tile 内的 `vl` 行与 `r` 列互相错位。

4. **增量与前向**：

   ```
   delta = B @ A                # (d_out, d_in), no alpha/r style extra scaling
   y     = x @ W0.T + b0 + x @ delta.T
   ```

   `b0` 为 `None` 时不加偏置。后一项等价于先乘 `A` 再乘 `B`（`((x @ Aᵀ) @ Bᵀ)`），这正是未合并路径的写法。

5. **精度**：中间计算全部用 float64，返回的 `y`、`A`、`B`、`delta` 都是 float32；`x` 允许任意前导维度。

返回 `(y, A, B, delta)`。禁止调用现成 PEFT 库。

## 示例

`d_in = d_out = 2`、`vl = 2`（所以两侧都只有 1 个 tile）、`V = 4`、`r = 2`、`topk = 2`、`W0 = I`、`x = [[1, 2]]`：

```
bank     = [[1, 0], [0, 1], [2, 2], [-1, 0.5]]
logits_A = [[[0, 1, 0.5, -1]],
            [[0, 0, 3, 1]]]
logits_B = [[[1, 0, 0.5, 2],
             [1, 1, 1, -2]]]
```

`logits_A` 的两行分别是秩 0、秩 1 的输入 tile；`logits_B` 的两行分别是输出 tile 0 的秩 0、秩 1。

- `logits_A[0]` 选出下标 1（分 1.0）与 2（分 0.5），`softmax([1, 0.5]) = [0.622459, 0.377541]`，得 `0.622459*[0,1] + 0.377541*[2,2] = [0.755081, 1.377541]`。
- `logits_A[1]` 选出下标 2（分 3.0）与 3（分 1.0），`softmax([3, 1]) = [0.880797, 0.119203]`，得 `[1.642391, 1.821196]`。
- `logits_B[0, 0]` 选出下标 3（分 2.0）与 0（分 1.0），`softmax([2, 1]) = [0.731059, 0.268941]`，得向量 `[-0.462117, 0.365529]`。
- `logits_B[0, 1]` 的最大值 `1.0` 并列在下标 0/1/2，`topk = 2` 按下标升序取 0 与 1，权重各 0.5，得向量 `[0.5, 0.5]`。

```
A     = [[0.755081, 1.377541],
         [1.642391, 1.821196]]
B     = [[-0.462117, 0.500000],
         [ 0.365529, 0.500000]]
delta = [[0.472260, 0.274013],
         [1.097200, 1.414129]]
y     = [[2.020285, 5.925458]]
```

注意 `B` 的第 0 列是 `[-0.462117, 0.365529]`（秩 0 那条向量的两个分量），第 1 列是 `[0.5, 0.5]`：分量落在行方向、秩落在列方向，正是转置后的结果。

## 约束

- `d_in`、`d_out` 都必须能被 `vl` 整除；`vl`、`V`、`r` 均为正整数；
- `0 < topk <= V`；
- `logits_A`、`logits_B` 的形状必须严格等于上表（`r` 与 `V` 要和 `vector_bank` 对齐）；
- `x` 的最后一维必须等于 `d_in`；`b0` 若给出则长度必须等于 `d_out`；
- 所有张量必须是浮点、有限值（`NaN`/`Inf` 非法）；
- 违反以上任一条时抛出 `ValueError`。
