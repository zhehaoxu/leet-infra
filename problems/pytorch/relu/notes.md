# ReLU 详解

## 定义

$$ \operatorname{relu}(x)=\max(0,x) $$

分段线性、单调非减，输出半轴 $[0,+\infty)$。现代神经网络默认激活，几乎是「没有激活函数」的代名词。

## 为什么是它

- **计算极廉**：一次比较，无指数/除法，前向反向都便宜。
- **稀疏激活**：负区输出精确 0，带来稀疏性并减轻相互干扰。
- **缓解梯度消失**：正区梯度恒为 1，不像 sigmoid/tanh 在饱和区把梯度压到 0。

## 实现与数值要点

- 参考解用 `torch.maximum(x, torch.zeros_like(x))`，向量化、无 Python 循环。`torch.clamp_min(x, 0)` 或 `F.relu` 等价。
- **别写 `x if x>0 else 0`** 这类 Python 分支——题面要求向量化，且逐元素标量判断在张量上非法。
- 次梯度在 $x=0$ 处不唯一，工程上按 0（或右导 1）处理，判题不受影响。

## 死神经元与其解药

负区梯度恒 0：若某神经元对全体样本恒负，它将永久停止学习（dying ReLU）。家族解法——

- Leaky-ReLU / ELU / SELU：给负区一个非零响应或斜率（见对应题）。
- 合理学习率与初始化避免大面积进入死区。

## 关联

ReLU6 = $\operatorname{clip}(x,0,6)$（给上界，量化友好）；hardtanh、PReLU（可学负斜率）都是其变体。
