# ReLU

## 题目描述

实现逐元素 ReLU（Rectified Linear Unit）激活函数，深度学习中最基础的算子：

$$
\text{ReLU}(x) = \max(0, x)
$$

它是 GELU、Swish 等所有现代激活函数的组成部分，也是理解反向传播的起点。

## 规则

- 实现 `solve(x: torch.Tensor) -> torch.Tensor`，对每个元素取 `max(0, x)`。
- 输出形状、dtype 必须与输入一致。
- 要求向量化实现，不能用 Python 逐元素循环。

## 示例

```
输入：[-2.0, -0.5, 0.0, 0.5, 2.0]
输出：[0.0, 0.0, 0.0, 0.5, 2.0]
```

## 约束

- 输入为 float32 或 float64 张量，任意形状
- 数值范围无限制（可能包含全负、全正、含零的输入）
