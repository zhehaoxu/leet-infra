# Sequoia: Optimal Draft Tree Dynamic Programming (Algorithm 1)

## Problem

Given a draft/verify configuration, Sequoia asks: **under a speculation budget (tree size) $N$ and at most $B$ branches per node, which draft tree shape maximizes the expected number of tokens generated per iteration?** **Sequoia** (Chen et al., 2024, [arXiv:2402.12374](https://arxiv.org/abs/2402.12374)) derives a closed-form expectation under the **positional acceptance assumption** and finds the optimal tree shape offline with a two-dimensional dynamic program (its Algorithm 1)—this problem asks you to implement that DP.

## Positional Acceptance and Expectation

The probability that the verification algorithm accepts "the $k$-th child of an already accepted node" depends only on $k$; write the acceptance vector as $P=(P[1],P[2],\dots,P[B])$ (the input `P` has length $B$, and `P[b-1]` is $P[b]$). For a tree node $v$, let $\texttt{Path}(v)$ be the sequence of "which child" indices along the path from the root to $v$; then its score is
$$f(v)=\prod_{i\in\texttt{Path}(v)} P[i],\qquad f(\text{root})=1.$$
The expected number of tokens generated by verifying a tree $\mathcal T$ (Prop 3.4) is
$$F(\mathcal T)=\sum_{v\in\mathcal T} f(v).$$

## DP: the table T[n,b]

Let $T[n,b]$ be the maximum $F(\mathcal T)$ over all trees with "size $=n$, the root's **number of direct children (FirstBranch) exactly $b$**, and out-degree $\le B$ for every node". Initialize to $-\infty$, with bases:
$$T[1,0]=1,\quad T_{\max}[1]=1,\qquad T_{\max}[n]=\max_{0\le b\le B} T[n,b].$$
Recurrence (split the subtree of the $b$-th child into a part of size $=m$; that subtree is counted only if the $b$-th child is accepted, with probability $P[b]$):
$$T[n,b]=\max_{1\le m\le n-1}\Big(T[n-m,\,b-1]+P[b]\cdot T_{\max}[m]\Big),\quad n=2..N,\; b=1..B.$$
Answer = $T_{\max}[N]$ (optimal among size $\le N$; in practice $n=N$ is used).

Return a `float`: $T_{\max}[N]$. The input `P` has length $B$, and `P[b-1]` corresponds to $P[b]$ (acceptance rate of the $b$-th child, $b=1..B$).

## Examples

```
N=3, B=1, P=[0.7]   (a single chain only)
  f(root)=1, depth1 = P[1]=0.7, depth2 = P[1]^2=0.49
  F = 1 + 0.7 + 0.49 = 2.19                       -> return 2.19

N=4, B=2, P=[0.9, 0.5]  (branching allowed)
  optimal tree shape found by DP gives F = 3.439  -> return 3.439

N=1, B=3, P=[0.9, 0.6, 0.3]  (root only, no speculation)
  F = 1.0                                        -> return 1.0
```

## Constraints

- $1\le N\le 32$, $1\le B\le N-1$ ($B$ may be arbitrary when $N=1$); results are compared with `abs(a-b) <= 1e-6*max(1,|b|)`.
- Monotonicity of $P[b]\in[0,1]$ is not required; the DP maximizes over all ordered trees with FirstBranch $\le B$ and size $=n$.
- $T[n,b]$ stays $-\infty$ for infeasible states (e.g. $b>n-1$), and $T_{\max}[n]$ is maximized only over feasible $b$.
