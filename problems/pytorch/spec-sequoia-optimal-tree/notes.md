# 解题说明 · Sequoia 最优草稿树 DP

## 把"选树形"变成填一张二维表

Sequoia 的洞察是：在**位置接受假设**下，期望生成 token 数只依赖树形（每个节点是它父亲的"第几个孩子"），且可分解成子问题。于是把候选空间用两个整数刻画——树的规模 $n$ 和根的**直接孩子数** $b$（FirstBranch）——填表 $T[n,b]$。答案是 $T_{\max}[N]=\max_b T[N,b]$。

## 转移为什么长这样

考虑一棵 size $=n$、根有 $b$ 个孩子的树。把根的第 $b$ 个孩子连同它的整棵子树单独拿出来（设其规模 $m$），剩下"根 + 前 $b-1$ 个孩子及后代"是一棵 size $=n-m$、FirstBranch $=b-1$ 的树，贡献 $T[n-m,b-1]$。而那棵被拆出的子树只有在**第 $b$ 个孩子被接受**（概率 $P[b]$）时才会被真正验证到，其内部最优期望是 $T_{\max}[m]$，故贡献 $P[b]\cdot T_{\max}[m]$。枚举 $m$ 取最大即得
$$T[n,b]=\max_{1\le m\le n-1}\big(T[n-m,b-1]+P[b]\,T_{\max}[m]\big).$$
注意 $T_{\max}[m]$ 内部用的是相对路径分数，孩子位置的 $P[b]$ 把整棵子树的分数按比例缩放——这正是 $f(v)=\prod_{\text{Path}} P$ 的可分解性。

## base 与不可行状态

- $T[1,0]=1$：只有根，"不投机也至少生成 1 个 token"（bonus/当前位）。
- $T[n,0]$ 对 $n>1$ 恒为 $-\infty$：size 大于 1 的树根不可能有 0 个孩子。
- $b>n-1$ 同样不可行（根的孩子数不能超过剩余节点数），保持 $-\infty$；$T_{\max}$ 只在可行 $b$ 上取 max。

## 退化到链

$B=1$ 时只能是一条链，$T[N,1]=\sum_{i=0}^{N-1} P[1]^i=\frac{1-P[1]^N}{1-P[1]}$——这就是经典单序列投机解码的期望接受长度上界。$B\ge2$ 允许分叉后，$T_{\max}$ 随 $N$ 近似对数增长（论文 Thm 3.6），这也是 Sequoia 相对固定树形的核心优势。

## 边界自检

- `check_example`：链 / 分叉 / 仅根三种规模的具体值。
- `check_chain_formula`：$B=1$ 与几何级数闭合式对齐。
- `check_monotone_in_N`：接受率全 1 时 $T_{\max}[N]=N$（每个节点都接受）。
- `check_matches_oracle`：小规模随机 $N,B,P$，与独立暴力枚举（根出度 + 组合划分递归）对拍。
