# 量化：SqueezeLLM 敏感度加权非均匀格点

## 题目描述

均匀量化的格点等距，但权重的**重要性**并不相等：微调后少数权重对输出影响巨大（大的 Fisher 信息 / 二阶敏感度），量化误差落在它们身上代价远高于落在无关紧要的权重上。**SqueezeLLM**（Kim et al., ICML 2023, arXiv:2306.07629）的做法是给每个权重一个敏感度 \(s_i\)，用**加权 k-means** 学出非均匀格点与分配：格点自动在敏感度高、样本密的区域加密。

本题在 1 维上实现这个加权 Lloyd 算法：

\[
\min_{\{c_j\},\ a_i}\ \sum_i s_i\,(w_i-c_{a_i})^2
\]

交替两步：

1. **分配**：\(a_i=\arg\min_j |w_i-c_j|\)（并列取较小的簇号）；
2. **更新**：\(c_j=\dfrac{\sum_{i:a_i=j}s_i\,w_i}{\sum_{i:a_i=j}s_i}\)（空簇保留原中心）。

每次更新后把中心**升序排序**（分配随之由下一次迭代重算），保证输出格点单调。

**初始化**（确定性）：把 `w` 升序排列，第 \(j\) 个中心取排序后第 \(\lfloor (j+0.5)N/k\rfloor\) 个元素（位置分位点，忽略权重）。

## 任务

实现 `solve(w, sens, k, iters)`：

- 输入：`w` float32 `(N,)`、`sens` float32 `(N,)`（非负且总和为正）、`k` 为 `1 ≤ k ≤ N` 的整数、`iters` 为非负整数（迭代次数）。
- 输出 `(centroids, assign, deq)`：`centroids` float32 `(k,)`（升序）；`assign` int64 `(N,)`（取值 `0..k-1`，对应升序中心）；`deq` float32 `(N,)`，满足 `deq[i] == centroids[assign[i]]`。

**约定**：内部 float64，输出 float32；容差 \(10^{-5}\)。`k` 越界、`iters < 0`、`sens` 含负数或全零抛 `ValueError`。

## 示例

```
w = [0, 1, 2, 3], sens = [1, 1, 1, 1], k = 2, iters = 1
初始中心：位置 floor(0.5*4/2)=1 → w[1]=1；floor(1.5*4/2)=3 → w[3]=3
分配：2 到 1 和 3 等距，并列取小簇 → [0,0,0,1]（左簇含 0,1,2）
更新中心：左簇均值 1、右簇均值 3（sens 全 1 退化为算术均值）
输出：centroids=[1.0, 3.0], assign=[0,0,0,1], deq=[1.0, 1.0, 1.0, 3.0]
```

## 约束

- 中心必须是**加权**均值（分母 \(\sum s_i\)），不是算术均值——`sens` 全 1 时才退化为普通 k-means。
- 每轮更新后中心升序排序；`assign` 按排序后的簇号重新给出。
- `k == 1` 时中心 = 全体的加权均值（与迭代次数无关）。
