# 检索：IVF 粗量化器分配

## 题目描述

倒排文件索引（IVF, Inverted File Index）是近似最近邻检索的核心结构（Jégou et al., *Product Quantization for Nearest Neighbor Search*, TPAMI 2011；Faiss `IndexIVF`）。它先用 k-means 训练 \(k\) 个**粗量化中心（centroids）**，把向量空间划分为 \(k\) 个 Voronoi 单元；建库时把每个候选向量分配到**最近的中心**（即所属倒排链），查询时只需扫描少数几个最近的链。本题只做这一步最基础的确定性操作：**为每个向量找到最近的粗量化中心**。

## 规则

实现 `solve(x, centroids)`。输入 `x`（float32，形状 \((n, D)\)）为待分配向量，`centroids`（float32，形状 \((k, D)\)）为 \(k\) 个粗量化中心。对每个向量 \(x_i\) 计算它到各中心的**欧氏距离平方** \(\sum_t (x_{i,t}-c_{j,t})^2\)，返回距离最小的中心下标。返回 int64 张量，形状 \((n,)\)。若多个中心并列最小，取**下标最小**者。

## 示例

\(n=3, D=2, k=2\)，`centroids=[[0,0],[5,5]]`，`x=[[0,0],[3,4],[1,1]]`：

```
x0=[0,0]: 距 c0=0, c1=50 -> 0
x1=[3,4]: 距 c0=25, c1=2 -> 1
x2=[1,1]: 距 c0=2, c1=32 -> 0
out = [0, 1, 0]   shape = (3,)
```

## 约束

- CPU float32；\(n, k \ge 1\)，\(D \ge 1\)。
- 距离用欧氏距离**平方**即可（平方根是单调变换，不改变 argmin）。
- 并列最小取中心下标最小者，保证确定性。
