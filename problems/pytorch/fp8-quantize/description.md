# FP8 (E4M3) 量化往返

## 题目描述

H100/MI300 起，FP8 成为训练与推理的新默认精度。最常用的一档是 **E4M3**：1 位符号、4 位指数（bias 7）、3 位尾数。本题把浮点张量**量化到最近的 E4M3 可表示值再转回浮点**（fake-quant 往返），要求逐元素复现 IEEE 式「就近舍入、平局取偶（RTNE）」，并在超出表示范围时**饱和**到最大有限值。

## E4M3 格式（务必按此）

记符号 $s$、指数字段 $E\in[0,15]$、尾数字段 $M\in[0,7]$：

- **规格化值**（$E\ge1$）：$v=(-1)^s\cdot 2^{E-7}\cdot\left(1+\dfrac{M}{8}\right)$。
- **次正规值**（$E=0$）：$v=(-1)^s\cdot 2^{-6}\cdot\dfrac{M}{8}=(-1)^s\cdot M\cdot 2^{-9}$（比最小规格化数 $2^{-6}=0.015625$ 更细的等距格点，间距 $2^{-9}$）。
- **最大有限值 $=448$**（$E=15, M=6$）。$M=7$ 且 $E=15$ 在本格式（`float8_e4m3fn`，fn=无 inf）里不作为数——故任何使数值达到 $480$ 舍入趋势的量都**饱和**为 $448$。

## 规则

实现 `solve(x)`，返回**量化往返后的浮点张量**（与 `x` 同形同 dtype），逐元素：

1. $y=|x|$（符号单独保留，$0$ 与 NaN 原样）。
2. 若 $2^{-6}\le y$（规格化区）：所在 2 的幂段 $2^e\le y<2^{e+1}$，格点间距 $\text{step}=2^{e-3}$；$n=\operatorname{RTNE}(y/\text{step})$，$y'=n\cdot\text{step}$。
3. 否则（次正规区 $y<2^{-6}$）：$\text{step}=2^{-9}$，$y'=\operatorname{RTNE}(y/\text{step})\cdot 2^{-9}$。
4. 饱和：若 $y'>448$ 取 $448$。
5. 返回 $\operatorname{sign}(x)\cdot y'$。

$\operatorname{RTNE}$ = 四舍六入、**恰为半数时取最近的偶数**（与 `torch.round` / Python `round` 一致）。

## 示例

```
1.06   → 1.0          1.12  → 1.125        0.03  → 0.029296875
0.015  → 0.015625     2^-9  → 0.001953125  -1.06 → -1.0
449    → 448          1000  → 448 (饱和)    448   → 448
```

## 约束

- 结果须与 `x.to(torch.float8_e4m3fn).to(x.dtype)` 逐元素一致（内置 oracle）——不要用该 cast，手写格点量化
- 输入为有限浮点（float32/float64）；输出 dtype、shape 同输入；不修改输入
- 常见坑：① 指数按 $y/step$ 落在 $[8,16)$ 时进位（$n=16$ → 下一段），别锁死段；② 次正规用**固定** $2^{-9}$ 间距而非按段；③ 平局必须取偶，不能一律向上
