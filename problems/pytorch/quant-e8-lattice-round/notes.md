# 量化：E8 格点最近点取整——算法详解

## 1. 标量量化的盲点

标量量化把每个坐标独立取整，误差按坐标累加；当平均位宽固定时，高维格点可以用更少的码字覆盖同样体积，从而降低率失真。E8 是 8 维里格点密度最高的格之一，每单位体积的格点数最多，因此成为向量量化码本（如 QuIP# 的 E8P）的天然骨架。

QuIP#（arXiv:2402.04396）的 E8P 码本构造是：取 `D8+1/2` 中范数不超过 `sqrt(10)` 的 227 个码字，补 29 个范数 12 的码字，再用 8 个符号翻转与 `±1/4` 偏移扩成 `2^16` 个码点。本题只保留其中最核心、与数据无关的一步：**完整 E8 上的最近点取整**。227+29 的码本裁剪与那 29 个手工码字依赖固定数据，不属于算子的考点。

## 2. D8 取整与奇偶修正

D8 的约束是「坐标全为整数且坐标和为偶数」。先逐坐标取最近整数 `y = round(x)`：

- 若 `sum(y)` 为偶数，`y ∈ D8`，任务完成；
- 若为奇数，必须恰好把一个坐标移动 1（移动两个坐标会让误差增加两次，不会更优）。

设第 i 个坐标的偏差 `d_i = x_i - y_i ∈ [-0.5, 0.5]`。把 `y_i` 朝 x 的方向移动 1 后，误差增量为

\[
\Delta_i = (1-|d_i|)^2 - d_i^2 = 1 - 2|d_i|
\]

因此应选 `|d_i|` 最大的坐标——它离中点最近，翻到另一个整数几乎不增加误差。若并列最大，本题约定取最小下标；若 `d_i = 0`（x 本身是整数），两个方向代价都是 1，约定取 `+1`。

## 3. D8+1/2 陪集与最终选择

E8 的另一个陪集是 `D8 + 1/2`。把 `z = x - 0.5` 平移到整数格上，对 z 做同样的 D8 取整得到 `y'`，候选点 `y' + 0.5`。注意判偶用的是 `y'` 的坐标和；`+0.5` 只是平移，不参与奇偶判断。

最后比较两个候选的平方误差 `||x - y||²`，coset 1 严格更小才选 1，平局选 0。这样得到的就是完整 E8 上的最近点：E8 是这两陪集的并，两个陪集各自的最优取较小者即为全局最优。

上游 `E8P12_codebook.quantize` 会尝试 `X+1/4` 与 `X-1/4` 两个平移后的码本。对**完整 E8** 而言这两个平移其实是同一个格：`(1/2,...,1/2)` 属于 D8（坐标和 8 为偶数），所以 `±1/4` 的差 `(1/2,...,1/2)` 本身就在 E8 里。只有当码本被截断成 E8P 的有限码字集合时，两次平移才会产生不同结果；本题不涉及截断，因此不做 `±1/4` 双路比较。

## 4. 边界与实现口径

- 逐坐标取整用「四舍五入到偶数」（`torch.round`），避免 x.5 处的方向歧义。
- 并列最大偏差取最小下标；偏差为 0 时方向取 `+1`。这两条规则只影响恰好落在对称位置的输入，但必须写死才能做确定性判题。
- 整数点且坐标和为奇数：所有 `|d_i|=0`，移动任一坐标代价都是 1；按约定得到最小下标 `+1` 的最近点。
- 两个陪集等距时（例如 `0.25` 的每个坐标）选 coset 0。
- 输入必须是 `[N, 8]` 的有限浮点张量；内部 float64，输出 float32。

## 5. 与本合集其他题的分工

- `quant-squeezellm-sensitive-kmeans`：1 维敏感通道聚类，码字位置自由、无格点约束；
- `quant-nf4-quantile-grid`：1 维分位格点，坐标之间独立；
- `quant-double-quant-scale`：对 scale 再做量化，仍是 1 维问题；
- 本题：**8 维 E8 格点 + 坐标和奇偶约束**，是唯一一个「坐标之间通过奇偶校验耦合」的取整问题；
- 与 QuIP# 的关系：本题实现 E8P 码本所依赖的最近格点取整；E8P 的截断码本与手工填充码字不在本题范围。

## 6. 验证方法

- `check_example`：手算示例，覆盖奇偶修正、移动方向与陪集选择。
- `check_lattice_membership`：coset 0 的行必须是偶坐标和整数点，coset 1 的行必须是偶坐标和的半整数点；`sse` 与 `||x-rounded||²` 一致。
- `check_matches_oracle`：40 行不同尺度的随机点与纯 Python 局部枚举 oracle（`y` 与 `y±e_i` 全枚举）对齐。
- `check_parity_fix`：`[1.2, 0, ...]` 必须修正为 `[2, 0, ...]`，验证移动方向与误差。
- `check_coset_selection`：`0.4` 在 `D8+1/2` 中更近，必须选 coset 1。
- `check_tie_prefers_d8`：`0.25` 到两个陪集等距，必须选 coset 0。
- `check_validation`：维度、形状、浮点类型、非有限值非法时抛 `ValueError`。
