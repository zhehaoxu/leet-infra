# Min-p 采样

## 题目描述

top-p 用「累积质量」截断，在分布很平坦时仍会留下一大堆噪声词；top-k 则与置信度无关。
**Min-p 采样**（Minh & Baker 2023）给出一条**相对于最高概率的地板**：只保留概率不小于
`p · p_max` 的 token（`p_max` 是分布里最大概率）。模型越自信（`p_max` 越大），地板越高、
砍得越狠；越困惑则自动放宽。它对高温下的创意写作和重度量化小模型尤其有效，是当下
推理引擎（llama.cpp 默认 `min-p`）里取代 top-k 的主力截断之一。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法实现。

## 规则

- 实现 `solve(logits, p, u)`：`logits` 形状 `(..., V)`，`p ∈ (0,1)`，`u` 形状 `(...,)` 或标量、取值 $[0,1)$。
- 步骤：① `probs = softmax(logits)`；② 记 `p_max = probs.max()`，保留满足 `probs >= p · p_max`
  的候选（最高概率者必被保留，故至少留 1 个），其余置 0；③ 保留部分重新归一化得 `filtered`；
  ④ 用 `u` 在 `filtered`（原顺序）CDF 上逆变换采样，返回选中 token 的原始索引。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`，`chosen` 形状 `(...,)`。
- 等价判据（softmax 单调）：保留 `logit >= logit_max + ln(p)`，即 llama.cpp 的做法。

## 示例

```
输入：logits = [2, 1, 0.5, -1, -2, -3]，p = 0.2，u = 0.9
  probs = [0.600294, 0.220836, 0.133944, 0.029887, 0.010995, 0.004045]
  p_max = 0.600294 → 地板 = 0.2 · 0.600294 = 0.120059
  保留 probs >= 0.120059 的前 3 个（0.029887 < 地板被砍）
  归一化（除以 0.955074）→ filtered = [0.628532, 0.231224, 0.140244, 0, 0, 0]
  CDF = [0.628532, 0.859756, 1.0]，u = 0.9 → 首个 ≥0.9 是位置 2 → 选中原始索引 2
输出：filtered = [0.628532, 0.231224, 0.140244, 0, 0, 0], chosen = 2
```

## 约束

- float32 输入；`p ∈ (0,1)`；`u ∈ [0,1)`
- `filtered` 每行和为 1，被砍位置严格为 0；`chosen` 必落在保留集合内
- 支持批量 `(..., V)`；`p_max` 沿最后一维逐行取
