# 详解：检索：k-means Lloyd 迭代与空簇重播种

## 出处

- Lloyd, *Least Squares Quantization in PCM*, Bell Labs Technical Report, 1957（后于 IEEE Trans. Inform. Theory, 1982 发表）：交替执行「按最近质心分配」与「按簇取均值」。
- MacQueen, *Some Methods for Classification and Analysis of Multivariate Observations*, 1967：命名 k-means 并给出在线更新版本。
- k-means++（Arthur & Vassilvitskii, 2007）解决的是初始化，本题刻意不用：初始质心由入参固定，考的是迭代本身与空簇处理。
- 空簇处理是工程实现的必备分支；scikit-learn 的 `_relocate_empty_clusters`、Faiss 的 Clustering 都有各自策略（具体选点与随机性随版本，**待回源**）。本题不复刻任何库，规则以 starter docstring 为准。

## 完整推导与下标约定

**目标函数与两步的最优性**。记第 \(i\) 个点的分配为 \(a_i\in\{0,\dots,K-1\}\)，目标
\[
J(\{a_i\},\{c_j\})=\sum_{i=1}^{N}\|x_i-c_{a_i}\|_2^2.
\]
固定质心时，每个点独立，\(a_i=\arg\min_j\|x_i-c_j\|_2^2\) 使 \(J\) 最小；平方根单调，所以比较平方距离即可。固定分配时，第 \(j\) 簇的贡献是 \(\sum_{i:a_i=j}\|x_i-c_j\|^2\)，对 \(c_j\) 求梯度 \(2\sum_{i:a_i=j}(c_j-x_i)=0\)，解得
\[
c_j=\frac{1}{|S_j|}\sum_{i\in S_j}x_i,
\]
即逐维算术均值。因此每轮两步都不会增大 \(J\)，且 \(J\) 有下界 0，迭代在实数意义下收敛。

**停止判据为什么看位移而不是目标函数**。本题的停止量是
\[
\text{disp}=\max_{j}\|c_j^{\text{new}}-c_j^{\text{old}}\|_2,
\]
要求 \(\text{disp}<\text{tol}\)（严格小于）。目标函数的变化量会被簇大小与距离尺度影响，而位移是逐质心的几何量，阈值更直观；两者并不等价，判题只认位移。`tol=0` 时即使 \(\text{disp}=0\) 也不会触发 `<`，所以会跑满 `max_iters`——这是刻意的边界，测试里有对应用例。

**空簇为什么必须重播种**。若某簇 \(S_j=\varnothing\)，均值分母为 0。本题的确定性规则是：

1. 空簇按簇下标升序处理；
2. 先算每个点到**本轮分配所用旧质心**集合的最近距离 \(r_i=\min_j\|x_i-c_j^{\text{old}}\|^2\)；
3. 所有点按 \((-r_i,\ i)\) 排序，即「最远优先、并列取小下标」；
4. 用一个 `used` 集合保证同一个点在一轮内最多被一个空簇当种子；取排序中第一个未使用的点，令该空簇的新质心等于该点坐标。

因此「最远点已经被选过就取次远」不是重新计算距离，而是沿着同一张排序表继续往下取。\(K\le N\) 保证空簇数不超过 \(N-1\)（至少一个簇非空），候选点足够。重播种只改质心，不改本轮标签；种子点仍按本轮分配计入它原属簇的均值，因为均值在第 3 步之前就算完了。这一点最容易写错成「先把种子点从原簇删掉再算均值」。

**多个空簇与并列**。示例第 1 轮 c1 为空；旧质心集合是 \(\{[0,0],[0,0],[10,0]\}\)。四个点的最近距离分别是 p0=0、p1=4、p2=0、p3=4；按 \((-r_i,i)\) 排序为 p1、p3、p0、p2，所以 c1 取 p1=[0,2]。若 c1、c2 同时为空，则 c1 取 p1、c2 取 p3（`used` 生效），而不是两个簇都取 p1。

**最终标签为什么重算**。停止时最后一轮的标签是按旧质心分配的，而重播种可能凭空造出一个簇；如果直接返回旧标签，重播种的簇永远是空的，`labels` 与 `centroids` 不自洽。因此参考实现在循环结束后用返回的质心再做一次最近分配（并列取小下标）。这会产生一个反直觉现象：最后一轮分配标签与最终 `labels` 可能不同；判题只认最终 `labels`。

**精度**。距离与均值在 float64 下累加，最终质心 cast 回输入 dtype，最终标签基于 cast 后的质心。float32 输入的容差是 \(10^{-5}\)，float64 是 \(10^{-9}\)；`labels` 与 `n_iters` 精确比较。

## 核心与易错点

1. **停止量是最大质心位移，不是目标函数差**；判据是严格 `<`，`tol=0` 会跑满 `max_iters`。
2. **空簇用旧质心算「最远」**：重播种发生在均值更新之后，但排序依据是本轮分配所用的旧质心集合，不是刚算出的新质心。
3. **重播种不改本轮标签**：种子点仍计入它原属簇的均值；不要先删点再取均值。
4. **多空簇按簇下标升序、种子点不重复**：同一轮内 `used` 集合必须跨空簇共享；并列按点下标小者优先。
5. **最终标签要重算**：用返回的最终质心重新 argmin；直接返回最后一轮标签会与重播种后的质心不一致。
6. **分配并列取小下标**：`torch.argmin` 天然返回首个最小值；手写循环要用严格 `<` 更新，不能 `<=`。
7. **\(K>N\) 直接报错**：空簇数可能超过可用点数，重播种规则无法执行；`N=0`、`K=0` 也同样报 `ValueError`。
8. **float32 输入不要用 float32 累加均值**：大 \(N\) 时误差会超过 \(10^{-5}\)；参考解统一在 float64 下算，最后 cast。
9. **重复点不是错误**：所有点重合时，重播种按点下标挑种子；若所有质心数值仍相同，首轮位移就是 0，可能在 1 轮内停止（测试覆盖）。
10. **`max_iters` 截断时仍要返回当前质心与基于它的标签**，而不是抛「未收敛」。

## 与邻近题的区别

- **vs `retrieval-ivf-assign`**：那题只做一次「给定粗中心，求每个向量的最近中心」，是本题的第 1 步（E 步）且没有质心更新、没有空簇、没有迭代。本题是**训练侧**的完整 Lloyd 循环。
- **vs `retrieval-pq-codes`**：那题在固定的分段码本上做逐段编码，码本不更新；本题的质心每轮都在变，且要处理全局空簇。
- **vs `retrieval-hnsw-greedy` / `retrieval-hnsw-build`**：那两题是图索引的查询侧与建图侧；本题是平面向量量化，不涉及图、层级或邻居选择。
- **vs 一般的 k-means 题**：本题固定初始质心（无随机初始化）、显式规定空簇重播种的排序与去重、并把停止判据钉死为质心位移，因此结果完全可复现。

## 对拍口径与复杂度

- **主 oracle**：`_oracle_kmeans` 用纯 Python 三重循环显式累加平方差、严格 `<` 更新 argmin、逐簇 `sum/count` 求均值、`sorted(..., key=(-r_i,i))` 重播种；与参考解的「广播距离矩阵 + `argmin` + `mean` + `bincount`」结构不同。
- **覆盖**：示例（含空簇重播种）、提前收敛（`tol=10` 一轮停）、`max_iters=1/2/3` 截断、`tol=0` 跑满、并列取小下标（两点对称）、\(K=1\)、\(N=K\) 且全重合、整数网格、float64。`labels`/`n_iters` 用精确比较，质心 float32 \(10^{-5}\)、float64 \(10^{-9}\)（`rtol=0`）。
- **复杂度**：每轮距离矩阵 \(O(NKD)\)、分配 \(O(NK)\)、均值 \(O(ND)\)、空簇排序 \(O(N\log N)\)；总计 \(O(\text{max\_iters}\cdot(NKD+N\log N))\)，临时距离矩阵 \(O(NK)\)。判题规模很小，瓶颈在正确性不在常数。
