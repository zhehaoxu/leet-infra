# 检索：k-means Lloyd 迭代与空簇重播种

## 题目描述

k-means 是向量量化与倒排索引最常用的训练过程：Lloyd 在 1957 年的 Bell Labs 技术报告里给出「分配—取均值」的交替迭代，MacQueen 在 1967 年把它命名为 k-means。给定 \(N\) 个 \(D\) 维点与 \(K\) 个初始质心，每一轮先按最近质心做硬分配，再把每个簇的质心更新为成员均值；目标函数
\[
J=\sum_{i=1}^{N}\bigl\|x_i-c_{a_i}\bigr\|_2^2
\]
在两步中都不增，因此迭代会收敛到某个局部最优。

本题把工程实现里两个容易被忽略的细节钉死：**初始质心完全由入参给出**（不调用任何随机初始化），以及**空簇必须重播种**。当某个质心一个点都没分到时，取均值无从谈起；本题规定把「离当前质心集合最远的点」搬过去充当该簇的新质心，并明确多个空簇、距离并列、种子点复用时的处理顺序。另一个隐藏考点是收敛判据只看**质心位移的最大值**，而不是目标函数的变化量。

CPU、全程确定性、不调用随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。下面只复述语义。

- **输入**：点集形状 \((N,D)\)，初始质心形状 \((K,D)\)，两者 dtype 相同（float32 或 float64）；要求 \(N\ge 1\)、\(K\ge 1\)、\(K\le N\)。距离一律用平方欧氏距离，开方是单调变换、不改变 argmin。分配时距离并列取**质心下标最小**者。
- **每轮四步**：① 每个点分配给平方欧氏距离最近的质心；② 每个非空簇的新质心取该簇所有点的逐维算术均值；③ 处理空簇（见下）；④ 计算本轮新质心相对上一轮质心的逐质心欧氏位移，取最大值 \(\text{disp}\)，若 \(\text{disp}<\text{tol}\) 则本轮结束后停止；执行满 `max_iters` 轮也停止。
- **空簇重播种**：按空簇下标**升序**逐个处理。候选点是本轮尚未被选作种子的所有点；按「该点到本轮分配所用**旧质心**集合的最近距离」**降序**排序，距离并列时点下标小者优先。取排序中第一个未用过的候选点，令该空簇的新质心等于这个点的坐标；同一个点在同一轮内最多充当一个空簇的种子。重播种只改质心，不回溯修改本轮的分配标签；种子点仍然计入它本轮所属簇的均值（均值在重播种之前已经算好）。
- **停止与计数**：`tol` 必须非负，停止条件是 \(\text{disp}<\text{tol}\)（严格小于）。因此 `tol=0` 时即使位移恰好为 0 也不会提前停止，会跑满 `max_iters`。返回的迭代次数是实际执行的轮数，包含触发收敛的那一轮，满足 \(1\le n\_iters\le \text{max\_iters}\)。
- **最终标签**：返回的 `labels` 是用**返回的最终质心**重新做一次最近分配得到的（并列取小下标），不是最后一轮分配时的标签。这样重播种产生的簇也能获得标签，且 `labels` 与 `centroids` 始终自洽。
- **退化与错误**：`N=0`、`K=0`、`K>N`、非二维张量、dtype 不是 float32/float64、两者 dtype 不同、特征维不一致、`max_iters` 不是正整数、`tol<0`，一律抛 `ValueError`。`K\le N` 保证空簇个数不超过可用种子点数。
- **精度**：距离与均值以 float64 累加，最终质心转回输入 dtype；最终标签基于转回后的质心计算。

## 示例

四个二维点、三个初始质心，其中前两个质心重合，第一轮必然有一个空簇：

```
points = [[0,0], [0,2], [10,0], [10,2]]
init   = [[0,0], [0,0], [10,0]]
tol = 1e-4, max_iters = 100
```

| 轮次 | 分配（点 → 簇） | 取均值后的质心 | 空簇重播种 | 最大位移 |
|---|---|---|---|---|
| 1 | p0,p1 → c0；p2,p3 → c2；c1 空 | c0=[0,1]，c2=[10,1] | c1 ← p1=[0,2]（p1 与 p3 到旧质心都距 4，取小下标 1） | 2 |
| 2 | p0 → c0；p1 → c1；p2,p3 → c2 | c0=[0,0]，c1=[0,2]，c2=[10,1] | 无 | 1 |
| 3 | 同第 2 轮 | 不变 | 无 | 0 |

第 3 轮 \(\text{disp}=0<10^{-4}\)，停止，实际迭代 3 轮。最终：

```
labels    = [0, 1, 2, 2]
centroids = [[0,0], [0,2], [10,1]]
n_iters   = 3
```

注意重播种的 c1 最终正好等于输入点 p1 的坐标，而不是某个簇的均值；若不做重播种、让空簇保留旧质心 [0,0]，最终标签会变成 `[1, 0, 2, 2]`（见详解实测）。

## 约束

- 返回三元组 `(labels, centroids, n_iters)`：`labels` 形状 \((N,)\)、dtype int64；`centroids` 形状 \((K,D)\)、dtype 与输入点相同；`n_iters` 是 Python `int`。
- 判题对 `labels` 与 `n_iters` 精确比较，对 `centroids` 用 float32 \(10^{-5}\)、float64 \(10^{-9}\) 的绝对容差。
- 实现路径不限（向量化距离矩阵、逐点循环、`argmin` 或严格小于的手写扫描均可），但必须遵守上面的并列、重播种与停止口径。
- 不使用随机数；不要求目标函数单调性检查，也不要求返回每轮历史。
