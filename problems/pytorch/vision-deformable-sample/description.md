# 检测：可变形采样与偏移聚合

## 题目描述

卷积和池化的采样位置是固定的网格，但很多视觉任务需要**在连续位置上取值**：可变形卷积（Dai et al., ICCV 2017）在每个卷积核位置学一个偏移，可变形注意力（Deformable DETR）在参考点周围取一组带偏移的采样点。偏移是实数，采样位置因此落在像素之间，只能做双线性插值；位置还可能被推出特征图之外，此时业界统一按**零填充**处理。

这一步看起来只是四次乘加，但工程里三个地方会静默出错：

- **越界角按 0 而不是按边缘复制**：零填充会让靠近边界的采样点少掉一部分贡献（例如 \(x=-0.5\) 只剩右边两个角的 0.5 权重），夹取边缘则会把边界像素复制过来，数值完全不同；
- **偏移要真的加到坐标上**：采样位置是 `point + offset`，不是 `point` 本身；
- **聚合权重不归一化**：可变形注意力的权重来自上游 softmax，算子本身只做加权和；在算子内再除以权重和会把结果整体缩小。

本题要求实现单尺度、可批量、可带权聚合的可变形采样。CPU、纯确定性、无随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- 特征 `feature` 是 \( (C,H,W) \)，坐标约定 \(x\) 是列下标（\(0..W-1\)）、\(y\) 是行下标（\(0..H-1\)）。
- `points` 与 `offsets` 都是 \( (N,K,2) \)：前者是像素坐标（可小数、可越界），后者是偏移 \( (\mathrm{d}x,\mathrm{d}y) \)，实际采样位置为 \( (x+\mathrm{d}x,\ y+\mathrm{d}y) \)。两者形状、dtype 必须一致，\(K\ge1\)，\(N\) 可为 0。
- 双线性：对采样位置令 \(x_0=\lfloor x\rfloor\)、\(y_0=\lfloor y\rfloor\)、\(f_x=x-x_0\)、\(f_y=y-y_0\)（向下取整，负数同样，如 \( \lfloor-0.5\rfloor=-1 \)）；四个角 \( (x_0,y_0),(x_0+1,y_0),(x_0,y_0+1),(x_0+1,y_0+1) \) 的权重依次为 \( (1-f_x)(1-f_y),\ f_x(1-f_y),\ (1-f_x)f_y,\ f_xf_y \)。**每个落在 \( [0,W-1]\times[0,H-1] \) 之外的角按 0 参与**——不夹取、不复制边缘、不截断坐标；四个角全越界时结果为 0。
- 不带权重时返回 \( (N,K,C) \) 的采样结果；带 \( (N,K) \) 权重时返回 \( (N,C) \)，其中 \( \mathrm{out}[n,c]=\sum_k w[n,k]\cdot\mathrm{sampled}[n,k,c] \)，**不除以权重之和**（权重可以求和不为 1、可以为负、可以全为 0）。
- 输出 dtype 跟随 `feature`（内部一律 float64 计算再转回），不修改任何输入。
- 非法输入一律抛 `ValueError`：`feature` 非张量/非三维/`C`、`H` 或 `W` 为 0/dtype 非 float32、float64；`points`、`offsets` 非张量、不是 \( (N,K,2) \)、形状不一致、dtype 与 `feature` 不同、\(K<1\)；`weights` 非张量、形状不是 \( (N,K) \)、dtype 不同；`points`/`offsets`/`weights` 含 NaN 或 Inf。

## 示例

特征 \(C=2,\ H=W=3\)：

```
ch0 = [[1, 2, 3],      ch1 = [[10, 20, 30],
       [4, 5, 6],             [40, 50, 60],
       [7, 8, 9]]             [70, 80, 90]]
```

\(N=1,K=3\)，三个点与偏移：

```
k=0:  point (1,1)   offset ( 0.5, 0  )  -> 采样 (1.5, 1  )
k=1:  point (0,0)   offset (-0.5, 0  )  -> 采样 (-0.5, 0 )
k=2:  point (1,1)   offset ( 0.5, 0.5)  -> 采样 (1.5, 1.5)
```

逐个展开：

- \(k=0\)：\(x_0=1,f_x=0.5,y_0=1,f_y=0\)，只有 `(1,1)` 与 `(2,1)` 有非零权重，\(0.5\cdot5+0.5\cdot6=5.5\)，第二通道 \( 0.5\cdot50+0.5\cdot60=55 \)。
- \(k=1\)：\(x_0=-1,f_x=0.5,y_0=0,f_y=0\)。角 \((-1,0)\) 越界记 0，角 \((0,0)\) 权重 \(0.5\)，于是 \(0.5\cdot1=0.5\)、第二通道 \( 0.5\cdot10=5 \)。**若把坐标夹取到 0，这里会得到 1 而不是 0.5。**
- \(k=2\)：四个角的权重都是 \(0.25\)，\(0.25(5+6+8+9)=7\)，第二通道 \( 0.25(50+60+80+90)=70 \)。

采样结果

```
sampled[0] = [[5.5, 55.0],
              [0.5,  5.0],
              [7.0, 70.0]]
```

带权重 \( [0.5,0.25,0.25] \) 聚合：

\[
\mathrm{out}_0=0.5\cdot5.5+0.25\cdot0.5+0.25\cdot7=4.625,\qquad
\mathrm{out}_1=0.5\cdot55+0.25\cdot5+0.25\cdot70=46.25 .
\]

```
aggregated[0] = [4.625, 46.25]
```

注意偏移的作用：\(k=1\) 若不加偏移会取到 \( (0,0) \) 的 `1`，\(k=0\) 会取到 \( (1,1) \) 的 `5`；权重 \( [1,1,0] \) 若不归一化得 \(6\)，归一化则会得 \(3\)——这些都是判题覆盖的判别点。

## 约束

- 不带 `weights` 返回 \( (N,K,C) \)，带 `weights` 返回 \( (N,C) \)；dtype 与 `feature` 相同。
- 判题对 float64 输入用绝对容差 \( 10^{-12} \)，float32 输入用 \( 10^{-5} \)；形状与 dtype 用精确断言。
- 双线性的四个角与权重顺序、越界角按零、偏移的加法、向下取整（含负数）、聚合不归一化、\(N=0\)、\(K\ge1\) 都是判题的一部分。
- CPU、确定性、不调用随机数；输入坐标大幅越界（如 \(50,-20\)）必须返回 0 而不是抛错。
