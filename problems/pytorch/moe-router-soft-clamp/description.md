# MoE：路由 logits 的 tanh 软限幅与饱和并列

## 任务

实现 `solve`：先对路由 logits 做 tanh 软限幅，再取 sigmoid 得到分数；一个**只参与「选谁」、不参与加权**的逐专家偏置可以改变选择结果，权重始终由不带偏置的 sigmoid 分数归一化。

这是「软限幅门控 + aux-free 选择偏置」的受限数值模型。限幅的位置、偏置的作用范围、并列顺序和下溢时的退路都由题面显式规定；它不是任何训练框架的逐步复刻，也不涉及梯度或偏置更新。

## 输入

- `logits`：CPU float64 `[T,E]`；允许非连续张量，不修改输入。
- `bias`：`None`，或 CPU float64 `[E]`。
- `k`：真正的 Python `int`，`1 <= k <= E`。
- `tau`：非负的有限 `int`/`float`；`tau = 0` 表示关闭软限幅。
- `T,E = 1..8`。

`bool` 冒充 `int`、浮点的 `k`、`k` 越界、`tau` 为 NaN/±inf/负数、`bias` 长度不等于 `E`、dtype 不是 float64、不在 CPU、维度不对、传入的不是张量——都抛出 `ValueError`。

## 精确规则

软限幅发生在 sigmoid **之前**。`tau > 0` 时限幅，`tau = 0` 时原样通过：

$$
c_{ij}=\tau\tanh\!\left(\frac{z_{ij}}{\tau}\right)\ (\tau>0),\qquad c_{ij}=z_{ij}\ (\tau=0).
$$

分数与选择分数：

$$
s_{ij}=\sigma(c_{ij})=\frac{1}{1+e^{-c_{ij}}},\qquad u_{ij}=s_{ij}+b_i.
$$

`bias=None` 时取 $b_i=0$。

每行按 $u_{ij}$ 降序取 $k$ 个专家，记选中的专家编号为 $\pi_1,\dots,\pi_k$；**完全并列时编号较小的专家优先**。权重只用不带偏置的 $s$ 归一化：

$$
w_{i,j}=\frac{s_{i,\pi_j}}{\sum_{\ell=1}^{k}s_{i,\pi_\ell}}.
$$

若分母恰好等于 0（选中项的 sigmoid 全部下溢成 0），该行给均匀权重 $1/k$，此时 $\mathit{scores}$ 仍然如实是 0。

`tanh` 严格单调，所以只要浮点上还分得开，限幅不会改变排序；它改变的是**大 logits 被压成同一个值之后产生的并列**：`tau=1` 时 `tanh(20)` 与 `tanh(21)` 在 float64 里都恰好等于 1.0，两个专家从此不可区分。

## 返回

返回三元 `tuple`：

```text
(weights, indices, scores)
```

| 项 | 形状 / 类型 | 含义 |
| --- | --- | --- |
| `weights` | float64 `[T,k]` | 每行和为 1 的归一化权重（分母为 0 时是均匀 `1/k`） |
| `indices` | int64 `[T,k]` | 选中的专家编号，按选择分数降序 |
| `scores` | float64 `[T,E]` | 限幅并 sigmoid 之后的分数，含未被选中的专家 |

浮点结果按 `rtol=2e-12, atol=2e-12` 比较。

## 示例

```python
logits = [[2.0, 0.0, -1.0],
          [1.0, 1.0, 0.5]]

solve(logits, None, 2, 1.0)
# scores  = [[0.72392747, 0.5,        0.31830026],
#            [0.68169974, 0.68169974, 0.61351630]]
# indices = [[0, 1], [0, 1]]
# weights = [[0.59147906, 0.40852094], [0.5, 0.5]]

solve(logits, [0.1, -0.2, 0.0], 2, 1.0)
# indices = [[0, 2], [0, 2]]
# weights = [[0.69459625, 0.30540375], [0.52632126, 0.47367874]]
```

第一行：`tanh(2)=0.9640275800758169`，`1/(1+exp(-0.96402758))=0.7239274686640463`；`tanh(0)=0` 给出 `0.5`；`tanh(-1)=-0.7615941559557649` 给出 `0.3183002578054738`。取前两名 0、1，权重 `0.72392747/(0.72392747+0.5)=0.59147906`。

第二行：两个 `1.0` 限幅后完全相同，是严格并列，按编号取 0、1，权重各 `0.5`。

加上 `bias=[0.1,-0.2,0.0]` 后，第一行的选择分数变成 `[0.82392747, 0.3, 0.31830026]`，专家 1 被挤掉、专家 2 顶替；但归一化仍然只用 `s`，`0.72392747/(0.72392747+0.31830026)=0.69459625`，偏置不出现在权重里。把 `bias` 换成全 `0.37`，选择与权重都不变——给所有专家加同一个常数不改变任何东西。
