# 检索：倒数排名融合 RRF

## 题目描述

混合检索（hybrid search）常有多路召回——例如 BM25 关键词一路、向量语义一路——各路打分尺度不同、无法直接相加。**倒数排名融合**（RRF, Reciprocal Rank Fusion，Cormack et al., SIGIR 2009；Elasticsearch/OpenSearch `rrf`）只用**名次**而不用原始分数，天然免标定：一个文档的融合分等于它在每一路里 \(\frac{1}{k+\text{rank}}\) 的累加，\(k\) 为平滑常数（论文推荐 \(k=60\)）。排在多路前列的文档获得最高融合分。本题实现 RRF 打分与重排。

## 规则

实现 `solve(ranks, k)`。输入 `ranks`（int64，形状 \((L, N)\)）：`ranks[l, d]` 是文档 \(d\) 在第 \(l\) 路结果里的 **1-based 名次**，若该路未召回文档 \(d\) 则记为 `0`。对每个文档 \(d\) 求融合分 \(\text{score}(d)=\sum_{l:\,r_{l,d}>0}\frac{1}{k + r_{l,d}}\)。返回按 score **降序**排列的文档下标（int64，形状 \((N,)\)）；score 并列时按下标**升序**。\((N,)\) 是 `ranks` 的列数（候选文档全集）。

## 示例

\(L=2, N=3, k=60\)：

```
ranks = [[1, 2, 0],     # 路0: doc0 第1名, doc1 第2名, doc2 未召回
         [2, 0, 1]]     # 路1: doc0 第2名, doc1 未召回, doc2 第1名
score(doc0)=1/61+1/62=0.032522
score(doc1)=1/62       =0.016129
score(doc2)=1/61       =0.016393
降序: doc0 > doc2 > doc1
out = [0, 2, 1]   shape = (3,)
```

## 约束

- CPU；`k` 为正整数（默认口径 \(k=60\)）。
- 名次为 1-based；`0` 表示该路未召回、不贡献分数。
- 融合分只用名次、绝不使用（也不得臆造）任何原始检索分数。
- 并列按文档下标升序，保证确定性。
