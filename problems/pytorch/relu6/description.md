# ReLU6

## 题目描述

ReLU6 就是「带上界的 ReLU」：把激活裁剪到区间 $[0, 6]$。相比无界的 ReLU，它限制了单层
输出范围，使量化到 int8 时动态范围可控，因而是 MobileNet 等移动端网络在原论文中为高效
推理特意选用的激活。

## 规则

- 实现 `solve(x)`，返回 $\operatorname{ReLU6}(x) = \min(\max(x, 0), 6)$，形状不变。
- 输入小于 0 → 输出 0；输入大于 6 → 输出 6；中间恒等。
- 结果须与 `F.relu6(x)` / `torch.clamp(x, 0, 6)` 一致，保持输入 dtype。

## 示例

```
输入：x = [-2.0, -0.5, 0.0, 0.5, 2.0, 7.0]
输出：[0.0, 0.0, 0.0, 0.5, 2.0, 6.0]
```

## 约束

- 支持 float32 / float64 输入，输出 dtype 与输入一致
- 逐元素运算，不改变形状
