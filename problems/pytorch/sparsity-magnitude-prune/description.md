# 稀疏化：全局幅值剪枝

## 题目描述

**幅值剪枝（magnitude pruning）** 是最经典、也最常考的非结构化剪枝判据：权重的绝对值越小、对输出的贡献越有限，越该被丢弃。Han et al.（Deep Compression, arXiv:1510.00149）的「全局幅值阈值」版本一次性把整个张量里 \(|w|\) 最小的一批元素置零，达到目标稀疏率。

给定权重张量 `weight` 和目标稀疏率 `sparsity`（要置零的元素占比），把所有元素按绝对值升序排列，将最小的 \(k=\mathrm{round}(\text{sparsity}\cdot N)\) 个置零（\(N\) 为元素总数），其余保持不变。

## 规则

输入 `weight`（任意形状 float32）、标量 `sparsity \in [0,1]`。返回同形状 float32 张量：绝对值最小的 \(k=\mathrm{round}(\text{sparsity}\cdot N)\) 个元素被置为 0，其余原值保留。并列（相同 \(|w|\)）时按展平后的**索引升序**决定谁先被剪，保证确定性。禁止直接调 `torch.nn.utils.prune`。

## 示例

`weight=[1,-5,3,-2,0.5,-9]`、`sparsity=0.5`（\(N=6,k=3\)）：

```
|w| = [1,5,3,2,0.5,9]，最小的 3 个是 0.5(i4)、1(i0)、2(i3) → 置零
out = [0, -5, 3, 0, 0, -9]
```

## 约束

- CPU float32；`sparsity` 取 \([0,1]\)，\(k\) 用 `round`。
- 全局阈值（跨整层比较）而非逐行/逐通道：不同元素竞争同一稀疏预算。
- 输出与原张量同形状，被剪位置严格为 0（不改动未剪元素的值与符号）。
