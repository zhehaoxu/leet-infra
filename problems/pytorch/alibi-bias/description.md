# ALiBi 位置偏置（Attention with Linear Biases）

## 题目描述

ALiBi 不加位置向量，而是在注意力分数上按 **query 与 key 的距离** $|i-j|$ 施加一个与头相关的线性惩罚，越远惩罚越大，从而获得外推性更强的位置感知。

$$ \text{bias}[h, i, j] = -\,m_h \cdot |i - j|, \qquad m_h = 2^{-8h/n} $$

其中共有 $n$ 个头，头序号 $h$ 从 **1** 开始（1-indexed）。

## 规则

- 实现 `solve(seq_len, num_heads, dtype=torch.float32)`，返回形状 `(num_heads, seq_len, seq_len)` 的偏置张量。
- 斜率序列：第 $h$ 头（1-indexed）为 $m_h = 2^{-8h/n}$。当 $n=8$ 时即 $[2^{-1}, 2^{-2}, \dots, 2^{-8}]$。
- **单调性**：头序号越大，斜率越小（几何递减），衰减越慢、看得越远。
- 对角线恒为 0（$i=j$）；矩阵关于对角线对称；所有元素非正。

## 示例

```
输入：seq_len=3, num_heads=1
   唯一斜率 m=2^(-8*1/1)=2^-8=0.00390625
   |i-j| 距离矩阵 = [[0,1,2],[1,0,1],[2,1,0]]
输出：[[[ 0.0      , -0.00390625, -0.00781250],
        [-0.00390625, 0.0      , -0.00390625],
        [-0.00781250, -0.00390625, 0.0      ]]]
```

## 约束

- `dtype` 支持 float32/float64
- 与手推公式 $-m_h|i-j|$ 一致
