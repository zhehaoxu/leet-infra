# P-less-norm 采样

## 题目描述

P-less-norm 是 [P-less](#) 的**放宽版**：同样免超参、同样用碰撞概率 $\sum p^2$ 作判据，
但把阈值**按词表规模归一**，门槛比原版 P-less 低，因而保留更多候选、更偏多样性
（论文建议用于「重多样性胜过连贯性」的场景）。

原版 P-less 阈值是 $\text{thr}=\sum_i p_i^2$。P-less-norm 把它改写成——记 $v=V$ 为词表大小：

$$\text{thr} = \frac{v\,\sum_i p_i^2 - 1}{v - 1}$$

由于 $\sum p^2\in[1/v,\,1]$，此阈值把 $[1/v,1]$ 仿射拉回 $[0,1]$：均匀分布时阈值降到 $0$
（全保留），尖峰分布时逼近 $1$。相比原版，中间地带的 token 更容易被留下。判据同样是
$p_i \ge \text{thr}$。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法（在保留分布的
> CDF 上取首个 $\ge u$ 的位置）。

## 规则

- 实现 `solve(logits, u)`：`logits` 形状 `(..., V)`，`u` 为每行一个、取值 $[0,1)$ 的
  均匀随机数（形状 `(...,)` 或标量）。**无其它超参**。
- 步骤（逐行）：① `probs = softmax(logits)`；② 令 `v = probs.shape[-1]`、
  `thr = (v * (probs**2).sum(-1, keepdim=True) - 1) / (v - 1)`；③ 保留 `probs >= thr`，
  其余置 0；④ 归一化 → `filtered`（形状同 `probs`，每行和为 1）；
  ⑤ 用 `u` 在 `filtered`（原顺序）CDF 上逆变换采样得 `chosen`。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`，`chosen` 形状 `(...,)`。

## 示例

```
输入：logits = [1, 0.8, 0.6, 0.4, 0.2, 0, -0.2]，u = 0.5
  probs(softmax) = [0.240601, 0.196987, 0.161279, 0.132044, 0.108109, 0.088512, 0.072468]
  v = 7, Σp² = 0.164913
  thr = (7 * 0.164913 - 1) / 6 = 0.025732
  保留 p >= 0.025732 → 全部 7 个都满足（最矮 0.0725 也 ≥ 阈值）
  归一化 → filtered = probs = [0.240601, 0.196987, 0.161279, 0.132044, 0.108109, 0.088512, 0.072468]
  CDF = [0.2406, 0.4376, 0.5989, ...]，u = 0.5 → 首个 ≥0.5 是位置 2 → 选中原始索引 2
输出：filtered = probs, chosen = 2
```

## 约束

- float32 输入；`u ∈ [0,1)`；无策略超参
- `V ≥ 2`（分母 `v-1` 需为正）
- `filtered` 每行和为 1，被丢弃位置严格为 0；`chosen` 必落在保留集合内
- 支持批量 `(..., V)`；argmax 恒被保留（thr ≤ p_max 恒成立）
