# 采样：Contrastive Search 候选退化惩罚选择（CNTRM）

## 题目描述

贪心与 beam search 会把自回归模型拖进**退化**（degeneration）：句子语法完好、却反复吐出同一批词，
信息量随长度衰减。纯随机采样确实能打散循环，代价是语义容易跑偏。**Contrastive Search**（论文里的
代号 CNTRM）把"下一个 token 选谁"改写成**双目标**：候选既要是模型自己觉得概率高的，又要在**表示空间**
里和已经写下的内容足够不像。于是一次解码步不再只比 \(\log p\)，而是比"置信度 − 退化惩罚"，并在
\(\top_k\) 候选集合上取 **argmax**。

惩罚项的**信息来源**是本题与所有重复抑制类采样的分水岭。`penalty-sampling` 只统计 token 在历史窗口里
出现了几次，是字符串级的计数；本题的惩罚来自"把候选接上前缀之后"重新取出的隐态与历史隐态之间的
**余弦相似度**，所以换了说法的复读、近义改写照样被压。相似度不由模型现算——判题环境里没有语言模型，
它作为显式入参 \(sim\) 给出，因此整道题就是一次纯张量运算。

还要注意本题**不接收随机数**。因为选择是 argmax，同一条输入永远给出同一条输出，确定性是白送的；
这是它与同合集 top-k / top-p / XTC 等"抽签型"采样最直接的接口差异（那些题都要求把均匀随机数当参数传进来）。
每一步只处理**一个**解码步：真实解码中被选中 token 的隐态会进入下一步的历史，退化惩罚随重复累积而单调抬升，
这个跨步效应本题不要求模拟，只体现在给定的 \(sim\) 数值里。

## 规则

记词表大小 \(V\)、logits \(z\in\mathbb{R}^{V}\)、历史隐态个数 \(T\)、折权 \(\lambda\in[0,1]\)。

- **① 候选集合**。\(p=\operatorname{softmax}(z)\)，按概率**降序**取前 \(K=\min(k,V)\) 个 token，
  概率并列时按 token 索引**升序**（稳定破平）→ \(\text{cand}_0,\dots,\text{cand}_{K-1}\)。
  \(k>V\) 被夹到 \(V\)，不是报错；\(k\ge 1\)。
- **② 退化惩罚**。\(sim\in\mathbb{R}^{K\times T}\) 的**第 \(j\) 行**必须对应**第 \(j\) 个候选**（即降序候选），
  而不是原词表的前 \(K\) 行：
  \[
  \deg_j=
  \begin{cases}
  \operatorname{clamp}_{[0,1]}\!\Big(\max_{1\le i\le T}\frac{sim_{j,i}+1}{2}\Big), & T>0,\\[6pt]
  0, & T=0\ \text{（无历史，此时 }sim\text{ 给 }K\times 0\text{ 空矩阵）.}
  \end{cases}
  \]
  \(\deg_j\in[0,1]\)：与历史某个隐态完全同向（\(\cos=1\)）记满 \(1\)，完全反向记 \(0\)。
  历史内部谁早谁晚无所谓，因为只取 \(\max\)——惩罚由"**最像的那一个**"决定，不是平均值。
- **③ 选择分数**。
  \[
  \text{score}_j=(1-\lambda)\cdot\big[\log\operatorname{softmax}(z)\big]_{\text{cand}_j}\;-\;\lambda\cdot\deg_j .
  \]
  log 概率取**全词表** \(\log\operatorname{softmax}\)，**不在候选核内重新归一**（这一点和 top-k 采样把核内
  概率除到和为 1 的口径不同）。
- **④ 选出**。\(j^{*}=\arg\max_j \text{score}_j\)，分数严格并列时取候选序列里**更靠前**者
  （即 logprob 更大的那个）；\(\text{chosen}=\text{cand}_{j^{*}}\) 是**原词表索引**。
  整个流程**没有抽签**，任何随机数入参都是多余且错误的。
- **返回四元组** \((\text{cand\_idx},\ \deg,\ \text{scores},\ \text{chosen})\)：`cand_idx` 为 `int64` 的 \((K,)\)；
  `deg`、`scores` 为 `float32` 的 \((K,)\) 且顺序与候选严格一致；`chosen` 为标量张量。

## 示例

```
输入：z = [1.5, 1.2, 0.5, -1.0]（V=4），k = 3，λ = 0.6，T = 2
  softmax(z)      = [0.456458, 0.338152, 0.167921, 0.037468]
  log_softmax(z)  = [-0.784259, -1.084259, -1.784259, -3.284259]
  候选（概率降序 top-3）= [0, 1, 2]，sim 行序与之对齐：
      sim = [[ 0.95,  0.90],   → deg_0 = max(0.975000, 0.950000) = 0.975000
             [-0.80, -0.60],   → deg_1 = max(0.100000, 0.200000) = 0.200000
             [ 0.00,  0.20]]   → deg_2 = max(0.500000, 0.600000) = 0.600000
      （sim 全在 [-1,1]，夹到 [0,1] 不改变结果）
  score_0 = 0.4·(-0.784259) − 0.6·0.975000 = -0.898704
  score_1 = 0.4·(-1.084259) − 0.6·0.200000 = -0.553703
  score_2 = 0.4·(-1.784259) − 0.6·0.600000 = -1.073704
  argmax → 候选内秩 j*=1 → chosen = cand_1 = 1   ← 概率最高的 token 0 被退化惩罚挤掉了
输出：cand_idx = [0, 1, 2]
      deg      = [0.975000, 0.200000, 0.600000]
      scores   = [-0.898704, -0.553703, -1.073704]
      chosen   = 1
```

同一份数据只换 \(\lambda\)，可以看到这是一条**连续的折权轴**：\(\lambda=0\) 时 `scores` 恰好等于
\([\log p_0,\log p_1,\log p_2]=[-0.784259,-1.084259,-1.784259]\)，选 \(0\)（退化成贪心）；
\(\lambda=0.2\) 时 scores \(=[-0.822407,-0.907407,-1.547407]\)，仍选 \(0\)；
\(\lambda=0.4\) 时 scores \(=[-0.860555,-0.730555,-1.310555]\)，改选 \(1\)。
精确翻盘点是 \(\lambda^{*}=0.3/(0.3+0.775)=0.279070\)（分子是两候选的 logprob 差，分母再加上退化惩罚差）。

```
极端 λ=1：只看"谁最不像历史"，候选集合本身不变
  z = [2.0, 1.0, 0.0, -1.0]，k = 4，λ = 1.0，T = 2
  sim = [[ 1.0,  0.8],   → deg = [1.000000, 0.250000, 0.700000, 0.400000]
         [-1.0, -0.5],      scores = −deg = [−1.000000, −0.250000, −0.700000, −0.400000]
         [ 0.0,  0.4],   chosen = cand[argmin deg] = 1
         [-0.2, -0.9]]
```

```
无历史 / 夹取 / 并列三个边界（各自独立的一行输入）
  T=0：z = [0.2, 1.9, -0.4, 0.7]，sim 形状 (4, 0)，k = 4，λ = 0.5
       cand = [1, 3, 0, 2]，deg = [0, 0, 0, 0]，
       scores = [-0.230020, -0.830020, -1.080020, -1.380020]，chosen = 1（λ 取 0/0.5/1 都一样）
  k>V：z = [1.0, 1.0, 0.0]，k = 99 → K = 3，cand = [0, 1, 2]（并列 1.0 按索引升序）
       sim = 全 0 的 (3, 2) → deg = [0.5, 0.5, 0.5]；λ = 0.5 →
       scores = [-0.680997, -0.680997, -1.180997]，0 与 1 严格并列 → chosen = 0（取更靠前的候选）
```

## 约束

- **纯 CPU、纯手写**。判题环境 `.venv-eval` 只有 `torch` / `numpy` / `transformers` 且**离线**：没有
  llama.cpp、没有 HF 的 `LogitsProcessor` / `GenerationMixin` 采样类可直接借用，`sklearn`、`nltk` 也不存在。
- **所有随机性必须来自显式入参**——而本题**根本没有随机数入参**：CNTRM 的单步选择是候选集合上的
  argmax，天然确定。不要调用 `torch.rand` / `manual_seed`，也不要把结果依赖在排序稳定性之外的东西上。
- 形状与 dtype：\(z\) 为一维 `float32` \((V,)\)；\(sim\) 为 `float32` \((K,T)\)，\(K=\min(k,V)\)，
  元素是余弦相似度、落在 \([-1,1]\)；\(T\) 可为 \(0\)。返回的 `cand_idx` / `chosen` 是 `int64`，
  `deg` / `scores` 是 `float32`。
- 取值范围：\(k\ge 1\)（允许 \(k>V\)，夹到 \(V\)）；\(\lambda\in[0,1]\)；\(\deg\in[0,1]\)。
- 判题容差：`deg` 用 `atol=1e-6`，`scores` 用 `atol=1e-5, rtol=1e-5`，`cand_idx`/`chosen` 要求**严格相等**。
- **恒成立的退化性质**：\(\lambda=0\) ⇒ 完全等于在 \(\top_k\) 里取 logprob 最大者 = 全局 argmax，且
  `scores` 恰为 \(\log p[\text{cand}]\)；\(T=0\) ⇒ \(\deg\equiv 0\)，\(\lambda\) 取任何值都不改变结果；
  \(\lambda=1\) ⇒ \(\text{score}=-\deg\)，选"最不退化"的候选，但**候选集合与 \(\lambda\) 无关**（换 λ 不换集合）。
- 与邻近题的分工（详见 `notes.md`）：`top-k-sampling` 同样取 \(\top_k\)，但它在核内归一后**抽签**、
  且概率本身是唯一准则；`penalty-sampling` 按历史 **n-gram 次数**改 logits、不选 token；
  `mirostat-v2-sampling` 用跨步的困惑度状态 \(\mu\) 自适应截断；本题用**嵌入相似度**、在候选集内 argmax。
