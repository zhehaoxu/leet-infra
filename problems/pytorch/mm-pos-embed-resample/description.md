# 多模态：二维位置嵌入的双三次重采样

视觉 Transformer 的位置序列通常由两部分组成：前面的 CLS 等 **prefix token**，以及按行主序展平的二维空间位置网格。改变空间分辨率时，应只重采样网格，不能把 prefix 混入空间邻域。

请拆分这两部分，用显式双三次插值把旧网格变为新网格，再按原顺序拼回 prefix。旧网格和新网格都可以是矩形。完整参数与返回值契约见 starter。

## 重采样规则

### 1. 保护 prefix

前缀必须逐位保持，不能参与插值或精度转换。先校验旧网格与空间 token 数量一致；若新旧高宽分别相同，直接返回输入的克隆。仅 token 总数相同，并不代表网格相同。

### 2. Half-pixel 坐标

每个空间轴独立映射。目标索引 $i$ 对应的源坐标为

$$
u=(i+0.5)\frac{n_{\mathrm{src}}}{n_{\mathrm{dst}}}-0.5.
$$

取 $\lfloor u\rfloor+[-1,0,1,2]$ 四个邻点。**不截断坐标 $u$**；只把各邻点的读取索引限制到有效范围，权重仍按截断前的邻点位置计算。重复落在边界的贡献须全部累加。

### 3. Keys 双三次核

令 $d$ 为源坐标到未截断邻点的绝对距离，$a=-0.75$：

$$
K(d)=
\begin{cases}
(a+2)d^3-(a+3)d^2+1,&0\le d\le1,\\
ad^3-5ad^2+8ad-4a,&1<d<2,\\
0,&d\ge2.
\end{cases}
$$

对两个轴的权重取乘积，将 $4\times4$ 个邻点加权求和。嵌入的每个通道独立计算，随后按行主序重新展平。

不使用 antialias，也不添加额外 offset。必须显式实现上述插值，禁止调用 `interpolate`、`grid_sample`、`upsample` 及其别名或封装；原生算子仅供测试 oracle 使用。

## 示例

```text
pos_embed = [[[99.0], [0.0], [8.0]]]
old_hw = (1, 2)
new_hw = (1, 4)
num_prefix_tokens = 1
```

输出：

```text
[[[99.0], [-0.84375], [1.8125], [6.1875], [8.84375]]]
```

示例使用 float32，来自参考实现实跑，并与原生非抗锯齿 bicubic 对拍。前缀 `99.0` 不变；空间结果超出原值范围是双三次核的正常过冲，不要截断。
