# PP-Structure recovery 双栏版面阅读顺序账

PaddleOCR 的 PP-Structure 恢复模块在把版面识别结果导出为 docx 之前，调用
`ppstructure/recovery/recovery_to_doc.py` 的 `sorted_layout_boxes` 对区域做
阅读顺序重排：双栏文档按"先左栏自上而下、再右栏自上而下"输出，全宽块
（标题、跨栏表格等）作为 `single` 分隔点切断分栏。本题要求你逐条复刻这
套规则的状态机。

## 接口

```python
solve(bboxes: list[list[float]], w: float) -> dict
```

- `bboxes`：版面框 `[x0, y0, x1, y1]`，下标即原始顺序；
- `w`：页宽；
- 返回 `{"order": [原始下标...], "layouts": ["single"/"double"...]}`，
  `order` 是重排后的输出顺序，`layouts` 与之对齐给出每框的栏属性。

## 规则

1. **单框直通**：`len(bboxes) == 1` 时不做任何排序，返回
   `order=[0], layouts=["single"]`；空输入返回两个空列表。
2. **扫描序**：其余情形先按 `(y0, x0)` 升序**稳定**排序（键相同的框保持
   原始相对顺序），得到扫描序列。
3. **扫描状态机**：维护左右两个桶，自左向右逐框处理：
   - **末框分支**（当前框是扫描序列最后一个）：
     - 若 `y0 > 前一框的 y1` 且 `x0 < w/2` 且 `x1 > w/2`（与前一框之间有
       纵向间隙且横跨中线）：先 flush 左桶、再 flush 右桶，末框标
       `single` 追加；
     - 否则若 `x1 > w/2`：末框标 `double` 追加进右桶，然后 flush 左桶、
       flush 右桶（末框在右桶组**内部**）；
     - 否则若 `x0 < w/2`：末框标 `double` 追加进左桶，然后 flush 左桶、
       flush 右桶（末框在左桶组**内部**）；
     - 否则（只有 `x0 == x1 == w/2` 的退化零宽框可能落入）：**静默丢弃**，
       且已攒的左右桶**一并丢弃不输出**。
   - **非末框**：
     - `x0 < w/4` 且 `x1 < 3w/4`：标 `double` 进左桶；
     - 否则 `x0 > w/4` 且 `x1 > w/2`：标 `double` 进右桶；
     - 否则：先 flush 左桶、再 flush 右桶，本框标 `single` 追加（作为
       分栏切换的分隔点）。
4. 所有比较均为**严格不等号**；flush 顺序恒为"先左桶后右桶"。

## 样例

```python
solve([[50,100,300,200],[600,100,900,200],
       [50,250,300,350],[600,250,900,350]], 1000)
# 两栏交替：左桶 [0,2]、右桶 [1]，末框(3)入右桶后 flush
# → {"order":[0,2,1,3], "layouts":["double"]*4}

solve([[50,100,300,200],[600,100,900,200],
       [100,400,900,500],[50,600,300,700]], 1000)
# 第 3 框全宽 → flush 左右桶后标 single；末框(3)窄左栏入左桶
# → {"order":[0,1,2,3], "layouts":["double","double","single","double"]}
```

## 提示

- 末框两个 `double` 分支的 flush 时机不同：横跨 `single` 分支是"先
  flush 后追加"，列分支是"先入桶后 flush"——输出顺序不同。
- 退化零宽框的丢弃分支同时丢掉两个桶，输出可能为空列表。
- 官方实现循环出口只有末框分支与空序列出口，出口后的残余 flush 不可达。
