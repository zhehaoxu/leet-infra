# 解题说明 · DAPO

## Clip-Higher 与熵塌缩

PPO 的裁剪把 $\rho$ 卡在 $[1-\epsilon,1+\epsilon]$ 内。对正优势样本，上界直接限制了「把一个低概率 token 的概率抬多快」；一旦大量 token 的概率被同步压低，策略熵就迅速下降，采样变得和贪心解码差不多，探索随之停止。DAPO 观察到大模型 RL 里熵塌缩往往从**少数被过度抑制的 token**开始，于是把上界单独放宽（$\epsilon_\text{high}$ 常取 0.28 而 $\epsilon_\text{low}$ 取 0.2）。注意这只影响"能被抬高多少"，对负优势侧没有放宽——$\min(\rho A,\bar\rho A)$ 在 $A<0$ 时选的是更负的未裁剪项，上界根本不参与。

## 动态采样：为什么可以整组丢

组内优势是中心化的，$acc_b=0$（全错）或 $1$（全对）时 std 为 0，所有优势也都是 0，组内每个 token 的 surrogate 都是 0。这些组对梯度的贡献恒为 0，却在组 batch 里占着位置、消耗采样预算。DAPO 把它们过滤掉，把省下的算力换成更多有效组。由于后续是**全局 token 平均**，丢掉整组不会改变保留组之间的相对权重——如果用「逐回答平均」再合成，删组就会改变各组的权重，所以「组过滤 + token 级平均」是一对必须一起用的设计。

## Token 级损失为什么重要

逐回答平均会让每个回答的总权重相同，于是长回答里的单个 token 权重只有短回答的 $1/|o|$。在 RL 里这等于系统性地降低长序列 token 的学习信号，模型倾向写短、或长序列里的关键决策学不到。DAPO 改成把所有保留 token 汇成池做一次平均，每个 token 等权，长度不再隐式调节梯度。

## 与 GRPO / Dr. GRPO 的关系

DAPO 的优势仍用 GRPO 的「组内中心化 + 除 std」，只是分子分母都换了范围（过滤组、全局 token 池）。与 Dr. GRPO 对照着看：Dr. GRPO 认为除 std 会带来难度偏置、坚决去掉；DAPO 保留 std，但用组过滤把「无信息的组」直接删掉，从另一个方向处理同一问题。三种口径放在同一合集里，可以把「归一化」与「采样筛选」这两个独立旋钮拆开理解。

## 退化与边界

整批都被过滤时 $N_\text{valid}=0$，损失定义为 0 而不是 NaN——真实训练里这种 batch 会被跳过，但函数本身必须给出确定值。奖励必须严格是 0/1（不是"近似二值"），因为 $acc_b$ 的过滤条件是严格不等式 $0<acc_b<1$，浮点奖励会让"全对"的组以 $1-10^{-17}$ 的形式漏过过滤。
