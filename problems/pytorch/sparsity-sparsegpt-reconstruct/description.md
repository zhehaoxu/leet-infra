# 稀疏化：SparseGPT 逐列剪枝与 Hessian 误差补偿

## 题目描述

一次性按幅值剪枝会让**输出**偏离原模型：被剪掉的权重值直接消失，它对下一层激活的贡献也一并消失了。SparseGPT / OBS 家族的核心技巧是：把每个被剪元素造成的**误差**，用校准数据的二阶信息（Hessian 的逆）分摊到**还没被处理的列**上，从而在保持硬掩码的同时把层输出误差压到最小。

问题形式化：最小化 \(\|W X-\hat W X\|_2^2\)，约束是 \(\hat W\) 必须服从掩码。OBS 的解是逐列扫描：处理到第 \(j\) 列时

$$
Q_j = W_{:,j}\odot m_{:,j},\qquad
e_j=\frac{W_{:,j}-Q_j}{[H^{-1}]_{jj}},\qquad
W_{:,j}=Q_j,\qquad
W_{:,j+1:}\mathrel{-}=e_j\otimes [H^{-1}]_{j,\,j+1:}
$$

其中 \(H=XX^\top\) 是校准激活的二阶矩，\(H^{-1}\) 由外部给定（真实实现用 Cholesky 增量求逆，本题把它作为输入，聚焦补偿规则本身）。第 \(j\) 列一旦被掩码定型，它造成的误差就只往右侧「推」，右侧列在轮到自己时同样先掩码、再继续右推。

## 规则

给定 `weight`（float32，\((R,C)\)）、`mask`（float32，\((R,C)\)，0 表示该元素被剪）、`Hinv`（float32，\((C,C)\)，对称正定，即 \(H^{-1}\)）：

对 \(j=0,1,\dots,C-1\) 依次执行：

1. `cur = W[:, j]`（当前值，可能已被左侧列推过）；
2. `Q = cur * mask[:, j]`；
3. `e = (cur - Q) / Hinv[j, j]`；
4. `W[:, j] = Q`；
5. 若 \(j+1<C\)：`W[:, j+1:] -= e ⊗ Hinv[j, j+1:]`（外积）。

返回 `W_out`，float32，形状 \((R,C)\)。禁止 `torch.linalg.inv` 与现成 SparseGPT 实现。

## 示例

```
weight = [[1, 2, 3],
          [4, 5, 6]]
mask   = [[1, 0, 1],
          [0, 1, 1]]
Hinv   = [[2, 1, 0],
          [1, 2, 1],
          [0, 1, 2]]

j=0: cur=[1,4]  Q=[1,0]   e=([1,4]-[1,0])/2=[0,2]
     W[:,0]=[1,0]; W[:,1:] -= [0,2]⊗[1,0] → 列1 [2,5]-[0,2]=[2,3]，列2 不变 [3,6]
j=1: cur=[2,3]  Q=[0,3]   e=([2,3]-[0,3])/2=[1,0]
     W[:,1]=[0,3]; W[:,2] -= [1,0]⊗[1] = [3,6]-[1,0] = [2,6]
j=2: cur=[2,6]  Q=[2,6]   e=0，无右侧列

W_out = [[1, 0, 2],
         [0, 3, 6]]
```

## 约束

- CPU float32；`Hinv` 对称正定（对角元可能很小但不为 0）。
- 掩码位必须**严格为 0**；未被掩码的位会被后续列的误差补偿改写，不保证保持原值。
- 最后一列没有右侧可推，误差被就地丢弃。
- 当 `Hinv` 为单位矩阵时列间无耦合，结果必须恰好等于逐元素掩码 `weight * mask`。
