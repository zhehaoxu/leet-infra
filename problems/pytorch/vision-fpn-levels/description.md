# 检测：FPN 自顶向下融合与层尺寸账

## 题目描述

FPN（Feature Pyramid Network，Lin et al., CVPR 2017）解决的问题是：检测器需要多尺度的特征图，而 backbone 只有一根「自底向上」的主干——深层语义强但分辨率低，浅层分辨率高但语义弱。FPN 用一条**自顶向下**的通路把深层语义补回浅层：每一级先用 1×1 侧接卷积把通道数统一到 `fpn_dim`，再把上一级（更粗糙）的融合结果按最近邻放大到本级尺寸逐元素相加。

工程实现里真正容易错的不只是卷积和相加，还有一本**尺寸账**：每一级输出多大、步长是多少、侧接卷积有多少参数、每个位置放几个 anchor、总共多少 anchor。这本账是后续 anchor 生成、损失分配、推理解码的共同输入，算错一处就会在训练时不报错、但 mAP 掉点。尤其是：

- 步长是**声明**出来的配置，不是从特征图尺寸反推的（尺寸不一定是 2 的幂）；
- 可选的 P6 由 P5 池化得到，它**没有侧接卷积**，但要有自己的步长（上一级的两倍）和 anchor 数；
- 非整数倍的放大（例如 3→5）必须按整数下标规则取整，插值会给出不同的值。

本题要求把「1×1 侧接 → 自顶向下最近邻相加 → 可选 P6 池化」这条链路与全部账本一次算对。CPU、确定性、无随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- 输入是一组 backbone 特征图，按分辨率从高到低排列，每项形状 \( (N,C_i,H_i,W_i) \)，各级 \(N\) 相同、\(C_i\) 可不同，\(H_i,W_i\ge1\)。
- 侧接：第 \(i\) 级用形状 \( (\text{fpn\_dim},C_i) \) 的二维权重做 1×1 卷积，输出 \( (N,\text{fpn\_dim},H_i,W_i) \)；偏置可逐级给或为 None，给了就是形状 \( (\text{fpn\_dim},) \) 的一维张量。所有级的 `fpn_dim` 必须相同。
- 自顶向下：最粗一级的融合结果就是它的侧接输出；对 \( i=L_{\text{in}}-2,\dots,0 \)，把 \( \text{fused}[i+1] \) 按**整数最近邻**规则放大到 \( (H_i,W_i) \) 后与 \( \text{lateral}[i] \) 相加：
  \[
  \text{src\_y}=\left\lfloor \frac{\text{dst\_y}\cdot H_{\text{up}}}{H_i}\right\rfloor,\qquad
  \text{src\_x}=\left\lfloor \frac{\text{dst\_x}\cdot W_{\text{up}}}{W_i}\right\rfloor .
  \]
  不插值、不夹取；放大倍率不整时（如 3→5）该规则把源行/列映射成 \( [0,0,1,1,2] \)。目标尺寸取自本级侧接输出，所以相加时天然对齐。
- 可选 P6：仅当显式要求时，对融合后的 P5 做 `kernel_size=2, stride=2, padding=0` 的最大池化，尺寸为 \( (\lfloor H_5/2\rfloor,\lfloor W_5/2\rfloor) \)——奇数边长丢掉最后一行/最后一列，不做 ceil 补齐；要求 \(H_5,W_5\ge2\)，否则抛 `ValueError`。P6 没有侧接卷积。
- 账本（返回 dict，键固定）：
  - 融合后的特征列表，长度 \(L=L_{\text{in}}+1\)（含 P6 时）或 \(L_{\text{in}}\)；
  - 每级尺寸 \( (L,2) \) 的 int64；
  - 每级步长 \( (L,) \)：默认第 \(i\) 级取 \(2^{2+i}\)（从 C2 起算的 4/8/16/32），显式给出时**原样记账**、不从尺寸反推；P6 的步长 = 最粗一级的两倍；
  - 每级侧接参数量 \( (L_{\text{in}},) \)：\( \text{fpn\_dim}\cdot C_i + (\text{fpn\_dim}\ \text{若该级有 bias}) \)，**不含 P6**，以及它们的和；
  - 自顶向下「放大 + 相加」的次数 \( L_{\text{in}}-1 \)（单级为 0，P6 的池化不计）；
  - 每级 anchor 数 \( (L,) \)= 每位置 anchor 数 \( \times H_l\times W_l \)，以及总和。
- 非法输入一律抛 `ValueError`：特征列表为空或某项不是四维张量、\(H/W<1\)；权重/偏置/步长列表长度不等于级数；权重不是 \( (\text{fpn\_dim},C_i) \) 的二维张量（含 `fpn_dim<1`、与特征通道数不一致、级间 `fpn_dim` 不一致）；偏置既不是 None 也不是 \( (\text{fpn\_dim},) \)；步长不是正整数；每位置 anchor 数 \(<1\)；要求 P6 但 P5 的 \(H\) 或 \(W<2\)。不修改任何输入张量。

## 示例

两级特征、`fpn_dim=2`。第一级 \(2\times2\)、两个通道，第二级 \(1\times1\)、三个通道：

```
f0 (ch0) = [[1,  2],      f0 (ch1) = [[10, 20],
            [3,  4]]                  [30, 40]]
f1 = [5, 6, 7]^T   (1x1，三个通道)
```

侧接权重：第一级取单位阵（通道直通、无 bias），第二级取 `[[1,1,0],[0,1,1]]`、bias `[0,1]`：

```
lateral0 = f0
lateral1 : ch0 = 5+6+0 (+0) = 11
           ch1 = 0+6+7 (+1) = 14
```

自顶向下：把 `lateral1` 放大到 \(2\times2\) 后逐元素相加，

```
P5 = [[[11]], [[14]]]                       （最粗一级直接就是侧接输出）
up = 把 P5 每格复制成 2x2 -> ch0 全 11、ch1 全 14
P4 = lateral0 + up:
     ch0 = [[1+11, 2+11], [3+11, 4+11]] = [[12, 13], [14, 15]]
     ch1 = [[10+14, 20+14], [30+14, 40+14]] = [[24, 34], [44, 54]]
```

账本：

```
sizes             = [[2,2], [1,1]]
strides           = [4, 8]                （默认 2^(2+i)）
lateral_params    = [2*2, 2*3+2] = [4, 8] （第二级有 bias）
num_lateral_params= 12
num_upsample      = 1
anchors_per_level = [3*4, 3*1] = [12, 3]
num_anchors       = 15
```

注意步长 4/8 与特征图尺寸 2×2 并不自洽——这是因为步长是**声明**的账本项（默认从 C2 起算），本题不按 \(H\) 反推它。

## 约束

- 返回 dict 的键固定为 `features`、`sizes`、`strides`、`lateral_params`、`num_lateral_params`、`num_upsample`、`anchors_per_level`、`num_anchors`；融合特征与输入同 dtype/device。
- 判题对融合特征用绝对容差 \( 10^{-5} \)（float32 输入）或 \( 10^{-12} \)（float64 输入）；`sizes`/`strides`/`lateral_params`/`anchors_per_level` 用 `torch.equal`；三个标量用精确相等。
- 放大下标、P6 的向下取整、`fpn_dim` 的级间一致性、步长不被尺寸反推、P6 不计侧接参数、`num_upsample = L_in - 1` 都是判题的一部分。
- CPU、确定性、不调用随机数；单级输入、非方形特征、非整数倍放大、奇数边长 P6 都要给出上述结果而不是报错。
