# 采样：logit 偏置与禁用 token

## 题目描述

调采样时最常见的外部指令有两种：把某个 token 的可能性**往上/往下推一推**，以及**绝对不许**某个 token 出现。前者是 OpenAI `logit_bias` 那套「token → 偏置值」的映射表，后者是各家引擎的 banned / suppress 列表。它们看着都是"改某个 token 的分数"，但数学上是两类东西：偏置是在 softmax **之前**给 logit 做**平移**，改的是这一项与其它项的差、其他 token 之间相对关系一点不动；禁用是把支持集**删掉一个元素**，只有写成 \(-\infty\) 才能让概率**恰好**为 \(0\)。

本题把这两步合成一个算子：偏置表 → 强制掩码 → softmax → 单次采样。它也是 llama.cpp 采样链里排在最前面的那一段（bias 与 banned 合成一个采样器、且在任何截断/温度之前执行），但这里**只考这一步的数学**：没有温度、没有 top-\(k\)/top-\(p\)，因此不存在顺序歧义。

## 规则

- 输入：`logits`（形状 \((V,)\) 或 \((\dots,V)\)，最后一维是词表）、一条偏置表（两个等长列表：token 下标与对应的偏置值，第 \(i\) 条就是把 `bias_value[i]` 加到下标 `bias_token[i]` 上）、一条禁用下标列表 `banned`、以及均匀随机数 \(u\)（标量、单元素，或与行数一致的一维，取值 \([0,1)\)）。**随机性只能来自 \(u\)。**
- **① 加性偏置，按列表顺序逐条作用**：\(\ell_t \leftarrow \ell_t + \delta\)。同一下标在表里出现多次就**逐条累加**（不做合并，`+0.5` 再 `+1.5` 等价于 `+2.0`）。**下标越界或为负的条目没有任何副作用**——不报错、不裁剪、不取模、也不影响表里其它条目。
- **② 强制掩码**：把 `banned` 里每个命中 \([0,V)\) 的下标的 logit **置 \(-\infty\)**；同样跳过越界/负下标。这一步在 ① **之后**执行，所以同一下标既被加了偏置又被禁用时，最终结果是 \(-\infty\)（掩码覆盖偏置）。
- **③ softmax**：对偏置与掩码之后的 logits 做 softmax。被禁用的项概率**恰好为 \(0\)**，其余项按**存活集合**归一化（等价于「先把这些 token 从词表里删掉，再做 softmax」，而不是先算全词表 softmax 再补归一化）。
- **④ 单次采样**：\(u\) 在 `filtered` 的**原下标顺序** CDF 上取逆变换（第一个使累积和 \(\ge u\) 的下标）得 `chosen`；\(\texttt{chosen}\) 必然落在未禁用的位置上。
- 输出三件：`biased_logits`（形状同 `logits`，含 \(-\infty\)，是新张量而不是对入参的就地修改）、`filtered`（每行和为 \(1\)、被禁用位为 \(0\)）、`chosen`（与行数一致；单行时是 0 维张量）。

## 示例

```
输入：logits = [1.0, 0.5, 0.0, -0.5, -1.0]
      偏置表：下标 [1, 1, 3] 对应偏置 [0.5, 1.5, -2.0]（按列表顺序逐条作用）
      禁用表：下标 [4]
      u = 0.6

① 偏置：下标 1 出现两次 → 0.5 + 0.5 + 1.5 = 2.5；下标 3 → -0.5 - 2.0 = -2.5；下标 0、2 不在表里 → 原样
② 掩码：下标 4 → -inf
   biased_logits = [1.0, 2.5, 0.0, -2.5, -inf]
③ softmax（存活集合归一化，被禁项精确为 0）
   filtered = [0.170075, 0.762222, 0.062567, 0.005136, 0.0]
   （没偏置没禁用时是 [0.428656, 0.259993, 0.157694, 0.095646, 0.058012]）
④ filtered 的原顺序 CDF = [0.170075, 0.932297, 0.994864, 1.0, 1.0]，u = 0.6 → 首个 ≥ 0.6 是下标 1

输出：biased_logits = [1.0, 2.5, 0.0, -2.5, -inf]
      filtered = [0.170075, 0.762222, 0.062567, 0.005136, 0.0]
      chosen = 1
```

批量与边界：

```
批量（两行共享同一条偏置表/禁用表，u 每行一个）：
  logits = [[2.0, 1.0, 0.0], [0.0, 1.0, 2.0]]，偏置表 下标 [0, 2] / 偏置 [-3.0, 1.0]，禁用表 [1]，u = [0.2, 0.9]
  biased_logits = [[-1.0, -inf, 1.0], [-3.0, -inf, 3.0]]
  filtered = [[0.119203, 0.0, 0.880797], [0.002473, 0.0, 0.997527]]
  各行原顺序 CDF = [[0.119203, 0.119203, 1.0], [0.002473, 0.002473, 1.0]] → chosen = [2, 2]

越界 / 负下标的条目全部无副作用：
  logits = [1.0, 0.0, -1.0]，偏置表 下标 [-1, 7, 999] / 偏置 [5.0, -5.0, 100.0]，禁用表 [-3, 42]，u = 0.2
  → 结果与「空表」完全一致：biased_logits = [1.0, 0.0, -1.0]，
    filtered = [0.665241, 0.244728, 0.090031]，chosen = 0

只禁用最大项时，剩余项按存活集合重归一：
  logits = [5.0, 4.0, 3.0, 2.0]，偏置表为空，禁用表 = [0]，u = 0.5
  → filtered = [0.0, 0.665241, 0.244728, 0.090031]（下标 0 精确为 0，chosen 永远不可能是 0）
```

## 约束

- 判题环境：**只有 CPU**；只允许 **torch / numpy**；**完全离线**——没有 llama.cpp，没有 transformers 的 sampler / logits-processor 类，也没有任何联网依赖。**所有随机性必须是显式入参**：均匀数由 \(u\) 传入，不许 `manual_seed`、`torch.rand` 或 `torch.multinomial`。
- \(V \ge 1\)；偏置表两条列表等长（可以为空表）；下标为整数，落在 \([0,V)\) 之外者一律无副作用。
- **每一行至少要留一个未被禁用的 token**：整行都是 \(-\infty\) 时「减最大值」会得到 \(\infty-\infty=\text{NaN}\)，该情形不在判题口径内。
- 执行顺序固定为 **① 偏置 → ② 掩码 → ③ softmax → ④ 采样**。掩码是**赋值**而不是加法，因此同一下标被两张表同时命中时以 \(-\infty\) 为准。偏置绝不能挪到 softmax **之后**按概率加减——那已经不是 logit 偏置（详见 `notes.md` 的口径对照）。
- 数值口径：float32 中间量，判题用 `atol = rtol = 1e-5`；`filtered` 每行和为 \(1\)、被禁用位为**精确**的 \(0.0\)。
