# 稀疏化：注意力头重要性打分与结构化剪枝

## 题目描述

结构化剪枝的最小单位不是单个权重，而是一整块「硬件/算子可识别」的结构——对多头注意力最自然的选择就是**整颗头**：把这颗头的 Q/O 投影切片整体置零，序列长度方向的计算就能直接跳过。难点在于**哪颗头该剪**。

本题用 **Wanda 式权重–激活联合显著度**打分：一颗头的权重是切片 \(W_h\in\mathbb{R}^{d_\text{head}\times d}\),校准集上这颗头的输入激活是 \(X_h\in\mathbb{R}^{N\times d_\text{head}}\)，定义

$$
\text{importance}_{l,h}=\|W_{l,h}\|_F\cdot\|X_{l,h}\|_F
$$

只大不小的权重配上几乎零的激活、或反之，都不该被保留；两者乘积同时刻画「权重能量」和「这条通路实际被用到的程度」（Michel et al. 2019 也是从「头级显著度」切入结构化剪枝的）。给出这个分数后，剪枝就变成一次全局排序：**跨所有层、所有头一起排**，剪掉最低的若干颗。

## 规则

给定：

- `weight`：float32，形状 \((L,H,d_\text{head},D)\)，第 `[l,h]` 片是该头的权重；
- `calib`：float32，形状 \((L,H,N,d_\text{head})\)，校准激活；
- `sparsity`：标量，\(\in[0,1]\)，表示**头**的剪枝比例。

计算：

1. 头权重范数 \(\|W_{l,h}\|_F\)（对该头的 \(d_\text{head}\times D\) 全部元素）；
2. 头激活范数 \(\|X_{l,h}\|_F\)（对该头的 \(N\times d_\text{head}\) 全部元素）；
3. `importance = 两者乘积`，形状 \((L,H)\)；
4. 剪枝数 \(k=\text{round}(\text{sparsity}\cdot L\cdot H)\)，把 `importance` 展平后**升序**取前 \(k\) 个（并列时按展平索引 \(l\cdot H+h\) **升序**先剪）；
5. 被剪头的整片 \((d_\text{head},D)\) 权重置零，其余头原样保留。

返回 `(pruned_weight, importance)`：前者形状同 `weight`，后者 float32 \((L,H)\)。禁止 `torch.nn.utils.prune`。

## 示例

\(L=1,H=2,d_\text{head}=2,D=2,N=2\)，`sparsity=0.5`：

```
weight[0,0] = [[1,2],[2,1]]   calib[0,0] = [[3,4],[0,0]]
weight[0,1] = [[0,1],[0,0]]   calib[0,1] = [[1,0],[0,0]]

‖W[0,0]‖_F = sqrt(1+4+4+1) = sqrt(10) ≈ 3.162278
‖X[0,0]‖_F = sqrt(9+16) = 5
importance[0,0] = sqrt(10)*5 ≈ 15.811388

‖W[0,1]‖_F = 1,  ‖X[0,1]‖_F = 1
importance[0,1] = 1.0

k = round(0.5*1*2) = 1  → 剪掉 importance 更低的头 1
pruned = [[[[1,2],[2,1]], [[0,0],[0,0]]]]
```

## 约束

- CPU float32；`importance` 必须按上面的乘积口径计算，不能改成只比权重大小。
- 剪枝是**全局**排序（跨层、跨头），不是每层各剪固定比例。
- 被剪头必须**整片**归零：不能只把该头里最小的几个元素置零。
- `sparsity=0` 时输出必须与输入逐元素相同；`sparsity=1` 时全部为 0。
