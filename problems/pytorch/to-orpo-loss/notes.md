# 解题说明 · ORPO

## 为什么可以没有参考模型

DPO 需要一个冻结的参考模型 $\pi_\text{ref}$ 来定义隐式奖励与 KL 约束。ORPO 的观察是：当 chosen 的**绝对似然**还没提上来时，比较 chosen/rejected 的相对改进意义有限。于是它把「提高 chosen 似然」的 SFT 项直接放进损失，充当防止策略跑偏的正则；偏好项则只负责拉开两者的**赔率**。两项共用一个模型、一次前向，省掉了参考模型的内存与前向开销。

## 为什么用赔率而不是概率

对数赔率 $\ell-\log(1-e^\ell)$ 是 logit 尺度上的量：当 $p\to 1$ 时它发散，因此「chosen 已经几乎确定」的样本仍会贡献较大的梯度，模型不会因为 sigmoid 饱和而停止优化。代价是数值更脆弱——必须用 `log1p(-exp(ℓ))`，直接算 $p$ 再取 $\log\frac{p}{1-p}$ 在 $\ell$ 接近 0 时会丢光有效位。契约里把「平均对数概率必须严格小于 0」写进校验，正是因为 $\ell\ge 0$ 会让 $1-p\le 0$、赔率无定义。

## 长度归一的位置

ORPO 的长度归一发生在**赔率之前**：先 $\ell=\text{logp}/|y|$，再取胜负双方赔率差。如果把归一放到后面（先算赔率差再除长度）或干脆不归一，长回答会因为 logprob 更负而被系统性压低赔率。测试里同一条序列 logprob 配不同长度，SFT 项必须随之变化，就是钉住这一步。

## 与 DPO/IPO 的对照

三种损失的偏好项分别作用在 $\beta\Delta$ 的三种函数上：DPO 是 $-\log\sigma(\beta\Delta)$（单调、饱和），IPO 是 $(\Delta-\frac{1}{2\beta})^2$（有明确目标边际、可双侧惩罚），ORPO 是 $-\log\sigma(\text{logodds}_w-\text{logodds}_l)$（赔率尺度、无参考模型）。把三者放在同一合集里，正是为了看清「锚点从哪来、损失形状如何影响梯度」。
