# Diffusion：TCFG 的 SVD 截断投影引导

## 题目描述

经典 CFG 沿 \(\epsilon_c-\epsilon_u\) 直线外推，但两支预测张成的是一个二维子空间：其中只有一个方向承载主要能量，另一个方向多是噪声或纹理的随机抖动。沿着后者强推，就会产生过饱和与结构性伪影。**Tangential CFG**（TCFG）因此先把无条件预测截断到主方向上，再以截断后的预测做外推：

把两支预测叠成 \(2\times D\) 矩阵，做 SVD 得到第一右奇异向量 \(v_1\)，把 \(\epsilon_u\) 投影到 \(v_1\)：

\[ p=(\epsilon_u\cdot v_1)\,v_1 \]

\[ \text{out}=p+s\,(\epsilon_c-p) \]

由于只有两行，\(v_1\) 必然落在 \(\{\epsilon_c,\epsilon_u\}\) 张成的平面内，投影只需要一个标量倍数。

## 规则

给定同形状的 `eps_cond` / `eps_uncond` 与 `guidance_scale=s`，返回 float32 张量：

1. 对每个样本，把 \(\epsilon_c,\epsilon_u\) 展平为两行，组成 \(2\times D\) 矩阵；
2. 取其第一右奇异向量 \(v_1\)，计算投影 \(p=(\epsilon_u\cdot v_1)v_1\)；
3. 输出 \(p+s(\epsilon_c-p)\)。

**并列情形**：当两个奇异值相等（主方向不唯一）时，约定主方向取 \(\epsilon_c\) 的方向，此时投影退化为 0（若 \(\epsilon_c\) 与 \(\epsilon_u\) 正交且模长相同，输出就是 \(s\,\epsilon_c\)）。

## 示例

\[ \epsilon_c=\begin{bmatrix}0.4&-1.2&0.6\\0.0&0.5&-0.5\end{bmatrix},\ \epsilon_u=\begin{bmatrix}0.1&-0.4&0.2\\0.2&-0.1&0.0\end{bmatrix} \]

```
s=0 -> [[ 0.127716, -0.392791,  0.196395], [ 0.002381, -0.055423,  0.054233]]
s=3 -> [[ 0.944568, -2.814419,  1.407210], [-0.004763,  1.610847, -1.608465]]
```

`s=0` 一栏就是投影本身。

## 约束

- 输入至少二维（第 0 维是 batch），两支形状必须一致；`s` 非负有限。
- **退化性质**：\(s=1\) 时输出逐位等于 `eps_cond`；两支平行时 \(v_1\) 就是公共方向，投影不改变 \(\epsilon_u\)，输出等价于裸 CFG；\(\epsilon_u\) 为零向量时投影为 0，输出为 \(s\,\epsilon_c\)。
- 投影残差与投影方向正交：\(\epsilon_u-p\perp p\)。
- 两支全零时输出全零，不能出现 NaN。
