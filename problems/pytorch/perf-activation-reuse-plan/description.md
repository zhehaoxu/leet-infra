# 激活显存复用：生命周期区间上的偏移规划与峰值下界

## 题目描述

训练/推理图里，激活张量的**生命周期并不覆盖整张图**：某个中间结果在最后一个消费者算完后就可以扔掉，它那块显存可以被后面的张量重新用。编译器和框架因此会做一次**离线显存规划**：给每个张量分配一个「地址偏移」，只要求**生命周期重叠**的两个张量不共享字节；生命周期不重叠的张量可以叠在同一段地址上。TensorFlow grappler 的 memory optimizer、TorchScript 的静态显存池都做这件事。

规划质量用**峰值**衡量：所有张量里 `offset + size` 的最大值。一个天然的下界是任一时刻**同时存活**的张量字节和的最大值——但它不一定可达（尺寸不一，空隙可能塞不进后来者），这正是本题要同时输出的两个量。

## 规则

给定张量集合：每个张量有生命周期 `[start, end)`（逻辑步，半开区间）与申请字节 `nbytes`，对齐粒度 `align`。两个张量**生命周期重叠**当且仅当 `max(s1, s2) < min(e1, e2)`。

1. 实际占用 `size = ceil(nbytes / align) * align`，起始偏移也必须是 `align` 的整数倍；
2. 放置顺序按 `(size 降序, start 升序, end 升序, 原始下标升序)`；
3. 依序为每个张量选**最小**的可放置偏移 `o`：`[o, o+size)` 与所有**已放置且生命周期重叠**的张量的字节区间都不相交（生命周期不重叠的已放置张量不构成约束）；
4. 峰值 `peak = max(o + size)`；
5. 下界 `lower_bound = max over t (Σ size of 存活于 t 的张量)`，`t` 取所有 `start` 值。

返回 `(offsets, peak, lower_bound)`：`offsets` 按**输入顺序**给出每个张量的偏移。

## 示例

`align=1024`，五个张量（`size` 已对齐）：

```
i0 [0,4) 3000 -> 3072
i1 [1,3) 2000 -> 2048
i2 [2,6) 5000 -> 5120
i3 [4,6) 2000 -> 2048
i4 [5,8) 1000 -> 1024

放置顺序（size 降序）：i2, i0, i1, i3, i4
  i2 最先：off 0                           [0,5120)
  i0 [0,4) 与 i2 [2,6) 重叠 -> 0 被占 -> off 5120        [5120,8192)
  i1 [1,3) 撞 i2、i0        -> off 8192                  [8192,10240)
  i3 [4,6) 只撞 i2          -> off 5120 可行             [5120,7168)
```

`i4` 的候选偏移是「0 与已放置且生命周期重叠者的末端」= {0, 5120, 7168}：0 撞 i2、5120 撞 i3，**7168 可行**，于是占 `[7168,8192)`。

```
offsets     = [5120, 8192, 0, 5120, 7168]
peak        = 10240      # 来自 i1: 8192 + 2048
lower_bound = 10240      # t=2 时 i0+i1+i2 = 3072+2048+5120
```

## 约束

- `end > start`、`nbytes >= 1`、`align >= 1`；允许空输入（返回空列表、峰值 0、下界 0）。
- 偏移必须是「最小可行」而不是任意可行：测试会把每个张量左移一格，断言必然与某个更早放置的、生命周期重叠的张量相撞。
- `peak >= lower_bound` 恒成立，但**不要求相等**：尺寸不一时按大小贪心会产生空隙（见样例集里的碎片用例）。
- 三个返回值类型固定：`list[int]`、`int`、`int`。
