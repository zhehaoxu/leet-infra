# 量化：BC 输出偏置补偿的逐通道流式更新

## 题目描述

量化后的层输出总比浮点输出差一点。多数 PTQ 方法去改**量化器**（挑 scale、挑舍入方向），Bias Compensation（Gong, Dong 等, arXiv:2404.01892）走的是另一条路：在量化层**后面**加一个逐通道偏置 $l$，用校准数据的输出差直接把它估出来，与量化器完全解耦。

本题给定浮点层与量化层在 $T$ 次校准前向上的输出，要求按上游实现的口径**流式**更新这个偏置。没有梯度、没有反向传播、没有随机数：同一份输入必须给出逐位一致的答案。要注意的都不是数学难度，而是上游代码里那几个容易写错的细节——计数先自增再使用、`post_bias` 加回的是**更新前**的偏置、归约只发生在单次前向的非通道轴上、负轴是按单次前向的秩归一化的。

## 规则

记单次前向的秩为 $d=\texttt{float\_batches.dim()}-1$（第 0 轴是"第几次校准前向"，不参与通道判定），$C=\prod(\texttt{bias\_shape})$ 为偏置长度。内部一律 float64，返回时按输入 dtype 给出。

1. **轴归一化**：`channel_axis` 里的 $a<0$ 换成 $a+d$（注意是 $d$ 而不是 $d+1$）；随后按升序收集所有**非通道轴**得到 `mean_axis`，并把通道轴位置填上该维大小、其余填 1 得到 `bias_shape`。
2. **逐次更新的均值向量**：第 $t$ 次（$t=0..T-1$）先取 $\Delta_t=\texttt{float\_batches}[t]-\texttt{quant\_batches}[t]$，若 `post_bias=True` 再加上**当前**偏置按 `bias_shape` 广播的形式，然后
   $$\texttt{bias\_updates}[t]=\operatorname{flatten}\bigl(\operatorname{mean}_{\texttt{mean\_axis}}(\Delta_t)\bigr).$$
   若 `mean_axis` 为空（所有轴都被声明成通道轴），上游**跳过取均值**，直接展平 $\Delta_t$，本实现照抄。
3. **流式平均**：上游先做 `nsamples += 1` 再用 `(bias * (nsamples - 1) + update) / nsamples`，也就是
   $$b_{t+1}=\frac{b_t\cdot t+\texttt{bias\_updates}[t]}{t+1},\qquad b_0=\texttt{init\_bias}\ \text{或}\ 0.$$
   第一个样本的权重是 1（等于直接覆盖初值），之后每个样本权重都是 $1/(t+1)$；**与校准 batch 的大小无关**，因为 batch 维已经在第 2 步被均值掉了。
4. **收尾**：`bias` 取 $b_T$；`corrected_output` 用**最终**偏置对每一次前向都做 $Q_t+\mathrm{broadcast}(b_T)$；$\texttt{residual\_mse}=\operatorname{mean}\bigl((F-\texttt{corrected\_output})^2\bigr)$ 对所有元素取均值。

返回一个字典，键固定为 8 个：

- `channel_axis_norm` tuple[int]：归一化后的通道轴；
- `bias_shape` tuple[int]：长度 $d$，非通道轴填 1；
- `mean_axis` tuple[int]：升序的非通道轴；
- `bias_updates` float $(T, C)$：每次更新的均值向量（第 2 步的结果，未参与平均）；
- `bias_after` float $(T, C)$：每次更新之后的偏置快照，`bias_after[t]` $=b_{t+1}$；
- `bias` float $(C,)$：最终偏置；
- `corrected_output` float $(T, *R)$：`quant_batches` 加上最终偏置；
- `residual_mse` float 0 维：最终偏置下的输出 MSE。

## 任务

- 输入：`float_batches` 与 `quant_batches` 同形状同 dtype 的 float32 或 float64 张量 $(T,*R)$，单次前向秩 $d\ge 2$；`channel_axis` 为 int 或 int 元组/列表；`init_bias` 为 `None`（等价于全零）或 $C$ 个元素；`post_bias` 为 bool；`channel_size` 为 `None` 或 int。
- 输出：上述 8 键字典；浮点容差 float32 用 `1e-5`、float64 用 `1e-9`；三个元组键按 Python 元组比较。
- 下列非法输入抛 `ValueError`：$T=0$、单次前向秩 $d<2$、两者形状不同、两者 dtype 不同、`channel_axis` 为空元组 / 含非整数 / 归一化后越界 / 重复、`channel_size` 不等于 $C$、`init_bias` 元素数不等于 $C$。

## 约束

- `bias_shape`/`mean_axis` 只看**单次前向**的 $d$ 个轴；第 0 个轴永远是"第几次更新"，不会被当成通道轴，负轴也按 $d$ 而不是 $d+1$ 归一化。
- 流式平均的权重是 $1/(t+1)$，与每次前向里的元素个数无关；把 `float_batches` 的 batch 维放大 10 倍不会改变结果。
- `post_bias=True` 时加回的是**上一次**更新结束后的偏置（不是本次的），因此它等价于"先把偏置从量化输出里减掉，再求均值"。
- `init_bias` 是流式平均的初值 $b_0$。`post_bias=False` 时它对返回结果毫无影响——$b_1=(b_0\cdot 0+u_0)/1$ 把它的权重直接归零；`post_bias=True` 时它被加进 $\Delta_0$，并且系数一路保持为 1，于是整条 `bias_updates`/`bias_after`/`bias` 轨迹都恰好平移 `init_bias`。
- 判题只看返回字典，不限定实现方式。
