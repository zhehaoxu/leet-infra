# 解题笔记：词表覆盖率与 OOV 统计

## 来源与统计口径

本题采用工程中的语料统计约定：将语料出现次数、文档频次、token 覆盖率和词种覆盖率分开报告。忽略规则、精确匹配、零分母取值及 OOV 排序均以本题契约为准，不依赖特定外部库，也不需要借用某篇论文的定义。

## 1. 先验证词表，再过滤 token

建立词表 token 到原始下标的映射。若映射大小与词表长度不同，说明存在重复项，应抛出 `ValueError`。这个检查不能被“空语料”或“重复词恰好被忽略”的情况绕过。

将忽略词转成集合只用于成员判断；其重复项没有统计意义。遍历文档时，先判断 token 是否被忽略，再进行任何计数。不做大小写折叠、Unicode 归一化或子串匹配，也不修改输入列表。

## 2. 区分出现次数与文档频次

为词表内词创建两个与词表等长的零数组，分别表示总出现次数与文档频次。OOV 使用按原始 token 分开的计数字典。

处理一篇文档时：

1. 每个保留 token 都增加该文档的保留次数；词表外 token 也增加该文档的 OOV 次数。
2. 将其计入对应的语料出现次数，同时加入本篇文档的 `seen` 集合。
3. 文档扫描结束后，对 `seen` 中每个 token 的文档频次增加一次。
4. 无条件追加本篇的 `(kept_count, oov_count)`，包括 `(0, 0)`。

`seen` 必须每篇重建；全语料共享一个集合会错误地将文档频次压成 1。反过来，每出现一次就累加文档频次，也会把它与出现次数混为一谈。

## 3. 对齐 OOV 排序

所有文档处理完后，按 `(-count, token)` 排序 OOV token。基于同一个有序 token 列表生成 `oov_counts` 和 `oov_doc_freq`，不能把三个数组分别排序。

Python 字典序比较原始字符串的 code point，不使用语言区域排序。同次数时大写与小写、数字字符串、预组合字符与组合字符都仍按原始字符串比较。不要用 unknown ID 合并不同 OOV，否则词种数、排序和文档频次都会丢失信息。

## 4. 两种覆盖率的分母不同

设 $K$ 为保留的词表内出现次数，$O$ 为保留的 OOV 出现次数，$V_+$ 为计数大于零的词表词种数，$U$ 为唯一保留 OOV 数：

$$
\mathrm{token\_coverage}=\begin{cases}K/(K+O),&K+O>0\\0.0,&K+O=0\end{cases}
$$

$$
\mathrm{type\_coverage}=\begin{cases}V_+/(V_++U),&V_++U>0\\0.0,&V_++U=0\end{cases}
$$

分母不是原始未过滤的 token 数，也不是词表大小；`type_coverage` 不计未观察到的词表词。用 Python 除法产生 `float`，零分母显式返回 `0.0`。

## 实跑样例复盘

- 示例 1：`vocab_counts=[0, 2, 0]`，`vocab_doc_freq=[0, 1, 0]`。OOV `x` 出现 2 次，分布在 2 篇文档。三篇统计为 `[(3, 1), (0, 0), (1, 1)]`，两种覆盖率都为 `0.5`。
- 示例 2：忽略 `É` 但保留 `é`，且组合形式仍是独立 OOV。已知出现 2 次，OOV 次数依次为 `[3, 1, 1]`。token 覆盖率的真实浮点输出为 `0.2857142857142857`，词种覆盖率为 `0.25`。

## 复杂度

令 $T$ 为输入 token 总数，$V$ 为词表长度，$I$ 为忽略列表长度，$D$ 为文档数，$U$ 为保留 OOV 词种数。以均摊常数时间哈希操作、受限长度字符串比较计，时间为 $O(T+V+I+D+U\log(U+1))$，空间（含返回值）为 $O(V+I+U+D)$。每篇 `seen` 的大小不超过保留的已知与 OOV 词种总数。空输入还需要常数开销。

## 独立验证

15 个 `check_*` 覆盖两种分母、重复出现与文档频次、词表内外忽略词、空语料/空文档/全忽略、未使用词表、全已知/全 OOV、次数排序与 Unicode 字典序、非法重复词表和输入不变。上界用例包含 30 篇各 100 token、100 个词表项和长度 30 的 token；固定种子 8202 的随机测试共 180 组。

oracle 不使用 `Counter`，也不复用单次扫描累积方案：先生成保留文档和展平语料，再对每个词表词、每个观察到的 OOV 分别扫描全文统计，逐文档用成员判断计算文档频次。覆盖率也直接基于展平语料与观察集合计算。测试另外检查恰有八个键、Python 整数/浮点类型、列表和文档统计元组，并检查嵌套输入不变。
