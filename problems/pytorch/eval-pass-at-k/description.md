# 评测：pass@k 无偏估计量

## 题目描述

代码模型每道题通常会采样 \(n\) 个候选程序、跑单元测试，得到 \(c\) 个通过。要报告的**不是** "\((1-(1-c/n)^k)\)" 这种把采样当独立事件的朴素值，而是 Chen et al.（*Evaluating Large Language Models Trained on Code*，arXiv:2107.03374，Codex/HumanEval）给出的**无偏估计量**：从 \(n\) 个样本里**不放回**地随机取 \(k\) 个，"至少一个通过"的概率恰为

\[ \mathbb{E}\big[\text{pass@}k\big] = 1 - \frac{\binom{n-c}{k}}{\binom{n}{k}} \]

分母是全部 \(k\)-子集数，分子是"全从失败样本里取"的 \(k\)-子集数。这个式子在 \(k=1\) 时退化回通过率 \(c/n\)，在 \(k=n\) 时给出"只要有一个正确样本就必为 1"——它衡量的是**子集层面**的覆盖率，而不是 \(k\) 次独立试验。HumanEval / MBPP / EvalPlus 的 pass@k 全是这个口径。

## 规则

- 输入是 Python int：\(n\)（采样总数）、\(c\)（其中通过数，\(0 \le c \le n\)）、\(k\)（取多少个，\(1 \le k \le n\)）。
- 计算 \(\binom{n-c}{k} / \binom{n}{k}\) 时必须走**精确整数组合数**（`math.comb` 或等价手写），**最后一步才转浮点**：中途用浮点阶乘 / `math.gamma` 会在 \(n\) 上百时把有效数字丢掉。
- \(\binom{a}{b}\) 在 \(b > a\) 时按定义取 \(0\)（于是 \(\text{pass@}k = 1\)）；不要抛异常、不要返回 nan。
- 禁止用 \(1-(1-c/n)^k\) 近似，禁止调用任何评测库。
- 返回 **Python float**，取值 \([0, 1]\)。

## 示例

```
n = 10, c = 2, k = 3
C(n-c, k) = C(8, 3) = 56
C(n, k)   = C(10, 3) = 120
pass@3 = 1 - 56/120 = 0.5333333333

对照：常见错法 1 - (1 - 2/10)^3 = 0.488，有偏且系统性偏低（k>1 时）
```

## 约束

- CPU；纯整数/浮点运算，不含任何随机性。
- **退化性质**（全部可从组合恒等式验证）：
  - \(c = 0 \Rightarrow \text{pass@}k = 0\)；
  - \(k = 1 \Rightarrow \text{pass@}k = c/n\)（与朴素版重合，这也是无偏性的锚点）；
  - \(k = n \Rightarrow c = 0\) 时为 \(0\)，否则为 \(1\)（取遍全部样本必然覆盖到正确解）；
  - \(c = n \Rightarrow\) 恒为 \(1\)；
  - \(n - c < k \Rightarrow\) 恒为 \(1\)（失败样本不够填满一个 \(k\)-子集）；
  - 固定 \(n, c\) 时，pass@k 对 \(k\) **单调不减**。
- 值域：\(0 \le \text{pass@}k \le 1\)。
