# GPTQ：逐列量化 + Hessian 误差补偿

## 题目描述

RTN（就近取整）把每个权重独立四舍五入，忽略它们之间的**耦合**：一个权重量化产生的误差，可以由还没量化的其它权重"吸收"掉。**GPTQ**（Frantar et al., 2022, [arXiv:2210.17323](https://arxiv.org/abs/2210.17323)）源自 OBQ/GPT 的逐列坐标下降思想：按顺序量化每一列，量化后立即把该列误差通过二阶信息（Hessian 的逆）反馈给剩余列，使整层输出误差尽量不变。只用一次求逆、逐列更新，就能把 3–4 bit 的量化损失大幅压低。

## 规则

给定权重 $W$ 形状 $(O, C)$、逐层 Hessian 近似 $H = 2XX^\top$ 形状 $(C,C)$、位宽 `bits`、阻尼 `damp`。

1. per-tensor 对称量化参数：$q_{max}=2^{bits-1}-1$，$s=\max|W|$（$s=0$ 时取 $1$）。
2. 阻尼求逆：$H^{-1}=(H+\texttt{damp}\cdot I)^{-1}$（$H$ 半正定，加阻尼保证可逆）。
3. 令工作副本 $W_q \leftarrow W$，输出 $O\leftarrow W$。对列 $i=0,1,\dots,C-1$：
   - 量化当前列 $w=W_{q,:,i}$（此时 $w$ 已含前面列传入的补偿）：
     $$q=\mathrm{clamp}\big(\mathrm{round}(w/s\cdot q_{max}),\,-q_{max}-1,\,q_{max}\big),\qquad \hat w=\frac{q}{q_{max}}\,s$$
   - 该列误差 $e = w - \hat w$，写回 $O_{:,i}=\hat w$。
   - **误差补偿**：把 $e$ 沿 $H^{-1}$ 的第 $i$ 行摊给尚未量化的列（$d_i=H^{-1}_{i,i}$）：
     $$W_{q,\,[:,\,i+1:]} \;-\!=\; \big(e/d_i\big)\otimes H^{-1}_{i,\,i+1:}$$

返回重构权重 $\hat W = O$，形状 $(O, C)$。

## 示例

```
W = [[1.0, 2.0, 0.5],       H = [[2.0, 0.5, 0.1],
     [0.3, 1.0, 1.5]],           [0.5, 1.5, 0.2],
                                 [0.1, 0.2, 1.0]]
bits = 2, damp = 0.1
s = max|W| = 2.0, qmax = 1  →  量化格点 ∈ {-2, 0, 2}（×s/qmax 后）

Wq = [[0.0, 2.0, 0.0],
      [0.0, 2.0, 2.0]]
```

（2-bit 下格点极粗，逐列补偿把先量列的误差推给后量列，使最终 $\hat W$ 比纯 RTN 更接近原层输出。）

## 约束

- CPU float32；结果用 `torch.allclose(atol=1e-3)` 比较。
- $H$ 对称半正定、$C\times C$；$W$ 的列数须等于 $H$ 的维数。
- 取整就近、`.5` 取偶（与 `torch.round` 一致）；列必须**从左到右**顺序处理（补偿只向后传播）。
