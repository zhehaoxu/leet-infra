# notes（quant-fp6-dual-subformat-pack）

## 回源

- 论文：arXiv 2401.14112（FP6-LLM），官方实现 `usyd-fsalab/fp6_llm`。核心主张：
  权重/激活的取值范围不同，`FP6_E3M2`（指数多、`max 28`）适合带离群值的激活，
  `FP6_E2M3`（尾数多、`max 7.5`、最小步长更细）适合范围小的权重。
- 位域（按 IEEE 风格 `1 + E + M`、`e=0` 走次正规、`bias = 2^(E-1) - 1`）：
  - `e3m2`：`E=3, M=2, bias=3`；`max = (1 + 3/4)·2^(7-3) = 28`；最小次正规 `0.25·2^-2 = 0.0625`。
  - `e2m3`：`E=2, M=3, bias=1`；`max = (1 + 7/8)·2^(3-1) = 7.5`；最小次正规 `0.125·2^0 = 0.125`。
  - 两者都**没有 inf / NaN**（指数全 1、尾数全 1 就是最大值 28 / 7.5）。
- 打包：官方 3 字节路径把 4 个 6 bit 码按小端位流拼成 24 bit。本题把三条字节公式显式写进
  题面，字节序自洽，不依赖仓库里 CUDA kernel 的具体写法。

## 官方实现里的坑

1. **6 bit 跨字节**：`b0` 里同时装着 `c0` 的 6 位和 `c1` 的低 2 位；先移位不掩码必然溢出
   到 >255，`packed` 就不再是字节序列。
2. **两套位宽不能混**：`e3m2` 的指数在 `bit4..2`、`e2m3` 在 `bit4..3`，解码时 `>> mbits`
   与 `& (2^ebits - 1)` 都要随格式变；只写死一套会在另一种格式上给出错值。
3. **`auto` 的边界是闭区间**：`amax == 7.5` 仍选 `e2m3`（正好装得下且更精细），
   `amax == 28` 仍选 `e3m2`；写成严格小于就会把恰好装得下的张量推到更宽的格式。
4. **显式格式下超界是饱和而不是报错**：只有 `auto` 在 `amax > 28` 时报 `ValueError`；
   显式 `e2m3` 遇到 `8.0` 要饱和到 `7.5` 并置 `sat_mask`。
5. **次正规与最小正规首尾相接、不重叠**：`e3m2` 的次正规顶格是 `0.1875`（码 3），
   最小正规是 `0.25`（码 4）。本次出题曾误以为 `0.25` 有「次正规 + 正规」两个编码，
   实测 64 个码值集合**没有重复值**（只有 `±0` 两个零码），已在用例里改成
   「次正规顶格 vs 最小正规」的衔接断言。
6. **补齐码要截掉**：`unpacked` 必须按原长度截断，否则长度为 1 的输入会多出 3 个 0 码。

## 本题的规范化

- `codes` 用 6 bit（`bit5` 符号），`packed` 用独立小端位流公式；`unpacked` 由 `packed`
  反解得到，等于「打包—解包」闭环的自证。
- `tie_mask` 的定义是「两个**取值不同**的码点与 scaled 等距」，精确命中的网格点不算平局
  （只有 `±0` 有两个码，但由符号位区分，不算等距两值）。
- 校验门：`fmt` 白名单、`NaN` 拒绝；空输入返回全空账本且 `pad_count=0`。
- 返回的张量互不共享存储，`codes` 与 `unpacked` 各自独立。

## 变异

19 条全部 CAUGHT：

```
m-spec-bias / m-spec-mbits     bias 或尾数位宽改错      → 极值用例抓
m-limit-formula                饱和点算成 2^(2^E - bias) → 28 / 7.5 用例抓
m-tie-ignore-parity            平局不看尾数奇偶          → 0.09375 用例抓
m-tie-no-sign                  去掉 ±0 的符号偏好       → -0.0 用例抓
m-tie-any-exact                精确命中即判平局         → 0.1875 / 0.25 用例抓
m-subnormal-shift              次正规少乘一次 2^(1-bias) → 0.0625 用例抓
m-pack-b0/b1/b2                三条字节公式各改一处     → 字节断言抓
m-unpack-c2/c3                 解包位移改错             → unpacked == codes 抓
m-pad                          补齐量算成 n % 4         → pad_count 抓
m-auto-le / m-auto-range       auto 边界/上界改错       → 选择用例抓
m-sat-ge / m-sat-nosign        饱和门含等号 / 丢符号    → 饱和用例抓
m-fmt-gate / m-nan-gate        白名单与 NaN 门失效      → validation 抓
```

等价变异（已剔除，不计数）：把 `_pick` 末位 tiebreak 从 `code` 改成 `-code`——两种格式的
64 个码值集合里没有重复值（只有 `±0`，由符号偏好先决定），该 tiebreak 不可达。

## 查重

- `quant-mx-microscaling`(612) 与 `quant-fp4-e2m1-grid`(740)：4 bit 元素格式与共享指数，
  不涉及非字节对齐打包。
- `quant-uint4-asym-pack`：4 bit 整数整除字节的打包，无跨字节位拼接。
- FP8 两题(125/445)：8 bit 整除字节。
- 本题唯一考点是「两个 6 bit 子格式的位域 + 4-in-3 跨字节重组」，与上述均不重叠。
