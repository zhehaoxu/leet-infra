# FP6 双子格式量化与 4-in-3 字节打包

6 bit 的浮点格式装不进一个字节：`FP6_E3M2` 用 3 位指数换动态范围，`FP6_E2M3` 用 3 位尾数
换精度，两种子格式按张量范围二选一。更麻烦的是存储——4 个 6 bit 码正好 24 bit，
必须跨字节拼成 3 字节。

## 接口

```python
def solve(values, fmt="auto") -> dict
```

`values` 是 1 维 `float64` 张量；`fmt` 取 `"auto"` / `"e3m2"` / `"e2m3"`。返回：

| 字段 | 含义 |
| --- | --- |
| `fmt` | 实际使用的子格式（`auto` 会解析成具体格式） |
| `codes` | 每元素 6 bit 码（bit5 符号 / 高 3 或 2 位指数 / 低位尾数） |
| `packed` | 每 4 个码压成的 3 字节（`int64`，取值 0–255） |
| `unpacked` | 从 `packed` 反解回来的码（应与 `codes` 相等） |
| `dequant` | 反量化值（`-0.0` 保留符号） |
| `sat_mask` / `tie_mask` | 是否饱和 / 是否恰好落在两个码点中点 |
| `pad_count` | 补齐到 4 的倍数时补了几个 0 码 |

## 输入输出

```
输入：values=[0.0, 0.25, 0.5, 0.75], fmt="e3m2"
输出：codes=[0, 4, 8, 10], packed=[0, 129, 40], pad_count=0
```

三个字节拆开看：`0x00` 装 `c0` 的低 6 位与 `c1` 的低 2 位，`0x81` 装 `c1` 的高 4 位与
`c2` 的低 4 位，`0x28` 装 `c2` 的高 2 位与整个 `c3`。

## 规则

- **两种子格式**（都无 `inf` / `NaN`，最大值即饱和点）：
  - `e3m2` = 1-3-2，`bias=3`，`max = 1.75 × 2^4 = 28`；最小次正规 `0.0625`，次正规顶格
    `0.1875`，最小正规 `0.25`。
  - `e2m3` = 1-2-3，`bias=1`，`max = 1.875 × 2^2 = 7.5`；最小次正规 `0.125`，次正规顶格
    `0.875`，最小正规 `1.0`。
- **`auto` 选择**：`amax <= 7.5` 选 `e2m3`（精度优先），`amax <= 28` 选 `e3m2`（范围优先），
  超过 `28` 抛 `ValueError`。显式指定格式时不做范围检查，超界一律饱和。
- **编码**：最近邻；平局取**尾数位为 0** 的码点；`|x|` 超过该格式最大值时饱和到最大码点
  （指数全 1、尾数全 1）并置 `sat_mask`，符号位照留。
- **打包（4-in-3）**：4 个 6 bit 码按小端位流拼成 3 字节——
  `b0 = c0 | (c1 & 3) << 6`、`b1 = (c1 >> 2) | (c2 & 0xF) << 4`、`b2 = (c2 >> 4) | c3 << 2`。
  等价说法：把 3 字节当小端 24 位整数，第 `k` 个码是 `bits >> (6k) & 0x3F`。
- **补齐**：元素数不足 4 的倍数时补 0 码（即数值 0），`pad_count = (-n) % 4`；`unpacked`
  要截回原长度，不能把补齐的 0 码算进结果。
- **校验**：`fmt` 不合法或 `values` 含 `NaN` 抛 `ValueError`；空输入合法（`packed` 为空、
  `pad_count=0`）。

## 提示

- 6 bit 码跨字节，`packed` 的每个字节都必须落在 `0–255`；写成 `c1 << 6` 而不先掩码会溢出。
- 指数位宽不同（3 与 2），解码公式里移位量与掩码都要跟着 `fmt` 变，别把两套布局写混。
