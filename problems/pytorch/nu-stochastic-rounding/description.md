# 随机舍入：无偏 SR 与 fwd/bwd 偏置的格点选择

## 题目描述

低精度累加最阴险的问题不是误差大，而是误差**有方向**：截断（RZ）永远把幅值往零的方向推，几千步梯度累加之后权重系统性地缩水。随机舍入（SR）用「按残差比例掷骰子」把偏置期望变成 0，代价是每一步都有随机噪声，因此需要 Philox/Threefry 之类的噪声流。本题把噪声作为入参给出，从而完全确定性可判：给定 \(x\) 与均匀随机数 \(u\)，逐元素决定落在 bf16 网格上的哪一端，并支持无偏 SR 与「前向偏向零 / 反向远离零」两种偏置变体。

## 规则

- 完整签名与参数含义只写在 starter 的 docstring 里，那是唯一判题口径。
- 不许调用 `x.to(torch.bfloat16)`；位运算自己写。
- 关键结构：**bf16 就是 float32 的高 16 位，所以格点在「高 16 位整数」上是均匀的**。把 \(x\) 的 32 位模式按无符号整数读作 \(u32\)：

```
lo  = (u32 >> 16) << 16              low neighbor toward zero
hi  = ((u32 >> 16) + 1) << 16        next grid point away from zero
r   = (u32 & 0xFFFF) / 65536.0       position inside the step, 0 <= r < 1
out = hi  if u < p(r)  else  lo      strict less-than
```

- 三种 variant 的取 \(hi\) 概率：`sr` 是 \(p=r\)（无偏）；`fwd` 是 \(r\le0.5\) 时 \(p=0\)、否则 \(p=2r-1\)（偏向零，激活用）；`bwd` 是 \(r\ge0.5\) 时 \(p=1\)、否则 \(p=2r\)（远离零，梯度用）。
- 于是 \(\mathbb E[\,|SR(x)|\,]=|x|\)、\(\mathbb E[|fwd(x)|]\le|x|\)、\(\mathbb E[|bwd(x)|]\ge|x|\)。
- 特殊值（都不看 \(u\)）：\(r=0\)（已在网格上，含 ±0、±inf）原值返回且 ±0 保留符号；NaN 输出仍是 NaN；\(|x|\) 超过 bf16 最大有限值时取 \(hi\) 自然溢出成 ±inf（不做饱和）。
- 校验：\(x\) 与 \(u\) 同形状、都是 float32（不广播）、\(u\) 每个元素在 \([0,1)\) 内、`variant` 属于三种，否则抛 ValueError。

## 示例

`[1,2)` 内 bf16 的 ulp 是 \(2^{-7}\)，所以 \(1+2^{-9}\) 的 \(r=0.25\)、\(1+3\cdot2^{-9}\) 的 \(r=0.75\)：

```
x  = [1.001953125, 1.005859375]        r = [0.25, 0.75]
u  = [0.25, 0.5]

sr   -> [1.0, 1.0078125]
fwd  -> [1.0, 1.0]
bwd  -> [1.0078125, 1.0078125]

u2 = [0.0, 0.9]

sr   -> [1.0078125, 1.0]
fwd  -> [1.0, 1.0]
bwd  -> [1.0078125, 1.0078125]
```

第一个元素在 `sr` 下 \(p=r=0.25\)，判定是**严格小于**，\(u=0.25\) 不进位；换成 \(u=0\) 就进位。第二个元素 \(r=0.75\)，`fwd` 的 \(p=2(0.75)-1=0.5\)，\(u=0.5\) 同样卡在边界不进位，而 `bwd` 在 \(r\ge0.5\) 时 \(p=1\)，\(u<1\) 恒成立所以必进位。

## 约束

- 逐元素操作，任意形状的 float32 张量，输出同形状 float32
- oracle 用 Python `struct` 在纯标量上做同一套位运算（不碰张量视图），要求逐位相等
- 无偏性另用 40000 个样本的均值方向断言：`sr` 的偏差 \(|E[\Delta]|\) 小于 2e-4，`fwd` 必须显著为负、`bwd` 显著为正，且 \(E[|fwd|]<E[|sr|]<E[|bwd|]\)
