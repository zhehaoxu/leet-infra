# Jensen-Shannon 散度损失

## 题目描述

KL 散度不对称、也不满足三角不等式，直接拿来当对称的分布匹配损失并不理想。**Jensen–Shannon 散度（JSD）** 通过对称化两个 KL 得到一个有界、对称的相异度，广泛用于伪标签/自训练、分布式对齐与图像分割一致性正则。

\[ \mathrm{JSD}_\beta(P\|Q) = \beta\,\mathrm{KL}(P\|M) + (1-\beta)\,\mathrm{KL}(Q\|M),\quad M = \beta P + (1-\beta) Q \]

其中 \(\beta\in(0,1)\) 为混合权重（常取 \(0.5\)）。当 \(\beta=0.5\) 时 JSD 关于 \(P,Q\) 对称，且以 \(\ln 2\) 为上界。

## 规则

实现 `solve(P, Q, beta=0.5)`，返回一个 0 维标量张量。`P`、`Q` 为 float32、形状 \((N, C)\) 的**逐行归一化**概率分布。按上式：先逐行求混合分布 \(M=\beta P+(1-\beta)Q\)，再算 \(\beta\,\mathrm{KL}(P\|M)+(1-\beta)\,\mathrm{KL}(Q\|M)\)，其中 \(\mathrm{KL}(A\|B)=\sum_c A_c\log(A_c/B_c)\) 约定 \(0\log 0=0\)；对每一行得到一个 JSD 值后，再对 \(N\) 行取**均值**。

## 示例

- \(N=1\)，`P=[[1.0,0.0]]`，`Q=[[0.0,1.0]]`，`beta=0.5`：两分布完全不相交，\(M=[[0.5,0.5]]\)，\(\mathrm{JSD}=\ln 2\approx 0.69314718\)（达到上界）。
- `P=[[0.7,0.3],[0.2,0.8]]`，`Q=[[0.4,0.6],[0.5,0.5]]`，`beta=0.5`：\(\mathrm{JSD}=0.04843632\)。

## 约束

- CPU float32；`P`、`Q` 每行均为归一化概率分布。
- \(0\log 0 = 0\)；因 \(M\) 在两分布之间，\(P_c>0\Rightarrow M_c>0\)，不会出现 \(\log\) 除零。
- `beta=0.5` 时结果关于 `P`、`Q` 交换对称；对任意 `beta`，\(0\le \mathrm{JSD}\le \ln 2\)（自然对数）。
- 当 `P` 与 `Q` 完全相同，返回值应约等于 0。
