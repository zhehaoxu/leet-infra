# 解题说明 · Sequoia 多分支采样与验证

## 为什么要在一个位置上验证多个分支

单序列拒绝采样（[arXiv:2211.17192](https://arxiv.org/abs/2211.17192)）在每个位置只拿一个 draft token 比对；而 tree-based 推测（SpecInfer、Sequoia）在同一位置挂着 $k$ 个候选分支。Sequoia 的 Algorithm 2 把这 $k$ 个分支串行地"消费"：每次从**当前的 draft 分布 $D$** 采一个候选 $s_i$，用**残差分布 $R$** 判定接受与否，一旦接受就返回；接受判定用比值 $R[s_i]/D[s_i]$（与标准拒绝采样同形，但 $R,D$ 会随拒绝动态更新）。

## 残差 R 与 draft D 的动态收缩

关键在于拒绝后的两个更新：
- $R\leftarrow\mathrm{norm}(\max(R-D,0))$：把本次已被 draft 覆盖的目标概率质量"扣掉"，只留下还没被解释的残差。这样后续若落到回退采样，$x\sim R$ 仍能把整体分布纠正回目标 $P$（这正是它保持无损性的原因）。
- $D[s_i]\leftarrow0$ 并归一化：被拒的 token 不再作为候选重复提出；当 $D$ 被削成全零（draft 质量全被拒完）时，在**非已拒集合**上重设均匀，避免除零。

## 边界与确定性

- $\mathrm{cdf}$ 一律取**最小** $j$ 使累积和严格 $>u$；接受判定用严格 $r_i < R[s_i]/D[s_i]$；$\mathrm{norm}$ 对零向量退化为均匀。这些边界若实现不一致就会和 oracle 逐步错开，所以题面把每个不等号方向都写死。
- $D[s_i]>0$ 的短路：若某步 $D[s_i]=0$（理论上 cdf 不会采到 0 质量，除非边界回绕），判定直接视为不接受走拒绝分支，保证与论文一致。

## 与其它投机题的关系

- 175 Medusa：单位置只取一条最深候选路径（typical acceptance），没有残差分布。
- **176（本题）**：单位置多分支 + 残差 $R$ 动态更新，是无损 tree 验证。
- 177 Sequoia 最优树：把"每层能接受多少"抽象成位置接受率向量 $P[b]$，用 DP 选树形结构（离线），与本题的在线验证互补。

## 边界自检

- `check_accept_first_branch`：第一个分支即被接受，返回 `[s0, 0]`。
- `check_example`：分支 0 被拒→残差更新→分支 1 被接受。
- `check_residual_fallback`：$k=1$ 且被拒，循环结束从 $R$ 采样回退 token `[x, 1]`。
- `check_matches_oracle`：随机 $P/Q/k$ 与随机均匀数，和独立纯 Python 逐步实现对拍。
