# 解题说明 · STFT 分帧频谱

## 三个参数各自管什么

| 参数 | 作用 | 典型陷阱 |
| --- | --- | --- |
| `n_fft` | 频率分辨率与窗长 | 奇数会让 Nyquist bin 无定义 |
| `hop_len` | 帧之间的步长 | 大于 `n_fft` 会跳过整段信号，本题直接禁止 |
| `center` | 是否在两侧补 `n_fft//2` | 补了之后帧数公式里不再出现 `n_fft` |

## 帧数公式的两种形态

补零版：`F = 1 + T // hop`。可以这样理解：补完之后总长 `T + n_fft`，最后一帧起点是 `T + n_fft - n_fft = T`，而起点必须是 `hop` 的整数倍且不大于 `T`，所以 `F - 1 = T // hop`。

不补版：`F = 1 + (T - n_fft) // hop`，最后一帧起点不超过 `T - n_fft`。

两者相差的是「补出来的两帧」，中间那些帧完全一样——这一条可以直接写成断言：`center=True` 的结果去掉首帧后，前 `F_false` 帧应与 `center=False` 逐元素相等。

## 反射填充的精确语义

`F.pad(x, (pad, pad), mode="reflect")` 的左侧是 `x[1], x[2], …` 的逆序（不含 `x[0]`），右侧是 `x[T-2], x[T-3], …`。这正是「不重复边界点」的含义。如果换成 `replicate`，等于把首样本复制 `pad` 份，会在帧边界上制造常数平台，直流 bin 凭空变大。

要求 `pad < T`（即 `T > n_fft//2`）：`reflect` 在 pad 长度超过输入长度时行为是重复翻折，语义绕且各家实现不一致，干脆禁掉。

## 周期窗才是 STFT 的窗

`w[n] = 0.5 - 0.5·cos(2πn/N)`，`n = 0..N-1`，末点 `w[N-1] = 0.5 - 0.5cos(2π - 2π/N) ≠ 0`。它满足 `w[n] = w[n+N]`，与 DFT 的周期延拓假设一致，因此「窗 × 信号」在帧边界处不发散。对称型（分母 `N-1`）在 `N` 很小时会明显削弱末点，`N = 4` 时周期窗是 `[0, 0.5, 1, 0.5]`，对称窗是 `[0, 0.75, 0.75, 0]`——差别一眼可见。

## 幅度谱的尺度

`|rfft|` 的能量与窗函数有关：常数信号 `A` 经过周期 Hann 后，直流 bin 是 `A·N/2`，两侧邻频各 `A·N/4`。这也是一个很好用的自检：如果实现的邻频为 0，说明窗用错了（用成了矩形窗）。

## 复杂度

时间 O(F·n_fft·log n_fft)，空间 O(F·n_fft)（帧矩阵）+ O(F·n_fft/2)（输出）。生产实现会用 `rfft` + 实数 FFT 缓存（如 KISS FFT 的 `kiss_fftr`），并把帧矩阵复用同一块 buffer，避免每次分配。
