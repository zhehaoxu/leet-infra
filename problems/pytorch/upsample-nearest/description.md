# 最近邻上采样（Nearest-Neighbor Upsampling）

## 题目描述

最近邻上采样把特征图放大整数倍：输出张量的每个像素，直接**复制**它映射到的那个输入像素，
不做任何插值。它是最廉价的 resize，常用于分割/检测里把低分辨率 mask 还原回原图尺寸，
以及像素风格、量化图像放大等不希望产生新灰度的场景。

## 规则

- 实现 `solve(x, scale)`，`x` 形状 `(N, C, H, W)`，`scale` 为整数放大倍数（或 `(sh, sw)`）。
- 输出形状 `(N, C, H*scale, W*scale)`。
- 映射采用与 `F.interpolate(mode='nearest', scale_factor=scale)` 一致的**向下取整**规则：
  输出第 `i` 行取自输入第 `i // scale` 行（列同理）。
- 每个输入像素恰好被复制成 `scale × scale` 的方块。

## 示例

```
输入：x = [[1, 2],
          [3, 4]]，scale = 2
输出：[[1, 1, 2, 2],
      [1, 1, 2, 2],
      [3, 3, 4, 4],
      [3, 3, 4, 4]]
```

## 约束

- float32 输入；`scale >= 1` 整数
- 输出是输入的「块状放大」，值集合与输入完全相同（不产生新数值）
