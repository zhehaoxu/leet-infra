# 优化器：ADOPT 去偏差 + 前一步二阶矩 + 梯度裁剪

## 题目描述

Taniguchi 等人（arXiv:2411.02853）证明 Adam 只有在 \(\beta_2\) 足够接近 1 时才收敛，且需要偏差修正。他们提出 **ADOPT**：**去掉偏差修正**、改用**上一步**的二阶矩来归一化当前梯度、并对归一化后的梯度做**随步数放宽的裁剪**——可证明它对任意 \(\beta_2\) 都能以最优速率收敛。它在大模型训练里以“更稳、不怕 \(\beta_2\) 取值”著称。

本题要求你**继承 `torch.optim.Optimizer`** 实现 ADOPT，`step()` 逐参数就地更新。评测喂入固定梯度序列并比对最终参数。

## 规则

- 工厂函数 `solve(params, lr=1e-3, betas=(0.9, 0.9999), eps=1e-6, weight_decay=0.0)`，返回 `torch.optim.Optimizer` 子类实例，`step()` 就地更新 `params`。
- 每参数维护 \(m=0,\ v=0\)，第 \(t\) 步（从 1 计）、梯度 \(g\)：
  1. 解耦权重衰减（wd≠0，先做）：\(p \leftarrow p\,(1-lr\cdot\text{wd})\)
  2. **首步（\(t=1\)）**：只令 \(v \leftarrow g^2\) 并**立即结束本步**（不更新 \(m\)、不更新 \(p\)）。
  3. 其后（\(t\ge 2\)），先用**上一步累积的** \(v\)：
     - 分母 \(d = \max(\sqrt{v},\ \epsilon)\)（逐元素 `clamp(min=eps)`）
     - 归一并裁剪：\(\tilde g = \operatorname{clip}\!\left(\dfrac{g}{d},\ \pm\, t^{1/4}\right)\)
     - 动量：\(m \leftarrow \beta_1 m + (1-\beta_1)\tilde g\)
     - 更新：\(p \leftarrow p - lr\cdot m\)　（**无偏差修正**，直接用 \(m\)）
     - 再更新二阶矩：\(v \leftarrow \beta_2 v + (1-\beta_2) g^2\)
- 关键顺序：**先用上一步的 \(v\) 归一并更新参数，最后才把当前 \(g^2\) 并入 \(v\)**；首步不更新参数。`grad is None` 参数整体跳过。全程 float32，禁止调用现成优化器。

## 示例

单个参数 \(p=[1.0,\,-2.0,\,0.5]\)，`lr=0.01`、`betas=(0.9,0.9999)`、`eps=1e-6`、`weight_decay=0.01`，喂入五步梯度（首步不更新参数）：

```
g₁ = [ 0.10, -0.20,  0.30]
g₂ = [-0.40,  0.05,  0.20]
g₃ = [ 0.15, -0.10, -0.25]
g₄ = [ 0.05,  0.30, -0.10]
g₅ = [-0.20, -0.10,  0.40]
五步后 p ≈ [1.000569, -2.000692, 0.499016]
```

## 约束

- dtype float32、就地更新；支持 1D 与多维混合
- 须与参考实现逐步一致（对拍口径见 notes.md）
