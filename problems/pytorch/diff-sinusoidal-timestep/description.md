# Diffusion：正弦时间步嵌入

## 题目描述

扩散模型的去噪网络要「知道现在是第几步」，但时间步 \(t\) 只是一个整数标量，直接喂进去信息量太低。惯例是把它编码成一串**不同频率的正弦/余弦**（和 Transformer 的位置编码同源，Ho et al. DDPM 附录），让网络能平滑地感知任意 \(t\)。

给定标量时间步 \(t\) 与偶数维度 `dim`，令 \(\text{half}=\text{dim}/2\)，频率

\[ \text{freq}_i = \frac{1}{10000^{\,i/\text{half}}},\quad i=0,1,\dots,\text{half}-1 \]

角 \(\theta_i = t\cdot \text{freq}_i\)。嵌入按「前半段 \(\sin\)、后半段 \(\cos\)」拼接：

\[ \text{emb} = \bigl[\sin\theta_0,\dots,\sin\theta_{\text{half}-1},\ \cos\theta_0,\dots,\cos\theta_{\text{half}-1}\bigr]\in\mathbb{R}^{\text{dim}} \]

## 规则

返回形状 \((\text{dim},)\) 的 float32 张量。\(t\) 以 Python 标量（int/float）传入。禁止现成扩散库。

## 示例

\(t=7,\ \text{dim}=8\)（half=4，freq=\([1,10^{-1},10^{-2},10^{-3}]\)）：

```
emb = [ 0.6569865942001343, 0.6442176103591919, 0.06994284689426422, 0.006999942008405924,
        0.7539022564888   , 0.7648422122001648, 0.9975510239601135, 0.9999755024909973 ]
```

`前 4 项 = sin([7,0.7,0.07,0.007])`，`后 4 项 = cos([7,0.7,0.07,0.007])`。

## 约束

- `dim` 为正偶数；float32。
- \(t=0\) 时 \(\sin\) 半段全为 0、\(\cos\) 半段全为 1。
- 频率指数用 \(i/\text{half}\)（等价于 \(2i/\text{dim}\)），最大周期固定 10000。
