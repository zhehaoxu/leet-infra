# RePaint 跳步表：逆向回跳的时间步安排

## 题目描述

RePaint 用「已知区域」的信息修补「待补区域」：它不按 0 到 T 单调去噪，而是周期性地把时间步**往回拨**（拨向更噪的方向），让模型反复重新生成、逐步把两部分拼接处的统计量对齐。这种「前进一大段、后退一小段」的时间表，由 `jump_length`（每次后退几步）与 `jump_n_sample`（每个回跳点最多退几次）两个参数控制。

本题只算**时间步表本身**：给定训练步数、推理步数与两个跳步参数，输出一个完整的一维整数序列，供调度器逐项执行。

## 规则

记 \(N_{\text{eff}}=\min(T,N)\) 为实际使用的推理步数。

1. **回跳点**：在 \(0, j, 2j, \dots\) 中取所有严格小于 \(N_{\text{eff}}-j\) 的点，每个点的初始配额是 \(n-1\)（\(j\) = `jump_length`，\(n\) = `jump_n_sample`）。
2. **主循环**（从 \(t=N_{\text{eff}}\) 开始）：

   ```
   while t >= 1:
       t = t - 1
       输出 t
       若 budget[t] > 0:
           budget[t] -= 1
           重复 j 次:
               t = t + 1
               输出 t
   ```
   关键在「回跳之后**并不**接着往下走」：循环继续从抬高后的 \(t\) 递减，于是刚走过的那 \(j\) 级会被**再走一遍**，后面每一级也都被重新走一遍——这就是表长会明显超过 \(N_{\text{eff}}\) 的原因。
3. **换算成训练步**：把整张表乘以步长比例 \(\lfloor T/N_{\text{eff}}\rfloor\)（整数除法）。

返回一维 `int64` 张量。

## 示例

`T = 100`、`N = 10`、`j = 2`、`n = 2`：回跳点是 0、2、4、6，各一次。递减到 6 时配额为 1，向上走到 8，随后从 8 重新递减；到 4、2、0 时再各回跳一次。

```
[90, 80, 70, 60, 70, 80, 70, 60, 50, 40, 50, 60, 50, 40,
 30, 20, 30, 40, 30, 20, 10, 0, 10, 20, 10, 0]
```

共 26 项（步长比例为 10）。可以看到 `60 → 70 → 80` 是一段长度恰为 \(j=2\) 的上升，紧接着的 `70, 60, 50, 40` 是把 6 以下重新走了一遍。

换成 `T = 30`、`N = 10`、`j = 3`、`n = 2`（回跳点 0、3、6，步长比例 3）：

```
[27, 24, 21, 18, 21, 24, 27, 24, 21, 18, 15, 12, 9,
 12, 15, 18, 15, 12, 9, 6, 3, 0, 3, 6, 9, 6, 3, 0]
```

共 28 项。

## 约束

- 四个参数都必须是 Python 整数且 \(\ge 1\)（布尔值不算整数，抛 `ValueError`）；
- 当 `num_inference_steps > T` 时取 \(N_{\text{eff}}=T\)，不做报错；步长比例用 \(N_{\text{eff}}\) 计算；
- `jump_length` 不小于 \(N_{\text{eff}}\) 时回跳点集合为空，输出退化为 \(N_{\text{eff}}-1, N_{\text{eff}}-2, \dots, 0\) 的等差递减；
- `jump_n_sample = 1` 时每个点的配额是 0，同样没有任何回跳；
- 性质：表首项为 \((N_{\text{eff}}-1)\cdot\lfloor T/N_{\text{eff}}\rfloor\)，末项为 0；任意相邻两项之差恰为 \(\pm\lfloor T/N_{\text{eff}}\rfloor\)；每段极长的上升步恰好长 \(j\)，这样的上升段个数等于 \((n-1)\times\) 回跳点个数。
