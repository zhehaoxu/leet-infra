# 解题说明 · RePaint 跳步表

## 出处

- `huggingface/diffusers` 的 `src/diffusers/schedulers/scheduling_repaint.py`：`RePaintScheduler.set_timesteps`（第 188–231 行）就是本题要复现的全部逻辑。`step` 里的掩码混合、方差与复用噪声是另一回事（`step` 的多处注释指向 RePaint 论文 Algorithm 1，编号 arXiv:2201.09865，可在源码第 340–390 行看到），本课不碰。
- RePaint 的直觉：扩散模型擅长「无条件生成」，但不保证补出来的区域与已知区域在拼接处一致；所以它在去噪途中周期性回跳到更噪的一级，让模型重新生成这一段，等价于反复做「加噪—去噪」的调和。

## 核心与易错点

**回跳之后是从高点继续递减，不是从原点继续。** 最容易写错的地方：看到「向上走 j 步」就以为了事后回到原来的 t。源码里 `t` 被就地抬高，`while` 循环接着从高位往下走，因此中间每一级都会被**再走一遍**，且每一级上的回跳配额还可能再次触发。`T=100, N=10, j=2, n=2` 的 26 项（而非 10 或 18 项）就是这条的直接结果。

**回跳点范围是 `range(0, N - j, j)`。** 上界是 \(N-j\) **不含**：若某个点 \(t\) 满足 \(t+j\ge N\)，向上走会越过最大时间步 \(N-1\)，源码直接不把它放进字典。写成 `range(0, N, j)` 会在表尾多出越界的项。

**配额是 `n-1`，不是 `n`。** 第一次递减到该点时会消耗一次，`n=1` 表示「一次都不跳」。因此 `n` 的效果是「该点最多连续跳 n 次」，而不是「跳 n 次」。

**两处整数除法。** 主循环的上界是 `min(T, N)`（推理步数不能超过训练步数），步长比例是 `T // N_eff`。两者都用夹过的 \(N_{\text{eff}}\)：`T=8, N=20` 时比例是 1 而不是 0，输出是 `7..0` 共 8 项。

**最后的 `* step` 是向量化乘法，不是索引。** 主循环内部完全在 \([0, N_{\text{eff}}-1]\) 上工作，最后统一乘步长比例；如果边循环边乘，`jumps` 的键就对不上了。

**结构判据比逐值比对更能抓错。** 相邻差必须恰为 \(\pm\)step、每段上升恰长 \(j\)、上升段个数等于 \((n-1)\times\)回跳点数——这三条一起把「跳了但跳错方向」「少跳一次」「回跳后没重走」都覆盖了。注意**不能**期望「去掉上升步之后的骨架是单调递减」：回跳后重走的那一段会留下新的较高值，骨架在接缝处是上跳的。

**返回 int64。** 时间步在调度器里是整数索引，用浮点张量会让后续 `alphas_cumprod[t]` 直接报错。

## 与其他题的分工

- `diff-ddim-inverse-step`：同样是「走回更噪的一级」，但那是连续公式的一步算术；本题是**离散的时间表编排**，不含任何 alpha 运算。
- `diff-sdedit-strength`：决定逆向从哪一级起步（截断）；本题决定整个循环里每一级何时被重复。
- `diff-ddpm-step` / `diff-ddim`：单步的数值更新；本题产生的是驱动它们的时间步序列。
- `diff-aspect-ratio-buckets`：另一类「先构造离散表、再做分配」的调度题，但那份表是分辨率而非时间。
