# 量化：AWQ 的缩放-裁剪联合网格搜索

## 题目描述

AWQ 的逐输入通道缩放 \(s_j\) 不是唯一旋钮。**裁剪**是第二个：权重里少数离群值会把整组的量化 scale 撑大，同组其它权重全被压成 0；把这些离群值裁到阈值内，牺牲一点点幅值，换回整组的有效码数。**收缩下界**是第三个：缩放把某些通道的权重压得太狠时，权重本身的量化误差会反噬，所以要限制 \(s_j\) 最低能压到多少。

本题给定权重、校准激活和三个旋钮的网格，要求对每个 \((\beta,\text{clip})\) 组合执行「定 scale → 归一化 → 收缩 → 全局裁剪 → 分组 int4 量化 → 激活加权误差」，返回最优组合、对应的 scale、量化码和整张误差表。

## 规则

记 \(q_{\max}=2^{\text{bits}-1}-1\)。对网格中每个 \(\beta\)（外层）和 `clip`（内层）：

1. **量级统计**：\(\text{xm}_j=\frac1T\sum_i|X_{ij}|\)、\(\text{wa}_j=\max_o|W_{oj}|\)、\(w_{\max}=\max_{o,j}|W_{oj}|\)。
2. **缩放因子**：\(s_j=\text{xm}_j^{\beta}/\text{wa}_j^{1-\beta}\)；\(\text{xm}_j=0\) 或 \(\text{wa}_j=0\) 的通道取 \(s_j=1\)。
3. **几何归一化**：\(s\leftarrow s/\sqrt{\max(s)\min(s)}\)（该值为 0 时跳过），让缩放不改变整体量级。
4. **收缩下界**：\(s_j\leftarrow\max(s_j,\,1-\text{max\_shrink})\)。`max_shrink=0` 时所有权重都不许被缩小。
5. **全局裁剪**：阈值 \(t=\text{clip}\cdot w_{\max}\)，\(W^{c}_{oj}=\operatorname{clamp}(W_{oj},-t,t)\)。注意阈值由**整个矩阵**的最大绝对值定，而不是逐行定——这样只有接近全局离群值的元素被裁。
6. **分组量化**：先缩放 \(W^{s}=W^{c}\odot s\)（按输入通道乘），再沿输入通道每 `group_size` 个一组做对称量化：组内 \(\text{scale}_g=\max|W^{s}_{g}|/q_{\max}\)（组内全 0 时 scale=1、码全 0），
   \[
   q_{oj}=\operatorname{clamp}\!\left(\operatorname{round}\!\left(\frac{W^{s}_{oj}}{\text{scale}_{g(j)}}\right),-q_{\max},q_{\max}\right).
   \]
7. **回到逻辑权重**：\(\hat W^{\text{log}}_{oj}=q_{oj}\,\text{scale}_{g(j)}/s_j\)。
8. **误差**（输出误差的对角近似，按通道激活幅值加权）：
   \[
   \mathcal{L}(\beta,\text{clip})=\frac{1}{O\cdot C}\sum_{o,j}\text{xm}_j\left(W^{c}_{oj}-\hat W^{\text{log}}_{oj}\right)^2.
   \]

取 \(\mathcal L\) 最小的组合；并列取先出现者（先比 \(\beta\) 下标、再比 `clip` 下标）。内部全程 float64，取整用「就近、`.5` 取偶」。

返回五元组：

- `best_beta`、`best_clip`：最优组合的两个浮点参数；
- `best_scales`：float32 \((C,)\)，该组合实际使用的 \(s\)（归一化与收缩之后）；
- `best_codes`：int64 \((O,C)\)，该组合下 \(W^c\odot s\) 的量化码；
- `losses`：float32 \((\text{len(ratios)},\text{len(clips)})\)，`losses[i, j]` 对应 `(ratios[i], clips[j])`。

## 任务

- 输入：`W` float32 \((O,C)\)、`X` float32 \((T,C)\)、`ratios`（非空 float 列表，元素在 \([0,1]\)）、`clips`（非空 float 列表，元素在 \((0,1]\)）、`max_shrink`（float，\([0,1]\)）、`group_size`（正整数，整除 \(C\)）、`bits`（2～8）。
- 输出：上述五元组；浮点容差 `1e-5`（loss 可用相对容差 \(10^{-4}\)）。
- `bits` 越界抛 `ValueError`；其余输入按题面保证取值。

## 示例

```
W = [[ 10.5, -6.0,  2.0],        X = [[0.02, 0.95, 0.48],
     [ -1.8, -2.8,  5.8],             [0.02, 0.06, 0.20],
     [ -2.4, -1.9, -2.6]]             [0.01, 1.36, 1.02],
                                      [0.01, 0.42, 0.94]]
ratios = [0.0, 0.5, 1.0],  clips = [1.0, 0.75, 0.5, 0.25, 0.1]
max_shrink = 0.5,  group_size = 3,  bits = 4
```

`xm = [0.015, 0.6975, 0.66]`、`wa = [10.5, 6.0, 5.8]`、`w_max = 10.5`。误差表（行 = β，列 = clip）：

```
              clip=1.0    0.75        0.5        0.25       0.1
β=0.0       1.29940e-2  1.32284e-2  9.88267e-3  3.14876e-3  3.11347e-4
β=0.5       2.00691e-2  2.97825e-2  1.43926e-2  1.80263e-3  1.38912e-4   <- 最优
β=1.0       3.02391e-2  5.21349e-2  6.84213e-2  2.85086e-2  5.74039e-3
```

```
best_beta   = 0.5
best_clip   = 0.1
best_scales = [0.5, 3.003466, 2.971558]
best_codes  = [[1, -7, 7], [-1, -7, 7], [-1, -7, -7]]
```

（`10.5` 这个离群值所在的通道 0 激活极小，裁到 \(\pm1.05\) 几乎不伤输出，却让同组的其它列从"码 0"变成满量程。）

## 约束

- 裁剪阈值是**层内全局**的 `clip * w_max`，不是逐行 absmax。
- 归一化用几何平均 \(\sqrt{\max\cdot\min}\)，不是算术平均；随后才施加 `1 - max_shrink` 的下界。
- 量化对象是 `W_clip * s`；误差里的逻辑权重要再除以 \(s\) 才与 `W_clip` 可比。
- 判题只看返回值，不限定实现方式。
