# 解题说明 · SmoothQuant

## 矛盾点：激活有离群、权重很规整

观察发现 LLM 的激活张量里存在少数"离群通道"（某些特征维度幅值高出其它通道 1~2 个数量级），而权重分布相对均匀。直接对激活做 INT8 per-tensor 量化，量程被离群通道撑满，绝大多数正常通道会被量化成接近 0 的值——精度暴跌。权重量化却没这个麻烦。

## 核心技巧：等价变换把难度"挪"给权重

既然激活难、权重易，就沿输入通道做一次**数学等价**的重参数化：

$$X W^\top = (X\,\text{diag}(s)^{-1})(W\,\text{diag}(s))^\top$$

只要同一通道 $X$ 除 $s_j$、$W$ 乘 $s_j$，乘积不变，但 $s_j$ 选得恰当就能"削峰填谷"：把激活离群通道压下去、把权重对应通道抬起来，让两边的量化难度都被拉平。

## 因子公式的几何含义

$$s_j = \frac{\max_i|X_{ij}|^\alpha}{\max_o|W_{oj}|^{1-\alpha}}$$

分子把激活该通道的峰值按 $\alpha$ 次幂"认领"一部分、分母把权重峰值按 $1-\alpha$ 次幂抵消，正好让迁移后激活与权重该通道的 absmax 之比被几何平衡。$\alpha$ 是难度分配旋钮：常用 0.5~0.8；太大则权重反被撑爆，太小则激活仍难量。

## 与其它量化题的正交

本题只到"迁移"这一步（返回 s、迁移后的 X/W），不涉及取整。真正的量化复用 symmetric/per-channel 那套 RTN。这样切题是为了把 SmoothQuant 独有的**缩放因子**单拎出来考，判题也最稳定。

## 恒等自检 `check_invariance`

迁移后 `X_hat @ W_hat.T == X @ W.T` 是排查 $s$ 方向写反（乘除搞混）最快的断言。`check_alpha_zero_one` 验证 $\alpha=0$ 时 $s=1/\max|W|$、$\alpha=1$ 时 $s=\max|X|$ 两个极端退化，确保幂次没写错。
