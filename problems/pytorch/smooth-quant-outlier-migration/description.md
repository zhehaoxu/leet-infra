# SmoothQuant：激活离群通道迁移

## 题目描述

W8A8 量化的最大障碍是**激活**里的离群通道：某几个特征通道的幅值能比其它通道大几个数量级，per-tensor 量化被这些离群值撑大量程、把其余通道全部压成 0。**SmoothQuant**（Xiao et al., 2023, [arXiv:2211.10438](https://arxiv.org/abs/2211.10438)）的关键洞察是：激活难量、权重好量，于是用一个逐输入通道的**等价缩放因子** $s_j$ 把激活的离群"迁移"一部分到权重上——$X$ 除以 $s$、$W$ 乘以 $s$，数学上 $XW^\top$ 完全不变，但两边的动态范围都被"抹平"、都更好量。

## 规则

给定激活 $X$ 形状 $(T, C)$（$T$ 个 token、$C$ 个输入特征通道）、权重 $W$ 形状 $(O, C)$、平衡系数 $\alpha \in [0,1]$。对每个输入通道 $j$：

$$s_j = \frac{\left(\max_i |X_{ij}|\right)^{\alpha}}{\left(\max_o |W_{oj}|\right)^{1-\alpha}}$$

然后迁移：

$$\hat{X}_{ij} = \frac{X_{ij}}{s_j},\qquad \hat{W}_{oj} = W_{oj}\cdot s_j$$

返回三元组 `(s, X_hat, W_hat)`，形状分别为 $(C,)$、$(T,C)$、$(O,C)$。

- $\alpha$ 大 → 更多离群量留给权重（权重更耐压）；$\alpha=0$ 全部由激活承担、$\alpha=1$ 全部推给权重。
- 若某通道算得 $s_j=0$（该列激活与权重全为 0），置 $s_j=1$ 避免除零。

## 示例

```
X = [[1, 2, 100],        W = [[0.1, 5.0, 0.2],
     [3, 0.5, 4],              [1.0, 0.3, 6.0]]
     [-2, 1, 8]],  alpha = 0.5

逐通道 absmax：
  X: col0=3, col1=2, col2=100
  W: col0=1, col1=5, col2=6
s = [sqrt(3)/sqrt(1), sqrt(2)/sqrt(5), sqrt(100)/sqrt(6)]
  = [1.732051, 0.632456, 4.082483]

X_hat = [[0.577350, 3.162278, 24.494898],
         [1.732051, 0.790569,  0.979796],
         [-1.154701, 1.581139,  1.959592]]
W_hat = [[0.173205, 3.162278, 0.816497],
         [1.732051, 0.189737, 24.494896]]
```

（离群通道 col2 的激活被 $1/4.08$ 压小、权重被 $\times 4.08$ 放大——迁移完成。）

## 约束

- CPU float32；$s$、$\hat X$、$\hat W$ 均用 `torch.allclose(atol=1e-4)` 比较。
- $X$ 与 $W$ 的最后一维（输入通道数 $C$）必须一致。
- absmax 沿"其它所有维"取：$X$ 沿 token 维（dim=0）、$W$ 沿输出维（dim=0）。
