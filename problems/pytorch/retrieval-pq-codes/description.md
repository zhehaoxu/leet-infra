# 检索：乘积量化编码

## 题目描述

乘积量化（PQ, Product Quantization，Jégou et al., TPAMI 2011）把 \(D\) 维空间**分解**为 \(m\) 个 \(d=D/m\) 维子空间的**笛卡尔积**，在每个子空间独立地用一套 \(k_{sub}\) 个码本中心做向量量化。一个向量由此被压缩成 \(m\) 个「子码」（每码约 \(\log_2 k_{sub}\) 位），远小于原始 \(D\) 维浮点。这是 Faiss `IndexPQ` / IVF-PQ 里精排与压缩的基石。本题实现 PQ 的**编码**这一步确定性操作。

## 规则

实现 `solve(x, codebook)`。输入 `x`（float32，形状 \((n, D)\)），`codebook`（float32，形状 \((m, k_{sub}, d)\)）为 \(m\) 套子码本（每套 \(k_{sub}\) 个 \(d\) 维中心），且 \(D = m\cdot d\)。对每个向量 \(x_i\) 沿特征维切成 \(m\) 段 \(x_i[j\!\cdot\!d : (j\!+\!1)\!\cdot\!d]\)，第 \(j\) 段子码 = 该子向量在**第 \(j\) 套码本**里平方欧氏距离最小的中心下标。返回 int64 张量，形状 \((n, m)\)。并列取中心下标最小者。

## 示例

\(m=2, k_{sub}=2, d=2\)（故 \(D=4\)）：

```
codebook[0]=[[0,0],[10,10]]   # 第 0 段（前 2 维）的两个中心
codebook[1]=[[0,0],[0,5]]     # 第 1 段（后 2 维）的两个中心
x = [[0,0, 0,0],             # 段0=[0,0]->0, 段1=[0,0]->0
     [3,3, 0,6]]             # 段0=[3,3]->0(距18<98), 段1=[0,6]->1(距1<36)
out = [[0,0],[0,1]]   shape = (2, 2)
```

## 约束

- CPU float32；\(D = m\cdot d\) 必须整除成立。
- 子空间**独立**：第 \(j\) 段只与第 \(j\) 套码本比较，绝不跨段混用码本。
- 距离用平方欧氏即可；并列取子码下标最小者。
