# 优化器：Lion 符号动量更新（Sign-based Momentum）

## 题目描述

Lion（arXiv:2302.06675，Google）由符号搜索自动发现。它的每一步更新只是**某个量在坐标轴上的符号**，因此每个坐标都精确移动 \(lr\) 的大小——没有 Adam 那种逐坐标自适应分母，状态也只需一份动量缓冲区，显存约为 Adam 的一半。核心是把「当前动量」和「当前梯度」做一次插值，取其符号作为更新方向。

本题要求你**继承 `torch.optim.Optimizer`** 实现 Lion，通过 `step()` 就地更新参数；评测喂固定梯度序列、比对最终参数与独立参照实现是否逐元素一致。

## 规则

- 实现工厂函数 `solve(params, lr=1e-4, betas=(0.9, 0.99), weight_decay=0.0)`，返回一个 `torch.optim.Optimizer` 子类实例；`params` 是待优化张量列表，`step()` 须**就地更新**这些张量本身。
- 对每个第 \(t\) 步有梯度的参数 \(p\)、梯度 \(g\) 与动量缓冲 \(m\)（初始为零）：
  1. **解耦权重衰减**（仅当 `weight_decay`≠0，先于方向计算）：\(p \leftarrow p\,(1 - lr\cdot\text{wd})\)
  2. 插值方向：\(u = \beta_1 m + (1-\beta_1)\, g\)
  3. 符号化：\(u \leftarrow \operatorname{sign}(u)\)
  4. 更新动量（用**旧** \(m\) 与当前 \(g\)）：\(m \leftarrow \beta_2 m + (1-\beta_2)\, g\)
  5. 参数更新：\(p \leftarrow p - lr\cdot u\)
- `sign(0)=0`。计算全程 float32，每个参数一份 \(m\)。`grad is None` 的参数整体跳过。**禁止**调用任何现成优化器，需手写。

## 示例

初始化单个参数 \(p=[1.0,\,-2.0,\,0.5]\)，`lr=0.1`、`betas=(0.9, 0.99)`、`weight_decay=0.01`，连续喂入三步梯度：

```
g₁ = [ 0.10, -0.20,  0.30]
g₂ = [-0.40,  0.05,  0.20]
g₃ = [ 0.15, -0.10, -0.25]
三步后 p ≈ [0.897103, -1.894106, 0.398801]
```

## 约束

- 输入张量 dtype 为 float32；输出就地更新、dtype 不变
- 支持任意形状参数；每个坐标单步位移恰为 \(lr\)（符号更新）或 0
- 与独立参照逐步完全一致（口径见 notes.md）
