# Top-n-sigma 采样

## 题目描述

top-k、top-p 都要人工挑一个「保留几个 / 留多大质量」的旋钮，与分布本身的形状无关。
**Top-n-sigma**（llama.cpp 的 `top-n-sigma`）换了个思路：把截断阈值和分布的**统计离散度**
挂钩。它计算整行 logits 的均值 $\mu$ 与（总体）标准差 $\sigma$，只保留
$\text{logit} \ge \max - n\sigma$ 的候选。分布越平坦（$\sigma$ 越大）留得越多，分布越尖锐
（$\sigma$ 越小）砍得越狠——阈值随置信度自适应，而无需固定 `k`。

> 为保证判题**确定性**，均匀随机数 `u` 作为显式输入传入，采样用逆变换法（在保留分布的
> CDF 上取首个 $\ge u$ 的位置）。

## 规则

- 实现 `solve(logits, n, u)`：`logits` 形状 `(..., V)`，`n` 为正的浮点数（sigma 倍数），
  `u` 为每行一个、取值 $[0,1)$ 的均匀随机数（形状 `(...,)` 或标量）。
- 步骤（对最后一维逐行）：① `probs = softmax(logits)`；② 令 `max = logits.max()`、
  `mean = logits.mean()`、`std = sqrt(mean((logits - mean)^2))`（**总体**标准差，除以 `V`）；
  ③ 保留 `logit >= max - n*std` 的候选，其余置 0；④ 保留部分重新归一化 → `filtered`
  （形状同 `probs`，每行和为 1）；⑤ 用 `u` 在 `filtered`（原顺序）CDF 上逆变换采样得 `chosen`。
- 返回 `(filtered, chosen)`：`filtered` 形状同 `probs`，`chosen` 形状 `(...,)`。

## 示例

```
输入：logits = [3, 2.5, 0, -0.2, -0.5, -4]，n = 1.0，u = 0.8
  probs(softmax) = [0.578640, 0.350963, 0.028809, 0.023587, 0.017473, 0.000528]
  mean = 0.133333, std = 2.288862, max = 3.0
  阈值 cut = max - n*std = 3.0 - 2.288862 = 0.711138
  保留 logit >= 0.711138 → 索引 {0, 1}（值 3.0、2.5）
  归一化 → filtered = [0.622459, 0.377541, 0, 0, 0, 0]
  CDF = [0.622459, 1.0]，u = 0.8 → 首个 ≥0.8 是位置 1 → 选中原始索引 1
输出：filtered = [0.622459, 0.377541, 0, 0, 0, 0], chosen = 1
```

## 约束

- float32 输入；`n > 0`；`u ∈ [0,1)`
- `std` 为总体标准差（除以元素个数 `V`，非 `V-1`）
- `filtered` 每行和为 1，被丢弃位置严格为 0；`chosen` 必落在保留集合内
- 支持批量 `(..., V)`；每行独立计算 `mean/std/max`
