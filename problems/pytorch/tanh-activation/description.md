# Tanh

## 题目描述

实现逐元素双曲正切激活：

$$
\tanh(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} \in (-1, 1)
$$

它是早期神经网络的标配激活，也是理解「数值稳定」的好例子：直接用 $e^{x}$ 会在大正数上溢。

## 规则

- 实现 `solve(x: torch.Tensor) -> torch.Tensor`，输出形状、dtype 与输入一致。
- 要求向量化实现，不能用 Python 逐元素循环。
- **数值稳定**：朴素写 `(exp(x)-exp(-x))/(exp(x)+exp(-x))` 时 `exp(800)` 会溢出为 `inf` 导致 `inf/inf = NaN`。可利用恒等式 $\tanh(x)=\frac{1-e^{-2|x|}}{1+e^{-2|x|}}$ 并按符号分支，$e^{-2|x|}$ 恒 $\le 1$ 不会上溢。

## 示例

```
输入：[-2.0, -1.0, 0.0, 1.0, 2.0]
输出：[-0.96402758, -0.76159412, 0.0, 0.76159412, 0.96402758]
```

## 约束

- 输入为 float32 或 float64 张量，任意形状
- 数值范围无限制（可能包含 ±800 等极值，需饱和到 ±1 而非 NaN）
