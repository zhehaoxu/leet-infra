# 非极大值抑制 NMS（Non-Maximum Suppression）

## 题目描述

目标检测器会为同一个物体吐出许多高度重叠的候选框。NMS 负责**去重**：反复保留当前分数最高
的框，抑制掉与它 IoU 超过阈值的所有框，直到候选清空。它是几乎所有检测/分割/姿态流水线
的最后一环（ Faster R-CNN、YOLO、DETR 后处理都依赖它）。

## 规则

- 实现 `solve(boxes, scores, iou_thresh)`，`boxes` 形状 `(N,4)`（`[x1,y1,x2,y2]`），
  `scores` 形状 `(N,)`。
- 贪心流程：① 按分数降序；② 取队首框放入 `keep`；③ 从剩余候选中删除所有与该框
  IoU `> iou_thresh` 的框；④ 重复直到候选为空。
- 返回保留框的**原始索引**（`long` 张量），顺序为分数从高到低。
- IoU 计算同「交并比 IoU」一题（角点格式、`clamp_min(0)`、并集为 0 记 0）。

## 示例

```
输入：boxes = [[0,0,10,10],   score 0.9
              [1,1,11,11],   score 0.8   （与框0 高度重叠）
              [50,50,60,60], score 0.7
              [51,51,61,61]] score 0.6   （与框2 高度重叠）
     iou_thresh = 0.5
  取框0 → 抑制框1（IoU 大）；剩 [2,3]；取框2 → 抑制框3；剩空
输出：keep = [0, 2]
```

## 约束

- float32 输入；`iou_thresh ∈ (0,1)`
- 返回索引唯一、按分数降序；`scores` 无并列以保证结果确定
