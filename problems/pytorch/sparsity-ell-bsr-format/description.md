# 稀疏化：ELL / BSR 格式转换与存储账

## 题目描述

同一个稀疏矩阵，在不同硬件上有不同的存储「形状」：

- **CSR（行压缩）**：省空间，但行与行的长度不等，GPU 上千个线程按行并行时会严重发散（长度不齐 → warp 内空转）。
- **ELL（等长行）**：把每行都补齐到「最长行的非零个数」\(M\)，存成两个 \(R\times M\) 的稠密矩阵——`values` 与列号 `indices`。行等长、访存完全规整，代价是补齐位浪费空间；行长度差异越大越亏。
- **BSR（块压缩）**：以 \(b_r\times b_c\) 的小块为单位存储，只存「块内至少有一个非零」的块。它既保留了压缩率，每块又是连续、对齐的稠密小矩阵，适合 Tensor Core / 分块 GEMM 直接吃。

工程上选格式靠的是「存储字节数」这本账：同样的矩阵，NNZ 数、最长行长度 \(M\)、非零块数 \(NB\) 三个量决定了三种格式各要多少字节。本题要求把稠密矩阵同时转成 ELL 与 BSR，并把三种格式的字节数一起算出来。

## 规则

给定 `dense`（float32，\((R,C)\)，\(R\%b_r=0\)、\(C\%b_c=0\)，非零判据 `!= 0.0`，\(-0.0\) 视为 0）与块形状 `block=(b_r,b_c)`：

**ELL**

1. 令 \(M=\max_i(\text{第 }i\text{ 行非零个数})\)（全零矩阵时 \(M=0\)，于是两个数组都是 \(R\times0\)）；
2. 每行把非零元素**按列号升序**依次填进该行前若干个位置；
3. 尾部补齐：`values` 补 `0.0`，`indices` 补 `-1`（用 −1 区分「补齐位」和「第 0 列」）；
4. `ell_values` 为 float32 \((R,M)\)、`ell_indices` 为 int64 \((R,M)\)。

**BSR**

1. 把矩阵切成 \(b_r\times b_c\) 的块网格，共 \(R/b_r\) 个块行、\(C/b_c\) 个块列；
2. 块内**至少一个**元素非零 ⇒ 该块保留，否则丢弃；
3. 按块行主序（块行优先、块列升序）依次输出：`bsr_values`（\((NB,b_r\cdot b_c)\)，块内行主序展平）、`bsr_indices`（每个块的块列号，int64）、`bsr_indptr`（长 \(R/b_r+1\)，第 \(i\) 个块行之前的块总数累加）；
4. `block=(1,1)` 时 BSR 退化为「按行优先顺序存的 COO」，\(NB=\text{nnz}\)。

**存储字节数**

记 \(\text{nnz}\) 为全矩阵非零元素个数、\(M\) 为最长行非零数、\(NB\) 为非零块个数、\(N_r=R/b_r\)；值占 4 字节、索引占 8 字节：

$$
\text{CSR} = \underbrace{4\,\text{nnz}}_{\text{values}} + \underbrace{8\,\text{nnz}}_{\text{col idx}} + \underbrace{8(R+1)}_{\text{indptr}}
$$

$$
\text{ELL} = 4RM + 8RM
\qquad
\text{BSR} = 4\,NB\,b_r b_c + 8\,NB + 8(N_r+1)
$$

返回 `nbytes`（int64，长 3）按 `[CSR, ELL, BSR]` 顺序排列。禁止 `torch.sparse` / `to_sparse_csr` / `to_sparse_bsr`。

## 示例

`dense` 为 4×4、`block=(2,2)`：

```
dense = [[1, 0, 0, 2],
         [0, 0, 3, 0],
         [4, 5, 0, 0],
         [0, 0, 0, 6]]

各行非零数 = [2, 1, 2, 1] → M = 2

ELL：
  行0 非零列 [0,3] → values [1,2]   indices [0, 3]
  行1 非零列 [2]   → values [3,0]   indices [2,-1]   # 补 1 位
  行2 非零列 [0,1] → values [4,5]   indices [0, 1]
  行3 非零列 [3]   → values [6,0]   indices [3,-1]   # 补 1 位

BSR（2×2 块网格 2×2，四块都含非零）：
  块(0,0)=[[1,0],[0,0]] → [1,0,0,0]  块列 0
  块(0,1)=[[0,2],[3,0]] → [0,2,3,0]  块列 1
  块(1,0)=[[4,5],[0,0]] → [4,5,0,0]  块列 0
  块(1,1)=[[0,0],[0,6]] → [0,0,0,6]  块列 1
  bsr_indices = [0, 1, 0, 1]，bsr_indptr = [0, 2, 4]
```

`nnz=6`、`M=2`、`NB=4`、`N_r=2`，于是

```
CSR = 6*4 + 6*8 + (4+1)*8 = 24 + 48 + 40 = 112
ELL = 4*4*2 + 8*4*2       = 32 + 64     =  96
BSR = 4*4*4 + 8*4 + (2+1)*8 = 64 + 32 + 24 = 120
nbytes = [112, 96, 120]
```

## 约束

- CPU float32 输入；`ell_values`/`bsr_values` 为 float32，其余索引与字节数为 int64。
- ELL 每行长度恒为 \(M\)：全零行必须整行补 `-1`/`0.0`，不能跳过。
- 补齐位一律「值 0、索引 −1」，且必须排在真实元素之后（列号升序）。
- BSR 只保留「块内至少一个非零」的块，**部分非零的块也要整块存**（块内零元素原样保留）。
- 全零矩阵：\(M=0\)、\(NB=0\)，`indptr` 全 0。
- 用 ELL 或 BSR 必须能无损还原原矩阵。
