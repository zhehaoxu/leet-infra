# 排序与 argsort（Sort & Argsort）

## 题目描述

排序给出一行元素升序后的**值**；`argsort` 给出把这些值排成升序所需的**原始索引**。
两者常配对出现：`argsort` 的索引可用于 `gather` 重排关联张量（如按分数排边界框、
按长度排 batch 里的序列）。请**不用 `torch.sort/argsort`**，用选择排序实现。

## 规则

- 实现 `solve(x)`，沿**最后一维升序**排序，返回 `(values, indices)` 元组。
- `values`：升序排序后的值，形状同输入；`indices`：对应元素在原最后一维中的位置。
- 用「在未排序部分取最小、写值与索引、再把它移出候选（置 `+inf`）」的选择法逐步构造。
- 结果须与 `torch.sort(x, dim=-1)` 在测试数据（无重复值）下一致。

## 示例

```
输入：x = [[3, 1, 7, 2, 9],
          [5, 8, 0, 6, 4]]
输出：values  = [[1, 2, 3, 7, 9],
                 [0, 4, 5, 6, 8]]
     indices = [[1, 3, 0, 2, 4],
                [2, 4, 0, 3, 1]]
```

## 约束

- float32 输入；沿最后一维排序
- 测试用随机连续值（无并列），使排序结果与 argsort 索引唯一确定
