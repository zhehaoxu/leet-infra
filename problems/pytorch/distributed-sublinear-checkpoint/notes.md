# 详解：次线性激活检查点

## 出处
Chen, Xu, Lin 2016，*Training Deep Nets with Sublinear Memory Cost*（arXiv:1604.06174）。论文证明：对 $n$ 层网络，用 $O(\sqrt n)$ 个检查点即可把激活显存降到 $O(\sqrt n)$，代价只多约一次前向。本题取其「每隔 $k$ 层存检查点」的周期性特例，把 $\lceil n/k\rceil + k$ 型峰值函数最优化成一道整数题。

## 核心与易错点
1. **峰值是两项之和**：常驻检查点 $\lceil n/k\rceil$ + 当前重算窗口 $k$。$k$ 太小 → 检查点太多；$k$ 太大 → 段内重算窗口太宽。两端都涨，中间有谷底，谷底在 $k\approx\sqrt n$、峰值 $\approx 2\sqrt n$。
2. **整数上取整**：$\lceil n/k\rceil$ 用 `-(-n//k)`，全程整数。用 `math.ceil(n/k)` 走浮点在 $n$ 很大（如 40000）时可能因精度抖一下，题面要求纯整数。
3. **并列取最小 $k$**：升序扫描、只在**严格更小**时更新即可保证；若写成 `<=` 会取到最大的并列 $k$，判等失败。
4. **store_all 是另一条基线**：$n\cdot a$，与 $\text{peak}$ 无 $\lceil\rceil$ 关系；$n$ 小时（如 $n=1$）检查点峰值 $2a$ 反而**大于**全存 $a$——这正常，本题只是枚举 $k$ 求 checkpoint 方案最小值，并单独报告全存基线，不要求谁更小。

## 对拍口径
参考解升序贪心扫描 $k$；判题 `_oracle` 用**两趟**结构（先列全部 peak 单位数、`min` 取最小值、再 `index` 回溯最小 $k$），交叉验证「并列取最小 k」的语义。另用 $n=m^2$ 时 $best\_k=m$、$peak=2m$ 的解析性质，以及 $act\_bytes$ 线性缩放、深网络 `min_peak<store_all` 三组断言卡边界。

## 复杂度
枚举 \(O(n)\)；$n\le 10^5$ 轻松。可用 $\lfloor\sqrt n\rfloor$ 附近常数级候选降到 \(O(1)\)，本题不要求。
