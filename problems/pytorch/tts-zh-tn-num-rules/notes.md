# 中文 TN 数字读法规引擎

## 背景与回源

TTS 文本前端（TN/Text Normalization）把书面文本转成可发音串。PaddleSpeech
`paddlespeech/t2s/frontend/zh_normalization/`（`num.py`、`chronology.py`、`phonecode.py`，
规则源自 WeTextProcessing 移植）的数字读法引擎是纯字符串规则，可完整转写。本题按
官方源码逐条钉口径。

## 机制账

1. **万/亿幂递归分节**（`_get_value`）：对 `stripped = value.lstrip('0')`，取
   `UNITS = {1:十, 2:百, 3:千, 4:万, 8:亿}` 中满足 `power < len(stripped)` 的最大幂，
   按 `value[:-k] / value[-k:]` **基于原串**（非 stripped）切分递归。中缀单位符号
   （万/亿）出现在两半之间。
2. **中间零补零**：递归叶子 stripped 长度 1 且小于原串长度（如 "001" 的 "1"）→
   `[零, X]`；stripped 为空 → `[]`。串首前导零因 lstrip 全丢（"07"→"七"），而
   尾段前导零补零（"1001"→"一千零一"）——两种零行为不对称。
3. **一十缩写**：仅对**整体符号串**首位 "一十" 生效（"10"→"十"、"100000"→"十万"、
   "1000000010"→"十亿零一十"）；段内不缩（"110"→"一百一十"）。
4. **num2str 小数**：小数部分 `rstrip('0')`（"3.20"→"三点二"）；整数读数空时补
   "零"（".22"→"零点二二"）；小数逐位（零也读，"0.05"→"零点零五"）。
5. **时刻**："30 分" 特判 "半"；分钟/秒去前导零后 num2str，若原串以 0 开头则先补
   回 "零"（"05"→"零五"）；全零省略（"8:00"→"八点"）。
6. **号码**：分段逐位 + 幺化（`replace('一','幺')` 只影响数字 1），mobile 按空格
   分段（strip 前导 '+'）、fixed 按 "-" 分段，段间全角 "，"。

## 独立 oracle 与对拍

- 固定锚点覆盖全部 quirk；300 组随机整数上官方字符串递归与**独立数值法**
  （万进制四位分节 + 段内零压缩 + 段间补零 + 首位一十缩写）互证一致。
- 小数/时刻/号码另 200 组随机对拍。

## 变异

14 条全抓：去 lstrip、全零返空串、幂条件 `<`→`<=`、去中间零补零、一十缩写放宽、
小数尾零不剥、空整数不补零、去半特判、去零五补零、幺化恒开/替换错串、
phone 去 strip '+'、fixed 改空格切、全角逗号→ASCII。
