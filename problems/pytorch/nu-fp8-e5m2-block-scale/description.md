# FP8 E5M2 分块缩放：2 的幂共享尺度与网格量化

## 题目描述

FP8 的有效数字只有 3 位（E5M2 是 1 符号 + 5 指数 + 2 显式尾数），单看数值范围比 bf16 窄了十几个数量级，能用的前提就是**分块共享尺度**：Microscaling、DeepSeek 的 tile-wise scaling、KV cache 的块量化都是「一块元素共用一个 2 的幂指数，块内只存 FP8 尾数」。本题把这条链路完整走一遍：按连续的 `block` 个元素切块、给每块算出**最小的、不会溢出的 2 的幂尺度**、把块内元素舍到 E5M2 网格上（ties-to-even）、再乘回尺度输出。输出仍是 float，方便逐位对拍。

## 规则

- 完整签名与参数含义只写在 starter 的 docstring 里，那是唯一判题口径。
- 不许调用 `x.to(torch.float8_e5m2)` / `float8_e4m3fn`，也不许借 autocast——E5M2 网格要自己列。
- E5M2 的幅值集合：正规数 \((1+M/4)\cdot2^e\)，\(e=-14..15\)、\(M=0..3\)，最大有限值 \(57344=1.75\cdot2^{15}\)；次正规数 \(M\cdot2^{-16}\)（步长 \(2^{-16}\approx1.526\times10^{-5}\)）。每个倍频程内只有 4 个格点。
- 流程（row-major 展平，最后一块可以短于 `block`）：
  1. \(m=\) 块内 \(|x|\) 的最大值；
  2. \(\text{scale}=2^e\)，\(e\) 是**满足 \(m\le57344\cdot2^e\) 的最小整数**并夹到 \([-127,127]\)；\(m=0\) 时 \(e=0\)；
  3. 每个元素 \(t=x/\text{scale}\) 舍到最近的 E5M2 格点（ties 取尾数域 \(M\) 为偶的那个），再乘回 scale；输出的 0 一律写成 +0.0。
- 因为尺度保证了 \(|t|\le57344\)，量化不会溢出，输出里不会出现 inf。
- 块内 absmax 是 inf 或块里有 NaN（含两者都有）→ 该块**整块输出 NaN**；全 0 块 → 全 0。
- `block` 必须是 \(\ge1\) 的整数；非浮点张量、非 Tensor、非法 `block` 抛 ValueError。

## 示例

```
x = [1.0, 3.0, 5.0, 0.6, 0.5625]

block=5  absmax=5  scale=2^-13  ->  [1.0, 3.0, 5.0, 0.625, 0.5]
block=3  [1,3,5] [0.6,0.5625]   ->  [1.0, 3.0, 5.0, 0.625, 0.5]

x=[4608.0]  block=1  ->  4096.0
x=[4915.2]  block=1  ->  5120.0
```

`block=5` 时 absmax 是 5，最小的 \(e\) 使 \(5\le57344\cdot2^e\) 是 \(e=-13\)，于是块内乘 \(2^{13}=8192\) 后落在格点上：1、3、5 三个本来就是格点值，0.6 落到 0.625、0.5625 落到 0.5。`block=3` 把它切成两块，第二块的尺度是 \(2^{-16}\) 而不是 \(2^{-13}\)，但因为两个尺度只差一个 2 的幂、格点集合是嵌套关系，0.6 仍然落到 0.625、0.5625 仍然落到 0.5，所以结果逐位相同。`4608` 正卡在 \([4096,8192)\) 区间的两个相邻格点 4096(\(M=0\)) 与 5120(\(M=1\)) 正中，ties-to-even 取 \(M=0\) 的 4096；4915.2 离 5120 更近所以进位。

## 约束

- 任意形状 float32/float64 输入，输出同形状同 dtype（内部按 float64 计算）
- oracle 与参考解结构不同：枚举全部 E5M2 幅值（次正规 4 个 + 正规 \(30\times4\) 个）并附上各自的位模式，用 `bisect` 取最近、按位模式奇偶判 ties，尺度用循环搜索而不是 `log2`
- 边界要求逐位相等：absmax 恰好是 \(57344\cdot2^k\) 时尺度必须是 \(2^k\)（取小了会把最大值削掉一半）
