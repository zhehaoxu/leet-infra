# 音频前端：MFCC（正交 DCT-II + lifter + CMVN）

## 问题

Mel 滤波器组的相邻频带高度相关（三角滤波器互相重叠），直接把 `n_mels` 维特征喂给分类器既冗余又难建模。**MFCC** 用一步 DCT 把这组相关特征旋转到近似不相关的倒谱域，取前 `n_mfcc` 维即可丢掉高频的细节、保留声道包络。

三个细节决定了「算得对不对」：

1. **DCT 的归一化**：只有正交（`norm="ortho"`）版本才能保能量。`c[k] = s_k · Σ_n x[n] cos(πk(n+0.5)/M)`，其中 `s_0 = sqrt(1/M)`、`s_k = sqrt(2/M)`。用非归一化 DCT（`s_k = 2`）会得到一个整体差 `sqrt(M/2)` 倍的矩阵，CMVN 之后看不出来，但 c0 的能量含义完全不同。
2. **lifter**：给每个倒谱系数乘 `1 + (L/2) sin(πk/L)`，把高频倒谱系数压低（等价于在倒谱域做一次平滑，抑制噪声）。它有个坑：`L = 2` 时 `k = 3` 的权重恰好是 `1 + sin(3π/2) = 0`，该系数被完全抹掉。
3. **CMVN**（倒谱均值方差归一）：按时间轴逐系数做 z-score，消除信道与录音设备带来的固定偏移，是 ASR 的标配。标准差要除以自由度 `T`（总体），不是 `T-1`。

## 任务

实现 `solve(logmel, n_mfcc, lifter=0, cmvn=False)`：

- 输入：`logmel` `(T, M)` 对数 Mel 能量；`n_mfcc ∈ [1, M]`；`lifter >= 0`（0 表示不提升）；`cmvn` 布尔。
- 正交 DCT-II（沿 Mel 轴）：`c[k] = s_k Σ_n x[n] cos(πk(n+0.5)/M)`，`s_0 = sqrt(1/M)`，`s_k = sqrt(2/M)`。
- `lifter > 0` 时 `c[k] *= 1 + (L/2) sin(πk/L)`。
- `cmvn=True` 时逐系数 `(c - mean_t) / (std_t + 1e-8)`，`std` 用总体标准差。
- 输出 `(T, n_mfcc)` float32。

## 示例

```
logmel = [[1.0, 2.0, 3.0, 4.0],
          [2.0, 2.5, 3.0, 3.5],
          [0.5, 1.5, 2.5, 3.5]]
n_mfcc = 4

MFCC（T=3, M=4）
[[ 5.000000, -2.230442,  0.000000, -0.158513]
 [ 5.500000, -1.115221,  0.000000, -0.079256]
 [ 4.000000, -2.230442,  0.000000, -0.158513]]

lifter = 4 时 w = [1, 2.414214, 3, 2.414214]
第一行变成 [5.0, -5.384764, 0.0, -0.382683]
```

## 约束

- **c0 的含义**：正交 DCT 下 `c[0] = sqrt(M) · mean(x)`，等价于把整帧能量压成一个标量；常数输入时除 c0 外全为 0。
- **能量守恒**：取满 `n_mfcc = M` 时 `Σ c² = Σ x²`，这是判断归一化是否写对的最快自检。
- **截断发生在 DCT 之后**：可以先算满 `M` 个系数再截前 `n_mfcc` 个，也可以只算前 `n_mfcc` 行；两者必须逐元素相同。
- **lifter 的零点**：`L = 2` 会杀死 `k = 3`；`L` 越大越接近恒等。
- **CMVN 的顺序在 lifter 之后**：先提升再归一；反过来会连带把 lifter 的权重也归一掉，两者不再可交换。
- **全零输入**在 CMVN 下不能产生 NaN：`std + 1e-8` 保证输出 0。
- **非法输入抛 `ValueError`**：非二维、`n_mfcc` 越界、`lifter < 0`。
