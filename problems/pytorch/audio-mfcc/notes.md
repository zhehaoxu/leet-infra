# 解题说明 · MFCC

## DCT 为什么是「降相关」

Mel 滤波器是重叠的三角，相邻两带的能量高度相关，协方差矩阵近似三对角。DCT-II 的基向量正是这套三角滤波器在离散意义上的近似特征向量，所以一步正交变换就能把协方差矩阵近似对角化。这也是为什么 MFCC 用 DCT 而不是 PCA：不需要统计数据，有闭式基。

## 正交归一化的三个常数

`c[k] = s_k Σ_n x[n] cos(πk(n+0.5)/M)`：

- `s_0 = sqrt(1/M)`：让常数向量的 c0 等于 `sqrt(M) · mean`，而不是 `M · mean`。
- `s_k = sqrt(2/M)`（`k ≥ 1`）：让整组基成为正交矩阵，`Σ_k c_k² = Σ_n x_n²`。
- 少了 `1/sqrt(2)` 这个修正（即全部用 `sqrt(2/M)`），能量会多出一倍来自 c0 的部分。

`scipy.fft.dct(x, type=2, norm="ortho")` 与本题完全一致；`norm=None`（默认）是「不归一」，差一个 `sqrt(2M)` 的整体因子，逐元素对拍会立刻暴露。

## c0 与 c1 的物理含义

c0 是帧能量（谱包络的整体幅度），c1 近似谱倾斜，c2 以上是更细的包络形状。ASR 里常把 c0 丢掉（因为它主要受录音音量影响），只保留 c1..c12——这也解释了为什么 MFCC 一般取 13 维。

## lifter 的公式与零点

`w[k] = 1 + (L/2) sin(πk/L)`，`w[0] = 1`、`w[L] = 1`、`w[L/2] = 1 + L/2` 是峰值。若 `L` 很小则 `k = 3` 这类系数可能被试到负权重甚至 0：`L = 2` 时 `w[3] = 1 + sin(3π/2) = 0`，`L = 1` 时 `w[1] = 1 + 0.5 sin(π) = 1`。这个「权重可能为 0」的性质在实现里不需要特判，但写测试时要挑到它。

## CMVN 的两个坑

- **自由度**：`std` 用总体口径（除以 `T`）。用样本口径（`T-1`）在 `T` 很小（比如 3）时偏差明显，而且和 librosa / Kaldi 的口径不一致。
- **零方差**：某列全相同时标准差为 0，必须加 `1e-8` 兜底。全零输入是最容易踩的边界：直接除会得到 NaN 或 inf。

## 复杂度

DCT 可以写成矩阵乘 `(T × M) @ (M × n_mfcc)`，O(T · M · n_mfcc)；`M` 通常只有 40–80，所以实际开销可忽略。生产实现用 FFT 加速 DCT（O(T · M log M)），只有在 `M` 上千时才值得。
