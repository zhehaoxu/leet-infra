# 音频前端：预加重 + 分帧 + 加窗

## 问题

任何语音模型（Whisper、HuBERT、wav2vec2）的第一层都不是神经网络，而是三段固定的信号处理：**预加重**、**分帧**、**加窗**。它们把一条一维波形切成「短时平稳」的小块，让后面的 FFT 有意义。

- **预加重**：语音的高频能量天然比低频弱（声门脉冲的频谱大致按 −6 dB/oct 衰减），做一阶差分 `y[t] = x[t] - a·x[t-1]` 可以把高频抬起来，让后面的频谱更平坦、动态范围更小。`a` 一般取 0.97。
- **分帧**：语音在 20–40 ms 内可以认为统计特性不变，所以按帧长 `frame_len`、帧移 `hop_len` 切；`hop_len < frame_len` 时相邻帧重叠，避免帧边界的信息被窗压没。
- **加窗**：直接切块等于乘矩形窗，频谱旁瓣衰减只有 −13 dB，会把强频点的能量漏到远处。换成 Hann（−31 dB）或 Hamming（−43 dB）能显著压低泄漏。

这三步的顺序不能换：预加重是逐样本的，必须在切块之前做，否则每帧的首样本都需要上一帧的尾样本。

## 任务

实现 `solve(wave, preemph, frame_len, hop_len, window="hann")`：

- 输入：`wave` `(T,)` 单声道波形；`preemph` 预加重系数 `a ∈ [0, 1)`；`frame_len` / `hop_len` 帧长与帧移（采样点）；`window` 取 `"hann"` / `"hamming"` / `"rect"`。
- 预加重：`y[0] = wave[0]`，`y[t] = wave[t] - a·wave[t-1]`（`t ≥ 1`）。
- 分帧：**不做任何 padding**，帧数 `F = 1 + (T - frame_len) // hop_len`，第 `f` 帧是 `y[f·hop_len : f·hop_len + frame_len]`。
- 加窗：逐帧乘窗 `w`，Hann 为 `0.5 - 0.5·cos(2πn/(N-1))`，Hamming 为 `0.54 - 0.46·cos(2πn/(N-1))`，`N = frame_len`；`N = 1` 时 `w = [1]`。
- 输出：`y` `(T,)` 与 `frames` `(F, frame_len)`，均 float32（内部 float64 计算）。

## 示例

```
wave    = [0.5, -0.25, 0.75, 0.0, -1.0, 0.25, 1.0, 0.5, -0.5, 0.125]
preemph = 0.97, frame_len = 4, hop_len = 3, window = "hamming"

预加重：y[0] = 0.5
        y[1] = -0.25 - 0.97*0.5   = -0.735
        y[5] =  0.25 - 0.97*(-1.) =  1.22
        y = [0.5, -0.735, 0.9925, -0.7275, -1.0, 1.22, 0.7575, -0.47, -0.985, 0.61]

帧数 F = 1 + (10 - 4) // 3 = 3，窗 w = [0.08, 0.77, 0.77, 0.08]

frame0 = y[0:4]  * w = [ 0.04  , -0.56595,  0.764225, -0.0582 ]
frame1 = y[3:7]  * w = [-0.0582, -0.77   ,  0.9394  ,  0.0606 ]
frame2 = y[6:10] * w = [ 0.0606, -0.3619 , -0.75845 ,  0.0488 ]
```

## 约束

- **窗是「对称型」口径**（分母 `N-1`），与 `torch.hann_window(N, periodic=False)` 一致；周期型（分母 `N`）是 STFT 的惯例，两者末端差一个点，别混用。
- **帧数公式是向下取整**：不足一帧的尾巴直接丢弃，不补零。`T < frame_len` 时报错而不是返回空。
- **`hop_len` 可以大于 `frame_len`**：此时帧之间有空隙，公式不变。
- **预加重只作用一次**：不要把已加重的信号再切一段加重。
- **非法输入抛 `ValueError`**：非一维、`preemph ∉ [0, 1)`、`frame_len < 1`、`hop_len < 1`、`T < frame_len`、未知窗名。
