# 采样：XTC 中间概率剔除（Exclude Top Choices）

## 题目描述

top-k、top-p、min-p 全都在**砍尾巴**：把低概率的长尾清出去，头部原封不动。后果是模型一旦在某一步
极度自信（例如 \(p_{\max}=0.98\)），头部两个候选就会**垄断**整条分布，输出继续在几个高频词之间打转。
**XTC**（Exclude Top Choices，llama.cpp 与 text-generation-webui 里的实现技巧）把这把刀**反过来用**：
它不看尾部，而是看"概率**高到离谱**的连续头部前缀"，设一个绝对概率阈值 \(t\)，把降序排列里所有
\(p\ge t\) 的候选（**除最后一个之外**）整批剔除，只留下它们中概率最低的那一个加上一整条尾巴，
再重新归一化。于是概率质量从中段与尾部重新上位，输出被迫"往下走一层"，而不至于掉进随机长尾。

两点必须点明的题面口径。第一，"至少两个头部候选达标才动刀"：若只有概率最大的那一个过阈值
（\(\text{pos\_last}=0\)），剔除集合就是空集，XTC 不动；这条保护让 XTC 在模型真正只信一个 token 时
退化为恒等变换。第二，XTC 是**概率意义上**的截断（比较发生在 softmax **之后**的 \(p\) 上，
阈值 \(t\le 0.5\)），不是 logit 域判据，也不用任何 \(\mu/\sigma\) 统计量——这一点把它和同合集的
`top-n-sigma-sampling` 清楚分开。另外它是**随机触发**的：每行先用一个伯努利式概率门决定这一步要不要动手
（\(u_{\text{gate}}\le\) `probability` 才动），因此本题有**两处**随机性入口，都必须作为显式入参给出。

## 规则

记每行词表大小 \(V\)，阈值 \(t\)、触发概率 \(\pi\)、存活下限 `min_keep` 为非负/区间参数，
\(\pi\in[0,1]\)、\(t\in(0,0.5]\)。所有运算沿最后一维**逐行独立**进行。

- **早退（任一命中即本行不触发）**：\(\pi\le 0\)；或 \(t>0.5\)（此时至多一个候选能达标，剔除无意义，
  实现直接整体关闭）；或 \(V<2\)（少于两个候选，"留下最后一个"这条规则本身不成立）。
  早退时 `filtered` 就等于 \(\operatorname{softmax}(z)\)、`applied` 为 `False`，但 `chosen` 仍照常用 \(u\) 采出。
- **① 概率门**。逐行取显式入参 \(u_{\text{gate}}\)，仅当 \(u_{\text{gate}}\le\pi\) 时该行**可能**触发剔除
  （对应 llama.cpp 里 `chance > probability` 就 `return` 的那一句）。
- **② 降序秩**。\(p=\operatorname{softmax}(z)\)，把列按概率**降序**排、并列时按**原索引升序**破平，
  得到秩 \(0,\dots,V-1\) 对应的原下标序列。softmax 单调 ⇒ "概率达标者"必是这个降序数组的**连续前缀**。
- **③ 前缀边界**。令
  \[
  cnt=\#\{\text{降序连续前缀中 } p\ge t\},\qquad \text{pos\_last}=cnt-1 ,
  \]
  即"最后一个达标候选的秩"（等价于 llama.cpp 的"遇到第一个 \(p<t\) 就 break"）。
  \(cnt=0\) 时 \(\text{pos\_last}=-1\)，只有 \(cnt=1\) 时 \(\text{pos\_last}=0\)。
- **④ 剔除**。当且仅当
  \[
  u_{\text{gate}}\le\pi\quad\wedge\quad \text{pos\_last}>0\quad\wedge\quad V-\text{pos\_last}\ge \texttt{min\_keep}
  \]
  三者同时成立时触发：剔除秩 \([\,0,\ \text{pos\_last}\,)\) 上的 token（**严格左闭右开**——
  秩 \(\text{pos\_last}\) 自己**保留**），尾部秩 \([\text{pos\_last},\,V)\) 全部保留。
  第三个条件是存活下限：剩下 \(V-\text{pos\_last}\) 个候选不够 `min_keep` 就整步放弃剔除。
- **⑤ 归一化**。`filtered` \(=\;p\odot\text{keep}\,/\,\textstyle\sum p\odot\text{keep}\)，**保持原词表顺序**，
  被剔除的位置严格为 \(0\)，每行和为 \(1\)。
- **⑥ 采样**。用显式入参 \(u\) 在 `filtered` 的**原顺序** CDF 上做逆变换：
  \[
  \text{chosen}=\min\{\,i:\ \textstyle\sum_{j\le i}\text{filtered}_j\ \ge\ u\,\},
  \]
  全行 CDF 都 \(<u\) 时（数值边界情形）取最后一个下标。按此定义 \(u=0\) 时恒返回下标 \(0\)，
  **即使该位置的质量为 \(0\)**（被剔除的位置也是合法返回值）——这是本题固定的约定。
- **返回三元组** \((\text{filtered},\ \text{chosen},\ \text{applied})\)：`filtered` 形状 `(..., V)` `float32`；
  `chosen` 形状 `(...,)` `int64`（原词表索引）；`applied` 形状 `(...,)` 的**布尔张量**，标记该行剔除是否真的发生。

## 示例

```
输入：z = [3.0, 2.5, 2.0, 0.0, -1.0, -2.0]（V=6），π = 1.0，t = 0.05，min_keep = 0，
      u_gate = 0.5，u = 0.4
  p = softmax(z) = [0.487983, 0.295977, 0.179519, 0.024295, 0.008938, 0.003288]（原序即降序）
  p ≥ 0.05 的连续前缀 = 秩 0,1,2 → cnt = 3 → pos_last = 2
  门：0.5 ≤ 1.0 ✓    pos_last > 0 ✓    存活 V − pos_last = 4 ≥ min_keep 0 ✓  → 触发
  剔除秩 [0, 2) = 秩 0 与秩 1（token 0、token 1）；保留秩 2（token 2，"最后一个达标者"）+ 尾部 3,4,5
  保留质量 = 0.179519 + 0.024295 + 0.008938 + 0.003288 = 0.216040
  filtered = [0.000000, 0.000000, 0.830953, 0.112457, 0.041371, 0.015219]
  CDF      = [0.000000, 0.000000, 0.830953, 0.943410, 0.984781, 1.000000]
  u = 0.4 → 首个 ≥ 0.4 的位置是 2
输出：chosen = 2，applied = True
      （注意被清零的是**概率最高的两个**头部候选，而尾部 token 5 依然留着 0.015219）
```

```
同一份 z，只换 min_keep：存活数 4 是硬约束
  min_keep = 3 → 4 ≥ 3 ✓        applied = True，chosen = 2
  min_keep = 4 → 4 ≥ 4 ✓（恰好通过）applied = True，chosen = 2
  min_keep = 5 → 4 ≥ 5 ✗        applied = False，filtered 就是原 softmax（一个都没被砍）
```

```
"至少两个头部达标"与极端退化两个边界
  只有一个头部过阈值：z = [9.0, -1.0, -2.0, -3.0]，π = 1.0，t = 0.5，min_keep = 0，u_gate = 0.1，u = 0.1
    p = [0.999932, 0.000045, 0.000017, 0.000006] → cnt = 1 → pos_last = 0 → 不动刀
    applied = False，filtered = p（XTC 从不会把 argmax 单独留下）
  全部候选都达标：z = [0.0, 0.0]（p = [0.5, 0.5]），t = 0.5，π = 1.0，min_keep = 0，u_gate = 0.0，u = 0.5
    cnt = 2 → pos_last = 1 → 剔除秩 0，存活 2 − 1 = 1 ≥ 0 → applied = True
    filtered = [0.000000, 1.000000]，CDF = [0.000000, 1.000000]，chosen = 1
    （argmax 被砍掉，且这一步变成确定性选择：任何 u ∈ [0,1) 都得 1）
```

```
批量：两行各自的门独立开合
  z = [[3.0, 2.5, 2.0, 0.0, -1.0, -2.0],
       [0.2, -0.1, 1.4, -2.0, 0.5, 0.1]]，π = 0.5，t = 0.05，min_keep = 0，
  u_gate = [0.2, 0.9]，u = [0.3, 0.7]
  行 0：0.2 ≤ 0.5 ✓ → 与上面同款剔除 → filtered[0] = [0.000000, 0.000000, 0.830953, 0.112457,
         0.041371, 0.015219]，CDF 首个 ≥ 0.3 在位置 2
  行 1：0.9 > 0.5 ✗ → 门不开，恒等变换 → filtered[1] = [0.134654, 0.099754, 0.447067, 0.014920,
         0.181764, 0.121840]，CDF = [0.134654, 0.234408, 0.681476, 0.696396, 0.878160, 1.000000]，
         首个 ≥ 0.7 在位置 4
输出：applied = [True, False]，chosen = [2, 4]
```

## 约束

- **纯 CPU、纯手写**。判题环境 `.venv-eval` 只有 `torch` / `numpy` / `transformers` 且**离线**：没有 llama.cpp、
  没有 HF 的 sampler / `LogitsProcessor` 类可借用，`sklearn`、`nltk` 也不存在——剔除与逆变换采样都得自己写。
- **所有随机性必须来自显式入参**：本题有**两处**独立入口——概率门 \(u_{\text{gate}}\)（决定这一步砍不砍）与
  采样抽签 \(u\)（决定活下来的谁）。两者都是 \([0,1)\) 上的均匀随机数，形状 `(...,)`（每行一个；单行时可传标量）。
  **不要**在实现里调用 `torch.rand` / `manual_seed`，也不能让 \(u_{\text{gate}}\) 与 \(u\) 复用同一个数。
- 形状与 dtype：输入 `logits` 为 `(..., V)` `float32`；输出 `filtered` 为 `(..., V)` `float32`、
  `chosen` 为 `(...,)` `int64`、`applied` 为 `(...,)` `bool`。
- 取值范围：\(\pi\in[0,1]\)（\(\le 0\) 关闭）；\(t>0\)，且 \(t>0.5\) 整体关闭；`min_keep` 为非负整数；
  \(u_{\text{gate}},u\in[0,1)\)。
- **恒成立的退化性质**：早退三条件任一命中、门不开、\(\text{pos\_last}\le 0\)、存活数不足——四种情形都给出
  `applied = False` 且 `filtered` 逐元素等于 \(\operatorname{softmax}(z)\)；触发时每行 `filtered` 之和仍为 \(1\)，
  被剔除位置**严格为 0**（不是接近 0）。
- 判题容差：`filtered` 用 `atol=1e-5, rtol=1e-5`；`chosen` 与 `applied` 要求**严格相等**。
- 与邻近题的分工（详见 `notes.md`）：`top-n-sigma-sampling` 用 \(\mu/\sigma\) **选留**统计上靠上侧的一带；
  `min-p-sampling` / `top-p-sampling` / `top-k-sampling` 都只**砍尾**，从不碰头部；本题是唯一一个把截断
  方向掉过来、专门**剔除高概率头部前缀**的采样器。
