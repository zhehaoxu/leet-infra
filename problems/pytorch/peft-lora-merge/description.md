# PEFT：LoRA 权重合并（merge_and_unload）

## 题目描述

LoRA 训练完，部署时通常把低秩旁路「折叠」回原权重，得到一个等价的稠密线性层——这就是 PEFT 库里的 `merge_and_unload()`：\(W' = W_0 + \frac{\alpha}{r} B A\)。合并后推理只剩一次矩阵乘、没有额外旁路开销，也可把这一层的 \(\Delta W\) 量化/蒸馏/换设备。

本题要求你实现这个合并：给定冻结权重与低秩因子，产出合并后的权重矩阵 \(W'\)。它与「LoRA 分步前向」逐元素等价（对同一输入 \(x\)，\(xW'^\top = xW_0^\top + \frac{\alpha}{r}(xA^\top)B^\top\)）。

## 规则

给定 `W0` \((d_\text{out}, d_\text{in})\)、`A` \((r, d_\text{in})\)、`B` \((d_\text{out}, r)\)、标量 `alpha`、`r`：

1. 缩放因子 \(s = \alpha / r\)。
2. 低秩更新 \(\Delta W = B A\)（形状 \((d_\text{out}, d_\text{in})\)）。
3. 合并权重 \(W' = W_0 + s\,\Delta W\)。

返回 `W'`（形状 \((d_\text{out}, d_\text{in})\)，与 `W0` 同形）。全程 float32，禁止调用现成 PEFT 库。

## 示例

沿用 LoRA 前向题的 \(W_0\)（3×5）、\(A\)（2×5）、\(B\)（3×2），\(\alpha=8.0\)、\(r=2\)（\(s=4.0\)）：

```
W' = [[ 0.780, -0.560,  0.100,  0.540,  0.040],
      [ 0.560,  0.280,  0.140,  0.000,  1.200],
      [-0.740,  0.780,  0.580, -0.280, -0.280]]
```

## 约束

- CPU float32；`W'` 与 `W0` 同形。
- 对任意输入 `x`，`x @ W'.T` 必须与 LoRA 分步前向逐元素一致。
- `alpha=0` 时 `W'` 恒等于 `W0`（未微调即恒等折叠）。
