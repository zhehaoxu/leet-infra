# 评测：语料级 BLEU

## 题目描述

BLEU（Papineni et al., ACL 2002）不看语义，只看**系统输出里的 n-gram 有多大比例能在人译参考里找到**，再乘一个惩罚「译得太短」的简洁惩罚。三个细节构成全部难度：n-gram 命中必须**按参考里的出现次数裁剪**（否则一句「the the the …」就能刷满 unigram 精度）、多阶精度取**几何平均**（任一阶为 0 总分即为 0）、以及 brevity penalty 的分母用的是**每条假设的最近参考长度**。为了让指标可复现，本题的输入已经是切好的 token id 序列，全程不碰任何分词器。

## 规则

- `hypotheses`：`list[list[int]]`，\(M\) 条候选译文，每条是一串 token id。
- `references`：`list[list[list[int]]]`，`references[i]` 是第 \(i\) 条假设的**参考集合**（至少 1 条，实践常用 1~4 条），与假设一一对应。
- `max_n`：精度阶数上界，计算 \(n = 1 \dots max\_n\)（默认 4）。
- `smoothing`：布尔开关，是否做加一平滑（见下）。

逐阶 \(n\) 的语料级统计：

1. **分母**：对每条假设枚举所有**连续** \(n\) 个 id 组成的 n-gram（重复要各算一次），条数 \(\max(0, |h|-n+1)\) 累加成 \(C_n=\sum_i \max(0,|h_i|-n+1)\)。
2. **分子（裁剪匹配）**：对每条假设里的每个不同 n-gram \(g\)，
   \[ \text{clip}(g)=\min\big(\text{count}_{h}(g),\ \max_{j}\text{count}_{r_j}(g)\big) \]
   其中 \(\max_j\) 是**在同一条假设的多条参考之间**取最大出现次数（不是跨语料取最大）；累加得 \(M_n\)。
3. \(p_n = M_n / C_n\)。若 \(C_n = 0\)（语料里根本不存在该阶 n-gram，例如所有假设长度都小于 \(n\)），规定 \(p_n = 0\)。
4. **平滑**：`smoothing` 为真时改用 Laplace 加一 \(p_n = (M_n + 1)/(C_n + 1)\)；但 \(C_n = 0\) 的阶仍记 \(0\)——"没有该阶 n-gram"和"该阶精度为 0"是两回事，加一救不回来。返回的精度就是**平滑后**真正进入几何平均的那组值。
5. **简洁惩罚**：令 \(c = \sum_i |h_i|\)，\(r = \sum_i \text{closest}_i\)，其中 \(\text{closest}_i\) 是与 \(|h_i|\) 差值最小的参考长度、**并列时取更短的那条**。
   \[ \text{BP} = \begin{cases} 1, & c \ge r \\ e^{\,1 - r/c}, & c < r \end{cases} \]
   \(c = 0\) 时 BP 无从定义，直接令 BLEU \(=0\)。
6. **几何平均**：\(\text{BLEU} = \text{BP}\cdot\exp\big(\frac{1}{max\_n}\sum_{n=1}^{max\_n}\ln p_n\big)\)；任一 \(p_n = 0\) 则 BLEU \(=0\)（等价于各阶等权的 \(1/max\_n\) 次幂连开）。

返回值：二元组 `(bleu, precisions)`。`bleu` 是 Python float；`precisions` 是 float32 张量，形状 \((max\_n,)\)，按 \(p_1 \dots p_{max_n}\) 排列。禁止使用 `nltk` / `sacrebleu` / `torchtext` 等现成实现（判题环境里也不存在）。

## 示例

```
hypotheses = [[1,2,3,4,5,6],          references = [[[1,2,3,4,5,6], [1,2,3,4,7,6]],
             [2,3,4,8]]                                          [[1,2,3,4,5]]]

n = 1:  C = 6 + 4 = 10,  M = 6 + 3 = 9    -> p1 = 0.9      (id 8 在参考里没有)
n = 2:  C = 5 + 3 = 8,   M = 5 + 2 = 7    -> p2 = 0.875    (bigram (4,8) 落空)
n = 3:  C = 4 + 2 = 6,   M = 4 + 1 = 5    -> p3 = 0.8333333
n = 4:  C = 3 + 1 = 4,   M = 3 + 0 = 3    -> p4 = 0.75     (4-gram (2,3,4,8) 落空)

c = 6 + 4 = 10
r = 6 + 5 = 11    （假设0 长 6，两条参考都长 6；假设1 长 4，最近参考长 5）
c < r -> BP = exp(1 - 11/10) = 0.9048374

bleu = 0.9048374 * (0.9 * 0.875 * 0.8333333 * 0.75)^(1/4) = 0.7578848
precisions = [0.9, 0.875, 0.8333333, 0.75]

同一语料 smoothing=True 时：
precisions = [0.9090909, 0.8888889, 0.8571429, 0.8],  bleu = 0.7806746
```

## 约束

- CPU；token id 是非负整数，取值范围任意（本题只比相等，不做任何词表映射）。
- 假设或参考都可以是**空列表**（长度 0）；`references[i]` 保证非空。
- **退化性质**：所有假设与各自参考逐条相同 \(\Rightarrow\) 各阶 \(p_n = 1\)、\(c=r\)、\(\text{BLEU}=1\)；某阶 \(C_n=0\) \(\Rightarrow\) \(p_n=0\)、未平滑 BLEU \(=0\)；把参考复制一份 \(\Rightarrow\) 结果不变（裁剪用 max、最近长度用距离最小）；\(c > r\) \(\Rightarrow\) BP 饱和为 1，"译得比参考长"得不到奖励。
- \(0 \le \text{BLEU} \le 1\)。
