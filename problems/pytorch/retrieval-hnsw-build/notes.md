# 详解：检索：HNSW 建图插入与邻居选择

## 出处

- Malkov & Yashunin, *Efficient and robust approximate nearest neighbor search using Hierarchical Navigable Small World graphs*, arXiv:1603.09320（TPAMI 2018）。Algorithm 1 是插入（INSERT），Algorithm 2 是 SEARCH-LAYER，Algorithm 3 是简单选邻居，Algorithm 4 是启发式选邻居。
- Faiss 的 `IndexHNSW`、hnswlib 都实现了这套结构；但不同实现对「邻居表溢出后如何收缩」有差异（论文 Algorithm 1 用启发式重选，本题按题面简化为删除最远者，规则以 starter 为准）。
- 论文用随机 level 采样 \(l=\lfloor-\ln(U)\cdot m_L\rfloor\)；本题改用显式 `levels` 入参，去掉随机性，才能逐边对拍。

## 完整推导与下标约定

**层模型**。节点 \(i\) 存在于第 \(0\) 到第 `levels[i]` 层，第 0 层包含所有节点。输出层数
\[
L=\max_i \text{levels}[i]+1.
\]
注意插入过程中当前最高层 `max_level` 必须初始化为 `levels[0]`，而不是全局的 \(\max_i\text{levels}[i]\)：节点 0 只存在于它自己的层级以下。若错误地把 `max_level` 初始化成全局最大值，节点 0 会被误认为存在于更高层，后续高点插入时会从 0 出发在这些层搜到它并连出伪边。这个坑在实现原型时实际踩过：示例中节点 4（层级 2）会在层 2 错误地连到 0，而正确结果层 2 只有 4 自己。

**插入流程**（Algorithm 1 的确定性版本）：

1. \(q\) 的层级 \(l=\text{levels}[q]\)，`ep=entry`。
2. 对 `lc` 从 `max_level` 递减到 \(l+1\)：`SEARCH-LAYER(q, ep, ef=1, lc)`，把 `ep` 换成结果中离 \(q\) 最近者。这是上层贪心下降：每层只保留一个最优点。
3. 对 `lc` 从 \(\min(\text{max\_level},l)\) 递减到 0：
   - `W = SEARCH-LAYER(q, ep, ef_construction, lc)`；
   - `R = SELECT-NEIGHBORS-HEURISTIC(q, W, M, lc)`；
   - 对 \(R\) 中每个 \(e\) 加双向边；
   - 对每个 \(e\) 做溢出收缩（见下）；
   - `ep = W` 中离 \(q\) 最近者，供下一层。
4. 若 \(l>\text{max\_level}\)，更新 `entry=q`、`max_level=l`。

第 1 层及以上出度上限是 \(M\)，第 0 层是 \(M_0=2M\)：底层承载精细近邻，需要更大的度数。

**SEARCH-LAYER 的定序与终止**。候选集 \(C\) 是「待扩展」的小顶堆，结果集 \(W\) 是「目前找到的 ef 个最近点」的大顶堆。每步取 \(C\) 中 (距离, 节点号) 最小者 \(c\)，若
\[
\text{dist}(c,q) > \max_{w\in W}\text{dist}(w,q)
\]
则停止；注意是严格大于，距离相等时仍继续扩展，这样并列点的探索不受堆弹出顺序影响。扩展 \(c\) 的邻居时按节点号升序遍历；未访问者标记访问，若 \(|W|<\text{ef}\) 或 \((d(e,q),e)\) 字典序优于 \(W\) 的最差 (距离, 节点号)，就同时压入 \(C\) 与 \(W\)，并在 \(|W|>\text{ef}\) 时弹出最差者。用 (距离, 节点号) 作为全序键，保证重复点、全零距离时也有唯一结果。

**Algorithm 4 为什么这样剪枝**。候选按到 \(q\) 的距离升序。已选集合 \(R\) 中的点彼此「分散」；若候选 \(c\) 到某个已选 \(r\) 的距离严格小于 \(c\) 到 \(q\) 的距离，说明 \(c\) 落在 \(r\) 的覆盖范围内：从 \(q\) 出发经 \(r\) 已经能到达 \(c\) 附近，直接连 \(c\) 对导航的边际收益低，于是剪掉。条件用严格 `<`：若 \(d(c,r)=d(c,q)\)，不剪，保留并列候选。选满 \(M\) 个立即停止；候选不足则全选。`ef_construction < M` 时 \(W\) 本身就不超过 `ef_construction` 个，所以新点最多只有这么多个邻居，不补足。

**双向连边与溢出替换**。对每个选中的 \(e\)，在 \(q\) 与 \(e\) 的该层邻居表里互加一次；加入前检查，避免自环与重复边。随后检查 \(e\) 的出度：若超过 `cap`（第 0 层 \(2M\)，否则 \(M\)），反复删除「到 \(e\) 的平方距离最大」的邻居，距离并列删节点号大者。刚加入的 \(q\) 也参与竞争，可能立刻被删；此时 \(q\) 的列表里仍有 \(e\)，但 \(e\) 的列表里没有 \(q\)，最终图**允许不对称**。这是本题与「维持严格无向图」的直觉最不一样的地方。

**入口更新**。只有 \(l>\text{max\_level}\) 才更新入口；\(l\le\text{max\_level}\) 时旧入口保留。新点在高于旧 `max_level` 的层上是孤立的：那些层此前没有节点，之后也可能只有它自己，所以邻居表为空。示例中节点 4 的层级 2 就是这种情况。

**输出下标**。`out[lc][i]` 是节点 \(i\) 在第 `lc` 层的邻居，内层按节点号升序；节点 \(i\) 在 `lc > levels[i]` 的层不存在，必须是空列表。外层长度固定为全局 \(L\)，不是插入过程中的 `max_level+1`。

## 核心与易错点

1. **`max_level` 初值是 `levels[0]`，不是 `max(levels)`**：否则节点 0 会被误认为存在于更高层，高点插入时连出伪边（示例中会在层 2 多出 0-4）。
2. **下降层与搜索层不同**：高于 \(l\) 的层只用 \(ef=1\) 的贪心；从 \(\min(\text{max\_level},l)\) 到 0 才用 `ef_construction`。把两者混用会改变候选集。
3. **SEARCH-LAYER 的停止是严格 `>`**：候选距离等于当前最差距离时仍继续扩展；用 `>=` 会提前停，可能漏掉并列点里节点号更小的那个。
4. **Algorithm 4 的剪枝是严格 `<`**：`d(c,r) < d(c,q)` 才剪；相等时保留。方向写反（用 `d(c,q) < d(c,r)`）会几乎剪光候选。
5. **溢出删「最远」而不是「最后加入的」**：距离并列删节点号大者；刚加入的 \(q\) 也可能被删，故最终图允许不对称。不要强行把边补回成双向。
6. **出度上限分层**：第 0 层 \(2M\)，其余 \(M\)；每层分别检查，不能统一用 \(M\)。
7. **入口只在 \(l>\text{max\_level}\) 时更新**：`l==max_level` 不换入口；新点在更高层是孤立的，输出空列表。
8. **输出内层必须升序且去重**：判题对嵌套 list 精确比较；邻居加入顺序（距离序）不是输出顺序。
9. **`ef_construction < M` 不补足**：新点该层邻居数受候选池限制；不要为了凑满 \(M\) 去选被剪掉的候选。
10. **重复点/全零距离**：所有键都带节点号，按 (0, id) 排序；溢出时删节点号最大者。测试专门跑了全重合点并连跑两次验证确定性。

## 与邻近题的区别

- **vs `retrieval-hnsw-greedy`**：那题是**查询侧**：给定一张已经建好的单层图（邻居表还是 `-1` 填充的定长张量），从入口做 \(ef=1\) 的贪心，返回停下的节点。本题是**建图 / 插入侧**：多层、逐点插入、`ef_construction` 候选队列、Algorithm 4 选邻居、双向连边与出度溢出替换，输出每层邻接表。两者共享「贪心下降」这一子过程，但本题的层间下降只是插入流程的一小段，主体是选邻居与维护图。
- **vs `retrieval-ivf-assign`**：那题是一次性把向量分到最近的粗中心，没有图、没有层级、没有邻居。
- **vs `retrieval-pq-codes`**：那题在固定分段码本上做逐段编码，不建图。
- **vs `retrieval-kmeans-lloyd`**：那题迭代质心、处理空簇；本题不更新任何中心，只维护邻接表。
- **vs 论文原版 HNSW**：本题用显式 `levels` 替代随机层级，并把溢出收缩简化为「删最远邻居」；其余（SEARCH-LAYER 的 ef、Algorithm 4、双向边、入口更新）与论文一致。

## 对拍口径与复杂度

- **主 oracle**：`_oracle_hnsw` 用纯 Python 列表，每步 `sort` 取最小/最差（不用堆），距离用双重循环显式累加；参考解用 `heapq` 小顶/大顶堆 + 预计算距离矩阵。两者结构不同，输出做嵌套 list 的精确相等比较。
- **覆盖**：示例（多层、溢出、不对称边）、单点图（层级 2，三层全空）、层级结构（节点只出现在 \(0..levels[i]\)）、出度上限与溢出替换（全重合点、\(M=1\) 时 0 的度从 2 涨到 3 再删）、重复点连跑两次验证确定性、`ef_construction < M`、多组 1-D/2-D/float64 oracle 对拍、非法输入。
- **复杂度**：预计算距离矩阵 \(O(N^2D)\)、内存 \(O(N^2)\)。每次插入最多经过 \(L\) 层；每层 SEARCH-LAYER 为 \(O(\text{ef}\cdot(\bar d+\log\text{ef}))\)（\(\bar d\) 为该层平均度），Algorithm 4 为 \(O(\text{ef}\log\text{ef}+M\cdot\text{ef})\)，溢出收缩最坏 \(O(M\log M)\)。总计约 \(O(N\cdot L\cdot \text{ef}\cdot M + N^2D)\)；判题规模很小，正确性优先。
