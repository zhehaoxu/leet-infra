# 检索：HNSW 建图插入与邻居选择

## 题目描述

HNSW（Hierarchical Navigable Small World，Malkov & Yashunin, arXiv:1603.09320）用多层可导航图组织向量：上层稀疏、负责快速跳到目标区域，下层稠密、负责精细近邻。建图时按插入序逐点加入，每个新点从入口点出发，在高于自己层级的层做贪心下降，到了自己的层级再用 `ef_construction` 宽度的候选队列搜一批近邻，最后用论文 Algorithm 4 的启发式从候选中挑出邻居并双向连边。插入完成后，每个节点的邻居表就是后续查询（`retrieval-hnsw-greedy` 那类单层贪心）所走的图。

本题只做**建图 / 插入侧**，并且把通常由随机数决定的层级改成**显式入参**：每个点的最高层由 `levels` 数组给出，`M`、`M0=2M`、`ef_construction` 也都由调用方指定。于是整个过程完全确定，可以逐边核对。难点在于：层间下降与层内候选搜索的边界、候选与结果的定序、Algorithm 4 的剪枝条件、双向连边后的出度溢出替换，以及重复点/距离并列时的确定性。

CPU、全程确定性、不调用随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。下面只复述语义。

- **输入**：点集 \((N,D)\)（float32 或 float64，\(N\ge1\)、\(D\ge1\)）；`levels` 是长度 \(N\) 的 int64 一维数组，`levels[i] >= 0`，表示节点 \(i\) 存在于第 \(0\) 到第 `levels[i]` 层（第 0 层最底）；`M >= 1` 是第 1 层及以上的出度上限，第 0 层上限为 \(M_0=2M\)；`ef_construction >= 1` 是候选搜索宽度。所有距离用平方欧氏距离。
- **插入序与入口**：节点按 \(0,1,\dots,N-1\) 插入。节点 0 先成为入口 `entry`，当前最高层 `max_level = levels[0]`；节点 0 在所有层的邻居表初始为空。
- **层间下降**：插入节点 \(q\)（\(l=\text{levels}[q]\)）时，令 `ep=entry`，对 `lc` 从 `max_level` 递减到 \(l+1\)，在 `lc` 层做宽度 \(ef=1\) 的候选搜索，把 `ep` 更新为结果中离 \(q\) 最近的点（距离并列取节点号小者）。
- **层内搜索与选邻居**：对 `lc` 从 \(\min(\text{max\_level},l)\) 递减到 0：以 `ep` 为起点、宽度 `ef_construction` 做候选搜索得到 \(W\)；对 \(W\) 做 Algorithm 4 启发式——候选按 (到 \(q\) 的平方距离, 节点号) 升序，依次考察，若候选 \(c\) 到已选集合 \(R\) 中任一节点 \(r\) 的平方距离**严格小于** \(c\) 到 \(q\) 的平方距离，则剪掉 \(c\)，否则选入 \(R\)，选满 \(M\) 个即停。随后对 \(R\) 中每个 \(e\) 加双向边 \(q\leftrightarrow e\)（禁止自环与重复边），并把 `ep` 更新为 \(W\) 中离 \(q\) 最近者，供下一层使用。
- **候选搜索的定序**：已访问集合从 `{ep}` 开始；候选集按 (距离, 节点号) 取最小，结果集 \(W\) 保留至多 `ef_construction` 个按 (距离, 节点号) 最优的节点。每步弹出候选集最优者 \(c\)，若 \(\text{dist}(c,q)\) **严格大于** \(W\) 中当前最差距离则停止（相等仍继续扩展）；否则按节点号升序遍历 \(c\) 在该层的邻居，未访问者标记访问，若 \(|W|<\text{ef}\) 或 \((\text{dist}(e,q),e)\) 优于 \(W\) 的最差 (距离, 节点号)，则加入候选集与 \(W\)，并在 \(|W|>\text{ef}\) 时弹出最差者。
- **出度溢出替换**：对 \(R\) 中每个 \(e\)，若其出度超过 `cap`（`lc=0` 时 \(2M\)，否则 \(M\)），反复删除「到 \(e\) 的平方距离最大」的邻居，距离并列删节点号大者，直到不超限。刚加入的 \(q\) 与其他邻居平等竞争，可能被删掉；因此最终图**允许不对称**（\(q\) 的列表里有 \(e\)，而 \(e\) 的列表里已经没有 \(q\)）。
- **入口更新**：只有 \(l>\text{max\_level}\) 时才把 `entry` 改为 \(q\)、`max_level` 改为 \(l\)；\(l\le\text{max\_level}\) 时入口不变。新点在高于旧 `max_level` 的层上是孤立的（那些层只有它自己），邻居表为空。
- **输出**：三层嵌套 list，`out[lc][i]` 是节点 \(i\) 在第 `lc` 层的邻居节点号。外层长度恰为 \(L=\max(\text{levels})+1\)，中层长度恰为 \(N\)，内层按节点号升序、无重复、无自环；第 0 层每个列表长度 \(\le 2M\)，其余层 \(\le M\)。节点 \(i\) 在 `lc > levels[i]` 的层不存在，对应列表为空。
- **并列与退化**：所有排序、argmin、最差者与溢出删除都以 (平方距离, 节点号) 为键，节点号小者优先；重复点、距离全为 0 也按此规则确定。`ef_construction < M` 时新点在该层最多只有 `ef_construction` 个邻居，不补足。`N=1` 合法，返回 \(L\) 层、每层一个空列表。
- **错误**：`points` 不是二维、dtype 不是 float32/float64、`N=0`、`D=0`；`levels` 不是 int64 一维、长度不等于 \(N\)、含负值；`M` 或 `ef_construction` 不是正整数（bool 也不接受）——一律抛 `ValueError`。

## 示例

五个一维点、显式层级、`M=1`（故 \(M_0=2\)）、`ef_construction=2`：

```
points = [[0.0], [0.1], [0.05], [0.02], [4.0]]
levels = [1, 0, 0, 0, 2]
M = 1, ef_construction = 2
```

插入过程（距离均为平方欧氏）：

| 插入 | 层级 | 关键动作 | 层 0 的邻接变化 |
|---|---|---|---|
| 0 | 1 | 成为 entry，max_level=1 | 空 |
| 1 | 0 | 从 0 搜索，选 0 | 0-1 |
| 2 | 0 | 到 0 与 1 的距离都是 0.0025，并列取小下标 0 | 0-2；0 的出度到 2，未超 \(M_0=2\) |
| 3 | 0 | 选 0；0 的出度变成 3，删掉距 0 最远的邻居 1（0-1 距 0.01，0-2 距 0.0025，0-3 距 0.0004） | 0 的列表变成 [2,3]；1→0 的反向边仍在 |
| 4 | 2 | 层 1 连 0；层 0 以 ef=2 搜索，\(W=\{2,3\}\)（0 距 16 被挤出），启发式选 2（3 到 2 距 0.0009，小于 3 到 4 的 15.8404，被剪）；随后 entry=4、max_level=2，层 2 只有 4 | 2-4；层 2 为空 |

最终输出（层 0、1、2）：

```
layer 0: [[2, 3], [0], [0, 4], [0], [2]]
layer 1: [[4], [], [], [], [0]]
layer 2: [[], [], [], [], []]
```

检查两个容易忽略的点：节点 1 的列表仍是 `[0]`，但节点 0 的列表里已经没有 1——溢出替换让边变成单向；节点 4 是最后插入的，却因为层级 2 成为新的入口，层 2 上只有它自己，所以为空。

## 约束

- 返回三层嵌套的 Python `list`（不是张量）：外层 \(L=\max(\text{levels})+1\)，中层 \(N\)，内层是升序、无重复、无自环的节点号。
- 出度上限：第 0 层 \(\le 2M\)，第 1 层及以上 \(\le M\)；节点只出现在 \(0..\text{levels}[i]\) 层，更高层必须为空列表。
- 判题对嵌套列表做精确相等比较；不允许用「先排序再比较边集」之外的方式改变邻居顺序——输出必须升序。
- 不使用随机数；重复点、并列距离必须按 (距离, 节点号) 的确定性规则处理。
- CPU；规模由判题用例控制，实现可以用堆、排序列表或暴力扫描，但语义必须与上述定序一致。
