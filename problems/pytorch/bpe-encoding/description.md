# 分词：用 BPE 规则编码文本

## 题目描述

给定已经学好的 BPE 合并规则（`bpe-training` 的产物），把一个词切成子词。这正是推理时把原始文本变成 token 序列的第一步。核心规则：**每次都应用「优先级最高（学习次序最靠前）」的那个当前可用合并对**，直到没有可用对为止。

## 算法（务必按此实现）

输入一个词 `word`（小写字母串）与有序合并规则 `merges`（`[(a, b), ...]`，索引即优先级 rank，越小越先应用）：

1. 拆字符并在末尾追加 `</w>`：`"newer"` → `["n","e","w","e","r","</w>"]`。
2. 记 `rank[(a,b)] = 该对在 merges 中的下标`。
3. 重复：在当前符号序列的所有相邻二元组里，挑出**出现在 `merges` 中**的那些，取 **rank 最小**（最靠前）的一对；把词内所有**从左到右、不重叠**的该对替换成拼接符号 `a+b`。
4. 当没有任何相邻二元组命中 `merges` 时停止，返回当前符号序列（即子词列表）。

> 注意是「每一轮重新取全局 rank 最小的可用对」，而不是按 merges 顺序从头扫一遍——因为早先的合并会创造出新的可合并对。

## 规则

实现 `solve(word, merges)`，返回子词列表 `list[str]`（含末尾 `</w>`）。

## 示例

用 `merges = [('e','r'), ('er','</w>'), ('l','o'), ('lo','w'), ('e','w'), ('ew','er</w>'), ('n','ewer</w>'), ('low','</w>')]`：

```
"newer" → ["newer</w>"]
"lowest"→ ["low", "e", "s", "t", "</w>"]
"wider" → ["w", "i", "d", "er</w>"]
"low"   → ["low</w>"]
```

`"lowest"` 里 `l o w` 被合成 `low`，但剩下的 `e s t` 无法再合成（`('e','s')`、`('s','t')` 不在 merges 中），故停在 5 段。

## 约束

- `word` 只含小写字母；`merges` 可为空列表（此时原样返回字符 + `</w>`）
- 纯字符串/字典运算、无随机；替换须**不重叠、从左到右**
- 与 `bpe-training` 呼应：训练产出 merges、编码消费同一 merges
