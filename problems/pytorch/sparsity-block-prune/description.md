# 稀疏化：块结构剪枝（按块范数）

## 题目描述

非结构化剪枝打散的零很难被硬件利用，**块稀疏（block / structured pruning）** 以规整的小块为单位整体丢弃：把矩阵沿最后一维切成若干宽度为 `block` 的连续块，用整块的**幅值和（L1 范数）**衡量重要性，优先剪掉最不重要的整块，从而保留可被向量化/分块 GEMM 加速的稠密子结构。

给定形状 \((R,C)\) 的 `weight`、稀疏率 `sparsity`、块宽 `block`（\(C\) 可被 `block` 整除）。每行按宽度 `block` 切块，共 \(B=R\cdot (C/\text{block})\) 个块。计算每个块的 L1 范数 \(\sum |w|\)，剪掉范数最小的 \(\mathrm{round}(\text{sparsity}\cdot B)\) 个整块（块内元素全部置零），其余块原样保留。

## 规则

输入 `weight`（float32 2-D）、标量 `sparsity`、整数 `block`。返回同形状 float32：被选中剪除的整块置 0，未剪块逐元素保留。块的重要性＝块内 \(|w|\) 之和；并列时按（行号，块号）展平索引升序先剪。禁止现成剪枝库。

## 示例

`weight=[[1,-5,3,-2],[0.5,9,-2,-8]]`、`sparsity=0.5`、`block=2`：

```
块 L1：行0块0=|1|+|-5|=6, 行0块1=|3|+|-2|=5
       行1块0=|0.5|+|9|=9.5, 行1块1=|-2|+|-8|=10
B=4, 剪 round(0.5*4)=2 个最小块 → 块(行0,块1)norm5 与 (行0,块0)norm6
out = [[0,0,0,0],[0.5,9,-2,-8]]
```

## 约束

- CPU float32；\(C \bmod \text{block}=0\)；剪除单位是整块（块内要么全留要么全零）。
- 与逐元素/逐行题不同：这里比较的是块聚合范数，跨所有块全局竞争稀疏预算。
- 被剪块覆盖的位置严格为 0，未剪块不动。
