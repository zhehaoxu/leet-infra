# unfold 与膨胀采样详解

## unfold 的真实语义（本关根本坑）

`Tensor.unfold(dim, size, step)` 的第三个参数是**窗口滑动步长 stride**，**不是膨胀 dilation**！它把 `dim` 轴切成一段段长 `size`、每次滑 `step` 的窗口，新增一维列出各窗口。

> 常见误解：`unfold(2, kH, dilation)` 以为能「按间隙取点」。实际得到的是**连续窗口**（步长=dilation 的滑动），当 `dilation>1` 时窗口之间反而错位、且窗口跨度仍是 `kH`，采不到「核元素间插零」的效果。

## 膨胀卷积感受野的正确做法

膨胀 $d$ 的卷积核等效把感受野**撑大**到跨度 $(k-1)d+1$ 的窗口，再在窗口内每隔 $d$ 取一个点。两步实现：

```
u = x.unfold(2, (kH-1)*d + 1, 1).unfold(3, (kW-1)*d + 1, 1)  # 连续大窗口，跨度=膨胀感受野
out = u[..., ::d, ::d]                                        # 窗口内每隔 d 抽样 -> 真膨胀
```

`step=1` 保证每个位置都起窗，再用 `[..., ::d, ::d]` 在两个 kernel 轴上做**间隙抽样**，得到 $(B,C,oh,ow,kH,kW)$ 且每个 kernel 维按 $d$ 间隔取原始像素——这才是 dilated 的感受野展开。

## 尺寸

大窗口跨度 $(k-1)d+1$，输出位数 $oh=H-(k-1)d-1+1$；按题给约定对齐 torch 参考（对拍用手工参考，别直接 `unfold(...,dilation)`）。

## 关联

与「im2col」同源（都是把感受野展开成 kernel 维），差别仅在膨胀多一步间隙抽样；理解 unfold 的 step 语义后，滑窗、膨胀、im2col 一次贯通。
