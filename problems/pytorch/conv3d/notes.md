# conv3d 详解

## 从 conv2d 到 conv3d：多一个滑动维

conv3d 把核沿 $(D,H,W)$ 三维滑动，权重形状 $(C_{out}, C_{in}, k_D, k_H, k_W)$，
计算量比 conv2d 多一个核维 $k_D$，是显存/算力大户。输出各维长度同样是 floor 公式
$L_{out}=\lfloor (L+2p-k)/s\rfloor+1$。

## 两种手写写法

1. **gather（逐输出点）**：对每个输出位置，切出窗口再乘核求和——三重/五重循环，直观但慢。
2. **scatter（逐核偏移）**：本参考答案采用。外层循环核内偏移 $(di,hi,wi)$，把标量
   `w[o,ci,di,hi,wi]` 乘到输入的一个**跨步切片** `xp[:,ci, di::s, hi::s, wi::s]`
   上并累加到 `out[:,o]`。这样把「窗口内的 $k^3$ 次乘加」转成「$k^3$ 次整片向量化累加」，
   避免了最内层对每个输出像素的 Python 循环，是教学中兼顾可读与性能的折中。

切片起止：`di : di+od*stride : stride`，保证切出恰好 `od` 个元素，形状与 `out[:,o]` 对齐。

## 常见坑

- **F.pad 参数顺序**：对 5D 张量，pad 元组是 `(W左,W右,H上,H下,D前,D后)`，即**从最后一维往前**。
  六元组全填 `padding` 即三维各向同性补零。
- **bias 广播**：`view(1,-1,1,1,1)` 对齐 `(N,Cout,D,H,W)`。
- **维度顺序**：是 `(Cout, Cin, kD, kH, kW)`，别把 Cin/Cout 弄反。

## 应用

医学体素分割（V-Net、3D U-Net）、视频动作识别（C3D、SlowFast 用 3D 核抽时空特征）、
点云/占用网格。3D 卷积贵，工程上常用 (2+1)D 分解：先用 $(1,k_H,k_W)$ 空间核再用 $(k_D,1,1)$
时间核，把 $k_D k_H k_W$ 的算力拆开，是 conv3d 的高效近似。
