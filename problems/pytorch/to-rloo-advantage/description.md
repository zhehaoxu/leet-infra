# RLOO：留一基线优势

## 题目描述

**RLOO**（REINFORCE Leave-One-Out，Ahmadian et al. 2024, *Back to Basics: Revisiting REINFORCE-Style Optimization for Learning from Human Feedback in LLMs*, arXiv:2402.14740, ACL 2024）是对 RLHF 里 PPO 那套「演员 + 评论家」的简化：既然每个 prompt 都要采样多条回答，**用同组其它回答的平均奖励当基线**就够了，不需要再训一个价值网络。

对第 $b$ 个 prompt 的第 $i$ 条回答：

$$A_{b,i}=r_{b,i}-\frac{1}{G-1}\sum_{j\ne i}r_{b,j},$$

其中 $G\ge2$ 是组大小。这个基线有两个关键性质：

- **无偏**：基线 $\frac{1}{G-1}\sum_{j\ne i}r_{b,j}$ 不依赖第 $i$ 条回答的采样，因此它与 $\nabla_\theta\log\pi_\theta(y_i)$ 相乘后期望为 0，不给策略梯度引入偏差；
- **留一**：分母是 $G-1$ 而不是 $G$、求和也排除了自身。若用含自身的组均值，$A_{b,i}$ 会与 $r_{b,i}$ 负相关，把优势系统性压小（$G$ 越小组内耦合越强）。

本题只做这一步优势计算，输入是一批标量奖励。

## 规则

给定奖励矩阵 $(B,G)$，$B\ge1$、$G\ge2$，元素为有限浮点：

1. 对每个 $(b,i)$，先求**同组其余** $G-1$ 个奖励的均值：$\big(\sum_j r_{b,j}-r_{b,i}\big)/(G-1)$。
2. 优势 $A_{b,i}=r_{b,i}-$ 上述均值。
3. 返回 $(B,G)$ 的 **float64** 张量，形状与入参一致。

由此立刻得到 $\sum_i A_{b,i}=0$：组内优势恒为零和。

## 示例

```
rewards = [[1.0, 0.0, 0.5],
           [2.0, 2.0, 0.0]]      G = 3

第 0 组：A = [1 - (0+0.5)/2, 0 - (1+0.5)/2, 0.5 - (1+0)/2]
           = [0.75, -0.75, 0.0]
第 1 组：A = [2 - (2+0)/2, 2 - (2+0)/2, 0 - (2+2)/2]
           = [1.0, 1.0, -2.0]
```

两组优势各自求和都是 0。若把分母误写成 $G$，第 0 组会得到 $[0.5,-0.5,0]$、第 1 组得到 $[0.667,0.667,-1.333]$，量级整体缩小且与正确值不成比例。

当 $G=2$ 时留一均值就是另一条回答本身，优势退化为原始差：$r=[1,0]\Rightarrow A=[1,-1]$。

## 约束

- 返回 $(B,G)$ float64；float32 输入内部升到 float64。
- 逐组零和：$\sum_i A_{b,i}=0$（浮点意义下到 $10^{-12}$）。
- 组内奖励全相同则优势全 0；$G=2$ 时 $A$ 是原始差值。
- 非法输入抛 `ValueError`：非张量 / 非二维 / 非浮点 / 含 NaN·Inf / $B<1$ / $G<2$。$G=1$ 时留一基线无定义，不允许退化成 0。
- CPU、确定性、不调用随机数。
