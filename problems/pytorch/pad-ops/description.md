# Padding 算子（常量补边）

## 题目描述

在张量边界填充元素。`torch`/`F.pad` 的 `padding` 是一个**从最后一个维开始、成对(左,右)**给出的序列，顺序与直觉相反，是最常见的踩坑点。

$$ \text{padding} = (\ell_{-1}, r_{-1}, \ell_{-2}, r_{-2}, \dots) $$

即**最后两个元素**补最后一维、再往前两个补倒数第二维，依此类推。本关只实现 `constant` 模式（新位置填 `value`）。

## 规则

- 实现 `solve(x, padding, mode="constant", value=0.0)`。
- `padding` 长度必须是偶数，元素按上面的"末维优先、(左,右)"顺序解释；每个维度新长度 = 原长 + 左 + 右。
- 仅支持 `mode="constant"`，其余 `mode` 应报错拒绝。
- 与 `F.pad(x, padding, mode="constant", value=value)` 一致。

## 示例

```
输入：x=[[1,2],[3,4]], padding=(1,1,1,1)   # 末维W左右各1、次末维H上下各1
输出：[[0,0,0,0],
      [0,1,2,0],
      [0,3,4,0],
      [0,0,0,0]]

输入：x=[[1,2],[3,4]], padding=(1,0)        # 只补最后一维左侧1列
输出：[[0,1,2],
      [0,3,4]]
```

## 约束

- float32/float64 输入；`padding` 各元素 $\ge 0$
