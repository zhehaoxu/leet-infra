# Causal 滑动窗口加权平均

实现一个只"看过去"的滑动窗口加权平均（等价于深度为 1 的因果 1D 卷积）。这是 Temporal Convolution / WaveNet 一类模型的核心原语。

## 计算定义

$$
\text{out}[b, t] = \frac{\sum_{i=0}^{W-1} \text{kernel}[i] \cdot x[b, t - i]}{\sum_{i=0}^{W-1} \text{kernel}[i]}
$$

其中 $t - i < 0$ 的越界项按 $0$ 处理（左侧零填充），因此输出长度与输入相同。

## 规则

1. 输出形状 `(B, L)`，与输入相同；dtype 与 `x` 一致。
2. **严格因果**：`out[b, t]` 只允许依赖 `x[b, 0..t]`，任何未来位置都不能影响当前输出。
3. 左侧不足窗口时用 0 填充（分母仍然是 kernel 全和，不重新归一化）。
4. 若 `kernel.sum() == 0`，抛出 `ValueError`。
5. 不允许使用 `F.conv1d` / `torch.nn.Conv1d`（评测有专门用例检查因果性）。

## 示例

```python
x = torch.tensor([[1.0, 2.0, 3.0, 4.0]])
kernel = torch.tensor([0.5, 0.5])   # 当前 + 上一时刻
solve(x, kernel)
# out[0] = (0.5*1)     / 1.0 = 0.5     （t=0 越界项补 0）
# out[1] = (0.5*2+0.5*1)/ 1.0 = 1.5
# out[2] = (0.5*3+0.5*2)/ 1.0 = 2.5
# out[3] = (0.5*4+0.5*3)/ 1.0 = 3.5
# tensor([[0.5, 1.5, 2.5, 3.5]])
```

## 提示

- 一种优雅做法：`x.pad` 左侧补 `W-1` 个 0，再用 `unfold(1, L+W-1? …)`——注意 `unfold` 窗口尺寸应为 `W`
- 也可以构造翻转后的 kernel 与每个位置做点积：`(padded.unfold(1, W, 1) * kernel).sum(-1)`
- `unfold` 后第 `t` 个窗口是 `[t, t+W)`，注意它与 `kernel[0]` 对齐当前时刻的方向问题

## 约束

- `1 <= B <= 64`，`1 <= L <= 2048`，`1 <= W <= 31`（W 可以大于 L）
