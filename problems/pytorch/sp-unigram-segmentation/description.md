# 分词：Unigram 最优子词切分（Viterbi）

## 题目描述

SentencePiece 的 **Unigram** 语言模型给词表里每个子词 \(x\) 一个出现概率 \(p(x)\)。把一个字符串切成一串子词 \(S=(x_1,\ldots,x_k)\) 的概率是各子词概率之积，取对数后变成求和。编码时就在这张「所有可能切分」的格点上做最短路：**选总对数概率最大的切分**

\[ \hat{S} = \arg\max_{S} \sum_{x \in S} \log p(x) \]

这是经典动态规划（Viterbi），\(O(nL)\)（\(n\) 串长、\(L\) 最长子词），比「贪心最长匹配」更能拿到全局最优。

## 规则

实现 `solve(text, vocab, log_probs)`，返回 int64 一维张量，元素是**被选中子词在 `vocab` 中的下标**（从左到右拼起来恰好等于 `text`）。

- `text`：str，待切分字符串。
- `vocab`：list[str]，子词表（可能含单字符）。`log_probs`：list[float]，与 `vocab` 等长，给出每个子词的对数概率（\(\le 0\)）。
- 用 Viterbi / DP 在所有「子词首尾相接、完整覆盖 `text`」的切分里，取 \(\sum \log p\) 最大者，返回其子词下标序列。
- 若不存在任何能完整覆盖 `text` 的切分（有字符无法由词表拼出），须抛 `ValueError`。

## 示例

`text="unigram"`，`vocab=["u","n","i","g","r","a","m","un","uni","gram","nig","am"]`，对应概率
`[.05,.05,.08,.05,.05,.09,.05,.1,.5,.4,.01,.02]` 取自然对数作 `log_probs`：

```
最优切分 = ["uni", "gram"]  -> 返回下标张量 [8, 9]
（"uni" 概率 0.5、"gram" 0.4，乘积 0.2 远大于逐字符或其它切法）
```

`text="abc"`，`vocab=["a","b","c","ab","bc","abc","ac"]`，概率 `[.01,.01,.01,.05,.02,.6,.03]`：

```
最优切分 = ["abc"]  -> 返回下标张量 [5]
```

## 约束

- 判题用例保证**最优切分唯一**（无并列最大对数概率），因此返回值不依赖并列规则。
- `vocab` 内子词非空；同一切分按 `vocab` 下标返回。
- 无法完整覆盖时抛 `ValueError`（负例用 try/except 断言，勿依赖 pytest）。
- 纯确定性字符串 + 浮点 DP，CPU、无随机。
