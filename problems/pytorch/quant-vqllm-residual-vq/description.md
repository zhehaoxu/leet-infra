# 量化：vqllm 的 std 归一化 + 多步残差向量量化

## 题目描述

KV cache 按 token 存成一个向量，同一个通道在不同 token 上的幅值能差两个数量级：共用一套静态码本时，大值 token 会把码字全占满，小值 token 只能落到最近的"大码字"上。vqllm（arXiv 2410.15704, ENLSP-IV 2024）的处理是两步：先把每条 token 的向量除以自身标准差，再在归一化坐标里做**残差向量量化**（RVQ）——一套量化器由 $N$ 个 $\hat d$ 维子码本拼成，每轮对每个子段取最近码字、减掉，剩下的残差交给下一轮，可以跑多轮也可以换下一套量化器。key 侧还多一步**通道重排**：把 $\hat d$ 个相邻通道组成的段转置后交织，让同一个子码本看到的是跨通道的坐标，而不是一段连续通道。

本题只考这条链上确定性的推理部分。上游用 `scipy.cluster.vq.kmeans2` 训练码本、再用 EMA 更新码字，这些都属于校准侧，不在范围内：码本以显式入参给出。

## 规则

记 `x` 为 $(B,L,D)$，`codebooks` 是长度 $Q$ 的 list，每套 $(N,M,\hat d)$ 且 $N\cdot\hat d=D$。内部一律 float64，返回值按输入 dtype。

1. **归一化**：`scale = x.std(dim=-1, keepdim=True)`，即**无偏**标准差（除以 $D-1$）；`scale == 0` 的位置换成 1，然后 `z = x / scale`。$D=1$ 时无偏标准差是 NaN，所以要求 $D\ge 2$。
2. **重排**（仅 `reorder_channel=True`，上游只在 key 上用）：把最后一维 `view(B,L,N,dhat)`，`transpose(-1,-2)` 成 $(B,L,\hat d,N)$ 再 `reshape` 回 $(B,L,D)$。等价于按 $c_{m\hat d+k}$ 收集成交织顺序：$N=2,\hat d=2$ 时 $[c_0,c_1,c_2,c_3]\to[c_0,c_2,c_1,c_3]$。量化全程在重排后的坐标里做，最后 `split(dhat,-1)` + `stack(-1)` + `reshape` 复原。
3. **逐轮最近邻**：对第 $q$ 套量化器的第 $s$ 轮，把当前残差切成 $N$ 段，每段与第 $k$ 个子码本的全部 $M$ 条码字比欧氏距离（用 $-\lVert z\rVert^2-\lVert c\rVert^2+2zc^\top$ 展开或直接差方都行），取最近的一条；距离并列时取**更小的条目号**。选中码字拼回 $(B,L,D)$ 后从残差里减掉。同一套量化器连续做 `num_residual_steps` 轮，然后换下一套。
4. **索引带偏移**：第 $k$ 段选出的条目号加 $k\cdot M$，于是全部下标落在 $[0, N\cdot M)$，一套量化器内不会撞号。
5. **重建**：`quantized = (z - 最终残差) * scale`，先乘回尺度、再按第 2 条的反操作还原通道顺序；`error = ||最终残差|| * scale`，是该 token 的重建误差（L2，已乘回尺度）。

返回 5 键字典：

- `scale`：$(B,L,1)$，每 token 的标准差（零已换成 1）；
- `residual_norm`：$(Q,S+1,B,L)$，每套量化器在**每轮之前**的残差范数，最后一列是跑完 $S$ 轮之后的值；第 $q>0$ 套的首列等于第 $q-1$ 套的末列；
- `indices`：$(Q,S,B,L,N)$ int64，每轮每段选中的条目号（已加 $k\cdot M$）；
- `quantized`：$(B,L,D)$，重建结果，通道顺序已复原；
- `error`：$(B,L)$，每 token 的重建误差。

## 任务

- `x`：三维 float32 或 float64 张量，$D\ge 2$；
- `codebooks`：非空 list/tuple，每项三维、与 `x` 同 dtype、共享 $(N,\hat d)$、$N\ge 1$、$M\ge 1$、$N\cdot\hat d=D$；
- `num_residual_steps`：$\ge 1$ 的 int（bool 不算）；`reorder_channel`：bool。

非法输入抛 `ValueError`。全程不得修改入参。

## 示例

$B=L=1$、$D=4$、$N=2$、$\hat d=2$、$M=2$、两轮残差、`reorder_channel=True`。重排把 $(1,3)$、$(2,6)$ 两段交织成 $(1,2)$、$(3,6)$，归一化后两段分别落到第 0 套码本的条目 0 与条目 1（偏移 $+2$）；第二轮残差符号反过来，两段都改选条目 1。

```
x                  = [[[1.0, 3.0, 2.0, 6.0]]]
codebooks          = [[[[0.5, 1.0], [-0.05, -0.1]],
                       [[1.5, 3.0], [-0.1, -0.2]]]]
num_residual_steps = 2
reorder_channel    = True

w            = [1.0, 2.0, 3.0, 6.0]                     # 重排后
scale        = [[[2.160246899469287]]]                 # sqrt(14/3)
z            = [[[0.4629100498862757, 0.9258200997725514,
                  1.3887301496588271, 2.7774602993176543]]]
residual_norm = [[[[3.2732683535398857]], [[0.26226555239285204]],
                  [[0.038319636922768574]]]]            # 形状 (1, 3, 1, 1)
indices      = [[[[[0, 2]]], [[[1, 3]]]]]              # 形状 (1, 2, 1, 1, 2)
quantized    = [[[0.9721111047611791, 3.0243456592570017,
                  1.9442222095223582, 6.048691318514003]]]
error        = [[0.08277987685119961]]
```

注意 `quantized` 的第 2、3 通道在重排坐标里是 $(1.9442, 3.0243)$，复原后才变成 $(3.0243, 1.9442)$：重建值按 $[c_0,c_2,c_1,c_3]$ 放回原位。

## 约束

- **无偏标准差**：`std` 默认 `correction=1`，分母是 $D-1$ 而不是 $D$。写成 `sqrt(mean(z^2))` 会整体偏小，`scale` 与 `quantized` 一起错。
- **零尺度换成 1**：常数 token 的标准差是 0，换成 1 后 $z$ 就是原始值本身，这一步只保证不出现 NaN/Inf，并不会把常数 token 归零，重建仍是这些原始幅值选中的码字。别改成 `clamp_min(eps)`：上游是精确的 `where(std == 0, 1, std)`。
- **重排不改变 scale**：标准差对通道置换不变，所以两种 `reorder_channel` 下 `scale` 完全相同；但子段内容不同，`indices`、`residual_norm`、`quantized` 都会变。
- **索引带段偏移**：`indices` 最大能到 $N\cdot M-1$，不是 $M-1$；每段减回 $k\cdot M$ 才是码本条目号。
- **同距取小条目号**：上游 `argmax` 不给同距顺序，本题钉成"最小条目号"，测试用重复码字造出并列局面。
- **残差轨迹的拼接点**：`residual_norm[q][0]` 就是第 $q$ 套量化器接手时的范数，`error` 等于最后一套的末值乘 `scale`。
