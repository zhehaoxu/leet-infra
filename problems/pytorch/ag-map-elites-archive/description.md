# MAP-Elites 质量-多样性档案账

进化搜索只留一个最优解时，种群会塌到一个峰上。MAP-Elites 换成一张**网格档案**：按行为
描述子把解空间切成格子，每个格子只保留落进来的最好那个解——既不丢多样性，也不放弃局部最优。
AlphaEvolve / OpenEvolve 这类「程序进化」系统的 archive 核，就是这张网格。

## 接口

```python
def solve(descriptors, scores, bins, ranges) -> dict
```

`descriptors` 是 `(N, D)` 的行为描述子（例如程序长度、延迟两个维度），`scores` 是 `(N,)` 的
适应度，`bins` 是每维的格数（标量表示各维相同），`ranges` 是每维的 `(lo, hi)` 取值区间。
返回：

| 字段 | 含义 |
| --- | --- |
| `cells` | `(N,)`：每个候选落到的扁平格号，越界为 `-1` |
| `accepted` | `(N,)`：是否成为该格新精英 |
| `elite_score` | `(总格数,)`：每格当前精英分，空格为 `-inf` |
| `elite_index` | `(总格数,)`：每格精英的候选下标，空格为 `-1` |
| `occupancy` / `best_score` / `best_index` | 占用格数、全局最优分与其下标 |

## 输入输出

```
输入：descriptors=[[0.0, 0.0], [0.9, 0.9], [1.0, 1.0], [0.5, 0.5]],
      scores=[1.0, 2.0, 3.0, 0.5], bins=2, ranges=[(0, 1), (0, 1)]
输出：cells=[0, 3, 3, 3], accepted=[True, True, True, False],
      elite_score=[1.0, -inf, -inf, 3.0], elite_index=[0, -1, -1, 2], occupancy=2
```

`[1.0, 1.0]` 恰好等于上界，夹到最后一格 `3`；它的 3.0 严格大于格子里的 2.0，所以替换；
`[0.5, 0.5]` 也落进 `3`，但 0.5 打不过 3.0，被拒。

## 规则

- **分格**：`slot = floor((v - lo) / (hi - lo) * bins[k])`；`v == hi` 时算出 `bins[k]`，
  夹到 `bins[k] - 1`（合法的边界解不能丢）。
- **越界解丢弃**：`v < lo` 或 `v > hi` 的候选不进档案，`cells` 记 `-1`、`accepted` 为假。
  注意是丢弃不是夹取。
- **扁平下标行优先**：`flat = ((i0·b1) + i1)·b2 + i2 …`，最后一维变化最快。
- **严格改进才替换**：只有 `score > 当前精英分` 才换人，同分保留**先到者**（档案是有记忆的，
  不是「最新即最优」）。
- **空格与全局最优**：空格精英分 `-inf`、下标 `-1`；全局最优取所有格精英里的最大分，
  并列时取**先出现的候选下标**。
- **校验**：`bins` 为 `>=1` 的整数或长度等于 `D` 的整数列表、`ranges` 长度等于 `D` 且每项
  `lo < hi`（相等也拒绝）、`scores` 长度等于 `N` 且不含 `NaN`；`N = 0` 合法。

## 提示

- 分格用 `floor`，不是四舍五入：`0.5` 在 `bins=2` 下属于第 1 格。
- `accepted` 与「落进某格」是两件事：落格了但分数不够，`accepted` 仍是假。
