# 集合通信：All-Reduce

## 题目描述

**All-Reduce** = 对所有 rank 的数据逐元素归约（求和），结果**同时出现在每个 rank 上**。它是数据并行
（DDP）每步同步梯度的核心原语，也等于「Reduce-Scatter 再 All-Gather」。

> 集合通信按纯函数建模：输入是「通信前各 rank 的本地数据」列表，输出是「通信后各 rank 的数据」列表。

## 规则

- 实现 `solve(inputs)`，`inputs` 是长度 $W$ 的列表，`inputs[r]` 是 rank `r` 的张量，**所有张量同形状**
  （一维或多维皆可）。
- 逐元素求和得到全局结果：
  $$ T = \sum_{r=0}^{W-1} \texttt{inputs[}r\texttt{]} $$
- 返回**长度 $W$ 的列表**，每个元素都等于 $T$（归约结果广播给所有 rank —— 这是与 Reduce-Scatter 的关键
  区别：这里人人拿到**完整**结果）。
- 不得修改输入张量。

## 示例

```
输入：inputs = [ [[1,2],[3,4]], [[10,20],[30,40]] ]   # W=2, 形状 (2,2)
  T = [[1+10, 2+20], [3+30, 4+40]] = [[11,22],[33,44]]
输出：[ [[11,22],[33,44]], [[11,22],[33,44]] ]        # 两个 rank 相同
```

## 约束

- `1 ≤ W ≤ 64`；所有输入张量形状一致
- 返回 `list[torch.Tensor]`，长度 $=W$，每项形状与输入相同
- 数据并行若要的是**梯度平均**，是 All-Reduce(求和) 之后统一除以 $W$ 的后处理；本题只求和
- 用 `torch.allclose`（浮点）/`torch.equal`（整型）判等
