# 扩散训练：分辨率分桶与最近桶分配

## 题目描述

扩散模型训练通常先把不同尺寸的图像归入一个离散的「分辨率桶」，再按桶组 batch。这样同一批样本共享张量形状、无需逐图 padding，同时保留原图长宽比、避免拉伸变形。

`generate_aspect_ratio_buckets` 由像素预算 `resolution²` 与一组长宽比生成桶：对每个比例 \(a=w/h\)，先令

\[ h=\sqrt{\text{resolution}^2/a},\qquad w=h\cdot a, \]

再把两条边各自对齐到 `divisibility` 的倍数（并夹到不小于 `divisibility`），按顺序去重。`find_nearest_bucket` 则用交叉相乘的度量

\[ \left|h\cdot b_w-w\cdot b_h\right| \]

把图像 \((h,w)\) 分到最近的桶 \((b_h,b_w)\)：它等价于按长宽比距离比较，但只用整数乘法、没有除法误差。度量并列时取列表中**更靠后**的桶。

## 规则

1. **桶的生成**：默认使用 11 种长宽比 `(1,1), (4,5), (5,4), (2,3), (3,2), (3,4), (4,3), (9,16), (16,9), (1,2), (2,1)`，按此顺序逐个生成，重复的 \((h,w)\) 只保留第一次出现。
2. **基于基准分辨率的生成**：若给出 `base_resolutions`（每项是 `(h, w)`），则用它们的长宽比替换默认表；源码内部换算为 \((w,h)\) 后再算 \(w/h\)，因此列表里给的是 \((h,w)\)，输出的桶仍然是 \((h,w)\)。
3. **对齐**：`round(x / divisibility) * divisibility`，其中 Python 的 `round` 是**银行家舍入**（`.5` 取偶）；随后 `max(divisibility, ...)` 兜底。
4. **分配**：对每张图 \((h,w)\) 遍历桶，取度量最小的下标；`<=` 比较意味着并列时后出现的桶胜出。

返回 `(buckets, assignments)`：前者是 `(B, 2)` 的 int64 张量（每行 `(h, w)`），后者是 `(N,)` 的 int64 张量（桶下标）。

## 示例

`resolution = 512`、`divisibility = 16`、默认比例，得到 11 个桶：

```
[(512, 512), (576, 464), (464, 576), (624, 416), (416, 624), (592, 448),
 (448, 592), (688, 384), (384, 688), (720, 368), (368, 720)]
```

`image_sizes = [[512, 512], [768, 512], [512, 768], [1088, 976], [720, 1280]]`：

```
assignments = [0, 3, 4, 1, 8]
```

其中 `1088×976` 对 `(512, 512)` 与 `(576, 464)` 的度量都等于 `57344`，恰好并列；按 `<=` 规则落到后一个桶（下标 1）。把高度略降为 `1070` 后，`1:1` 桶的度量更小，就应回到下标 0。

## 约束

- `resolution`、`divisibility` 必须是正整数（布尔值不算）。
- `image_sizes` 必须是 `(N, 2)` 的 `int32` / `int64` 张量，宽高均为正；允许 `N = 0`。
- `base_resolutions` 可省略；给出时必须是非空列表/元组，每项是两个正整数 `(h, w)`。
- 违反以上任一条时抛 `ValueError`。
- 桶的每条边都是 `divisibility` 的倍数且不小于它；默认比例在 `divisibility=16` 时每个桶的像素量与 `resolution²` 相差不超过约 2%（粒度越大或分辨率越低，偏差会更大，不要把「接近」理解成等式）。
- 低分辨率下不同比例可能对齐到同一个桶，必须保序去重（例如 `resolution=16`、`divisibility=16` 时只剩一个 `(16, 16)`）。
