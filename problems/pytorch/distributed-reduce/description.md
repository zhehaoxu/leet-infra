# 集合通信：Reduce（根归约）

## 题目描述

**Reduce** 是最基础的集合通信原语：把所有 rank 的数据逐元素归约（这里求和），结果**只汇聚到指定的根 rank（root）**，其余 rank 的缓冲区保持不变。All-Reduce 正是「Reduce + Broadcast」，而 Reduce-Scatter 是「Reduce 后各 rank 只留一段」。理解 Reduce 的「只有 root 拿到完整结果」是这组原语的起点。

> 集合通信按纯函数建模：输入是「通信前各 rank 的本地数据」列表 + 根 rank 下标，输出是「通信后各 rank 的数据」列表。

## 规则

- 实现 `solve(inputs, root)`，`inputs` 是长度 $W$ 的列表，`inputs[r]` 是 rank `r` 的张量（**所有张量同形状**，一维或多维皆可）；`root`（$0\le root<W$）是汇聚目标 rank。
- 逐元素求和得到全局结果：
  $$ T = \sum_{r=0}^{W-1} \texttt{inputs[}r\texttt{]} $$
- 返回**长度 $W$ 的列表**：第 `root` 项等于 $T$；**其余每一项保持该 rank 自己的原始输入不变**（与 All-Reduce 的关键区别——结果不广播给所有人，只在根上）。
- 不得修改输入张量。

## 示例

```
输入：inputs = [ [[1,2],[3,4]], [[10,20],[30,40]] ],  root = 0   # W=2, 形状 (2,2)
  T = [[1+10, 2+20], [3+30, 4+40]] = [[11,22],[33,44]]
输出：[ [[11,22],[33,44]],   # root=0 拿到完整和
        [[10,20],[30,40]] ]  # rank 1 保持自己原值
```

## 约束

- `1 ≤ W ≤ 64`；`0 ≤ root < W`；所有输入张量形状一致
- 返回 `list[torch.Tensor]`，长度 $=W$，每项形状与输入相同
- 只实现求和归约（`SUM`）；非根 rank 保留原值、不清零、不广播
- 用 `torch.allclose`（浮点）/`torch.equal`（整型）判等
