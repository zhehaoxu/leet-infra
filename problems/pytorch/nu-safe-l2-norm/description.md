# 安全 p 范数：先按段内最大幅值缩放再归约

## 题目描述

「平方求和再开方」是看起来最不可能写错的一行代码，但它有两个静默失效的方向：大数平方上溢成 \(+\infty\)，小数平方下溢成 \(0\)，于是同一个函数在两端都给出错得离谱却毫不喧哗的结果。工程上正确的做法是先把整段按段内最大幅值缩到 \([0,1]\)，归约完再把缩放因子乘回去。本题要求你实现这个带缩放的 p 范数，支持任意 \(p>0\)（含 \(p=+\infty\)）、任意归约轴与 `keepdim`，并把 NaN、\(\pm\infty\)、全零段、空段这几类退化情形按明确优先级定下来。

## 规则

- 完整签名与参数含义只写在 starter 的 docstring 里，那是唯一判题口径。
- 不许调用 `torch.norm` / `torch.linalg.norm` / `x.norm()` / `torch.linalg.vector_norm`，也不许先算 \(\sum|x_i|^p\) 再开 \(p\) 次方——那正是会错的写法。
- 核心恒等式，seg 是一个待归约段、\(m=\max_i|x_i|\)：

```
||x||_p = m * ( sum_i (|x_i| / m)^p ) ^ (1/p)
```

- 缩放后每一项都落在 \([0,1]\)，取幂既不上溢也不下溢；\(p=+\infty\) 时直接返回 \(m\)——幂次对 max 没有意义，而这个 \(m\) 恰好就是缩放因子本身。\(0<p<1\) 是拟范数，恒等式照样成立。
- 特殊情形按优先级从上往下判，先命中先定值：①段内有 NaN → NaN（NaN 优先于 inf）；②段内有 \(\pm\infty\) → \(+\infty\)；③\(m=0\)（整段是 0）→ \(0.0\)，否则 \(|x_i|/m\) 变成 \(0/0\)；④段长度为 0（空张量或被归约轴长度为 0）→ \(0.0\)；⑤其余走缩放公式。
- 校验：\(x\) 必须是 float32 或 float64 张量，非 Tensor 或非浮点抛 ValueError；\(p\) 是 int 或 float 且必须 \(>0\)（bool 不算数，NaN、\(\le0\)、\(-\infty\)、非数值类型都抛 ValueError，允许 `math.inf`）；`dim=None` 表示整体归约、返回 0-D 张量且此时 `keepdim` 不起作用，否则必须是 int（允许负轴，归一化后不在 \([0,\text{ndim})\) 内抛 ValueError）；`keepdim` 只接受 bool。
- 中间量一律 float64 累加，输出 dtype 跟随输入；float32 输入下超出范围的结果自然变成 inf 是允许的，但不许变成 NaN。

## 示例

```
x = [[3e154, 4e154, 0.0],
     [3e-200, 4e-200, 0.0]]

p=2    -> [5e154, 5e-200]
p=1    -> [7e154, 7e-200]
p=inf  -> [4e154, 4e-200]
```

第一行缩放因子 \(m=4\times10^{154}\)，\((0.75^2+1^2+0^2)^{1/2}=1.25\)，乘回 \(m\) 得 \(5\times10^{154}\)；第二行 \(m=4\times10^{-200}\) 走同一条路得 \(5\times10^{-200}\)。不缩放时第一行 \(9\times10^{308}+16\times10^{308}\) 直接爆成 \(+\infty\)、第二行 \(9\times10^{-400}\) 彻底消失成 \(0\)——`torch.linalg.norm(x, dim=1)` 与 `torch.sqrt((x*x).sum(1))` 实测都给 \([\infty,\,0]\)，`numpy.linalg.norm` 也一样。能手算的小数：\([3,4,0]\to 5\)、\([-5,12]\to 13\)（\(p=2\)）/ \(17\)（\(p=1\)）/ \(12\)（\(p=\infty\)）。

## 约束

- 任意形状、任意单一归约轴（含负轴）与 `keepdim` 组合；被归约轴长度为 0 时输出形状正确、全 \(0\)
- oracle 与缩放算法毫无关系：`Decimal`（60 位精度）直接累加 \(\sum|x_i|^p\) 再开 \(p\) 次方，逐段喂数据
- 判题用相对容差：示例 1e-12、随机与特殊值 1e-9、float32 极端量级 1e-6
- 时间 \(O(\text{numel})\)，比朴素写法多一次段内 max 与一次逐元素除法
