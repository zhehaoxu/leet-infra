# 解题说明 · Mel 滤波器组

## 顺序：mel 域等距 → 回到 Hz

正确的流程只有一条：把 `f_min`、`f_max` 映射到 mel 域，在 mel 域上等距切 `n_mels + 2` 个点，再映射回 Hz。反过来（Hz 等距再映射到 mel）会让低频只分到一两个滤波器、高频占掉绝大多数，因为 Hz 等距在 mel 域上越往上越密。

`n_mels + 2` 而不是 `n_mels` 的原因：每个三角滤波器需要「左零点、中心、右零点」三个边界，相邻滤波器共享边界，所以总共需要 `n_mels + 2` 个点。

## 两套刻度

HTK：`mel = 2595 log10(1 + f/700)`，反函数 `f = 700(10^{mel/2595} - 1)`。全程对数，所以低频也不会退化。

Slaney：`f < 1000` 时 `mel = f / (200/3)`（即 3 mel 每 200 Hz），以上接 `mel = 15 + ln(f/1000) / (ln(6.4)/27)`。常数 `log(6.4)/27` 让 1000 Hz 之后每 27 mel 翻一倍频率（6.4 是 Slaney 选定的跨越比）。两端在 1000 Hz 处连续且一阶可导，因此没有拐点。

两者在 1 kHz 都是 15 mel 附近（HTK 是 1000.6，Slaney 是 15），但「mel 的绝对刻度」不同，所以不能只换一半。

## 面积归一

`2 / (hz[m+2] - hz[m])` 的来历：连续域里三角滤波器对功率谱的积分近似为 `宽 × 高 / 2`，除以 `宽/2` 就得到「平均功率密度」。没有这一项，同样强度的白噪声在高频带会得到更大的 mel 值，纯粹因为带更宽。这也是为什么 Slaney 刻度的 mel 值比 HTK 小三个数量级——不影响训练（后面还会取 log、再标准化），但影响可读性与跨实现对比。

## 端点与 DC

第一个滤波器的左边界是 `f_min`。当 `f_min = 0` 时，频点 0 正好落在左端点上，权重 `(f - lo)/(ce - lo) = 0`；最后一个滤波器的右边界是 `f_max`，`f_max = sr/2` 时 Nyquist 频点同样是 0。于是「DC 与 Nyquist 都不进任何滤波器」——听起来反直觉，但正是 librosa 的行为，也是本题的一个断言点。

## 上下文的 `1e-10`

Whisper 的实现里用的是 `log10(max(mel, 1e-10))` 再 `(x + 4) / 4` 归一，本质就是本题的 `log` + 线性缩放。下限的作用是让静音帧变成一个大负数而不是 `-inf`。

## 复杂度

滤波器矩阵 O(n_mels · F)，投影 O(T · F · n_mels)。真实实现会把它当成稀疏矩阵或直接按频点区间求和（每个三角只覆盖少数几个 bin），复杂度降到 O(T · F)。
