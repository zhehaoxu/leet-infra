# 音频前端：Mel 滤波器组与 log-mel

## 问题

人耳对频率的分辨不是线性的：1 kHz 以下近似线性，以上近似对数。Mel 刻度就是对这个感知的拟合，而**Mel 滤波器组**是用一组三角滤波器把线性功率谱压到 `n_mels` 个频带上的矩阵，`log-mel` 则是 Whisper / HuBERT 等模型真正的输入特征。

工程上最容易出错的不是三角滤波器的形状，而是两个刻度定义：

- **HTK 刻度**：`mel = 2595 · log10(1 + f/700)`。这是 HTK 书与早期 Kaldi 的口径，全程对数。
- **Slaney 刻度**：`f < 1000 Hz` 时 `mel = f / (200/3)`（线性，且 1000 Hz 恰好映射到 mel = 15），以上换成对数。librosa 默认用这一套。

两者在 1 kHz 附近几乎重合，但在低频和高频分别偏得很多。另一个独立开关是**面积归一**：每个滤波器乘 `2 / (hz[m+2] - hz[m])`，让各频带的能量量纲一致（否则高频带更宽、积分值天然更大）。librosa 的 `norm="slaney"` 就是它，本题把它和 Slaney 刻度绑定，作为「一套口径」来考。

## 任务

实现 `solve(power_spec, sample_rate, n_mels, f_min, f_max, scale)`：

- 输入：`power_spec` `(T, F)` 线性功率谱（`F` 个频点等间隔铺在 `[0, sr/2]`）；`n_mels` 滤波器个数；`f_min` / `f_max`；`scale ∈ {"htk", "slaney"}`。
- 在 mel 域取 `n_mels + 2` 个等距边界（含 `f_min`、`f_max`），映射回 Hz 得 `hz[0..n_mels+1]`。
- 三角滤波器 `m` 在 `[hz[m], hz[m+1], hz[m+2]]` 上升-下降，其余为 0。
- `scale == "slaney"` 时再乘 `2 / (hz[m+2] - hz[m])`；`htk` 不归一。
- `mel = power_spec @ filters.T`，`logmel = log(max(mel, 1e-10))`。
- 输出 `(filters (n_mels, F), mel (T, n_mels), logmel (T, n_mels))`，均 float32。

## 示例

```
sr = 8000, n_mels = 3, f_min = 0, f_max = 4000, scale = "htk"
频点 = [0, 500, 1000, 1500, 2000, 2500, 3000, 3500, 4000]
mel 边界（Hz）= [0, 428.0, 1119.0, 2232.2, 4000]

filters =
[[0, 0.893459, 0.165692, 0,        0,        0,        0,        0,        0      ]
 [0, 0.106541, 0.834308, 0.650824, 0.198715, 0,        0,        0,        0      ]
 [0, 0,        0,        0.349176, 0.801285, 0.842585, 0.561724, 0.280862, 0      ]]

power_spec[0] = [1..9]
mel[0]    = [2.283994, 6.312877, 16.637600]
logmel[0] = [0.825926, 1.842592, 2.811665]
```

## 约束

- **绑定关系**：`slaney` 刻度 + 面积归一是一套，`htk` 刻度 + 不归一是一套；不要交叉组合。
- **边界点在 mel 域等距**，不是 Hz 域等距——这是 Mel 滤波器组的全部意义。改成 Hz 等距就等于普通滤波器组。
- **`1e-10` 下限**：静音段 `mel = 0` 时取 `log(1e-10) ≈ -23.03`，不能是 `-inf`（会污染训练）。
- **频带外严格为 0**：`f_min > 0` 时低频侧整列为 0；`f_max < sr/2` 时高频侧同样。
- **DC 频点在第一个滤波器的左端点上，权重为 0**：所以纯直流信号会被整组滤波器忽略，这是容易忽略的一处。
- **非法输入抛 `ValueError`**：`scale` 不是两个名字之一、非二维、`n_mels < 1`、`f_min < 0`、`f_min >= f_max`、`f_max > sr/2`、频点少于 2 个。
