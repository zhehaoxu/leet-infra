# DIoU-NMS 抑制判据账

## 背景与位置

Distance-IoU Loss（1911.08287, AAAI 2021）指出：NMS 只看 IoU 时，对「 IoU 低但中心远离」的框会误抑制（当作同一目标的不同视角），对「IoU 低但中心接近」的框反而放过。DIoU-NMS 把抑制判据换成 **DIoU = IoU − ρ²/c²**：NMS 流程一字不动，只换公式。官方实现仓（Zzhiter/DIoU-NMS）已 404，本题按论文公式 + 社区通行转写（ultralytics/mmdet 语义）落地。

## 精确账目

1. **DIoU = IoU − ρ²/c²**：
   - ρ² = 两框中心点欧氏距离平方；
   - c² = **最小外接框**的 w² + h²（对角线平方）。
2. **NMS 流程不变**：分数降序稳定排序（并列取小下标）→ 贪心保留当前最高分 → 抑制与已保留框 **DIoU > thresh（严格大于）** 的剩余框 → 重复。
3. **方向性**：完全分离框 IoU=0 → DIoU = −ρ²/c² ≤ 0，正阈值下永不被抑制；完全重合 ρ=0 → DIoU=IoU；等值边界（DIoU == thresh）不抑制。
4. 输出保留序列（按保留顺序的原始下标）与抑制映射 {被抑制 → 抑制者}。

## 约束

1. 框 [x1,y1,x2,y2] 满足 x2≥x1、y2≥y1；坐标/分数有限；thresh ∈ [0,1]。
2. c²=0（两点框）时退化为纯 IoU。
3. 禁改入参；判据只允许逐对计算，无全局状态。

## 数据规模

- n ≤ 10³（O(n²) 判据账）。

## 验收锚点（节选）

- A=[0,0,2,2]、B=[1,1,3,3]：iou=1/7、ρ²=2、c²=18 → **DIoU=2/63**；thresh=2/63 恰等不抑制、0.03 抑制。
- 小位移重复（B=[0.2,0,2.2,2]）：DIoU≈0.8137 > 0.5 抑制。
- 分离框（[0,0,1,1] vs [5,5,6,6]）：DIoU=−32/50 < 0.5 不抑制。
- **DIoU 换判据的关键差异**：A=[0,0,10,10] vs B=[8,8,12,12]，IoU≈0.0345 > 0.03 会抑制（IoU-NMS），DIoU≈−0.139 不抑制——中心惩罚项压过重叠项。
