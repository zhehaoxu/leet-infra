# 广播机制实战 详解

## 广播规则（两句话）

对齐时从**末维往前**逐维比较：两维相等、或其中之一为 1，则可广播；否则报错。缺失的高维按 1 补齐。结果是把大小为 1 的维「虚拟复制」到对方的尺寸——**不发生真实拷贝**，stride 在该维置 0。

## 三种典型模式

| op | 参考解 | 语义 |
|----|--------|------|
| `row_scale` | `a * b[:, None]` | `b` 是 `(B,)`，`[:, None]`→`(B,1)`，对每一**列**按行缩放。 |
| `col_bias` | `a + b[None, :]` | `b` 是 `(D,)`，`[None, :]`→`(1,D)`，对每一**行**按列加偏置。 |
| `outer` | `a[:, None] * b[None, :]` | 两个一维向量 → `(len(a), len(b))` 外积矩阵。 |

## unsqueeze 的坐标感

`x[:, None]` 在 dim=1 插一个长度 1 的轴，把一维变二维列向量；`x[None, :]` 在 dim=0 插轴成行向量。`b[:, None]` 而非直接 `b`，是因为 `a` 是二维 `(B,D)`：不插轴的话 `(B,D)` 与 `(B,)` 会在末维 $D\ne B$ 时对齐失败。**先想清楚要把 `b` 沿哪个轴铺开，就在哪个位置补 `None`/`unsqueeze`。**

## 常见坑

- 广播张量是只读语义的「扩展视图」；想独立物化用 `.expand(...).contiguous()` 或 `.repeat(...)`。
- `b[:, None]` 与 `b.unsqueeze(1)` 完全等价，选可读性好的。
- 广播不检查数值，只检查形状；尺寸不符会抛 `RuntimeError` 而非静默截断。

## 关联

linear-layer（$xW^\top+b$ 里的 $b$ 就是 col_bias 广播）、layernorm/batchnorm 的仿射、outer-product 类注意力都建立在这三种模式上。
