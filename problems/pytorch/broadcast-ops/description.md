# 广播机制实战

## 题目描述

广播（Broadcasting）让形状不同的张量直接做逐元素运算：从尾部维度对齐，`1` 或缺失的维度自动扩展。它是 PyTorch 向量化代码的第一生产力——用对广播能消灭绝大多数 Python 循环。

## 规则

实现 `solve(a: torch.Tensor, b: torch.Tensor, op: str) -> torch.Tensor`，只用广播运算（`unsqueeze` / `None` 索引 / 四则），不得写逐元素 Python 循环：

| op | 输入 | 语义 | 输出形状 |
|---|---|---|---|
| `"row_scale"` | `a (B,D)`，`b (B,)` | 第 `i` 行乘以 `b[i]` | `(B, D)` |
| `"col_bias"` | `a (B,D)`，`b (D,)` | 第 `j` 列加上 `b[j]` | `(B, D)` |
| `"outer"` | `a (m,)`，`b (n,)` | 外积 `a[i] * b[j]` | `(m, n)` |

`op` 不在上表中时抛 `ValueError`。

> 提示：一维张量与二维运算前，通常需要 `a[:, None]`（等价 `a.unsqueeze(1)`）把长度-`B` 的向量变成 `(B,1)`，广播对齐到每一列。

## 示例

```
a = [1.0, 2.0], b = [10.0, 20.0, 30.0], op = "outer"
输出：[[10.0, 20.0, 30.0],
       [20.0, 40.0, 60.0]]
```

## 约束

- 输入为 float32 张量，维度长度保证与表中形状匹配
- 结果需与向量化参考实现逐元素一致（`allclose` 级别）
