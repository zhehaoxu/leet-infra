# 前向/反向 Hook：抓激活与改梯度

## 题目描述

Hook 是框架留给我们伸进 `nn.Module` 执行流的手：forward hook 能抓激活（甚至可以**替换**模块输出），`register_full_backward_hook` 返回的新梯度会原样向上传播——这正是做特征可视化、梯度探针、gradcam 与"梯度手术"的机制。本题布置五路 hook，要求把它们的可观测后果全部记成账。

## 规则

实现 `solve()`，按 starter docstring 的固定模型（显式权重，无随机数）与五路 hook 布置执行一次前向+反向，返回行为账 dict。要点：

1. tanh 上的 forward hook 返回 `out * 2.0`（非 None）：**替换**模块输出，下游 fc2 收到 \(2\tanh(a_1)\)。
2. fc1 上的 `register_full_backward_hook` 返回 `tuple(2*g+1 for g in gin)`：改写发给输入的梯度，`x.grad` 变为 \(2g+1\)；参数梯度**不受该改写污染**，仍等于解析值。
3. fc2 上的 legacy `register_backward_hook` 只计数不改写（返回 `None`）。
4. 每路 hook 都要计数触发次数；`acts` 记录**替换前**的模块输出。
5. 改写后的 `x.grad` 必须与解析重算值一致：先手算原始 \(g\)，再套 \(2g+1\)。

## 示例

```
输入：无
输出：
{
 "loss": 0.003973240032792091,
 "acts": {"fc1": [0.30000001192092896, 0.75],
          "tanh": [0.29131263494491577, 0.6351489424705505],
          "fc2": [0.9369663596153259]},
 "fc2_input": [0.5826252698898315, 1.270297884941101],
 "fired": {"fc1_fwd": 1, "tanh_fwd": 1, "fc2_fwd": 1, "fc1_bwd": 1, "fc2_bwd": 1},
 "x_grad": [0.945848822593689, 0.9139541983604431, 0.8820595145225525],
 "fc1_weight_grad": [-0.034610647708177567, 0.06922129541635513, -0.13844259083271027,
                     -0.04512597247958183, 0.09025194495916367, -0.18050388991832733],
 "fc2_weight_grad": [-0.0734499841928482, -0.16014300286769867],
 "fc1_bias_grad": [-0.06922129541635513, -0.09025194495916367]
}
```

推演：\(a_1=(0.3,0.75)\)，\(h=2\tanh(a_1)=(0.5826,1.2703)\)，\(out=0.3h_0+0.6h_1=0.93697\)，\(loss=(out-1)^2=0.003973\)。原始 \(\partial L/\partial x_0=-0.02708\)，hook 改写后 \(2(-0.02708)+1=0.94585\)。

## 约束

- 数值对拍 `atol=1e-5, rtol=1e-5`；触发计数与 dict 结构精确一致。
- 全流程单次前向 + 单次反向，无随机数。
