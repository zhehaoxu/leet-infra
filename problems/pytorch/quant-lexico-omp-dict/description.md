# 量化：Lexico 的 KV 稀疏字典编码（逐行 OMP）

## 题目描述

Lexico（arXiv 2412.08890）把 KV cache 当成信号而不是数值：先在 WikiText 上离线训一个与输入无关的小字典（约 4k 个原子），然后把每条 KV 向量表示成字典里**少数几个原子的线性组合**，存下来的只有「原子 id + 权重」这一对稀疏三元组（CSR）。本题实现这条链路里确定性的那一半——逐行正交匹配追踪（OMP）与 CSR 打包。

字典的训练（K-SVD）、按 20000 行分块、以及把权重压成 float8 都属于校准侧或存储侧，不进题：字典以显式入参给出，权重按输入 dtype 返回。

## 规则

记 `vectors` 为 $(N,D)$（每行是一条待编码的 KV 向量 $y$），`dictionary` 为 $(D,M)$（**原子是列**，第 $m$ 个原子是 `dictionary[:, m]`）。逐行独立，行与行互不影响；内部一律 float64，返回值按输入 dtype。

每行的过程：

1. **初始化**：已选集合 $S=\varnothing$，残差 $r=y$，$I=\lVert y\rVert^2$ 记作初值能量。
2. **每轮先判停**：对第 $k$ 轮（$k=0,\dots,$`n_atoms`$-1$），若给了 `tol` 且 $\lVert r\rVert^2 \le \text{tol}^2\cdot I$，本行**就此结束**：`lengths` $=k$（已经选中的个数），本轮及之后不再选任何原子；预算跑满则 `lengths` $=$ `n_atoms`。
3. **选原子**：在**尚未选过**的原子里算 $|\langle r, a_j\rangle|$，取最大者；同分取**最小下标**。把 $j$ 追加到 $S$ 末尾（行内顺序就是被选中的先后）。
4. **整组重解**：对整个 $S$ 重解最小二乘 $w=(X_S^\top X_S)^{-1}X_S^\top y$，$r \leftarrow y - X_S w$。**不是**只更新新原子那一项，也不是增量投影——每轮加入新原子都会改写老原子的权重。
5. **零行是确定性的**：$y=0$ 时所有相关系数都是 0，给了 `tol`（哪怕 `tol=0.0`）第 0 轮判定 $0\le 0$ 直接停，`lengths` $=0$；不给 `tol` 就依次选中 $0,1,\dots,$`n_atoms`$-1$，权重全为 0。
6. **秩亏集合取最小范数解**：若选中的原子线性相关（字典里有冗余列时会发生），$(X_S^\top X_S)$ 不可逆，本题口径是**最小范数最小二乘解**，即 `torch.linalg.lstsq` / `numpy.linalg.lstsq` 的返回值；同一行的 `recon` 不受影响（投影唯一），只有 `csr_values` 的分配会变。

返回 6 键字典（CSR 三元组的口径与上游 `omp()` 一致）：

- `lengths`：int64 $(N,)$，每行真正用到的原子数；
- `csr_indptr`：int64 $(N+1,)$，`[0] + lengths` 的前缀和；
- `csr_indices`：int64 $(\text{total},)$，各行选中的原子 id 按行拼接；
- `csr_values`：输入 dtype $(\text{total},)$，与 `csr_indices` 一一对应的权重；
- `residual_norm`：输入 dtype $(N,)$，该行在**自己的停止点**上的 $\lVert y-\text{recon}\rVert$；
- `recon`：输入 dtype $(N,D)$，$X_S w$；`lengths == 0` 的行是全零。

## 任务

实现 `solve(vectors, dictionary, n_atoms, tol=None)`：

- `vectors`：二维 float32/float64 $(N,D)$；`dictionary`：与 `vectors` 同 dtype 的 $(D,M)$，两者只读；
- `n_atoms`：正整数且 $\le M$（Lexico 的 `max_sparsity`，上游默认 14）；
- `tol`：`None`，或落在 $[0,1)$ 的浮点数。

非二维、dtype 不是 float32/float64、两者 dtype 不一致、`dictionary` 行数不等于 $D$、`n_atoms` 非法（`bool`、`3.0` 都算非法）或超过 $M$、`tol` 不在 $[0,1)$（`1.0`、`-0.1`、`True` 都要拒）一律抛 `ValueError`。

## 示例

$D=3$、$M=5$，原子是列：$a_0=(1,0,0)$、$a_1=(0,2,0)$、$a_2=(0,0,1)$、$a_3=(1,1,0)$、$a_4=(0,1,1)$，`n_atoms=2`。第 0 行首轮 $\langle y,a_3\rangle=3$ 最大，选中后残差 $(0.5,-0.5,0)$，第二轮 $|{-1}|$ 的 $a_1$ 胜出，重解得 $w=(2,-0.5)$ 精确归零；第 1 行首轮 $a_2$ 与 $a_4$ 并列取小下标，残差已为 0，第二轮只是补了个零权重原子；第 2 行选中 $a_1$ 后残差 $(1,0,1)$，$a_0,a_2,a_3,a_4$ 相关系数全是 1，又并列取到 $a_0$，预算用尽还剩 1.0。

```
vectors    = [[2.0, 1.0, 0.0], [0.0, 0.0, 3.0], [1.0, 1.0, 1.0]]
n_atoms    = 2          tol = None

lengths        = [2, 2, 2]
csr_indptr     = [0, 2, 4, 6]
csr_indices    = [3, 1,  2, 0,  1, 0]
csr_values     = [2.0, -0.5,  3.0, -0.0,  0.5, 1.0]
residual_norm  = [0.0, 0.0, 1.0]
recon          = [[2.0, 1.0, 0.0], [0.0, 0.0, 3.0], [1.0, 1.0, 0.0]]
```

换成 `tol=0.9` 时三行都在第二轮判停（$\lVert r\rVert^2$ 分别是 $0.5,0,2$，都不超过 $0.81\cdot I$），`lengths` 变成 $[1,1,1]$、`residual_norm` 变成 $[0.707107, 0.0, 1.414214]$。

## 约束

- **判停在选原子之前**：`lengths` 是停止那一刻**已选**的个数，`residual_norm` 也报在同一时刻；先选后判会把早停的行多算一个原子。
- **每轮整组重解**：第 0 行第一个原子的权重从 $1.5$（单原子）被改写成 $2.0$（两原子）。贪心只更新新原子的那一套数值（匹配追踪的另一支）在这里会错。
- **相关系数取绝对值**：$\langle y,a_1\rangle=-8$ 照样比 $+4$ 大；权重可以是负的。
- **同分取最小下标**：上游 `argmax` 给的就是第一个最大值；并列时别按浮点噪声挑。
- **`tol=0.0` 是有效阈值**：本题按 `tol is not None` 判定，零行给 `tol=0.0` 会立刻停在 `lengths=0`。上游写的是 `if tol:`，$0.0$ 会被当假值当成「关闭」——本题不照抄这一点。
- **已选原子不再竞选**：残差与已选子空间正交，上游靠投影 downdate 达到同样效果，但没有显式屏蔽，极端并列时会重复选中同一列；本题钉成显式排除。
