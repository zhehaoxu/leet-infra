# 详解：MLA 解码的权重吸收

## 出处

DeepSeek-V2 的 Multi-head Latent Attention（arXiv:2405.04434，§3.1 给出 MLA 的结构与 \(W_{UK},W_{UV}\) 的定义）。吸收恒等式是两条线性映射的结合律，可直接由定义推出：

\[ q_h^\top\left(W_{UK,h}c_{KV}\right)=\left(q_h^\top W_{UK,h}\right)c_{KV},\qquad \sum_t p_t\left(W_{UV,h}c_{KV,t}\right)=W_{UV,h}\left(\sum_t p_t c_{KV,t}\right) \]

本题只做**解码**这一侧：查询与位置编码已经算好，输入的是每头的 \(q^{\text{nope}},q^{PE}\)、潜在缓存与两族升维矩阵，不涉及 \(W_{DQ}/W_{UQ}/W_{QR}\) 的投影链。仓库里的 `llm-deepseek-mla` 覆盖的正是未吸收的整层前向（含 q LoRA 路径、RMSNorm、解耦 RoPE、因果注意力与 `o_proj`），本题与它构成一对：**同一个数学对象的两种计算图**，因此可以把「未吸收的前向」当作天然的独立 oracle。

## 核心与易错点

1. **\(W_{UK},W_{UV}\) 的坐标系**：两者都是 \((H,d_h,d_c)\)，"第 \(k\) 行是 \(k^{\text{nope}}\) 的第 \(k\) 个坐标对潜在向量的系数"。吸收进查询要按行收缩（\(q_h^\top W_{UK,h}\)，得到 \(d_c\) 维），升维输出要按列展开（\(W_{UV,h}z_h\)，得到 \(d_h\) 维）。把这两个 einsum 的下标写反、或在 \(d_h\ne d_c\) 时靠形状碰巧不报错，是最常见的一类错误——判题专门用 \(d_h\ne d_c\) 的随机用例对拍。
2. **RoPE 分量不参与吸收**：\(k^{PE}\) 在头之间共享、且与潜在缓存无关，只能作为独立的 \(q^{PE}\cdot k^{PE}\) 项加在打分上。把 \(q^{PE}\) 也乘进 \(W_{UK}\) 会直接改变打分（维度都对不上）；把 \(k^{PE}\) 当成「每头一份」也会在头之间引入本不存在的差异。
3. **值的加权求和可以先做**：\(\sum_t p_t (W_{UV}c_t)=W_{UV}(\sum_t p_t c_t)\)。这样升维只做一次，而不是每个 token 一次——这正是解码省显存/带宽的关键。反之若先逐 token 升维再加权，结果虽然等价但失去了吸收的意义。
4. **打分缩放只乘一次**：`scale` 作用在「潜在内积 + RoPE 内积」之和上，不是分别乘。分别乘在数学上等价于同一个标量，但若误把 RoPE 项漏乘就会改变注意力分布。
5. **softmax 沿序列维**：`dim=-1` 是 \(S\) 维，不是头维也不是特征维。
6. **退化检查很有力**：\(S=1\) 时权重恒为 1，输出与查询彻底无关，只等于 \(W_{UV,h}c_{KV,0}\)；查询与 RoPE 键全零时权重均匀，输出等于 \(W_{UV,h}\cdot\text{mean}_t(c_{KV})\)。这两条不依赖任何随机数，能直接指出「查询/位置项被错误地混进了值路径」。

## 对拍口径

参考解在 float64 下用三个 einsum 完成吸收路径（吸收查询、打分、潜在空间加权求和 + 一次升维），最后转 float32。判题 `_oracle` 走**朴素路径**：先用 `einsum("bsc,hkc->bhsk")` 把每个 token 的 \(k^{\text{nope}}\) 与 \(v\) 逐头升维出来，再用常规打分与「逐 token 加权求和」，两条计算图没有任何共享的中间量。结构断言六组：三组不同 \((B,H,d_h,d_r,d_c,S)\)（含 \(d_h\ne d_c\)）的双尺度对拍、\(S=1\) 的查询无关性与精确值、全零查询的均匀注意力、头间独立性、RoPE 键的独立贡献、非法输入。阈值 `allclose(atol=1e-5)`。

## 复杂度

设序列长 \(S\)、头数 \(H\)、潜在维 \(d_c\)、头维 \(d_h\)。吸收路径：吸收查询 \(O(H d_h d_c)\)，打分 \(O(BHSd_c)\)，潜在加权求和 \(O(BHSd_c)\)，升维 \(O(BH d_h d_c)\)——与 \(S\) 相关的部分只在 \(d_c\) 上，且不需要 \(S\times H\times d_h\) 的中间张量；朴素路径的注意力部分是 \(O(BHSd_h)\) 计算并物化同规模中间量。解码（\(S\) 很小、\(d_c\ll H d_h\)）时吸收路径的带宽优势最明显。
