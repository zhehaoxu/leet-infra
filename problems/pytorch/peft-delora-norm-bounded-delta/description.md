# DeLoRA：按行范数归一化的有界低秩更新

## 题目描述

普通 LoRA 的更新量 `B A` 没有界，训练步长一大就容易把基座权重推远。DeLoRA 的做法是给每个秩 1 分量单独配一个缩放，使每个分量的范数恰好是 `lam / r`，于是整个更新量的 Frobenius 范数不超过 `lam`；再乘上基座权重每列的范数 `w_norm`，让更新量按输入通道的尺度自适应。

本题要求给定基座权重、低秩因子、边界参数与列范数，输出逐分量的缩放、更新矩阵和合并后的权重。

## 规则

记 `rank = r`（由 `A` 的行数决定），`An_i = max(||A_i||_2, 1e-4)`（`A` 第 `i` 行的范数），`Bn_i = max(||B^i||_2, 1e-4)`（`B` 第 `i` 列的范数）。

1. **逐分量缩放**：

   ```
   scaling_i = lam / r / (An_i * Bn_i)
   ```

   范数下限 `1e-4` 用来挡住零行/零列，否则缩放会变成无穷大。

2. **更新矩阵**：

   ```
   delta = B @ diag(scaling) @ A
   delta = delta * w_norm          # 按列（输入通道）逐列缩放
   ```

3. **合并**：`merged = W0 + delta`。

关键点：缩放**只**依赖 `A` 的行范数与 `B` 的列范数，与数据分布无关；`w_norm` 是训练开始时冻结的基座列范数，训练过程中不更新。当 `A` 的行与 `B` 的列都是单位向量时，各秩 1 分量互相正交，`delta` 的 Frobenius 范数精确等于 `lam / sqrt(r)`。

返回 `(scaling, delta, merged)`：`scaling` 形状 `(r,)`，`delta` 与 `merged` 形状 `(out_features, in_features)`，均为 float32。

## 示例

`W0 = [[1, 2, 3], [4, 5, 6]]`、`A = [[1, 0, 0], [0, 2, 0]]`、`B = [[1, 0], [0, 3]]`、`lam = 1.5`、`w_norm = [1, 2, 1]`

```
An = [1, 2]        Bn = [1, 3]
scaling = [1.5/2/(1*1), 1.5/2/(2*3)] = [0.75, 0.125]

delta = B @ diag([0.75, 0.125]) @ A = [[0.75, 0, 0],
                                       [0,  0.75, 0]]
delta * w_norm（按列，w_norm = [1, 2, 1]）= [[0.75, 0, 0],
                                             [0,  1.5, 0]]

merged = [[1.75, 2.0, 3.0],
          [4.0,  6.5, 6.0]]
```

若把 `A` 的第一行换成全零，则 `An_0` 被夹到 `1e-4`，`scaling_0 = 1.5/2/(1e-4 * 1) = 7500`（取 `lam=1.5`、`Bn_0=1` 时）；本题用 `lam=1.0` 时该值为 `5000`。

## 约束

- `A`、`B` 必须是二维，`rank >= 1`；
- `B.shape[1] == A.shape[0]`；
- `W0.shape == (B.shape[0], A.shape[1])`；
- `w_norm` 是一维且长度等于 `A.shape[1]`；
- `lam >= 0`；
- 违反以上任一条时抛出 `ValueError`。
