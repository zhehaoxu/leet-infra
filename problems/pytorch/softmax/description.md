# Softmax（数值稳定）

## 题目描述

实现沿指定维度的数值稳定 Softmax，把一组 logits 归一化为概率分布。它是 Attention 的核心组件：

$$
\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

直接对 `logits=1000` 量级的输入算 `exp` 会上溢为 `inf`（float32 在 $e^{88}$ 就溢出）。关键技巧：**分子分母同乘 $e^{-\max z}$**，即先减去沿该维度的最大值再归一化，结果数学上不变，但 `exp` 的参数恒 $\le 0$，永不上溢。

## 规则

- 实现 `solve(logits: torch.Tensor, dim: int = -1) -> torch.Tensor`。
- 沿 `dim` 维度做稳定 softmax（减 max 技巧），结果每一片和为 1。
- 输出形状与输入一致；向量化实现；不得出现 `NaN`/`inf`（含 `logits=1000` 量级输入）。

## 示例

```
输入：[[1.0, 2.0, 3.0],
       [0.5, 0.5, 0.5]]   (dim=-1)
输出：[[0.09003, 0.24473, 0.66524],
       [0.33333, 0.33333, 0.33333]]
```

## 约束

- 输入为 float32 或 float64 张量，任意形状（至少 2 维）
- `dim` 为合法维度（可能是负数）
- 元素范围可达 ±1000
