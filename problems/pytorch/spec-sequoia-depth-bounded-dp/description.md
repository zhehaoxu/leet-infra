# 推测解码：Sequoia 深度受限最优草稿树 DP

## 题目描述

一次投机迭代的产出取决于草稿树的**形状**。**Sequoia**（Chen et al., 2024, [arXiv:2402.12374](https://arxiv.org/abs/2402.12374)）用动态规划离线求最优树形：题面 `spec-sequoia-optimal-tree`（本题合集 order 177）实现的是其 Algorithm 1——**无深度上限**、接受率只按「父节点的第几个孩子」一维索引、并且固定树规模取最大期望。

本题做该 DP 的两处扩展，对应 Sequoia 论文的有界深度 DP（附录 C.2.2）与代价目标（§3.3.1 式 (1)，speedup $=G(n,d)/(t(n)+d\,c)$）：

1. **深度上限 $D$**：草稿树再深也超出 draft 能力（self-speculation 时 draft 只有有限层可用），故树高被限制为 $D$。
2. **按深度索引的二维接受率矩阵**：自投机下「第 $k$ 个孩子」的接受率还依赖于它处在第几层，于是接受率从一维 $P[b]$ 升级为矩阵 $A[d][b]$；这使「子树规模相同、所处深度不同」的价值不再相等，DP 必须把**绝对深度**放进状态（平移不变性被破坏）。
3. **代价目标**：不再固定规模取最大期望，而是在 $1\dots N$ 里自选规模 $n$，最大化**单位时间产出** $F(n)/(t_{\text{v}}+n\,t_{\text{d}})$，其中 $t_{\text{v}}$ 是一次 target 验证的固定代价、$t_{\text{d}}$ 是逐节点草稿代价。

## 规则

入参：
- `A`：形状 $(D, B)$ 的接受率矩阵，$A[d-1][b-1]$ = 在父链已全部接受的前提下，处于**绝对深度** $d$（根为深度 0）且是父节点**第 $b$ 个**孩子的节点被接受的概率。
- `N`：树规模预算上限；`B`：每个节点最多孩子数（$=A$ 的列数）；`D`：最大深度（$=A$ 的行数，可为 0）。
- `td`：每草拟一个节点的草稿代价；`tv`：一次目标模型验证的固定代价（$>0$）。

一棵有序树 $\mathcal T$ 的期望产出（与 177 同口径）：
$$ f(\text{root})=1,\qquad f(v)=\prod_{i=1}^{\text{depth}(v)} A[\,i-1\,][\,\text{第 } i \text{ 步走的孩子的序号}-1\,],\qquad F(\mathcal T)=\sum_{v\in\mathcal T} f(v). $$
记 $F(n)=\max\{F(\mathcal T): |\mathcal T|=n,\ \text{出度}\le B,\ \text{深度}\le D\}$（不可行则 $-\infty$），要求
$$ \max_{1\le n\le N}\ \frac{F(n)}{t_{\text v}+n\,t_{\text d}} . $$

深度受限 DP 的递推（$d$ 为**绝对深度**）：
$$ T[1,0,d]=1,\quad T_{\max}[n,d]=\max_{0\le b\le B}T[n,b,d],\quad T[n,b,D]=-\infty\ (b\ge1), $$
$$ T[n,b,d]=\max_{1\le m\le n-1}\Big(T[n-m,\,b-1,\,d]\;+\;A[d][\,b-1\,]\cdot T_{\max}[m,\,d+1]\Big), $$
即把根的第 $b$ 个孩子（它在绝对深度 $d+1$，本身被接受的概率是 $A[d][b-1]$）整棵子树拆成规模 $m$，剩下的 $b-1$ 个孩子仍留在深度 $d$；答案取 $F(n)=T_{\max}[n,0]$。

返回 `(ratio, n_star)`：`ratio` 是 float 最优目标值，`n_star` 是对应的树规模（int；若多个规模并列最优，取最小的 $n$）。

## 示例

```
A = [[0.75, 0.5],       # 深度 1 的两个分支接受率
     [0.5, 0.25]],      # 深度 2 的两个分支接受率   => D=2, B=2
N = 4, td = 0.25, tv = 1.0

  F(1) = 1.000  -> 1.000 / (1.0 + 0.25*1) = 0.8
  F(2) = 1.750  -> 1.750 / (1.0 + 0.25*2) = 1.1666666666666667
  F(3) = 2.250  -> 2.250 / (1.0 + 0.25*3) = 1.2857142857142858
  F(4) = 2.625  -> 2.625 / (1.0 + 0.25*4) = 1.3125            <- 最优
输出 = (1.3125, 4)

同一 A，草稿免费 td = 0.0, tv = 1.0（深度上限 D=2 使 4 层链不可行，最优仍是满规模）
输出 = (2.625, 4)

A = 形状 (0, 2) 的空矩阵（D = 0，一步都不能投机）, N = 4, B = 2, td = 0.25, tv = 1.0
只有根可行：F(1) = 1
输出 = (0.8, 1)
```

## 约束

- CPU float32；`A` 形状 $(D,B)$，$0\le A[d][b]\le1$；$1\le N\le 32$，$1\le B\le 8$，$0\le D\le \max(N-1,0)$；$t_{\text d}\ge0$，$t_{\text v}>0$。返回 `(float, int)`，`ratio` 用 `abs(a-b) <= 1e-6*max(1,|b|)` 比较、`n_star` 用整数相等比较。
- 规模不可行的 $n$（$n>1+B+B^2+\dots+B^D$）在 DP 中保持 $-\infty$，不参与取最大；$n=1$（只有根）恒可行，故返回值总有定义。
- **退化性质**：$D=0$ 时结果恒为 $\big(1/(t_{\text v}+t_{\text d}),\,1\big)$；$A$ 全 $0$ 时所有规模期望都是 $1$，最优为 $\big(1/t_{\text v},\,1\big)$；$B=1$ 且 $A$ 各行同为 $[c]$ 时 $F(n)=\sum_{i=0}^{\min(n-1,D)}c^{i}$。
- 与 `spec-sequoia-optimal-tree`（order 177）的分工：当 $A$ 的各行相同、$D\ge N-1$（深度上限不起约束）、$t_{\text d}=0,\,t_{\text v}=1$ 时，本题的 `ratio` 必须等于 177 的 $T_{\max}[N]$。
