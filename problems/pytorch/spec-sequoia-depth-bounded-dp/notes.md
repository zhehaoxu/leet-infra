# 详解：Sequoia 深度受限最优草稿树 DP

## 出处
Chen et al., *Sequoia: Faster Lossless Large Language Model Acceleration via Dynamic Speculative Decoding*（arXiv:2402.12374，官方实现 [Infini-AI-Lab/Sequoia](https://github.com/Infini-AI-Lab/Sequoia)）。题面的三层扩展分别对应：
- **期望口径**：论文 §3.2 的 position-dependent acceptance —— 树上节点 $v$ 被计入期望的概率等于根到 $v$ 路径上每一步接受率的乘积，一次迭代的期望产出 $F(\mathcal T)=\sum_{v\in\mathcal T}f(v)$（含 target 自己那一个 token，故 $f(\text{root})=1$）。
- **深度受限 DP**：论文附录 C.2.2 的 bounded-depth DP，在 Algorithm 1 的 $T[n,b]$ 之上再加一维深度。
- **代价目标**：论文 §3.3.1 式 (1) 的 speedup $=G(n,d)/(t(n)+d\,c)$，本题把与树大小相关的验证代价取成常数 $t_{\text v}$、草稿代价取成逐节点线性 $n\,t_{\text d}$，于是只需枚举规模 $n$。
- **按深度索引的二维接受率**：论文的 self-speculative decoding（同一个模型用前几层当 draft）里，越深的投机位置用的层数越多、接受率不再是「第几个孩子」的纯函数，必须用 $A[d][b]$ 表达。

## 核心：为什么必须把绝对深度放进状态
Algorithm 1（177 题）能只用 $T[n,b]$ 两维，是因为它假设一棵子树的期望与其挂在树里的高度无关：接受率只跟「我是父亲的第几个孩子」有关，于是任意子树都同构，$T_{\max}[m]$ 可以复用。一旦接受率变成 $A[d][b]$，**同样规模 $m$ 的子树挂在深度 1 和挂在深度 3 的期望完全不同**（路径上逐层的接受率不同），平移不变性消失。因此状态取
$$T[n,b,d]=\text{「根在绝对深度 } d\text{、恰有 }b\text{ 个孩子、规模恰为 }n\text{、全树深度}\le D\text{」的最大 }F.$$
转移沿用 Sequoia 的「剥最后一个孩子」技巧：把根的第 $b$ 个孩子连同它的 $m$ 个节点整棵子树拆出去，剩下的 $b-1$ 个孩子仍是同一根的孩子（所以仍在深度 $d$，用 $T[n-m,b-1,d]$）；而拆出去的那棵子树根在第 $b$ 个孩子处，绝对深度是 $d+1$，它本身要被接受才计入（乘 $A[d][b-1]$），其内部后代的接受率整体下移一层（用 $T_{\max}[m,d+1]$）。
两个易错点：**(1)** 若错误地写成 $T_{\max}[m,d]$ 或 $T[n-m,b-1,d+1]$，就把「哪一维跟着下移」搞反了，深度上限永远不生效；**(2)** base 是 $T[1,0,d]=1$ **对每个 $d$ 都成立**（一棵只含根的子树在任何深度都合法），只在 $T[1][0][0]$ 置 1 会让所有 $n\ge2$ 变成不可行。

## 深度上限如何把可行域切断
出度 $\le B$、深度 $\le D$ 的树最多有 $1+B+B^2+\dots+B^D$ 个节点，规模超过它的 $n$ 在 DP 里应保持 $-\infty$，绝不能参与取最大；否则 $F(n)$ 会被 $-\infty$ 与 $0$ 混淆，目标值直接飞掉。判题里 $D=1,\,B=2,\,N=4$ 时最优规模只能到 $3$，$D=0$ 时只剩根，这两条是探针。反过来 $D\ge N-1$ 时深度上限形同虚设，若 $A$ 的各行还相同，本题就退回 177 的 $T_{\max}[N]$——这正是本题与 177 的**分工边界**：177 无深度维、无代价、接受率一维；本题三者皆有。

## 代价目标为什么仍然可 DP
$F(n)/(t_{\text v}+n\,t_{\text d})$ 对 $n$ **不是**可加的，不能塞进 DP 的转移里。正确姿势是先 DP 出每个规模的 $F(n)$（分子），最后再对 $1\le n\le N$ 枚举一次取最大比值（分母只依赖 $n$）。这也解释了为什么返回值要带 $n_{\star}$：光有比值看不出预算该怎么花。并列时取最小 $n$ 是纯粹的去歧义约定（$t_{\text d}=0$ 且 $A$ 全 $0$ 时所有规模比值相同，必须定序）。

## 数值与实现坑
- $A$ 是 float32 张量，`A.tolist()` 后按 Python float 递推；$-\infty$ 用 `float("-inf")` 哨兵，比较时用 `== NEG` 而不是 `<=` 阈值，避免 $-\infty$ 参与乘法产生 `nan`（$-\infty\times 0$ 会炸）。
- 判题用相对容差 `1e-6*max(1,|b|)`：DP 与暴力枚举对同一棵树是**不同的加法顺序**，但被选中的两棵树即使不同、其目标值也必相等，容差足够。
- 复杂度 $O(N^2 B D)$ 时间、$O(NBD)$ 空间，$N\le32,B\le8,D\le31$ 时毫秒级；DP 的枚举对象是「规模 × 首分支数 × 深度」，与树的个数无关，这正是 DP 相对暴力枚举的优势。

## 对拍口径
参考解是自底向上的三维 DP。判题 `_oracle` 走完全另一条路：**递归枚举**所有出度 $\le B$、绝对深度 $\le D$、规模 $\le N$ 的有序树（表示成「孩子子树」的嵌套元组），对每一棵树用显式栈沿根到各节点的路径逐层乘 $A[\text{深度}-1][\text{序号}-1]$ 求 $F$，再直接对每棵树算 $F/(t_{\text v}+t_{\text d}|\mathcal T|)$ 取最大（并列取最小规模）。两侧都没有共享子问题，一条是 DP 状态转移、一条是结构枚举 + 路径累乘。另外用闭式与退化族做交叉验证：$B=1$ 且各行同为 $[c]$ 时 $F(n)=\sum_{i\le\min(n-1,D)}c^i$（几何和）、$A$ 全 $0$、$D=0$、$A$ 全 $1$（此时最优规模是最大可行规模 $1+B+\dots+B^D$ 与 $N$ 的较小者）、以及「$A$ 各行相同 + $D\ge N-1$ + $t_{\text d}=0$」必须复现 177 的 $T_{\max}[N]$。
