# Sigmoid

## 题目描述

实现逐元素 Sigmoid 激活函数，把任意实数压缩到 $(0, 1)$ 区间：

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

朴素写法在 $x$ 为大负数时 `exp(-x)` 会上溢为 `inf`。数值稳定的经典做法是按符号分支：

- $x \ge 0$：$\sigma(x) = \frac{1}{1 + e^{-x}}$（指数参数为负，不会上溢）
- $x < 0$：$\sigma(x) = \frac{e^{x}}{1 + e^{x}}$（同样让指数参数为负）

## 规则

- 实现 `solve(x: torch.Tensor) -> torch.Tensor`，返回逐元素 sigmoid。
- 必须使用上面的**按符号分支稳定写法**：任意输入下中间计算不得产生 `inf`/`NaN`。
- 输出形状、dtype 与输入一致；向量化实现。

## 示例

```
输入：[-2.0, 0.0, 2.0]
输出：[0.11920, 0.5, 0.88080]
```

## 约束

- 输入为 float32 或 float64 张量，任意形状
- 元素范围可能达到 ±800（远超 `exp` 在 float32 下的安全区）
