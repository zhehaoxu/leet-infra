# 评测：shingle 污染审计

## 题目描述

训练一个语言模型之前，先要回答一个尴尬的问题：评测集里的内容，是不是早就混进了训练语料？一旦污染，测试分数就虚高——模型不是"学会推理"，而是"背过答案"。shingle 污染审计用一张可复现的重叠矩阵来回答它：把每篇文档切成**连续 n-gram 的集合**（shingling，思路源自文档近似重复检测，Broder 1997），再逐对衡量"这篇评测文档的 shingle 有多大比例出现在某篇训练文档里"。

关键在于用哪个比值。Jaccard \(\frac{|A\cap B|}{|A\cup B|}\) 是对称的，一旦训练文档很长（真实语料动辄上万 token），并集被训练侧的巨大集合撑爆，哪怕评测文档被**逐字包含**也只剩一个贴近 0 的小数。包含率（containment）\(\frac{|A_i\cap B_j|}{|A_i|}\) 把分母固定钉在**评测侧**：它问的是"这篇评测文档被那篇训练文档覆盖了多少比例"，不受训练文档长度稀释——这正是 LLM 泄漏审计普遍用 n-gram 包含率、而不是 Jaccard 来判重叠的原因。本题两个矩阵都算，并据此标记命中的评测文档。为了让判题确定、绕开分词差异，输入已是切好的 token id 序列，全程不碰任何分词器或去重库。

## 规则

- `eval_docs`：`list[list[int]]`，\(M_{\text{eval}}\) 篇待审计的评测文档，每篇是一串非负整数 token id（已切好，不用分词器）。
- `train_docs`：`list[list[int]]`，\(M_{\text{train}}\) 篇训练语料文档，同种形式。
- `n`：正整数，shingle 长度（连续 id 窗口）。
- `threshold`：浮点数，命中阈值。

**shingle 集合**：一篇文档 \(d\) 的 shingle 集 \(S(d)\) 由它所有**连续 \(n\) 个 id**（重叠窗口）构成的整体**去重**后得到——同一个 \(n\)-gram 出现多次只算一次。若 \(|d| < n\)，一个窗口都取不出，\(S(d) = \varnothing\)。记评测文档 \(i\) 的集合为 \(A_i = S(\text{eval\_docs}[i])\)，训练文档 \(j\) 的为 \(B_j = S(\text{train\_docs}[j])\)。

对每一对 \((i, j)\)（\(0 \le i < M_{\text{eval}},\ 0 \le j < M_{\text{train}}\)）：

- **包含率**（分母在评测侧，非对称）：
  \[ \text{contam}[i,j] = \frac{|A_i \cap B_j|}{|A_i|} \]
- **Jaccard**（对称，分母是并集）：
  \[ \text{jac}[i,j] = \frac{|A_i \cap B_j|}{|A_i \cup B_j|}, \qquad |A_i \cup B_j| = |A_i| + |B_j| - |A_i \cap B_j| \]
- **空集哨兵**：\(|A_i| = 0\) 时该整行都记 \(0.0\)（\(0/0\) 不会出现），并集为空也记 \(0.0\)。因此任一评测文档短于 \(n\)，它对应的 contam 行与 jac 行全为 0。

**命中判定 `flagged`**：一个**升序**的评测文档下标列表，第 \(i\) 篇入选当且仅当三条同时成立——

1. \(|A_i| > 0\)（shingle 集非空）；
2. 训练集非空（\(M_{\text{train}} > 0\)）；
3. \(\max_j \text{contam}[i,j] \ge \text{threshold}\)（**取到等号也算命中**）。

**返回**三元组 `(contam, jac, flagged)`：`contam` 与 `jac` 都是形状 \((M_{\text{eval}}, M_{\text{train}})\) 的 float32 张量，`flagged` 是一个 int64 张量。任一侧语料为空时矩阵形状相应退化成 \((M_{\text{eval}}, 0)\)、\((0, M_{\text{train}})\) 或 \((0, 0)\)，`flagged` 为空。

**禁止**使用任何现成的去重 / 近似重复 / 文本相似度库；shingle 集合必须由手写窗口与集合运算得到。

## 示例

```
eval_docs = [
    [1, 2, 3, 6, 4],       # e0 -> A0 = {(1,2,3),(2,3,6),(3,6,4)},            |A0| = 3
    [1, 5, 3, 6, 4],       # e1 -> A1 = {(1,5,3),(5,3,6),(3,6,4)},            |A1| = 3
    [1, 2],                # e2 -> 长度 2 < n=3, A2 = 空集
]
train_docs = [
    [1, 2, 3, 6, 4],            # t0 -> B0 = {(1,2,3),(2,3,6),(3,6,4)},                                          |B0| = 3
    [1, 2, 3, 6, 4, 7, 8, 9],   # t1 -> {(1,2,3),(2,3,6),(3,6,4),(6,4,7),(4,7,8),(7,8,9)},                       |B1| = 6
    [1, 5, 3, 6, 4, 2, 9],      # t2 -> {(1,5,3),(5,3,6),(3,6,4),(6,4,2),(4,2,9)},                               |B2| = 5
]
n = 3,  threshold = 0.6

包含率 contam（分母 |A_i| 恒在评测侧，逐对数交集再除以评测集合大小）：
  e0: |A0∩B0|=3 -> 3/3=1.0   |A0∩B1|=3 -> 3/3=1.0   |A0∩B2|=1 -> 1/3=0.3333333
  e1: |A1∩B0|=1 -> 1/3       |A1∩B1|=1 -> 1/3       |A1∩B2|=3 -> 3/3=1.0
  e2: |A2|=0 -> 整行 0.0, 0.0, 0.0
contam = [[1.0,        1.0,        0.3333333],
          [0.3333333,  0.3333333,  1.0],
          [0.0,        0.0,        0.0]]

Jaccard jac（分母 |A_i ∪ B_j| = |A_i| + |B_j| - |A_i∩B_j|）：
  e0: 交3并3 -> 1.0   交3并6 -> 0.5   交1并7 -> 0.14285715
  e1: 交1并5 -> 0.2   交1并8 -> 0.125 交3并5 -> 0.6
  e2: 全 0.0
jac = [[1.0,   0.5,   0.14285715],
       [0.2,   0.125, 0.6],
       [0.0,   0.0,   0.0]]

flagged（取每行 max_j contam >= 0.6；空集 e2 永不入选）：
  e0 max=1.0 ✓    e1 max=1.0 ✓    e2 跳过
flagged = [0, 1]
```

留意 e0 对 t1 这一格：包含率是 \(1.0\)（评测文档的三个 shingle 全被更长的 t1 覆盖），Jaccard 只有 \(0.5\)（并集被 t1 多出的三个 shingle 撑到 6）。同一个"逐字命中"，两个指标差一倍——这就是分母钉在评测侧还是钉在并集上的口径之差。

## 约束

- 判题环境：仅 CPU；`torch` / `numpy` 离线可用，无网络；`nltk`、MinHash/LSH、`datasketch`、`text-dedup` 等现成去重/相似库**一律禁止**（环境里也不存在），shingle 集合必须手写。
- token id 为非负整数，本题**只比较相等**、不做任何词表映射；\(n \ge 1\)。
- \(0 \le \text{contam} \le 1\)、\(0 \le \text{jac} \le 1\)，且逐元素成立 \(\text{jac}[i,j] \le \text{contam}[i,j]\)（因 \(|A_i \cup B_j| \ge |A_i|\)）。
- **退化性质**：
  - 评测文档短于 \(n\) ⇒ \(A_i = \varnothing\) ⇒ 该行 contam、jac 全 0，即使 `threshold = 0` 也不进 `flagged`。
  - 训练侧为空 ⇒ 矩阵形状 \((M_{\text{eval}}, 0)\)、`flagged` 空（即使 `threshold = 0`）；评测侧为空同理 \((0, M_{\text{train}})\)。
  - 评测集与训练集逐篇相同 ⇒ 对角线 contam = jac = 1，`threshold = 1.0` 时命中（边界含等号）。
  - 词表完全不相交 ⇒ 两矩阵全 0；`threshold > 0` 无人命中、`threshold = 0` 全员命中（空集行除外）。
  - 集合口径 ⇒ 包含率恒 \(\le 1\)：重复 n-gram 只算一次，\([1,1,1]\) 在 \(n=2\) 下只有 \(\{(1,1)\}\)。
  - `threshold > 1` ⇒ `flagged` 必为空（包含率上界为 1）。
