# 检测：旋转框 NMS 与交叠面积

## 题目描述

航拍、遥感、场景文字这类目标没有「水平」可言：一艘斜停的船、一排倾斜的货架、一条弯曲的文本行，用轴对齐矩形（AABB）框住会带进大量背景。工业界的做法是直接回归**旋转框** \( (c_x,c_y,w,h,\theta) \)，再用旋转 IoU 做抑制。轴对齐的 NMS 在这里会失效：两艘沿对角线并排的船，AABB 可能重叠 0.6，而真实旋转框的交叠只有 0.05——按 AABB 抑制就会把正确的检测删掉。

旋转 IoU 没有闭式解：两个可以任意旋转的矩形，交集是一个最多八条边的凸多边形，必须**算几何**。本题要求从中心/宽高/角度构造四角，用多边形裁剪（Sutherland–Hodgman）求交集、鞋带公式求面积，得到完整的 \(N\times N\) IoU 矩阵，再按（分数降序，同分取小下标）做贪心 NMS。三处容易错：

- **角点顺序与旋转方向**：裁剪要求裁剪多边形是逆时针的，方向搞反会让「内侧」判断全部翻转；
- **阈值严格性**：IoU 恰好等于阈值时应当保留，只有严格大于才抑制；
- **比较对象**：一个框要与**所有已保留框**比较，而不是只与上一个。

CPU、纯确定性、无随机数。

## 规则

完整签名、参数含义与默认值只写在 starter 的 docstring 里，那是唯一判题口径。

- 每个框是 \( (c_x,c_y,w,h,\theta) \)：中心、宽、高、**逆时针**弧度角。四角在中心坐标系里的偏置依次为 \( (+w/2,-h/2) \)、\( (+w/2,+h/2) \)、\( (-w/2,+h/2) \)、\( (-w/2,-h/2) \)（逆时针），再整体旋转 \( \theta \) 并平移。要求 \(w>0\)、\(h>0\)，\(N\) 可以为 0。
- IoU：交集面积用 Sutherland–Hodgman 把 A 的四边形按 B 的四条边裁剪得到，面积用鞋带公式；并集 \( =|A|+|B|-|A\cap B| \)，IoU \( = \) 交集 / 并集。所有几何在 float64 中计算。
- 返回完整的 \( (N,N) \) float64 IoU 矩阵：对角为 1，对称，元素在 \( [0,1] \) 内；它与 NMS 的结果无关，总是全量返回（矩阵本身也是判题对象）。
- NMS：按（分数降序，同分取原始下标升序）依次处理；框 \(i\) 被保留当且仅当对所有**已保留**框 \(k\) 都有 \( \mathrm{IoU}(i,k)\le \text{thr} \)。严格大于才抑制，因此 IoU 恰等于阈值时保留；被抑制的框不再参与后续比较。
- 返回 `(keep, keep_mask, iou_matrix)`：`keep` 是 \( (K,) \) int64、按处理顺序（分数降序）排列的原始下标；`keep_mask` 是 \( (N,) \) bool，置 True 的位置与 `keep` 相同；`iou_matrix` 是 \( (N,N) \) float64。\(N=0\) 时分别为 \( (0,) \)、\( (0,) \)、\( (0,0) \)。
- 非法输入一律抛 `ValueError`：不是张量、框不是 \( (N,5) \)、分数不是一维或长度不符、dtype 不是 float32/float64 或两者不一致、\(w\le0\) 或 \(h\le0\)、出现 NaN/Inf、`iou_thr` 不在 \( [0,1] \) 内。

## 示例

三个框，分数 \( [0.9,0.8,0.7] \)，阈值 0.5：

```
A = (0, 0, 2, 2, 0)          轴对齐 2x2 正方形，中心在原点
B = (0, 0, 2, 2, pi/4)       同一个正方形绕中心逆时针转 45°
C = (10, 10, 2, 2, 0)        远处，与 A、B 都不相交
```

A 与 B 的交集是一个正八边形。把 B 看成菱形 \( |x+y|\le\sqrt2,\ |x-y|\le\sqrt2 \)（边长 2 时顶点在 \( (\pm\sqrt2,0),(0,\pm\sqrt2) \)）。它与 \( [-1,1]^2 \) 的差别只是四个角 \( (\pm1,\pm1) \) 被切掉：以角 \( (1,1) \) 为例，切线 \( x+y=\sqrt2 \) 与 \( x=1 \)、\( y=1 \) 相交于 \( (1,\sqrt2-1) \) 与 \( (\sqrt2-1,1) \)，切掉的等腰直角三角形直角边长 \( 2-\sqrt2 \)，面积 \( \tfrac12(2-\sqrt2)^2 \)。于是

\[
|A\cap B| = 4-4\cdot\tfrac12\,(2-\sqrt2)^2 = 8(\sqrt2-1)\approx 3.313708 ,
\]

并集 \( =4+4-3.313708=16-8\sqrt2\approx 4.686292 \)，于是

\[
\mathrm{IoU}(A,B)=\frac{8(\sqrt2-1)}{16-8\sqrt2}=\frac{\sqrt2-1}{2-\sqrt2}=\frac{1}{\sqrt2}\approx 0.707107 .
\]

```
IoU(A, B) = 0.7071067811865476   (实测，= 1/sqrt(2))
IoU(A, C) = 0
IoU(B, C) = 0
```

NMS：A（0.9）保留；B（0.8）与 A 的 IoU 0.7071 > 0.5，抑制；C（0.7）与 A 的 IoU 0，保留。

```
keep      = [0, 2]
keep_mask = [True, False, True]
```

注意对角线为 1（自比较），矩阵对称；把阈值换成 0.71，B 的 0.7071 不再大于阈值，`keep` 会变成 `[0, 1, 2]`——这正是「严格大于才抑制」的判别点。

## 约束

- 返回 `(keep, keep_mask, iou_matrix)`；矩阵与框的输入 dtype 无关，恒为 float64；`keep` 为 int64、`keep_mask` 为 bool。
- 判题对矩阵用绝对容差 \( 10^{-9} \)（float64 输入）或 \( 10^{-6} \)（float32 输入）；对 `keep`/`keep_mask` 用 `torch.equal`。
- 角点顺序、逆时针角度、交集裁剪、并集口径、阈值严格性、同分取小下标、「与所有已保留框比较」、矩阵对角与对称性都是判题的一部分。
- CPU、确定性、不调用随机数；\(N=0\)、互斥框、完全重合框、非轴对齐角度都必须按上述约定返回而不是抛错。
