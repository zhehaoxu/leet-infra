# 解题说明 · 级联残差

## 残差的物理含义

`rem` 是「target 还想说、但还没有任何 draft 说出口的那部分概率质量」。第 1 级的 rem 就是 \(p\) 本身；每级只能拿走自己与 rem 重叠的部分 \(\min(q_l, rem)\)，拿走要立刻扣减。走完所有级后剩下的 rem 没有任何 draft 覆盖，只能交回 target。

这条规则把「多级 draft 相互重叠」这件事一次性处理干净：无论 L 个 draft 多相似，前一级吃掉的质量绝不会被后一级重复计算，`Σ accepted_mass ≤ 1` 恒成立。

## 为什么是按级 min 而不是按级乘积

有人会把多级 draft 想成「独立的多重验证」：都以某个概率通过，于是用连乘。但推测解码的实际语义是**串行填坑**——同一位置只会输出一个 token，第 1 级已经解释了 0.8 的质量，第 2 级只能争剩下的 0.2。所以是逐级取小后累加，不是概率连乘。

## 回退方式决定了是否有偏差

- **按 \(p\) 重采**（本题）：`out = Σacc + |rem|·p`。残余质量是按 \(p\) 的比例重新分配的，而命中质量已经全部计入，所以 draft 覆盖得好的 token 会被额外抬高（\(p(x)\) 变成 \((1+|rem|)p(x)\)），覆盖不到的 token 只拿到 \(|rem|p(x)\)——分布整体往「draft 押得准的位置」倾斜。
- **按残差重采**：`out = Σacc + rem/|rem| · |rem| = Σacc + rem ≡ p`。这是严格的拒绝采样，分布严格保持，代价是要在残差上做一次归一化后的采样。

本题输出前者的 out，是为了让「偏差」这件事可被计算与观察：只要 `target_mass > 0`，`out` 就不等于 \(p\)。

## 级序的影响

逐 token 看，命中质量等于 \(\min(p(x), \sum_l q_l(x))\)——逐级取小等价于一次性截断，所以 `out` 与级序无关。但每级拿到的功劳分配完全由顺序决定：同一组 draft，先跑覆盖广的那一级，后面的级就只能捡漏。工程上这意味着「级序应按命中率/成本排序」，把便宜又准的 draft 放前面。

## 边界

- \(L=0\)：`out = p`、`accepted_mass` 为空、`target_mass = 1`——退回纯 target 采样。
- 某级 \(q_l = p\)：该级吃满 1，后续所有级贡献 0。
- 所有行归一化是硬约束：不归一的分布会让 `min` 失去「质量」语义，必须报错而不是默默接受。
