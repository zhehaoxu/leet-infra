# 推测解码：多 draft 级联的残差逐级补齐

## 题目描述

单个 draft 的拒绝采样只解决「一位」的正确性。多 draft 场景（Medusa-2 的 sequential 模式、MTP 的多级草稿）里，同一个位置上可能有 L 个不同来源的提议分布 \(q_1,\dots,q_L\)，它们的质量会大量重叠——同一个高概率 token 被 L 个 draft 同时押中。如果每级都独立地按 \(\min(1, p/q)\) 算接受概率，重叠部分就被重复计入，总接受质量会超过 1。

正确的记账方式是**残差逐级补齐**：维护一个「还没被解释的 target 质量」向量 `rem`，初始为 \(p\)。每级 draft 只能贡献它和 `rem` 的重叠部分：

\[
\text{acc}_l = \min(q_l,\ \text{rem}),\qquad \text{rem} \leftarrow \text{rem} - \text{acc}_l
\]

前一级已经吃掉的 token 质量，后一级拿不到。走完 L 级后，`rem` 的总量 \(|rem|\) 就是「所有 draft 都覆盖不到」的概率——这部分只能退回 target 模型重新采样：

\[
\text{out} = \sum_{l} \text{acc}_l + |\text{rem}| \cdot p
\]

这个式子暴露了一个容易忽略的**偏差**：退回 target 时是按 \(p\) 的比例分配残余质量，而不是按残差 \(rem/|rem|\) 分配。真正的拒绝采样用后者，于是 \(\sum\text{acc}_l + \text{rem} \equiv p\)，分布严格保持；按 \(p\) 分配则让「draft 覆盖到的 token」额外被抬高、覆盖不到的被压缩，采样分布整体偏向 draft 押得准的位置。本题输出前者，正是为了让这个偏差可被看见。

## 任务

实现 `solve(p, qs)`：

- 输入：`p`（`(T,)` float32，target 分布，归一化）；`qs`（`(L,T)` float32，第 \(l\) 行是第 \(l\) 级 draft 的分布，每行归一化，\(L\ge 0\)）。
- 输出：
  - `out`（`(T,)` float32）：`Σ acc_l + |rem|·p`；
  - `accepted_mass`（`(L,)` float32）：每级贡献的总质量 \(|\text{acc}_l|\)；
  - `target_mass`（float32 标量）：\(|rem|\)，退回 target 的概率。
- 所有量内部用 float64 计算后转 float32。
- `p`/`qs` 含负值、`p` 或某一行 `qs` 未归一化（容差 \(10^{-5}\)）、词表大小不一致、维度不对，抛 `ValueError`。

## 示例

```
p  = [0.5, 0.3, 0.2]
q1 = [0.5, 0.5, 0.0]
q2 = [0.0, 0.0, 1.0]

第 1 级：acc1 = min(q1, p)      = [0.5, 0.3, 0.0]   质量 0.8
         rem  = p - acc1        = [0.0, 0.0, 0.2]
第 2 级：acc2 = min(q2, rem)    = [0.0, 0.0, 0.2]   质量 0.2
         rem  = rem - acc2      = [0.0, 0.0, 0.0]

out          = acc1 + acc2 + 0 * p = [0.5, 0.3, 0.2]   (= p，覆盖完整)
accepted_mass= [0.8, 0.2]
target_mass  = 0.0
```

两级恰好互补：q1 覆盖前两个 token，q2 只补它漏掉的第三个。注意 q2 若也押第一个 token，那部分质量在第二级是**拿不到**的（rem 已经是 0）。

## 约束

- **每级必须扣减 rem**：写成 `sum(min(q_l, p))` 会重复计入重叠质量，总接受质量可以超过 1。
- **叠加的是 min 而不是乘积**：多级 draft 不是「同时接受」，而是「依次填坑」，所以是 per-token 的取小累加。
- **`out` 与级序无关**：逐 token 看，命中质量等于 `min(p(x), Σ_l q_l(x))`（逐级取小等价于一次性截断），所以 `out` 只取决于 Σq，不依赖顺序；但 `accepted_mass` 强烈依赖顺序——同一个多级集合，谁先谁后决定了功劳归属。
- **回退用 \(p\) 而不是残差**：这是本题的偏差点，也是与严格拒绝采样的分界线；写残差会得到 `out ≡ p`，所有用例都会「看起来更对」但语义已变。
- 校验归一化时留 \(10^{-5}\) 容差：上游 softmax 之后常有 1e-7 量级的漂移，把容差设成严格相等会让合法输入被判错。
