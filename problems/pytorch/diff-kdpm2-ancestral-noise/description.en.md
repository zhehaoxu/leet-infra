## Problem

Deterministic KDPM2 (problem 754) spreads DPM-Solver-2 across an interleaved sigma table without adding noise; the ancestral variant (`KDPM2AncestralDiscreteScheduler`) keeps the same two-call skeleton but does three things: (1) the midpoint is not interpolated between sigma and sigma_next but between sigma and **sigma_down**; (2) the second call's dt changes from the full step `sigma_next - sigma` to **`sigma_down - sigma`**; (3) after landing, `noise * sigma_up` is **injected** into prev. Since sigma_up^2 + sigma_down^2 = sigma_next^2, the ancestral semantics is exactly a split of the deterministic step into the deterministic part sigma -> sigma_down plus a noise part sigma_up whose magnitude is set by the sigma ratio.

Judge inputs:

- `model_output` / `sample`: same-shape float tensors (the second call's `sample` is the **midpoint sample**);
- `sigmas`: 1-D float tensor, the **unexpanded** base table `[s0, ..., s_{N-1}, 0]` (length N+1, N >= 2), finite, non-negative, non-increasing, first N > 0 and the last exactly 0;
- `step_index`: current index;
- `state`: `None` = first call; `{"sample"}` = second call (pass back the first call's return value);
- `noise`: **required on the second call** (generated by a generator upstream; an explicit input here), same shape as `model_output`; ignored on the first call;
- `prediction_type` in {`epsilon`, `v_prediction`}.

## Rules

**Auxiliary table construction** (recomputed per call, verbatim from upstream `set_timesteps`):

- `s_next = roll(-1)` (with `s_next[N] = 0`);
- `up[k] = sqrt( s_next[k]^2 * (s[k]^2 - s_next[k]^2) / s[k]^2 )` — at k=N this is 0/0 = **nan** (same as upstream; the slot is never read);
- `down[k] = sqrt( s_next[k]^2 - up[k]^2 )`, then **force `down[N] = 0`** (clears the nan at k=N);
- `interpol[k] = exp( lerp(log s[k], log down[k], 0.5) )`, then **force `interpol[N-1] = interpol[N] = 0`** — on the torch path `lerp(finite, -inf, 0.5)` is measured to be **nan** (not -inf!), so both k=N-1 (`down[N-1]=0 -> log = -inf`) and k=N (both ends -inf) are nan, and upstream's `[-2:] = 0.0` clearing must cover both slots;
- math identities: `down[k] = s_next[k]^2 / s[k]` and `sqrt(s[k] * down[k]) = s_next[k]` — the interpol table equals sigma_next elementwise in exact math, so the explicit construction is redundant upstream (see notes for the cancellation discussion);
- four expanded tables (length **2N+2**, head 1 + repeat_interleave(2) + tail 1): `sigE / sigIE / sigUp / sigDown`. **Unlike problem 754**: the ancestral interpol table has no `[0, ...]` dead head — `interpol[0] = sqrt(s0 * down0)` is itself the midpoint of logical step 0.

**Index structure**: logical step j (0 <= j <= N-1) occupies indices 2j (first call) and 2j+1 (second call); the **last logical step has only the first call** (second calls limited to i <= 2N-3). First and second calls read the **same slot**: `sigIE[2j] = interpol[j]`.

**First call** (`state is None`, i even, 0 <= i <= 2N-2):

- `s = sigE[i]` (sigma_hat = s*(gamma+1), gamma = 0 so identical), `m = sigIE[i]`;
- `x0 = pred(sample, mo, s)`; `derivative = (sample - x0)/s` (denominator is s);
- `dt = m - s` (half-step to the midpoint); `prev = sample + derivative*dt`;
- `state = {"sample": sample}` — stores only the **original sample**; `noise` ignored; returns `sigma_up / sigma_down` as `None`. Upstream also fetches `sigmas_up[i]` and `sigmas_down[i-1]` in the first-call branch but never reads them (dead assignments; at i=0 `down[-1]` wraps around without raising).

**Second call** (state is a dict with only `sample`, i odd, 1 <= i <= 2N-3):

- `s = sigE[i-1]`, `m = sigIE[i-1]`, `u = sigUp[i-1]`, `d = sigDown[i-1]`;
- `x0 = pred(sample, mo, m)`; `derivative = (sample - x0)/m` (denominator is the **midpoint**);
- `dt = d - s` — **not the full step**: the noise consumes the up part;
- `prev = state["sample"] + derivative*dt + noise*u` — departs from the **stored sample** and injects noise; `state = None`; the first-call derivative is discarded.

**prediction_type** (sigma_input is s on the first call, m on the second):

- `epsilon`: `x0 = sample - sigma_input * mo`;
- `v_prediction`: `x0 = mo * (-sigma_input/sqrt(sigma_input^2+1)) + sample/(sigma_input^2+1)`.

Last logical step j=N-1: s_next = 0, so up = down = interpol = 0; it lands straight on x0 with **no noise**.

Returns a dict: `prev_sample` / `pred_original_sample` (float32), `state` (dict or None), `derivative` (float32), `dt` (float), `sigma_up` / `sigma_down` (floats on the second call, None on the first). Validation failures raise `ValueError`.

## Example

```
input : sigmas = [4, 1, 0], first call mo = 0.3, sample = 2.0, i = 0
output: down0 = 1^2/4 = 0.25, interpol[0] = sqrt(4*0.25) = 1.0
        x0 = 2 - 4*0.3 = 0.8, derivative = (2 - 0.8)/4 = 0.3
        dt = 1.0 - 4 = -3.0, prev = 2 + 0.3*(-3) = 1.1
        state = {"sample": 2.0}, sigma_up / sigma_down = None

input : second call mo = -0.5, sample = 1.1 (midpoint), noise = 1.5, i = 1
output: up0 = sqrt(1*(16-1)/16) = sqrt(0.9375), down0 = 0.25
        x0 = 1.1 - 1.0*(-0.5) = 1.6, derivative = (1.1 - 1.6)/1.0 = -0.5
        dt = 0.25 - 4 = -3.75
        prev = 2.0 + (-0.5)*(-3.75) + 1.5*sqrt(0.9375) = 3.875 + 1.4524 = 5.3274
        state = None, sigma_up = sqrt(0.9375), sigma_down = 0.25
```
