# bfloat16 舍入：位级 RNE、截断与 ties-to-even

## 题目描述

bf16 没有专门的硬件转换指令，它就是 float32 的高 16 位——尾数砍掉 16 位、指数与符号原样保留。所有「把权重塞进 bf16」「梯度以 bf16 all-reduce」「CPU 上模拟混合精度」的实现最终都要回答同一个问题：**丢掉的那 16 位怎么舍**。本题要求在 float32 的位模式上亲手实现三种舍入（就近取偶 rne、向零截断 rz、ties 远离零 rna），结果仍以 float32 返回（fake cast），并保证与硬件转换逐位一致。

## 规则

- 完整签名与参数含义只写在 starter 的 docstring 里，那是唯一判题口径。
- 不许调用 `x.to(torch.bfloat16)` / `x.bfloat16()`，也不许借 numpy 或 struct 做类型转换。
- 设 `u` 是 32 位模式按**无符号**整数读出，\(L=u\,\&\texttt{0xFFFF}\) 是被丢掉的低位，第 16 位（`u >> 16` 的最低位）是保留下来的尾数末位：

```
rz  : (u & 0xFFFF0000)                      -> take the high 16 bits
rne : u + 0x7FFF + ((u >> 16) & 1)           -> then the high 16 bits
rna : u + 0x8000                             -> then the high 16 bits
```

- rne 的含义是：\(L>\texttt{0x8000}\) 进位、\(L=\texttt{0x8000}\)（恰好落在网格中点）时看保留末位是 1 才进位、其余不进位；rna 则是 \(L\ge\texttt{0x8000}\) 一律进位（ties 远离零）。
- 进位顺着尾数溢出到指数位就自然把过大的值推成 ±inf，不需要额外的溢出分支。
- 特殊值：±0 保留符号位；±inf 原样返回；NaN 保留符号位并把保留下来的尾数最高位强制置 1（仍要是 NaN）；已经在网格上的值三种模式都原样返回（幂等）。
- 非 float32 输入、非法 `rounding` 抛 ValueError。

## 示例

`[1,2)` 区间上 bf16 的网格步长是 \(2^{-7}=0.0078125\)，下面四个数**全是**相邻格点的中点：

```
x = [1.00390625, 1.01171875, 1.01953125, 1.02734375]

rne -> [1.0, 1.015625, 1.015625, 1.03125]
rz  -> [1.0, 1.0078125, 1.015625, 1.0234375]
rna -> [1.0078125, 1.015625, 1.0234375, 1.03125]
```

rne 在四个 ties 上一边一偶地来回跳（1.0 与 1.015625 的保留末位是 0，1.0078125 与 1.0234375 的保留末位是 1），这正是「取偶」的锯齿；rz 永远向下，rna 永远向上。float32 的最大值 \(3.4028234663852886\times10^{38}\) 在 rne/rna 下进位溢出成 `inf`，在 rz 下截到 \(3.3895313892515355\times10^{38}\)。

## 约束

- 任意形状的 float32 张量，输出仍是同形状的 float32
- oracle 用真实的 `x.to(torch.bfloat16).to(torch.float32)` 硬件转换做逐位对拍（覆盖正规、次正规、\(10^{38}\)、\(10^{-38}\) 各量级），NaN 位置单独比对
- 通用不等式也会被检查：\(|rz|\le|x|\)、rne 的绝对误差不大于 rz 的绝对误差、\(|rna|\ge|rz|\)，以及 rne 的相对误差上界 \(2^{-8}\)（半格）
