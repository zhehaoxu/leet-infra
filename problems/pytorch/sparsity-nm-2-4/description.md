# 稀疏化：2:4 结构化 N:M 剪枝

## 题目描述

**2:4 结构化稀疏**是 NVIDIA Ampere/Hopper Sparse Tensor Core 原生支持的「半结构化」模式：把权重沿最后一维每 **4 个连续元素分成一组**，每组**只保留绝对值最大的 2 个**、其余置零（「out of every four, two must be zero」）。它兼顾接近非结构化剪枝的精度和硬件可加速的规整内存布局，是当前大模型推理剪枝的高频考点。

## 规则

输入 `weight`（float32，最后一维长度是 4 的倍数）。沿最后一维以步长 4 切组，每组内按绝对值保留最大的 2 个元素（原值与符号不变），其余 2 个置零。并列（组内相同 \(|w|\)）时保留**更靠前的索引**。返回同形状 float32 张量。禁止 `torch.sparse`/cuSPARSELt。

## 示例

`weight=[[1,-5,3,-2, 0.5,-9,2,8]]`（形状 1×8，两组）：

```
组0 [1,-5,3,-2]：|w|=[1,5,3,2]，top-2 = -5, 3 → [0,-5,3,0]
组1 [0.5,-9,2,8]：|w|=[0.5,9,2,8]，top-2 = -9, 8 → [0,-9,0,8]
out = [[0,-5,3,0, 0,-9,0,8]]
```

## 约束

- CPU float32；最后一维可被 4 整除；分组只在最后一维内进行（不同行/不同组互不影响）。
- 每组恰好保留 2 个、剪 2 个，整体稀疏率恒为 50%。
- 与被保留元素的正负无关，只比较绝对值。
