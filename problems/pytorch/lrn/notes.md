# LRN 详解

## 跨通道侧抑制

LRN 的核心思想是「邻近通道会互相抑制」：某个通道在某一空间位置的激活越大，
它周围通道（同一位置、相邻通道）的平方和就把它除下去。公式为

$$ y_{i} = \frac{x_{i}}{\left(k + \dfrac{\alpha}{\text{size}} \sum_{j \in \text{win}(i)} x_{j}^{2}\right)^{\beta}} $$

窗口 $\text{win}(i)$ 沿**通道维**关于 $i$ 对称、宽 `size`；越界通道补零。注意归一化的
「局部」指的是**通道局部**，而非空间局部——对每个 $(h,w)$ 独立沿 $C$ 滑动。

## 与 BN / LN 的谱系关系

- **BatchNorm**：在 batch×空间的统计上做每通道标准化（可学习 $\gamma,\beta$），推理依赖 running stats。
- **LayerNorm**：在特征维（通道等）上做零均值单位方差标准化，与 batch 无关，Transformer 常用。
- **LRN**：既不减均值也不除标准差，只做「除以邻通道平方和的幂」，是一种**无均值中心化**的、
  数据相关的增益抑制。它没有可学习参数，也不需要 batch 统计。

正因 LRN 收益有限、又拖慢训练，LeCun 等后续工作与 AlexNet 之后的网络普遍弃用它，转向 BN。

## 易错点

- **窗口方向**：窗口沿通道维（dim=1），不是空间维；$H,W$ 元素彼此独立。
- **`alpha/size` 而非 `alpha`**：平方和要除以窗口宽度 `size` 再乘 `alpha`，否则与
  `F.local_response_norm` 对不上（这也是本题 dump 参考解特意保留 `/size` 的原因）。
- **边界补零**：首/尾通道的窗口不满 `size`，缺失项按 $0$ 计入平方和（等价零填充），
  不要做周期/复制扩展。
- `size` 用**奇数**才有对称中心；分母里的求和**含自身通道** $x_i^2$。

## 应用与历史

LRN 出自 Krizhevsky 的 AlexNet（2012），用于ReLU大激活的归一化以稳定训练。但 Sainath
等（2012）与后续实证表明其在多数现代架构上增益甚微，BatchNorm（2015）出现后基本退出主流。
今天它主要作为「归一化家族」的教学对照，以及理解侧抑制（lateral inhibition）生物启发起源的样例。
