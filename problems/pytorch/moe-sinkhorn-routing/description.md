# MoE：Sinkhorn 双随机路由与列塌缩

## 任务

实现 `solve`：把一个 batch 的路由 logits 推成近似**双随机**的分配矩阵——每一行（token）在专家上归一化，每一列（专家）的负载被迭代地压向 1。可选地再做一次逐元素平方来锐化分配。

这是 MoE 里「用双随机投影代替辅助损失做负载均衡」的受限数值模型。迭代轮数、交替方向、eps 的位置、平方支路和 NaN 语义都由题面显式规定；它不是任何训练框架的逐步复刻，也不涉及梯度或参数更新。

## 输入

- `logits`：CPU float64 `[T,E]`，两维都非空；允许非连续张量，不修改输入。
- `iters`：真正的 Python `int`，`0 <= iters <= 16`；`bool`、浮点、负数、越界都非法。
- `tau`：正的有限 `int`/`float`，默认 `1.0`；softmax 的温度。
- `square`：真正的 Python `bool`，默认 `False`。
- `eps`：非负的有限 `int`/`float`，默认 `0.0`。
- `T,E = 1..8`。

结构或标量非法时抛出 `ValueError`。

## 精确规则

起始分配是带温度的行 softmax：

$$
R^{(0)}_{ij}=\frac{\exp(z_{ij}/\tau)}{\sum_{j'}\exp(z_{ij'}/\tau)}.
$$

每一轮做两次归一化，**先列后行**，除数一律是「和加 eps」：

$$
C^{(t)}_{j}=\varepsilon+\sum_{i}R^{(t-1)}_{ij},\qquad
R'^{(t)}_{ij}=\frac{R^{(t-1)}_{ij}}{C^{(t)}_{j}},
$$

$$
D^{(t)}_{i}=\varepsilon+\sum_{j}R'^{(t)}_{ij},\qquad
R^{(t)}_{ij}=\frac{R'^{(t)}_{ij}}{D^{(t)}_{i}}.
$$

列归一化沿 token 轴把每个专家的负载拉向 1，行归一化让每个 token 的分配重新和为 1。一轮以行归一化收尾，因此返回矩阵的**行和恒为 1**，列和只是被逼近 1：当 $T\neq E$ 时列和不可能全是 1，因为总质量只有 $T$。

跑满 `iters` 轮后，若 `square=True` 再做一次锐化并重新按行归一化：

$$
Q_{ij}=\frac{\left(R^{(\mathrm{iters})}_{ij}\right)^{2}}{\varepsilon+\sum_{j'}\left(R^{(\mathrm{iters})}_{ij'}\right)^{2}}.
$$

若 `square=False`，则 $Q=R^{(\mathrm{iters})}$。`iters=0` 且 `square=False` 就是普通的行 softmax。

eps 加在**除数**上，不是加在被除数上。`eps > 0` 时一列全零归一化后仍然是 0（$0/(0+\varepsilon)=0$）；`eps = 0` 时归一化一列全零得到 $0/0=$ NaN，并且 NaN 会经由行和扩散到整行。题目要求如实返回 NaN，不做任何掩盖。

## 返回

返回二元 `tuple`：

```text
(Q, col_load)
```

| 项 | 形状 / 类型 | 含义 |
| --- | --- | --- |
| `Q` | float64 `[T,E]` | 归一化之后的分配矩阵 |
| `col_load` | float64 `[E]` | `Q` 的列和，即每个专家在这个 batch 上的实际负载 |

浮点结果按 `rtol=2e-11, atol=2e-11` 比较，`NaN` 视为与 `NaN` 相等。

## 示例

```python
logits = [[0.0, 0.6931471805599453],
          [0.0, 0.6931471805599453]]

solve(logits, 0)
# Q = [[0.333333, 0.666667],       col_load = [0.666667, 1.333333]
#      [0.333333, 0.666667]]

solve(logits, 1)
# Q = [[0.5, 0.5],                 col_load = [1.0, 1.0]
#      [0.5, 0.5]]

solve(logits, 0, 1.0, True)
# Q = [[0.2, 0.8],                 col_load = [0.4, 1.6]
#      [0.2, 0.8]]
```

`exp(0.6931471805599453) = 2`，所以行 softmax 给出 $[1/3,\,2/3]$，两行相同因此列和是 $[2/3,\,4/3]$。一轮列归一化把两列都除以各自的列和，$(1/3)/(2/3)=0.5$、$(2/3)/(4/3)=0.5$，矩阵变成全 $0.5$；此时行和已经是 1，行归一化不再改变任何东西，再多的轮数都是定点。平方支路把 $[1/3,2/3]$ 变成 $[1/9,4/9]$，除以行和 $5/9$ 得到 $[0.2,0.8]$。
