# 解题说明 · 接受率解析账

## 期望吐词的两行式

\(e(\gamma)\) 不需要推导概率树，直接写成前缀乘积的累加：维护一个「前 \(i\) 位全中」的概率 `prod`，每多一位就 `prod *= alpha[i]` 并累加进 \(e\)。基础项 1 是 bonus token——target 在整条草稿的最后一位之后一定会采样一个，这是推测解码永远不亏的那一个 token。

注意「第 \(i\) 项对应前 \(i\) 位全中」：一旦第 \(i\) 位被拒，第 \(i+1\) 位即使碰巧猜对也不算数，因为 token 序列已经分叉了。所以是乘积而不是单个 \(\alpha_i\)。

## 分母是时间，不是步数

\(1 + \gamma c\) 里那个 1 是 target 的一次前向，\(\gamma c\) 是草稿的逐 token 生成成本。两个常见错误：

1. 把草稿成本按一次 forward 计（写成 \(1 + c\)）——会严重高估加速比；
2. 忘记草稿也要自回归（以为 \(c \ll 1\) 可以忽略）——小模型 \(c\) 可能只有 0.05，但在 \(\gamma=10\) 时就占了一半时间。

## 最优 γ 的形状

分子按 \(\prod \alpha_j\) 指数收敛到 \(1/(1-\alpha)\)，分母线性增长，所以 \(s(\gamma)\) 先升后降。\(\alpha\) 大、\(c\) 小时最优点靠后；\(c \ge 1\)（草稿不比 target 便宜）时最好直接不投机。

并列的情况不罕见：\(c = 1\) 且 \(\alpha = 1\) 时每一项都恰好等于 1，此时「不投机」与「投机」等价，约定取最小 \(\gamma\) 才能保证可复现。实现里 `argmax` 天然返回第一个最大值，正好符合约定。

## 边界

- \(\alpha = 0\)：\(e(\gamma)\equiv 1\)，分母一直变大使 \(s\) 单调下降，最优 \(\gamma = 0\)——「永远不接受的草稿没有价值」。
- \(\alpha = 1\)：\(e(\gamma) = 1+\gamma\)，\(s = (1+\gamma)/(1+\gamma c)\)；\(c<1\) 时 \(\gamma\) 拉满，\(c>1\) 时退到 0。
- 逐位接受率可以不同：前面位通常更高，用平均值会低估「短草稿」的相对优势。本题因此按逐位输入，而不是只给一个 \(\alpha\)。
