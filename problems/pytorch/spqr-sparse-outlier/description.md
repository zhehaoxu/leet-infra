# SpQR：稀疏离群权重保留 + 逐行量化

## 题目描述

LLM.int8() 按**整列**豁免离群，粒度太粗——一列里往往只有一两个真正的大权重，其余陪跑回 FP 白白浪费位宽。**SpQR**（Dettmers et al., 2023, [arXiv:2306.03078](https://arxiv.org/abs/2306.03078)）把豁免粒度精细到**单个权重**：只有绝对值超过阈值的极少数元素作为**稀疏矩阵**用高精度（FP16）存，其余稠密部分才做低位宽量化。因为离群元素稀疏（占比很小），用 CSR 之类的稀疏格式存它们开销极低，而稠密主体能被压到 3–4 bit。

## 规则

给定权重 $W$ 形状 $(O, C)$、离群阈值 $\tau$、位宽 `bits`（默认 8）。

1. **离群掩码**（逐元素）：$\text{mask}_{oj}=|W_{oj}|>\tau$。这些位置视作稀疏离群，**原样保留**（等价 FP16 分支不量化）。
2. **稠密主体逐行量化**：对每一行 $o$，取该行**非离群**元素，按 per-row 对称 RTN：
   - 行内 scale $s_o=\max_{j:\neg\text{mask}_{oj}}|W_{oj}|$（该行无非离群元素则跳过）；
   - $q_{max}=2^{bits-1}-1$；
   - $q=\mathrm{clamp}(\mathrm{round}(W_{oj}/s_o\cdot q_{max}),\,-q_{max}-1,\,q_{max})$，反量化 $\hat W_{oj}=\dfrac{q}{q_{max}}s_o$。
3. 离群位置保持原值写回。

返回二元组 `(recon, mask)`，形状分别为 $(O, C)$ 的 float 与 $(O, C)$ 的 bool。

- 与 LLM.int8()（整列 absmax 判定）不同，SpQR 用**逐元素** $|W_{oj}|>\tau$ 判定，粒度更细。
- 量化量程是**逐行**（per-row）而非 per-tensor：每行有各自的 scale，减少行间幅值差异带来的精度损失。

## 示例

```
W = [[0.1, 9.0, 0.2],
     [0.4, 0.5, 8.0]],  tau = 6.0, bits = 8

mask = [[False, True,  False],
        [False, False, True ]]        # 9.0 与 8.0 是离群，原样保留

row0 非离群 {0.1, 0.2}: s=0.2 → 0.1→0.1008, 0.2→0.2
row1 非离群 {0.4, 0.5}: s=0.5 → 0.4→0.4016, 0.5→0.5

recon ≈ [[0.1008, 9.0, 0.2],
         [0.4016, 0.5, 8.0]]
```

## 约束

- CPU float32；`recon` 用 `torch.allclose(atol=1e-4)`、`mask` 用 `torch.equal` 比较。
- 取整就近、`.5` 取偶（与 `torch.round` 一致）。
- 掩码逐元素判定；离群元素不参与所在行的 scale 计算，也不被改动。
