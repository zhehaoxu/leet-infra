# 双线性网格采样（Bilinear Grid Sample）

## 题目描述

`grid_sample` 是「可微分地按任意坐标从图像取值」的通用算子：给一张特征图 `x` 和一个
归一化坐标网格 `grid`，输出在每个网格点处对 `x` 做**双线性插值**得到的值。它是 STN
（Spatial Transformer Network）、可变形卷积（DCN）、图像 warp、跨分辨率特征对齐等
的核心原语——因为它对 `x` 和 `grid` 都可导，能把几何变换接进端到端训练。

## 规则

- 实现 `solve(x, grid)`：`x` 形状 `(N, C, H, W)`，`grid` 形状 `(N, Ho, Wo, 2)`。
- `grid[..., 0]` 是**宽度(x)**方向、`grid[..., 1]` 是**高度(y)**方向的归一化坐标，范围 `[-1, 1]`；
  `(-1,-1)` 对应左上角像素中心，`(1,1)` 对应右下角像素中心。
- 采用 `align_corners=False` 的坐标变换（映射到像素坐标）：
  $$ x_{pix} = 0.5\,(g_x+1)\,W - 0.5,\qquad y_{pix} = 0.5\,(g_y+1)\,H - 0.5 $$
- 对每个输出位置取其四周 4 个整数像素做双线性加权；落在图像外的采样点按 **0 填充**
  （`padding_mode='zeros'`）。
- 输出形状 `(N, C, Ho, Wo)`，逐通道用同一组坐标采样。

## 示例

```
输入：x = [[0, 1, 2],
          [3, 4, 5],
          [6, 7, 8]]   (1,1,3,3)
     grid 四个点(顺序 Ho=2,Wo=2)：(0,0), (-1,-1), (1,1), (0.5,0.5)
输出：[[4.0, 0.0],        # (0,0)→正中心像素 4；(-1,-1)→左上角外越界补 0
       [2.0, 7.0]]        # (1,1)→右下角外，8*0.5*0.5=2；(0.5,0.5)→双线性得 7
```

## 约束

- float32 输入；`grid` 值域 `[-1, 1]`（题面已 clamp）
- 需与 `F.grid_sample(x, grid, mode='bilinear', padding_mode='zeros', align_corners=False)`
  在 `atol=1e-4` 内一致
