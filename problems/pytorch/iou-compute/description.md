# 交并比 IoU（Intersection over Union）

## 题目描述

IoU（又叫 Jaccard 指数）度量两个矩形框的重叠程度：交集面积除以并集面积，范围 $[0,1]$。
它是目标检测/分割的基石——匹配预测框与真值框、NMS 去重重叠框、mAP 判定 TP/FP，全都以
IoU 为准则。请实现逐对 IoU。

## 规则

- 实现 `solve(a, b)`，框采用 $[x_1, y_1, x_2, y_2]$（左上角 + 右下角），形状 `(..., 4)`，可广播。
- 交集宽高：$w=\max(0,\min(x_{2a},x_{2b})-\max(x_{1a},x_{1b}))$（$y$ 同理），负值截 0。
- $\text{IoU} = \dfrac{\text{交集}}{\text{面积}_a + \text{面积}_b - \text{交集}}$；并集为 0 时返回 0。
- 输出形状为去掉最后维后的广播形状。

## 示例

```
输入：a = [0, 0, 2, 2]（面积 4）
     b = [1, 1, 3, 3]（面积 4）
  交集 = [1,1,2,2] → 1×1 = 1；并集 = 4 + 4 - 1 = 7
输出：1/7 ≈ 0.142857
```

## 约束

- float32 输入；坐标满足 $x_2\ge x_1, y_2\ge y_1$（退化零面积框并集为 0 时返回 0）
- 完全重合 → 1；完全不相交 → 0
